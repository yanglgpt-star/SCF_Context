# 家庭大冒险 — 项目整体规划

## 1. 项目概述

### 1.1 产品定位
一款面向 3-8 岁儿童的 **O2O（Online-to-Offline）任务驱动型益智游戏** 微信小程序。通过"线上发布任务 → 线下动手执行 → 回到线上反馈 → 获得奖励"的闭环设计，将日常生活中的认知训练、逻辑培养、感官探索转化为游戏化体验。

### 1.2 核心理念
| 原则 | 说明 |
|------|------|
| **任务闭环** | 每次游戏都是一个完整的"接受→行动→反馈→奖励"循环 |
| **线下为主** | 屏幕时间是引导，动手动脑的线下活动才是核心 |
| **语音驱动** | 学龄前儿童不识字，语音指令是主要交互方式 |
| **家长可控** | 家长可以自定义任务、审核完成情况、管理奖励 |
| **安全第一** | 所有任务必须避开危险区域，启动前有安全宣誓 |

### 1.3 目标用户
- **直接用户**：3-8 岁儿童（操作者）
- **管理用户**：家长（配置者、审核者）

## 2. 技术选型 — 微信云开发

### 2.1 为什么选择微信云开发？

| 需求 | 云开发方案 | 优势 |
|------|-----------|------|
| 数据库 | 云数据库（JSON 文档型） | 无需自建后端，控制台可视化编辑 |
| 文件存储 | 云存储 | 存储任务语音、图片，自带 CDN |
| 用户登录 | 微信开放能力 + 云函数 | 一键获取 openId，免去鉴权开发 |
| 定时任务 | 云函数定时触发器 | 每日刷新任务池、重置签到 |
| NFC 能力 | wx.getNFCAdapter() | 未来拓展 NFC 贴纸验证 |
| 费用 | 按量计费，免费额度充足 | 个人项目几乎零成本 |

### 2.2 技术栈
```
前端：微信小程序原生框架 + WXML / WXSS / JavaScript
后端：微信云开发（Node.js 云函数）
数据库：云数据库 MongoDB
存储：云存储（图片、音频）
工具：微信开发者工具
```

### 2.3 环境规划
- **开发环境**：日常开发调试
- **体验环境**：家庭成员内测
- **生产环境**：正式发布上线

## 4. 页面结构规划

### 4.1 儿童端页面

| 页面 | 功能 |
|------|------|
| **首页 / 冒险入口** | 动画角色打招呼，显示今日状态，"开始冒险"按钮 |
| **任务卡片页** | 显示当前任务：语音朗读 + 图文说明 + 计时器 |
| **任务执行页** | 拍照 / 录音 / 扫码 三种验证方式的入口 |
| **完成反馈页** | 动画庆祝、获得星星、成长进度反馈 |
| **我的成就页** | 勋章墙、虚拟树成长、历史任务记录 |
| **愿望清单页** | 查看已积累星星、兑换愿望 |

### 4.2 家长端页面

| 页面 | 功能 |
|------|------|
| **家长管理首页** | 密码 / 生物识别进入，任务统计概览 |
| **任务管理** | 任务库列表、新增/编辑/上架/下架任务 |
| **审核中心** | 待审核任务列表，播放录音/查看照片，通过/驳回 |
| **愿望管理** | 设定愿望、所需星星数、开启/关闭兑换 |
| **成长报告** | 完成趋势图、类别分布、难度分布 |
| **安全设置** | 安全宣誓内容编辑、危险区域提醒设置 |

### 4.3 公共页面

| 页面 | 功能 |
|------|------|
| **安全宣誓页** | 启动前展示安全规则，家长/孩子共同确认 |
| **加载 / 过渡页** | 角色动画加载，提升等待体验 |

## 6. 云函数规划

| 云函数 | 功能 |
|--------|------|
| `login` | 用户登录，获取 openId，创建/查询用户 |
| `getDailyTask` | 每日随机抽取任务（根据难度和孩子等级） |
| `submitTask` | 提交任务成果（拍照/录音），创建任务记录 |
| `reviewTask` | 家长审核任务，通过则增加星星 |
| `redeemWish` | 兑换愿望，扣除星星 |
| `getStats` | 统计完成情况（趋势图数据） |
| `checkSafety` | 检查安全宣誓是否过期 |
| `addTask` | 家长新增/编辑任务 |

## 7. 奖励成长体系

### 7.1 星星获取规则
| 行为 | 星星 |
|------|------|
| 完成 1 星任务 | +1 |
| 完成 2 星任务 | +2 |
| 完成 3 星任务 | +3 |
| 完成 4 星任务 | +4 |
| 完成 5 星任务 | +5 |
| 连续 7 天完成 | +10 额外 |
| 连续 30 天完成 | +50 额外 |
| 首次完成新类别 | +5 |

### 7.2 虚拟树成长
```
种子（0%）→ 发芽（20%）→ 小苗（40%）→ 小树（60%）→ 开花（80%）→ 结果（100%）
```
每完成一个任务，成长值 +2~5。满 100% 后重置并解锁新区域。

### 7.3 勋章体系
| 勋章 | 条件 |
|------|------|
| 初次冒险 | 完成第 1 个任务 |
| 小侦探 | 完成 10 个任务 |
| 超级英雄 | 完成 50 个任务 |
| 颜色大师 | 完成 5 个颜色形状类任务 |
| 搬运冠军 | 完成 5 个整理类任务 |
| 坚持不懈 | 连续 7 天完成 |
| 铁人勋章 | 连续 30 天完成 |
| 收藏家 | 集齐 4 类任务各完成 3 个 |
