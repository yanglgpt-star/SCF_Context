# 任务类型与内容库设计

---

## 一、任务类型体系

### 四大分类

| 类型 | 英文标识 | 培养能力 | 难度范围 | 适合年龄 |
|------|---------|---------|---------|---------|
| 🎨 颜色/形状侦探 | `color_shape` | 观察力、认知 | ★☆☆~★★★ | 2-6岁 |
| 📦 小小搬运工 | `sorting` | 逻辑思维、空间感 | ★★☆~★★★★ | 3-7岁 |
| 🔊 声音采集家 | `sound` | 听觉敏感度、探索 | ★☆☆~★★☆ | 2-5岁 |
| 🗺️ 藏宝图寻宝 | `treasure` | 空间想象、推理 | ★★★~★★★★★ | 4-8岁 |

## 二、任务内容库（预置 40+ 个任务）

### 🎨 颜色/形状侦探（12 个）

| 难度 | 任务标题 | 验证方式 | 提示 |
|------|---------|---------|------|
| ★☆☆ | 找 1 个红色的物品 | 家长确认 | 苹果、杯子、积木都可以 |
| ★☆☆ | 找 1 个蓝色的物品 | 家长确认 | 看看玩具箱里有没有蓝色小汽车 |
| ★☆☆ | 找到圆形的东西 | 家长确认 | 盘子、硬币、钟表都是圆的 |
| ★★☆ | 找 3 个绿色的物品 | 家长确认 | 绿植、绿衣服、绿色积木 |
| ★★☆ | 找到正方形的物品 | 家长确认 | 书本、魔方面、饼干盒 |
| ★★☆ | 找 1 件黄色和 1 件蓝色的物品 | 家长确认 | 颜色配对游戏 |
| ★★☆ | 找 1 个三角形的物品 | 家长确认 | 三角尺、三明治、衣架 |
| ★★★ | 找 3 个红色的圆形物品 | 家长确认 | 红苹果、红杯盖、红积木 |
| ★★★ | 找 2 个相同颜色的不同形状 | 家长确认 | 比如绿色圆形碗 + 绿色方形积木 |
| ★★★ | 找到带条纹/波点的物品 | 家长确认 | 条纹衣服、波点杯子 |
| ★★★ | 找出最大的和最小的球 | 家长确认 | 皮球、弹珠、篮球都是球体 |
| ★★★ | 找 3 件白色/黑色的物品 | 拍照 | 袜子、遥控器、绘本 |

|------|---------|---------|------|

| ★★★ | 把 5 本书从大到小排列 | 拍照 | 像台阶一样排排站 |
| ★★★ | 把袜子配对叠好 | 家长确认 | 看看谁和谁是一对 |
| ★★★ | 把玩具按颜色分类 | 拍照 | 红色一堆，蓝色一堆 |
| ★★★ | 帮水杯排队（从矮到高） | 家长确认 | 矮个子排前面 |

## 四、自定义任务模板（给家长参考）

家长可以在任务编辑器中自行创建任务，以下提供模板格式：

```json
{
  "title": "【动词】+【数字】+【形容词】+【物品】",
  "category": "从四大类中选择",
  "difficulty": "1-5",
  "verifyType": "photo / audio / parent_confirm / nfc / qrcode"
}
```

### 万能任务公式
| 公式 | 例子 |
|------|------|
| 找 + [数量] + [颜色] + [物品] | 找 2 个紫色的东西 |
| 把 + [物品] + [动作] + [方式] | 把娃娃按大小排好 |
| 学 + [动物/角色] + [动作/声音] | 学青蛙跳 3 下 |
| 去 + [地点] + 找到 + [物品] | 去阳台找到浇水壶 |

### 自定义任务池建议
- 日常家务可转化：叠毛巾、放碗筷、给植物浇水、喂宠物
- 季节主题：春天找落叶、夏天找扇子、秋天找果实、冬天找围巾
- 节日主题：过年找红色装饰、生日布置吹蜡烛
