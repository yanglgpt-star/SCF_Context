## 一、总体架构图

```mermaid
flowchart TB
    subgraph L1["基础数据层"]
        direction LR
        A1["企业档案 / 品牌 / 品类 / 场景"]
        A2["仓库 / 商品SKU / 用户权限"]
    end

    subgraph L2["核心业务层"]
        direction TB
        B1["底层资产池<br/>(登记 / 池视图 / 入池出池)"]
        B2["货权管理<br/>(货权转移 / 仓单凭证 / 权属流水)"]
        B3["资产包管理<br/>(静态包 / 动态包 / 包内资产)"]
        B4["资产监管<br/>(实时监控 / 预警 / 台账报告)"]
    end

    subgraph L3["资产交易层"]
        direction LR
        C1["挂牌"] --> C2["认购"] --> C3["签约结算"] --> C4["交割"] --> C5["存续期管理"]
    end

    subgraph L4["集成与外部交互层"]
        direction LR
        D1["代采/货押/采购贷"]
        D2["WMS/仓储方"]
        D3["银行/外部资金方"]
        D4["财务系统"]
    end

    L1 --> L2 --> L3
    D1 -. 资产沉淀 .-> B1
    D2 -. 库存/交割确认 .-> B4
    D3 -. 资金/确权 .-> C5
    D4 -. 结算 .-> C3
```

**说明**：基础数据层为上层提供档案支撑；核心业务层承载资产池、货权、资产包、监管四大模块；资产交易层支撑资产/资产包转让给外部资金方；集成层对接现有业务系统、WMS、银行/资金方与财务系统。

## 二、整体流程图

### 2.1 端到端主流程

```mermaid
flowchart LR
    A["底层资产沉淀登记"] --> B["资产池统一管理"]
    B --> C{"是否需要货权转移"}
    C -->|"是"| D["货权转移"]
    D --> B
    C -->|"否"| E["资产打包"]
    B --> E
    E --> F["静态/动态资产包"]
    F --> G{"资产包用途"}
    G -->|"监管/存续"| H["资产监管"]
    G -->|"转让给外部资金方"| I["资产购买交易"]
    I --> H
```

### 2.2 角色协作时序图

```mermaid
sequenceDiagram
    participant S as 业务系统(代采/货押)
    participant A as 资产管理员
    participant R as 风控/审批
    participant W as 仓储方/WMS
    participant B as 银行/质权人
    participant F as 外部资金方

    S->>A: 沉淀底层资产(在库/在途)
    A->>A: 登记入池，形成资产池
    A->>R: 货权转移申请
    alt 资产已质押
        R->>B: 征询质权人意见
        B-->>R: 同意 / 解押
    end
    R->>W: 仓储交割确认
    W-->>A: 仓单/货权凭证变更
    A->>A: 更新权属信息，登记流水
    Note over A,R: 资产池统一管理
    A->>F: 资产包挂牌(转让给外部资金方)
    F->>F: 认购并付款
    F->>A: 签约/交割接收
    Note over A,F: 存续期管理(回款/回购/到期)
```

## 三、子流程图

### 3.1 资产登记与入池流程

```mermaid
flowchart TD
    A["资产来源识别"] --> B{"自动同步 or 手工登记"}
    B -->|"自动同步"| C["对接代采/货押/采购贷/WMS同步"]
    C --> D["数据清洗与校验"]
    B -->|"手工登记"| E["资产管理员录入资产信息"]
    E --> D
    D --> F{"资产形态"}
    F -->|"在库"| G["登记存放仓/库位/库存信息"]
    F -->|"在途"| H["登记发货/物流/预计到货信息"]
    G --> I["资产确权与估值"]
    H --> I
    I --> J["生成资产编号并入库"]
    J --> K["按场景/品牌/品类归入资产池"]
    K --> L["资产池视图可查询/统计"]
```

### 3.2 货权转移流程

```mermaid
flowchart TD
    A["发起货权转移申请"] --> B["选择资产与转让双方"]
    B --> C["填写货权转移协议及附件"]
    C --> D["提交审批"]
    D --> E{"风控/监管审批"}
    E -->|"驳回"| F["退回修改或终止"]
    E -->|"通过"| G{"资产是否质押"}
    G -->|"是"| H["质权人确认/解押"]
    H -->|"不同意"| I["流程终止并通知"]
    H -->|"同意"| J["仓储方/WMS确认交割"]
    G -->|"否"| J
    J --> K{"资产形态"}
    K -->|"在库"| L["仓单/货权凭证变更"]
    K -->|"在途"| M["运单变更/提货权让渡<br/>物流方确认"]
    L --> N["登记权属变更流水"]
    M --> N
    N --> O["资产池权属信息更新"]
    O --> P["通知转让双方完成"]
```

### 3.3 静态资产包生成流程

```mermaid
flowchart TD
    A["创建静态资产包"] --> B["设置包基本信息<br/>(包名称/类型/期限)"]
    B --> C["从资产池筛选并勾选资产"]
    C --> D{"资格校验<br/>(权属/状态/金额/数量)"}
    D -->|"校验失败"| E["剔除异常资产并提示"]
    E --> C
    D -->|"校验通过"| F["锁定所选资产"]
    F --> G["生成资产包编号与包内清单"]
    G --> H["资产包生效"]
    H --> I["存续期管理/到期终止"]
```

### 3.4 动态资产包生成流程

```mermaid
flowchart TD
    A["创建动态资产包"] --> B["设定入池/出池规则<br/>(品类/品牌/评级/折扣/账期/限额)"]
    B --> C["资产包生效并启动规则引擎"]
    C --> D["按周期自动扫描资产池"]
    D --> E{"满足入池条件?"}
    E -->|"是"| F["资产自动入池"]
    E -->|"否"| G{"是否触发出池条件?"}
    G -->|"是"| H["资产自动出池"]
    G -->|"否"| I["维持不变"]
    F --> J["包内资产动态更新"]
    H --> J
    I --> J
    J --> K["实时统计包规模/合格覆盖率"]
    K --> L["监管与预警"]
```

### 3.5 资产购买流程（转让给外部资金方）

```mermaid
flowchart TD
    A["资产/资产包挂牌"] --> B["外部资金方查询与选购"]
    B --> C["询价/报价与定价"]
    C --> D{"内部审批"}
    D -->|"驳回"| E["终止或重新定价"]
    D -->|"通过"| F["签订资产购买协议"]
    F --> G["资金方付款结算"]
    G --> H{"交割类型"}
    H -->|"货权交割"| I["货权转移+仓储交割+凭证变更"]
    H -->|"债权交割"| J["债权转让登记"]
    I --> K["登记交易与权属流水"]
    J --> K
    K --> L["存续期管理<br/>(回款/收益分配/回购/到期)"]
```

### 3.6 监管管理流程

```mermaid
flowchart TD
    A["数据采集<br/>(库存/价格/权属/交易)"] --> B["实时监控"]
    B --> C{"触发预警规则?"}
    C -->|"否"| D["正常监控"]
    C -->|"是"| E["生成预警工单"]
    E --> F["监管员处置"]
    F --> G["处置结果记录"]
    G --> H["监管台账与报告"]
    H --> I["管理层查看/决策"]
```
