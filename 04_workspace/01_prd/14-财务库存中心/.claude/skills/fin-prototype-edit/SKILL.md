## 硬约束

1. **`tbody td` 里禁止出现英文码**——码只准进 `title` 属性。
2. **界面定死一态**——不加 `prefers-color-scheme` 分支。
3. **令牌源只认 `PC端界面.html`**——配色/间距/字号从这里取，不要自己发明。
4. **规格抽屉 `tbl--spec` 与文档逐列对齐**——文档里的字段表改了，抽屉要跟着改（历史上曾出现抽屉与文档小数位不一致）。
5. **维度名**：一级货主 / 二级产权人（「二级货主」已废弃）。
6. **负库存期间**本行均价同时显示 `—`。

## 改一处原型的标准动作

```
1. 读 CLAUDE.md（权威层级 + 门禁 + 命名禁令）
2. 确认改的是哪一页 / 哪个抽屉 / 哪层浮层
3. 手工编辑 HTML（不用脚本）
4. 若动了列或字段 → 同步「原型说明_v1.0.md」对应小节
5. 若动了列或字段 → 检查规格抽屉 tbl--spec 是否同步
6. 全文检查：tbody td 无英文码
7. 跑 build_proto_doc.py 重出阅读版
8. 报告：改了哪几处、抽屉与文档是否已对齐
```

cd "04_workspace/01_prd/14-财务库存中心"

# 校验：td 里有没有英文码
grep -oE '<td[^>]*>[^<]*[A-Za-z_]{3,}[^<]*</td>' "财务库存中心（一期）原型页面.html" | head
