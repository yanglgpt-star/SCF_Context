## 二、三道门禁

### 2.1 字段层默认冻结

字段层（字段、列、表结构）**默认冻结**；**解冻需单独授权**。历史上已解冻三次（`owner_l2` 必填 / D1–D4 五层模型 +13 字段 / 二级自有均价池 `own_*` 3 列），每次都是**单独授权**的。

### 2.2 跨文档传播需单独授权

一处口径改动要扩散到其它文档时：**先出变更清单 → 停下 → 等用户单独授权 → 才动手**。

- 授权是**一次性的、不继承的**——上次同意传播 X，不代表这次 Y 也可以。
- 「已报未改」清单里的项，**未获授权前一律不动**。

### 2.3 方案类交付物写成仓库内 md

设计方案、分析结论、拆分方案等**一律落成仓库内的 md 文件**，不只在对话里输出。

## 三、命名与写法禁令

1. **正文不写裸码**：`MA` / `SI` / `FIFO` 不得裸露出现，一律写中文全称（移动加权平均 / 个别计价 / 先入先出法）；「中文全称（码）」这种带括注的写法**可以**。
2. **原型 HTML 的 `tbody td` 禁止出现英文码**——码只准进 `title` 属性。
3. **「二级货主」是已废弃称谓**，一律用「**二级产权人**」（一级用「**一级货主**」）。
   - ⚠️ **例外**：既有**对象名**不改——表名 `t_owner_allocation`（二级货主分摊账）、`t_owner_balance_l2`（二级货主结存表）等保持原样。
4. **交付文档里英文字段 / 枚举 / 错误码都要带中文说明**，**每个出现处都加**，不必等用户提。

**三条跨页恒定口径**（不随页变）：

1. **数量标注口径**：库存金额标 `（存货口径·一级货主层·is_internal=1）`；库存数量标 `（权属口径·一级货主层）` 或 `（物理口径·仓库）`；内部结算损益与二级自有均价标 `（管理口径·非会计损益）`。**任何对外分发的报表与指标必须带口径标注**。
2. **批次号在结存余额口径下三个维度恒为 `—`**——核算单元是三轴聚合，批次不属于聚合键；**仅记账流水口径该列有值**。
3. **管理口径两列（`own_amount` / `own_unit_price`）只出现在二级产权人粒度**——仓库维度、一级货主维度**无此列**。

**术语速查**：核算单元 = 商品 × 仓库 × 一级货主；二级层口径 = 「一个数量、三个金额」（`alloc_amount` 二级分摊金额 / `internal_amount` 二级内部结算金额 / `own_amount` 二级自有结存金额）；池化差异 `D`；对平 `V1`/`V2`/`V3`/`M1`/`M2`/`M3`/`E-11`/`E-12`/`E-13`。
