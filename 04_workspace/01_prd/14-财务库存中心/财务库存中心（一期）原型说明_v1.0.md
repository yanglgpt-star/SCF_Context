# 财务库存中心（一期）原型说明 v1.0

> **本文是什么。** 本文是原型 `财务库存中心（一期）原型页面.html` 的**逐页说明书**——16 个页面每页一节，给出该页的**菜单位置、对应系统需求、页面说明、页面规模，以及搜索条件 / 按钮交互 / 字段说明三张表**。
>
> **内容从哪来。** 三张表逐行取自**原型页面内置的「字段与按钮说明」抽屉**（`tbl--spec`），即原型的最新状态；导航路径、对应系统需求与页面说明取自 `财务库存中心项目-整体PRD_v1.0-原文件.md`（系统需求 SR01–SR08），与 `财务库存中心（一期）需求文档 1.0（原型页面与核算引擎）.md`（下称**原文**）`§三` 逐页对应。**三者口径不一致时以原文为准。**
>
> **一处改写。** 引用原型文案时，**裸英文计价方法码已按全项目术语约定还原为「编码（中文）」双语形式**（`` `MA` `` → `` `MOVING_AVG`（移动加权平均） ``、`` `SI` `` → `` `INDIVIDUAL`（个别计价） ``），其余文字逐字保留。原型自身仍存在的裸码见 [`附录 A`](#附录-a原型与原文的已知差异)。

- **菜单位置**：`财务库存中心` → `配置管理` → `计价模型配置`
- **对应系统需求**：SR01_F01 计价模型配置
