# 库存批次管理系统 整体方案

**版本**：V1.0（方案稿）
**日期**：2025-09-01
**状态**：待评审

---

## 一、项目概述

### 1.1 项目背景

公司现有库存管理缺乏按"批次"维度的精细化管理，存在以下痛点：

- 同一物料多个批次（不同生产日期、供应商、采购价格）混放，无法区分与追踪；
- 出库时无法按先进先出（FIFO）或指定批次出库，易产生过期/呆滞库存；
- 库存数量与财务金额脱节，月末核算依赖人工 Excel，效率低、易出错；
- 缺少批次全程追溯能力，质量/售后问题无法快速定位到供应商与客户。

### 1.2 建设目标

建设一套**面向公司内部的库存批次管理系统**，实现：

1. **业务库存批次管理**：以"批次"为核心，管好批次档案、批号规则、出入库、调拨、盘点、追溯、效期预警，保证账实相符；
2. **财务库存批次管理**：在业务数据基础上自动完成成本核算（移动加权平均 / FIFO）、库存价值报表、财务月结、凭证对接，实现业务财务一体化；
3. **支撑数千人规模**：系统部署在公司服务器，内部员工按角色权限使用，支持并发操作与数据安全。

### 1.3 用户范围与角色

| 角色 | 职责范围 | 主要功能 |
|---|---|---|
| 系统管理员 | 系统配置与权限 | 用户/角色/权限、参数配置、数据字典 |
| 基础资料维护员 | 物料、仓库、往来单位维护 | 商品档案、仓库库位、供应商/客户、单位 |
| 仓管员 | 仓库实物作业 | 入库、出库、退库、调拨、盘点、批次查询 |
| 采购/销售业务员 | 业务单据发起 | 采购入库、销售出库、退货处理 |
| 财务人员 | 成本核算与月结 | 成本核算、月结、库存价值报表、凭证 |
| 管理层 | 数据查看 | 库存报表、价值报表、追溯查询 |

### 1.4 术语定义

| 术语 | 说明 |
|---|---|
| 批次（Batch） | 同一物料在特定时间、按特定来源（供应商/生产批次）形成的一批存货，具有唯一的"批号"，是数量与成本核算的基本单元 |
| 批号（Lot No.） | 批次的唯一标识，可由系统按规则自动生成 |
| 逻辑批次 | 以"物料 + 批号"定义的概念批次，是追溯和成本归集的维度 |
| 物理批次库存 | 逻辑批次在各仓库/库位下的实际数量分布 |
| 可用数量 | 在库数量中可参与出库的数量（扣除锁定/冻结） |
| 在库数量 | 当前实际存放在仓库的数量 |
| 库存成本 | 批次存货的金额价值，按核算方法（移动加权平均/FIFO）计算 |
| 过账（Posting） | 单据审核后正式影响库存数量与金额的动作，不可再随意修改 |
| 月结（Month-end Close） | 月度财务关账动作，锁定当月数据，结转期初期末结存 |

## 二、总体架构

### 2.1 业务架构：业务与财务"双轨并行、单据驱动"

系统采用 **业务账 + 财务账双轨制**：

```
                    ┌──────────────────────────────────────────┐
                    │           业务单据（唯一入口）              │
                    │  采购入库 / 销售出库 / 退库 / 调拨 / 盘点   │
                    └───────────────┬──────────────────────────┘
                                    │ 过账（审核）
                ┌───────────────────┴───────────────────┐
                ▼                                       ▼
   ┌─────────────────────────┐           ┌─────────────────────────┐
   │  业务库存账（数量维度）    │           │  财务库存账（金额维度）    │
   │  批次档案 · 批次库存      │           │  成本核算 · 成本流水     │
   │  库存流水 · 追溯 · 预警   │           │  库存价值 · 月结 · 凭证   │
   └─────────────────────────┘           └─────────────────────────┘
                │                                       │
                └───────────────┬───────────────────────┘
                                ▼
                      ┌─────────────────────┐
                      │  报表与查询（管理层）  │
                      │  收发存汇总/价值/账龄  │
                      └─────────────────────┘
```

**核心原则**：

- **单据驱动**：所有库存变动必须由业务单据触发，禁止直接改库存数字；
- **过账即生效**：单据审核（过账）时，业务账和财务账在同一事务内同步更新，保证数量与金额一致；
- **可追溯**：每一笔库存变动都有来源单据，可正向/反向追溯。

### 2.2 应用架构（简要）

- **展现层**：Web 浏览器访问，管理后台风格界面；
- **应用层**：业务模块（基础资料、业务批次、财务批次、系统管理）+ 公共服务（权限认证、日志、报表导出、消息通知）；
- **数据层**：MySQL 8 关系型数据库，支撑事务一致性与并发控制；
- **集成层**：预留财务软件（金蝶/用友等）对接接口、Excel 导入导出。

### 2.3 部署架构（简要）

- 系统部署在公司**内部服务器**（或内网可达的私有云）；
- 浏览器通过内网地址访问，无需安装客户端；
- 数据库与应用可同机部署（中小规模）或分机部署（数千人规模建议应用多实例 + 数据库独立服务器）；
- 定期自动备份数据库。

> 详细技术选型与部署方案在《详细设计》阶段输出，本方案聚焦业务功能。

## 四、业务库存批次管理（业务侧）

### 4.1 基础资料

#### 4.1.1 商品（物料）档案

- 字段：物料编码（唯一）、名称、规格型号、计量单位、物料类别、默认仓库、批次管理标志、有效期管理标志、保质期（天）、**成本核算方法**（移动加权平均 / FIFO，可继承全局默认）、库存上下限、状态（启用/停用）；
- 支持按物料类别批量设置核算方法。

#### 4.1.2 仓库与库位

- 仓库：编码、名称、地址、负责人、状态；
- 库位：属于某仓库，编码、名称、状态；
- 支持"批次 + 仓库 + 库位"维度的库存明细。

#### 4.1.3 供应商与客户

- 供应商：编码、名称、联系人、联系方式、状态；
- 客户：编码、名称、联系人、联系方式、状态；
- 用于采购入库与销售出库时记录来源/去向，也是追溯的关键节点。

#### 4.1.4 批号规则

支持配置批号自动生成规则，常用规则组合示例：

- `前缀 + 年月日 + 流水号`，如 `CG20250901-001`；
- `物料编码 + 生产日期 + 流水`，如 `M0001-250901-01`；
- 可配置前缀（采购/生产/自定义）、日期格式、流水位数、是否按物料独立流水；
- 生成后可手工修改（需唯一性校验）。

### 4.2 批次档案管理

**批次是系统的核心对象**。每个批次包含：

| 属性组 | 字段示例 |
|---|---|
| 标识 | 批号（唯一）、物料、批次名称/描述 |
| 来源 | 供应商、生产日期、采购/生产单据号 |
| 效期 | 有效期至、保质期天数 |
| 价格成本 | 批次单价、批次价格（含税/参考价）、实际入库成本 |
| 数量 | 入库数量、在库数量、可用数量、锁定数量、累计出库数量 |
| 位置 | 所在仓库、库位（可多位置） |
| 状态 | 在途 / 在库 / 部分出库 / 售罄 / 冻结 / 过期 / 停用 |

**批次生命周期**：

```
生成（入库过账） → 在库 → 部分出库 → 售罄 → 归档
                      │
                      ├─ 冻结（质量问题/锁定）→ 解冻 → 继续
                      └─ 过期预警 → 过期处理（报废/退货）
```

**关键规则**：

- 同一物料 + 批号全局唯一；
- 数量、单价、批次价格等关键字段由单据过账自动生成，不允许直接改；
- 冻结批次不可出库，需解冻后恢复。

### 4.3 入库管理

| 入库类型 | 说明 | 对批次的影响 |
|---|---|---|
| 采购入库 | 供应商到货入库 | 生成新批次（或追加至相同批号批次），记录供应商、单价 |
| 生产入库 | 生产完工入库 | 生成生产批次，记录生产日期 |
| 退货入库 | 客户退货/销售退回 | 回到原批次（如原批次存在）或新建退货批次 |
| 其他入库 | 盘盈、赠品、借入等 | 生成对应批次 |

- 入库单：单号、日期、仓库、供应商、明细（物料、数量、单价、批次信息）、审核/过账流程；
- **过账动作**：增加批次库存数量 → 生成业务库存流水 → 生成财务成本流水（见财务侧）；
- 支持一张入库单多批次、多个物料。

### 4.4 出库管理

| 出库类型 | 说明 | 批次策略 |
|---|---|---|
| 销售出库 | 销售给客户 | 按 FIFO 或指定批次出库 |
| 领料出库 | 内部领用/生产领料 | 按 FIFO 或指定批次出库 |
| 退货出库 | 退供应商 | 指定批次 |
| 其他出库 | 报废、盘亏、借出等 | 指定批次 |

- **出库批次匹配策略**（可按单据选择或按物料默认）：
  1. **先进先出（FIFO）**：按批次生产日期/入库日期从早到晚自动匹配（系统默认）；
  2. **指定批次**：手工指定某个批次出库；
  3. **优先效期**：按有效期最近到期的先出（可配置）。
- **负库存控制**：默认禁止负库存出库，可配置为允许（需审批）。

### 4.5 退库管理

- 销售退库：冲减销售出库影响，库存回到对应批次，金额按原出库成本或退货价处理；
- 采购退库（退供应商）：从批次库存扣减，生成红字/负向单据；
- 退库单独立类型，保留完整业务轨迹，不直接改原单。

### 4.6 调拨管理

- **仓库间调拨**：批次库存从 A 仓库移至 B 仓库，数量不变，成本不变（财务上不产生损益）；
- **库位间调拨**：仓库内库位调整；
- 调拨单：来源仓库/库位、目标仓库/库位、物料、批号、数量；
- 过账后生成调拨出入库流水，批次在目标仓库数量增加、来源仓库数量减少；
- 支持在途调拨（发出未到货）状态。

### 4.7 盘点管理

- **盘点计划**：选择仓库/物料/批次范围，生成盘点计划单；
- **盘点执行**：录入实盘数量，系统自动计算差异（盘盈/盘亏）；
- **盘盈盘亏处理**：差异过账生成盘盈入库单/盘亏出库单，业务账更新数量，财务账按成本生成相应金额（盘盈入账、盘亏损失）；
- 支持全盘与抽盘，盘点期间可冻结被盘范围。

### 4.8 批次追溯

**双向追溯能力**：

- **正向追溯（批次 → 去向）**：输入批号，查询该批次所有出库记录 → 客户/领用部门 → 直至最终去向；
- **反向追溯（批次 → 来源）**：查询批次来源（供应商、采购单、生产批次、原料批次）；
- **追溯视图**：按时间轴展示批次全生命周期（入库 → 在库 → 出库 → 退回），可追溯到上游原料批次（生产 BOM 场景，二期）。

### 4.9 有效期与预警

| 预警类型 | 规则 | 处理 |
|---|---|---|
| 效期到期预警 | 距有效期到期 N 天内（N 可配） | 列表标红、到期批次提醒、可生成预警报表 |
| 呆滞预警 | 超过 N 天无出入库（N 可配） | 呆滞库存报表，提示清理 |
| 库存上下限 | 库存低于下限/高于上限 | 补货/积压提醒 |
| 冻结/过期批次 | 过期批次自动标记 | 不可出库，提示报废或退货处理 |

## 五、财务库存批次管理（财务侧）

### 5.1 成本核算方法

系统支持两种核算方法，**按物料（或物料类别）配置**，也可设置全局默认：

#### 5.1.1 移动加权平均法

- 按批次（或按物料整体）维护加权平均单价；
- **入库时**：新加权单价 =（原库存金额 + 本次入库金额）/（原库存数量 + 本次入库数量）；
- **出库时**：按当前加权单价结转出库成本，库存金额相应减少；
- 适用于价格波动不大、批次间差异不敏感的物料。

#### 5.1.2 先进先出法（FIFO）

- 出库时严格按批次入库顺序（生产/入库日期先后）匹配批次；
- 各批次保留各自成本单价，**出库成本 = 所出批次的实际成本单价**；
- 可实现"批次成本"精细化，出库毛利更准确；
- 适用于价格波动大、需要按批次考核成本的物料。

> 两种方法可并存：不同物料用不同方法，报表与凭证按各自口径出数。

### 5.2 批次成本管理

| 环节 | 业务规则 |
|---|---|
| 入库成本确定 | 采购入库成本 = 采购单价（+ 运费/杂费，可配置）；生产入库成本 = 生产成本/标准成本（二期接生产） |
| 出库成本结转 | 按核算方法自动结转：FIFO 按批次单价，移动加权按加权单价 |
| 成本调整单 | 财务可手工做成本调整（调价），影响库存金额与后续成本计算，留审计轨迹 |
| 退货成本 | 销售退库按原出库成本（或退货协议价）回冲 |

### 5.3 库存价值报表

| 报表 | 内容 |
|---|---|
| 收发存汇总表 | 按物料/仓库/批次汇总：期初、入库、出库、期末（数量+金额） |
| 库存价值明细 | 每个批次在库数量 × 成本单价 = 库存金额，可按仓库/物料汇总 |
| 账龄分析 | 按入库日期分账龄段（30/60/90/180/365天）统计库存数量与金额 |
| 批次毛利分析 | 按批次出库收入 - 出库成本 = 毛利（FIFO 下尤其有价值） |
| 差异报表 | 业务数量与财务数量/金额差异核对表 |

- 所有报表支持按期间、仓库、物料、批号筛选，导出 Excel。

### 5.4 财务月结

**月结流程**：

```
月度关账检查 → 确认本期单据全部过账 → 检查差异/未处理事项
    → 生成期初期末结存（数量+金额） → 锁定本期数据 → 允许开启下月
```

- **关账**：每月结账后，本期业务单据不可再新增/修改（除非反结账）；
- **反结账**：由财务主管授权执行，反结账后需重新结转；
- **期初期末结存**：期末结存自动成为下月期初，数量金额自动衔接；
- **月结检查清单**：未过账单据、负库存、负金额、未处理预警等，检查通过方可结账。

### 5.5 凭证对接 / 导出

- **凭证模板配置**：按单据类型 + 业务场景配置借贷科目模板（如：借：库存商品，贷：应付账款；借：主营业务成本，贷：库存商品）；
- **凭证生成**：月结或实时按过账单据批量生成凭证，支持预览与调整；
- **导出**：凭证数据导出为 Excel（标准格式），或按财务软件（金蝶/用友等）导入格式生成文件；
- **接口预留**：预留标准 API，便于与现有财务系统对接（二期实施）。

## 六、系统管理

- **组织用户**：组织/部门树、用户账号（工号、姓名、部门、状态）；
- **角色权限（RBAC）**：角色定义（管理员/仓管/财务/业务/查看等），按菜单与按钮授权（如：过账、反结账、成本调整等敏感操作单独授权）；
- **操作日志**：记录关键操作（新增/修改/过账/反结账/成本调整）的操作人、时间、内容，支持审计查询；
- **参数配置**：系统参数（是否允许负库存、预警天数、默认核算方法、单据编号规则等）；
- **数据字典**：物料类别、单据类型、仓库类型等枚举维护。

## 七、关键业务流程

### 7.1 采购入库流程

```
采购到货 → 仓管创建采购入库单（物料/数量/单价/生产日期/效期）
   → 录入/自动生成批号 → 审核过账
   → [业务] 批次库存增加、生成库存流水
   → [财务] 按单价计算入库成本、更新加权单价（移动加权）或批次成本（FIFO）
```

### 7.2 销售出库流程

```
销售下单 → 仓管创建销售出库单 → 选择出库策略（FIFO/指定批次）
   → 系统自动匹配批次并锁定数量 → 审核过账
   → [业务] 批次库存减少、生成出库流水、记录客户去向
   → [财务] 按核算方法结转出库成本
```

### 7.3 调拨流程

```
发起调拨单（来源仓库/库位 → 目标仓库/库位，物料/批号/数量）
   → 审核过账 → 来源批次库存减少、目标批次库存增加
   → 财务：数量金额不变，无损益
```

### 7.4 盘点流程

```
创建盘点计划 → 冻结盘点范围 → 录入实盘数量 → 计算差异
   → 生成盘盈/盘亏单 → 审核过账 → [业务]调整数量 [财务]调整金额
```

### 7.5 财务月结流程

```
月度结束 → 月结检查（未过账单据/差异）→ 生成期末结存 → 结账锁定
   → 生成库存价值报表/收发存汇总 → 生成凭证 → 开启下月
```

### 7.6 批次追溯流程

```
输入批号 → 展示批次档案（来源/效期/成本）→ 正向：出库流水→客户
   → 反向：入库流水→供应商 → 全生命周期时间轴
```

## 八、核心业务规则汇总

1. **批次唯一**：物料 + 批号全局唯一，批号规则自动生成、可改不可重；
2. **单据驱动**：一切库存变动源于单据过账，禁止直接改数；
3. **事务一致**：业务流水与财务流水同事务提交，保证数量金额账实一致；
4. **过账不可改**：已过账单据不允许修改/删除，只能红冲/退货处理；
5. **负库存控制**：默认禁止，允许配置 + 审批；
6. **FIFO 匹配**：出库默认先进先出，支持指定批次与效期优先；
7. **冻结即停**：冻结/过期批次不可出库；
8. **成本一致**：期末库存金额 = 期初 + 入库 - 出库（含调整），月结校验平衡；
9. **权限最小化**：过账、反结账、成本调整等高敏操作单独授权并留痕；
10. **追溯闭环**：任何批次可正向反向追溯到供应商与客户。

## 九、数据模型概览（逻辑层）

主要实体及关系（详细物理设计在详细设计阶段输出）：

| 实体 | 关键字段 | 主要关系 |
|---|---|---|
| 物料 Material | 编码、名称、规格、单位、核算方法 | 1:N 批次 |
| 仓库 Warehouse / 库位 Location | 编码、名称 | 1:N 库位 |
| 供应商 / 客户 Partner | 编码、名称 | 关联单据 |
| 批次 Batch | 批号、物料、供应商、生产日期、有效期、单价、批次价格、状态 | N:1 物料；1:N 批次库存 |
| 批次库存 BatchStock | 批次、仓库、库位、在库数量、可用数量、锁定数量 | N:1 批次 |
| 业务单据 Doc + 明细 DocLine | 单号、类型、日期、状态、仓库、明细行（物料/批次/数量/单价） | 1:N 明细 |
| 库存流水 StockFlow | 单据、物料、批次、仓库、方向、数量、变动前/后结存 | 关联单据与批次 |
| 成本流水 CostFlow | 单据、批次、成本单价、数量、金额、核算方法 | 关联单据与批次 |
| 凭证 Voucher + 明细 | 凭证号、模板、科目、借贷金额 | 关联单据 |
| 月结 MonthEnd | 期间、状态、期初/期末结存 | 关联期间数据 |
| 用户/角色/权限 | 账号、角色、权限点 | RBAC |

**核心关系图（简化）**：

```
物料 1──N 批次 1──N 批次库存 N──1 仓库/库位
                │
                ├──N 库存流水 ←── 业务单据（过账生成）
                └──N 成本流水 ←── 业务单据（过账生成）
                └──N 凭证 ←── 业务单据（凭证生成）
```

## 十、非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 支持数千用户在线；常用查询 < 2s；单据保存/过账 < 1s；高峰期并发过账不丢数、不超卖 |
| 并发控制 | 库存扣减采用数据库行级锁/乐观锁，防止超卖与重复扣减 |
| 数据一致性 | 关键操作事务化，库存流水/成本流水/单据同事务提交 |
| 安全 | 账号密码安全策略、登录限流、RBAC 权限、操作审计日志、敏感操作二次确认 |
| 可用性 | 数据库每日自动备份；故障可恢复；定期演练恢复 |
| 可扩展 | 模块化设计，预留：多组织、生产 BOM 追溯、条码/PDA 扫码作业、财务系统接口 |
| 易用性 | 中文界面，批次相关字段贯穿查询与单据，报表可导出 |

## 十二、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 历史数据/期初库存不准确 | 期初数与实际不符 | 上线前组织专项盘点，录入期初批次与成本 |
| 核算方法选择不当 | 成本数据失真 | 方案评审阶段确认各物料核算方法；支持调整与成本调整单兜底 |
| 业务流程变化 | 单据流程不符 | 模块化设计 + 参数化配置（负库存、预警天数、编号规则等） |
| 数千人并发压力 | 性能瓶颈 | 数据库设计优化、索引、行级锁、分页查询、应用可水平扩展 |
| 数据安全风险 | 敏感数据泄露 | RBAC 权限、审计日志、数据库备份、内网部署 |
