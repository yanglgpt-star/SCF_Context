# 园聪学习 iPad 横屏第一阶段实现与测试报告

> 版本：v0.4 | 日期：2026-08-23  
> 技术：微信原生小程序  
> 第一阶段：点数练习、数的分解、10以内加减法、骰子游戏

## 1. 已确认的产品决策

- 继续使用微信原生，不迁移UniApp。
- 儿童页面统一iPad横屏。
- 首页不强调星星数量，只显示“我的收获”。
- 前台连续使用10分钟后必须家长长按才能继续。
- 第一阶段开放点数、分解、加减法和骰子四个入口。

## 2. 已实现公共能力

| 能力 | 实现 |
|---|---|
| 横屏 | 所有页面JSON配置 `pageOrientation: landscape` |
| 竖屏提示 | `orientation-guard` 监听窗口变化并显示全屏旋转提示 |
| 自定义导航 | 全局 `navigationStyle: custom`，页面自行提供返回 |
| 胶囊安全 | 顶部使用 `capsule-safe` 预留右侧空间 |
| 大屏限制 | 页面最大宽度1200px并居中 |
| 休息管理 | `session-manager` 只累计前台时间，10分钟触发 |
| 家长继续 | `rest-overlay` 家长长按1.5秒后重置时长 |
| 儿童结束 | “今天先玩到这里”进入锁定，返回首页仍不能自行继续 |

## 3. 第一阶段模块

### 3.1 点数练习

- 随机1～10个糖果、水果、小鱼或花朵。
- 点击后保留物体但降低透明度，防止重复点数。
- 每次点击播放对应数字语音。
- 数完后显示3个大答案。
- 答错恢复物品并重新数，不报答案。
- 每局5组，无分数和计时。

### 3.2 积木分一分

- 目标数为5～10。
- 原生touch拖拽积木到左右篮子。
- 两篮实时显示数量。
- 不设置错误分法，所有积木分完即完成。
- 完成反馈“A和B合起来是N”。

### 3.3 十以内加减法

- 现有题库、答案校验、语音和帮助继续保留。
- 改为左侧实物与算式、右侧大答案的横屏布局。
- 返回和语音按钮避开右上角胶囊。

### 3.4 骰子游戏

- 两个骰子均为1～5点，和不超过10。
- 滚动动画约0.7秒。
- 3个大答案按钮。
- 答错提示分别点数，不显示输赢和积分。

## 8. 横屏滚动问题修复

真机反馈横屏后页面无法滑动。根因是儿童页面同时设置了 `disableScroll: true`、`height: 100vh` 和 `overflow: hidden`，内容超出可视高度时被直接截断。

修复内容：

- 首页、点数、分解、加减法、骰子和结算页均开启页面纵向滚动。
- 页面根容器改为 `min-height: 100vh`，内容不足时仍铺满屏幕，超出时自然增长。
- 根容器使用 `overflow-y: auto`，不再隐藏垂直溢出。
- 积木本身继续使用 `catchtouchmove`，只在拖拽积木时阻止页面跟随移动。
- 新增T20自动测试，保证后续页面不会重新禁用横屏滚动。

## 9. 手机与iPad自动适配

- 新增 `device-profile`，根据屏幕短边自动分类：短边≥600px为tablet，短边<600px为phone。
- iPad使用原有宽松双栏、大插画和大篮子布局。
- 手机横屏通过统一媒体查询切换为紧凑双栏，缩短顶部、间距、装饰和非关键字号。
- 手机端的答案、点数物体等核心触控区域继续保持不小于120rpx。
- 手机和iPad共用相同WXML、业务逻辑、题库、语音和学习记录，不维护两套功能页面。
- 两种设备均允许内容超出后纵向滚动。
- 新增T21设备分类边界测试和T22响应式样式覆盖测试。
- 完整自动测试更新为 **22/22通过**，预计主包约1.83MB。
