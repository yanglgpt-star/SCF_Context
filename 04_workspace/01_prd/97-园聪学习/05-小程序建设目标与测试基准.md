# 园聪学习小程序建设目标与测试基准

> 基线版本：MVP v0.4 | 设备：iPad横屏 | 视觉方案：B「轻柔积木」  
> 建立日期：2026-08-21  
> 用途：后续每次开发、体验测试和版本验收均以本文为统一基准。

## 1. 总目标

建设一个面向约 4 岁、刚接触加减法的儿童微信小程序，让孩子在低刺激、少文字、语音优先的环境中，通过“看见两组物品合起来”和“拿走后看剩余”理解 10 以内加减法，并能独立完成一局 5 题的学习闭环。

## 2. MVP 目标

| 目标编号 | 建设目标 | 可量化验收标准 |
|---|---|---|
| G01 | 孩子能独立进入游戏 | 首页只有一个高优先级开始按钮；首次说明后 80% 测试儿童能找到入口 |
| G02 | 孩子理解加法“合起来”和减法“拿走后剩余” | 加法展示两组汇合，减法展示拿走与剩余；所有题画面、算式与答案 100% 一致 |
| G03 | 孩子能轻松完成操作 | 答案按钮不少于 88rpx，最多 3 个选项；关键点击均有即时反馈 |
| G04 | 答错也愿意继续 | 首次答错无红叉、扣分和失败文案；测试中答错后继续率 ≥ 80% |
| G05 | 控制视觉和使用负担 | 低饱和暖色背景、单屏一个任务、每局 5 题、目标时长 3～5 分钟 |
| G06 | 支持逐级帮助 | 提供主动帮助；首次错重演合并，第二次错演示计数与答案 |
| G07 | 学习结果可追踪 | 记录首次正确、尝试次数、提示级别、时长；重启后数据不丢失 |
| G08 | 家长能理解结果 | 家长页展示局数、最近首次正确率、提示率和一条陪学建议 |
| G09 | 核心能力离线可用 | 无登录、无网络也能开始、完成、结算并保存一局 |
| G10 | 奖励可靠且不过度 | 完成 +1 星，全首次正确额外 +1；同一局重复打开不重复发奖 |

## 3. 视觉与护眼目标

| 编号 | 标准 |
|---|---|
| V01 | 主背景使用暖米色、低饱和灰紫和浅灰蓝，不使用大面积纯白或纯黑 |
| V02 | 文字与背景保持清楚对比，但不使用荧光色和粗黑描边 |
| V03 | 主色数量不超过 3 种；装饰不能抢过题目和答案 |
| V04 | 核心数字不小于 64rpx，正文不小于 28rpx，主要按钮高度不小于 96rpx |
| V05 | 无快速闪烁；答错不抖动；单个动效不超过 2 秒且不阻塞操作 |
| V06 | 每局约 3 分钟；达到每日建议局数或连续 15 分钟给出休息提醒 |

## 4. 功能验收目标

### 4.1 首页

- 能展示昵称、累计星星、今日推荐和三个岛屿状态。
- 萌芽岛可进入；另外两岛锁定且点击有友好说明。
- 家长入口长按后才能进入，降低儿童误触。

### 4.2 游戏

- 每局 5 题，必须同时包含加法和减法；加数至少为 1，所有数值及答案在 0～10。
- 加法结果不得超过 10；减法被减数不得超过 10，且不得出现负数。
- 同局“运算类型+数字组合”不重复，首题的被操作数和答案不超过 5。
- 每题 3 个 0～10 的唯一答案，且一定包含正确答案。
- 连续点击只处理第一次有效点击。
- 第一次答错可继续选择；第二次答错展示正确答案。
- 退出后保存未完成进度，并可在 30 分钟内继续。

### 4.3 结算与报告

- 一局只结算一次奖励。
- 结算页不出现“失败、不及格、倒数”等负面或比较性表达。
- 家长统计基于真实题目日志，不使用模拟数字。
- 家长可以切换语音、音乐和每日建议局数，并能清除学习记录。

## 5. 自动测试基线

每次发布前必须执行以下自动检查：

1. `app.json`、所有页面 JSON 可解析。
2. 全部 JavaScript 文件通过语法检查。
3. `app.json` 中声明的页面文件齐全。
4. 题目生成 1,000 局时均满足十以内加减法边界、无负数、每局两种运算齐全、选项唯一、包含答案、单局不重复。
5. 奖励计算、正确率、提示率和建议逻辑通过单元测试。
6. WXML 不引用不存在的事件处理函数。
7. 核心页面包含最低字号、按钮尺寸和低刺激色板约束。
8. 禁止项扫描：生产页面不得包含远程头像、广告、排行榜、分享换奖励或负面失败文案。

## 6. 人工儿童体验测试

自动测试不能代替真实儿童测试。每个候选版本邀请至少 3 名接近 4 岁的儿童，在家长陪同但不主动指导的情况下完成一局，记录：

- 找到开始入口所需时间。
- 是否理解“又送来”和“一共”。
- 点击错误率与误触位置。
- 第几题出现分心。
- 答错后是否继续。
- 是否会主动寻找语音或帮助按钮。
- 单局实际时长。

## 7. 版本通过条件

- 自动测试必须全部通过。
- P0 功能不得存在阻断问题。
- 真实儿童首局完成率达到 80%，且无明显视觉不适或高频误触。
- 语音、物品数量、算式与答案必须逐题人工抽检一致。
- 如任何结果未达标，测试报告需注明问题、影响目标编号、修复建议和复测结果。
