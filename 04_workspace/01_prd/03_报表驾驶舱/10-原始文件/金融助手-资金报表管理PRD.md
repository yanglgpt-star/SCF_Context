## 1. 文档目的

本文档定义金融助手“报表管理—资金报表”的产品范围、页面功能、标准字段、字段取值、数据来源、统计口径、计算公式、异常规则、权限、审计和验收标准，供产品设计、数据建模、接口开发、前后端开发和测试共同使用。

本文档中的规则分为三类：

| 标识 | 含义 | 处理要求 |
|---|---|---|
| 已确认原则 | 用户已明确或可由系统设计确定 | 研发可按本文档实施 |
| Excel 参考口径 | 来自原 Excel 公式或缓存值 | 只能用于核对，不能直接成为生产系统口径 |
| 待业务确认 | 涉及资金、财务或经营判断 | 确认前不得作为正式结算规则上线 |

## 2. 核心原则

### 2.1 数据权威原则

1. **金融助手系统是唯一权威数据源。**
2. 正式驾驶舱、报表、导出和接口均读取金融助手数据。
3. Excel 仅作为只读核对来源，不参与正式指标计算。
4. Excel 不得直接覆盖、回写或替代金融助手数据。
5. 金融助手与 Excel 不一致时，报表仍展示金融助手数据，同时在“核对差异中心”生成差异记录。
6. 疑似系统缺失或错误必须回溯合同、订单、出入库单、银行流水、发票等原始业务单据。
7. 经业务和财务确认后，只能通过金融助手的补录、调整、冲销、审批流程修改系统数据。
8. Excel 的公式缓存值、批注、颜色和未来日期数据只能作为核查线索。

### 2.2 数据不可变与可追溯原则

- 已确认或已锁定记录不得直接修改；
- 更正使用调整单或冲销单；
- 必须保留原值、调整值、调整原因、附件、申请人、审批人和时间；
- 所有报表数据必须能够下钻至系统业务记录；
- 每次导出必须记录操作者、条件、时间和文件标识。

### 2.3 时间与版本原则

- 业务发生日期、系统创建时间、系统确认时间、报表归属日期分别保存；
- 历史报表绑定当时生效的参数版本；
- 实际数据与预测数据物理或逻辑隔离；
- Excel 中预生成到 2027 年的日期不得进入实际报表。

## 3. 项目背景

现有 Excel 覆盖日资金占用、项目资金、采购库存、出货毛利等业务，但存在以下问题：

- 费率、最低加价系数等规则直接写在公式内；
- 项目、客户、供应商、商品以文本关联，缺少稳定主键；
- 依赖 `TODAY()` 的指标无法还原历史结果；
- 项目状态、合同、发票、额外费用等字段使用不完整；
- Excel 与标准 XLSX 工具存在公式及样式兼容风险；
- 核对差异、异常评论没有形成结构化闭环；
- 权限只能控制文档，无法控制组织、字段和敏感指标。

本项目将在金融助手中建立标准数据模型、统一计算口径及报表能力。

### 4.1 产品目标

- 运营查看采购、入库、出库、库存及库龄；
- 所有报表差异可定位、分派、审批和关闭；
- 所有正式指标均可复现、可解释、可下钻。

## 7. 全局数据规则

### 7.1 记录纳入正式报表的条件

一条记录同时满足以下条件才进入正式实际报表：

```text
record_status IN ('CONFIRMED', 'LOCKED')
AND is_deleted = false
AND scenario_type = 'ACTUAL'
AND report_date <= 查询截止日期
```

以下记录不进入正式实际报表：草稿、待提交、待复核、已退回、已作废、被冲销原记录、预测、Excel 核对记录。

### 7.2 冲销与调整

- 冲销记录金额与原记录绝对值相等、方向相反；
- 原记录保留，状态设为 `REVERSED`；
- 冲销记录状态为 `CONFIRMED` 或 `LOCKED` 后进入报表；
- 调整记录必须关联 `original_record_id`；
- 报表值 = 原始确认值 + 已确认调整值 + 已确认冲销值。

### 7.3 金额与数量精度

| 数据 | 存储精度 | 展示精度 |
|---|---|---|
| 金额（元） | decimal(20,2) | 列表统一按元保留 2 位并显示千分位，单元格不追加“元/万元”；KPI和图表必须在标题或数值旁明确单位 |
| 单价 | decimal(20,4) | 默认 2–4 位 |
| 数量 | decimal(20,4) | 按商品计量单位展示 |
| 比例 | decimal(12,8) | 百分比默认 2 位 |
| 日费率 | decimal(12,6) | 保留最多 6 位 |
| 天数 | integer | 整数 |

禁止使用浮点数存储资金金额。

### 7.4 空值、零值和不适用

| 值 | 含义 |
|---|---|
| `NULL` | 未填写、未知或尚未计算 |
| `0` | 已确认数值为零 |
| `NOT_APPLICABLE` | 业务不适用，只用于状态型辅助字段 |

统计时不得将 `NULL` 自动视为 0。金额计算中，只有经过字段规则明确允许的可选金额字段才能使用 `COALESCE(value, 0)`。

### 7.5 金额方向

系统统一存储非负 `amount` 与方向 `direction`，统计时换算为有符号金额：

```text
signed_amount = CASE direction
  WHEN 'IN'  THEN +amount
  WHEN 'OUT' THEN -amount
END
```

资金占用公式另外使用“占用影响方向”，详见第 15 章。

### 8.1 通用状态

| 字段 | 编码 | 中文值 | 是否进入正式报表 |
|---|---|---|---|
| record_status | DRAFT | 草稿 | 否 |
| record_status | SUBMITTED | 已提交/待复核 | 否 |

| record_status | VOIDED | 已作废 | 否 |
| record_status | REVERSED | 已被冲销 | 原记录否，冲销记录按自身状态判断 |

### 8.2 项目状态

| 编码 | 中文值 | 进入报表 | 说明 |
|---|---|---|---|
| NOT_STARTED | 未开始 | 是 | 已建档，尚无业务发生 |
| IN_PROGRESS | 进行中 | 是 | 存在未完成采购、库存、回款或费用 |
| PENDING_CLOSE | 待完结 | 是 | 业务完成，等待关账检查 |
| COMPLETED | 已完结 | 是 | 关账检查通过 |
| SUSPENDED | 已暂停 | 是 | 暂停但保留余额 |
| CANCELLED | 已取消 | 否或仅历史 | 未发生业务可不纳入；已发生业务保留历史 |

### 8.3 BU 标准值

首期标准值：`DIGITAL/数码`、`LOGISTICS/物流`、`APPLIANCE/家电`。新增 BU 通过组织主数据配置，不允许在业务记录中自由输入。

### 8.3.1 业务模式

| 编码 | 中文值 | 业务定义 | 主要风险关注 |
|---|---|---|---|
| PROCUREMENT_FINANCING | 代采服务 | 金融助手代客户采购并管理付款、入库、销售及结算 | 采购金额、入库数量、销售金额、资占金额 |
| STORAGE_SALES | 代储代销 | 金融助手持有或控制货权，承担仓储及销售过程管理，通过商品销售及回款实现资金退出和收益 | 库存货值、库龄、货值波动、销售进度、应收回款、毛利 |

两种模式本质均为货押业务。业务模式为项目级必填字段，同一项目原则上只允许一个主模式；发生模式变更时必须保留变更记录和生效日期。

### 8.4 平台标准值

首期标准值：

| 编码 | 名称 | 备注 |
|---|---|---|
| FIN_ASSISTANT | 金融助手 | 当前权威系统 |
| OPS_ASSISTANT | 运营助手 | 来源/业务平台 |
| JUSHUITAN | 聚水潭 | 来源/业务平台 |
| NO_WAREHOUSE | 无仓 | 业务模式，不建议与来源系统混用 |
| PURCHASE_RETURN | 采退 | 业务类型，不建议与平台混用 |
| OTHER | 其他 | 必须填写说明 |

实施时应将“来源系统”“仓储模式”“业务类型”拆为独立字段，不能继续共用一个平台字段。

### 8.5 款项类型

| 编码 | 中文值 | 默认资金方向 | 默认资金占用影响 |
|---|---|---|---|
| PURCHASE_PAYMENT | 采购付款 | OUT | 增加占用 |

### 8.6 场景

| 编码 | 中文值 | 说明 |
|---|---|---|
| ACTUAL | 实际 | 正式业务数据 |
| FORECAST | 预测 | 计划付款、预计回款等 |
| SIMULATION | 试算 | 临时测算，不进入正式报表 |

### 8.7 差异类型与状态

差异类型：`COVERAGE/数据覆盖`、`MASTER_DATA/主数据`、`QUANTITY/数量`、`AMOUNT/金额`、`METRIC/指标`、`STATUS/状态`、`TIMING/时间差`、`POLICY/口径差异`。

差异状态：`OPEN/待处理`、`INVESTIGATING/核查中`、`PENDING_APPROVAL/待审批`、`RESOLVED/已解决`、`CLOSED/已关闭`、`WAIVED/已豁免`。

原因分类：Excel 缺失、Excel 多出、时间差、口径差异、映射差异、系统疑似缺失、系统疑似错误、人工调整、重复记录、原始单据异常、其他。

### 9.1 项目完结校验

项目从 `PENDING_CLOSE` 转为 `COMPLETED` 时，默认要求：

```text
未入库数量 = 0
AND 库存数量 = 0（或存在已审批豁免）
AND 应收未回 = 0（或存在已审批豁免）
AND 保证金未结 = 0（或存在已审批豁免）
AND 待处理重大差异 = 0
AND 待确认费用 = 0
```

最终完结条件需业务确认。

## 15. 计算公式

本章公式均以金融助手已确认/已锁定数据为输入。Excel 公式只作为参考。

### 15.1 通用统计条件

下文所有 `SUM` 默认附加：

```text
record_status IN ('CONFIRMED', 'LOCKED')
AND is_deleted = false
AND scenario_type = 查询场景
AND report_date BETWEEN 查询开始日期 AND 查询结束日期
AND 满足当前用户数据权限
AND 满足页面筛选条件
```

### 15.2 日初资金占用

```text
当日日初资金占用 = 前一自然日已确认日末资金占用
```

首日处理：

```text
若存在经确认期初余额：使用期初余额
否则：取查询开始日前最近一个已锁定日末余额
若仍不存在：不得默认置 0，应提示“缺少期初余额”
```

### 15.3 单笔业务对资金占用的影响

建议使用配置表 `fund_occupancy_effect`，不要在代码内硬编码。

```text
占用影响金额 = amount × occupancy_sign
```

其中 `occupancy_sign`：增加占用为 `+1`，减少占用为 `-1`，不影响为 `0`。

首期建议值：

| 款项类型 | occupancy_sign | 状态 |
|---|---:|---|
| 采购付款 | +1 | 建议确认 |
| 费用支出 | +1 | 建议确认 |
| 采购退款 | -1 | 建议确认 |
| 销售回款 | -1 | 建议确认 |
| 销售退款 | +1 | 建议确认 |
| 支付保证金 | -1 | 来自 Excel 参考口径，**待业务确认** |
| 收取/退回保证金 | 待配置 | **待业务确认** |
| 上下游返利 | 待配置 | **待业务确认** |

### 15.4 日末资金占用

通用公式：

```text
日末资金占用
= 日初资金占用
+ SUM(当日所有已确认业务的占用影响金额)
+ SUM(当日已确认资金占用调整金额)
```

按 Excel 参考字段展开：

```text
日末资金占用
= 日初资金占用
+ 采购付款
+ 费用支出
- 保证金影响
- 采购退款
- 销售回款
± 已审批调整
```

注意：展开式中的保证金方向尚未确认，生产实现必须以配置表为准。

### 15.5 资金收益

Excel 参考公式：

```text
日资金收益 = 日末资金占用 ÷ 10,000 × 2.5
```

标准系统公式：

```text
日资金收益 = 计费资金占用 ÷ rate_unit_amount × company_daily_rate
```

参数说明：

| 参数 | Excel 参考值 | 正式要求 |
|---|---:|---|
| rate_unit_amount | 10,000 元 | 参数化，默认 10,000 |
| company_daily_rate | 2.5 | 单位推测为元/万元/天，待财务确认 |
| 计费资金占用 | 日末资金占用 | 期初/期末/日均口径待确认 |

若日末资金占用为负，是否产生负收益或按 0 计费，**待财务确认**。上线前不得自行选择。

### 15.6 财务成本

Excel 参考公式：

```text
日财务成本 = 日末资金占用 ÷ 10,000 × 2
```

标准系统公式：

```text
日财务成本 = 计费资金占用 ÷ rate_unit_amount × finance_daily_rate
```

`finance_daily_rate` 的 Excel 参考值为 2，单位、适用项目和负余额处理待确认。费率必须按项目/BU/资金来源和有效期取值。

### 15.7 资金项目预计收益

Excel 字段名为“项目预计毛利”，其公式实际是资金收益差额：

```text
资金项目预计收益 = 日资金收益 - 日财务成本
累计资金项目预计收益 = SUM(期间每日资金项目预计收益)
```

为避免与商品销售毛利混淆，系统字段建议命名为 `funding_spread_income/资金利差收益`，不建议继续叫“项目预计毛利”。

### 15.8 采购金额

```text
采购金额 = ROUND((采购数量 - 采购退货数量) × 采购单价, 2)
```

若采购退货单独形成负向业务记录，则原采购金额不减退货数量，报表使用：

```text
净采购金额 = SUM(采购确认金额) - SUM(采购退货确认金额)
```

两种模式只能选择一种，建议使用独立退货流水。

### 15.9 销售金额

```text
销售金额 = ROUND(销售数量 × 销售单价, 2)
```

销售退款/退货必须使用独立负向业务记录，不直接修改历史出货数量。

### 15.10 销售成本

一期如沿用原表：

```text
销售成本 = ROUND(销售数量 × 成本单价, 2)
```

正式系统需确认成本法：批次成本、移动加权平均、先进先出或指定成本。成本单价必须由库存成本模块产生，手工调整需审批。

### 15.11 商品毛利额

```text
商品毛利额 = 销售金额 - 销售成本
```

若报表需要“扣仓储毛利”，单独定义：

```text
扣仓储毛利 = 销售金额 - 销售成本 - 仓储费
```

页面必须明确展示使用哪一种，不能都叫“毛利”。首期驾驶舱“业务毛利”默认使用未扣各项期间费用的商品毛利额。

### 15.12 毛利率

```text
毛利率 = 商品毛利额 ÷ 销售金额
```

边界处理：

```text
若销售金额 = 0，则毛利率 = NULL，并显示“—”
不得返回 0%，避免误判为无毛利
```

### 15.13 仓储费

Excel 参考公式：

```text
仓储费 = 销售数量 × 仓储单价 × ROUNDUP((打款日期 - 采购日期) ÷ 30, 0)
```

该公式存在问题：打款日期不等同出库日期，且按整月向上取整。标准公式待仓储业务确认。建议配置为：

```text
仓储费 = 计费数量 × 仓储费率 × 计费周期数
计费周期数 = CEILING(计费天数 ÷ 周期天数)
```

需确认：起算日期、截止日期、免费期、周期天数、是否按自然月、部分退货和无仓项目处理。

### 15.14 库存数量

按项目、SKU、仓库、批次统计：

```text
库存数量
= SUM(入库数量)
+ SUM(销售退回入库数量)
- SUM(出库数量)
- SUM(采购退货出库数量)
- SUM(报损数量)
± SUM(已审批库存调整数量)
```

原 Excel 简化公式：`库存 = 入库数量 - 已出库数量`，系统不得忽略退货、报损和调整。

### 15.15 未入库数量

```text
未入库数量 = 净采购数量 - 累计有效入库数量 - 已取消未执行数量
```

不得将空白入库数量当成已全部入库。若结果小于 0，生成“超入库”异常。

### 15.16 库存成本/库存价值

一期原表参考：

```text
库存成本 = 库存数量 × 采购单价
```

正式系统：

```text
库存价值 = SUM(各库存批次数量 × 对应单位成本)
```

若采用移动加权平均：

```text
入库后移动平均成本
= (入库前库存金额 + 本次入库金额) ÷ (入库前库存数量 + 本次入库数量)
```

成本法需财务确认，一经启用不得随意切换；切换需版本、生效日期和历史影响评估。

### 15.17 今日提货价

Excel 参考公式：

```text
资金占用加价 = 占用天数 × 日资金费率 × (采购单价 ÷ 10,000)
候选价 = 采购单价 + 资金占用加价
最低价 = 采购单价 × 1.002
今日提货价 = ROUND(MAX(候选价, 最低价), 2)
```

标准系统公式：

```text
提货参考价(as_of_date)
= ROUND(MAX(
    采购单位成本 + 占用天数 × 采购单位成本 ÷ rate_unit_amount × 适用日资金费率,
    采购单位成本 × 最低加价系数
  ), 2)
```

参数 `最低加价系数=1.002` 和日资金费率均来自 Excel 参考，待确认。必须传入 `as_of_date`，不得使用数据库当前日期或前端当前日期隐式计算。

### 15.18 资占天数

禁止使用不可复现的 `TODAY()`。标准定义：

```text
资占天数 = DATEDIFF(占用起始日期, 计算截止日期) + 首尾日调整值
```

计算截止日期：

- 已全部回款：最后一笔覆盖该占用的回款日期；
- 未全部回款：用户选择的报表截止日期；
- 预测场景：预测截止日期。

首尾是否都计入（Excel 为 `+1`）及自然日/工作日口径待确认。

### 15.19 回款周转天数

Excel 存在 `收款金额 × 周转天数` 的加权计算。建议系统口径：

```text
单笔回款周转天数 = 回款日期 - 对应占用起始日期 + 首尾日调整值

加权回款周转天数
= SUM(单笔回款金额 × 单笔回款周转天数)
 ÷ SUM(单笔回款金额)
```

若总回款金额为 0，返回 `NULL`。回款与采购/销售的匹配规则必须明确：逐笔指定、先进先出或项目级加权，待业务确认。

### 15.20 应收未回

```text
应收未回 = 已确认销售应收金额 - 已匹配销售回款 - 已确认销售退款 - 已确认坏账/折让调整
```

不得简单使用“销售订单金额 - 全部收款金额”，因为保证金、其他收款不能自动冲减应收。

### 15.21 保证金未结余额

```text
保证金未结余额
= 保证金初始确认金额
- 已释放金额
- 已退回金额
- 已抵扣金额
- 已扣除金额
± 已审批调整
```

按收取与支付两个方向分别统计，驾驶舱需要明确展示“应收保证金”“应退保证金”“已付保证金”等具体口径，不建议只显示一个含义不清的余额。

### 15.22 项目业务收入

原 Excel 的业务收入等同商品毛利：

```text
业务收入（Excel参考） = 销售订单金额 - 对应成本
```

该命名易与会计收入混淆。系统建议：

- `sales_revenue/销售收入` = 销售金额；
- `gross_profit/商品毛利` = 销售金额 - 销售成本；
- 不再使用含义不清的“业务收入”，或由财务给出正式定义。

### 15.23 项目净利润

Excel 参考：

```text
项目净利润 = 业务收入 - 财务成本 - 仓储成本 - 系统成本
```

但 Excel 另有税务成本列，公式样例未扣税务成本。建议标准公式：

```text
项目净利润
= 商品毛利
- 财务成本
- 仓储成本
- 系统成本
- 税务成本
- 其他项目费用
+ 已确认上游返利
- 已确认下游返利
± 已审批利润调整
```

税务成本、返利及额外费用是否纳入净利润必须由财务确认。页面需展示利润构成，不能只展示结果。

### 15.24 公司收益

Excel 参考公式：

```text
公司收益 = 对应成本 ÷ 10,000 × 日资金费用率 × 周转天数
```

该指标可能与资金收益重复或代表业务收费，应确认正式名称、计费基数、费率、起止日期及是否含税。确认前只在口径管理中显示为“待定义指标”，不进入正式驾驶舱。

### 15.25 货押本金余额

项目维度：

```text
货押本金余额
= 累计已确认资金投放
- 累计已确认本金回收
- 已确认本金冲销
± 已审批本金调整
```

- 代采服务的资金投放通常为代采付款；
- 代储代销的资金投放通常为形成货权的采购成本及经确认的必要占用；
- 收益、费用、保证金和本金必须分账，不得用全部回款直接冲减本金；
- 本金回收分配顺序及回款匹配规则需财务确认。

### 15.26 押品基础货值与合格押品价值

单批次押品基础货值：

```text
押品基础货值 = 可控库存数量 × 经审批押品估值单价
```

单批次合格押品价值：

```text
合格押品价值
= 押品基础货值
× 货权控制系数
× 品类折扣率
× 库龄折扣率
× 质量/可售状态系数
```

项目合格押品价值：

```text
项目合格押品价值 = SUM(项目下所有有效押品批次的合格押品价值)
```

参数规则：

- 货权凭证不完整、不可定位或已被质押给第三方时，货权控制系数应为 0；
- 已销售/已出库商品不得继续计入库存押品；
- 超龄、残损、冻结、退货待检等商品按规则降低折扣率或排除；
- 押品估值单价应采用经审批的成本价、市场价或二者孰低规则，具体口径待风控和财务确认；
- 估值必须保存估值日期、价格来源和参数版本。

### 15.27 押品覆盖率

项目押品覆盖率：

```text
项目押品覆盖率 = 项目合格押品价值 ÷ 项目货押本金余额
```

边界处理：

- 本金余额大于 0 时正常计算；
- 本金余额等于 0 时返回 `NULL`，页面显示“—”；
- 合格押品为 0 且本金大于 0 时，覆盖率为 0%；
- 预警线、补保线和处置线均由参数中心按业务模式、品类或项目配置，原型使用的 110% 仅为演示值。

组合覆盖率：

```text
组合押品覆盖率 = SUM(项目合格押品价值) ÷ SUM(项目货押本金余额)
```

组合覆盖率不能代替单项目风险判断，禁止用某项目超额押品抵消另一项目不足，除非存在合法、明确且已审批的交叉担保安排。

### 15.28 风险敞口

项目风险敞口：

```text
项目风险敞口 = MAX(项目货押本金余额 - 项目合格押品价值, 0)
```

组合风险敞口：

```text
组合风险敞口 = SUM(各项目风险敞口)
```

因此，即使组合押品覆盖率大于 100%，只要部分项目覆盖不足，组合风险敞口仍可能大于 0。

如后续将受控销售应收、保证金或其他增信计入保障，应分别展示：

```text
综合保障价值 = 合格押品价值 + 合格受控应收价值 + 合格保证金价值 + 其他合格增信
综合风险敞口 = MAX(货押本金余额 - 综合保障价值, 0)
```

“押品覆盖率”和“综合保障覆盖率”必须分开展示，不能混用。

### 15.29 代储代销销售进度

```text
可售库存数量 = 合格入库数量 - 已销售出库数量 - 不可售数量
销售进度 = 累计已销售出库数量 ÷ 累计合格入库数量
库存周转天数 = 统计期平均库存成本 ÷ 统计期销售成本 × 统计期天数
```

当累计合格入库数量或销售成本为 0 时，对应比例/天数返回 `NULL`。

### 15.30 《报表说明》三张报表计算口径

以《报表说明.xlsx》中三张工作表的批注/文本框说明为口径依据。产品类型统一使用“代采服务”和“代储代销”。

#### 15.30.1 采购与库存

```text
采购总额 = ROUND(采购单价 × 采购数量, 2)
实际总额 = ROUND(采购单价 × 入库数量, 2)
未入库数量 = 采购数量 - 入库数量
入库率 = 入库数量 ÷ 采购数量
```

- 业务名称：代采（预付）取协议名称，代采（先货）取“付款日期+供应商名称”，代储取“审批通过日期+供应商名称”。
- 业务编号：代采（预付）取协议编号，代采（先货）取确认编号，代储取批次编号。
- 订单编号：代采取采购订单编号，代储取代储编号。
- 采购单价：代采取付款金额；代储取评估单价×比例。
- 采购数量为 0 时，入库率返回 `NULL`；未入库数量小于 0 时生成“超入库”异常。

#### 15.30.2 销售与出库

```text
销售金额 = 销售支付的总金额
成本金额 = ROUND(销售数量 × 采购单价, 2)
业务收入 = 销售金额 - 成本金额
周转天数 = DATEDIFF(采购付款时间, 销售支付时间) + 1
资金成本 = 周转天数 × 成本金额 × 日财务费率
系统成本 = 周转天数 × 成本金额 × 年系统费率 ÷ 360
税务成本 = 业务收入 ÷ (1 + 税率) × 税率
仓储成本 = 成本单价 × 周转天数 ÷ 30 × 台数
净利润 = 业务收入 - 资金成本 - 仓储成本 - 系统成本
```

- 业务名称/编号沿用采购与库存的代采/代储映射规则。
- 采购单号取销售关联的采购单号或代储单号。采购单价取对应采购单价；代储为评估单价×比例。
- 采购付款时间取采购付款时间；代储取支付保证金时间。
- 日财务费率、年系统费率、税率和代储评估比例必须参数化并绑定生效版本。
- 按当前说明，税务成本单独展示，不进入净利润扣减项；如后续调整，需财务确认并升级口径版本。

#### 15.30.3 项目资金台账（资产总览）

```text
入库数量 = SUM(实际入库数量)
付款总金额 = SUM(实际付款金额)
销售数量 = SUM(项目下销售明细.销售数量)
销售总金额 = SUM(销售单价 × 销售数量)
库存货值 = 剩余库存 × 采购金额（截图原文）
剩余成本金额 = 采购金额 - 成本金额
业务收入 = SUM(销售明细.业务收入)
资金/系统/税务/仓储成本 = SUM(销售明细.对应成本)
净收入 = SUM(销售明细.净利润)
周转天数 = SUM(单笔回款金额 × 单笔周转天数) ÷ SUM(回款金额)
```

- 项目状态：采购数量=销售数量且不为 0 时为“完成”；入库数量>0 且未完成时为“执行中”；入库数量=0 时为“待执行”。
- 项目名称：代采取协议名称；代储取“审批日期+供应商名称”。
- 项目编号：代采取批次号和确认编号；代储取批次编号。
- 业务归属人：代采取采购时业务归属人；代储取审核时业务归属人。
- 保证金、返利金额无值时显示 0。周转天数分母为 0 时返回 `NULL`。
- “剩余库存×采购金额”在量纲上存在歧义，需确认此处“采购金额”是指采购单价还是其他单位金额；确认前 PRD 保留原文，开发不得自行替换。
- `资占金额` 在当前截图中未显示完整说明，暂沿用第 15.3—15.4 节的资金占用影响汇总口径。

```text
同比增长率 = (本期值 - 上年同期值) ÷ ABS(上年同期值)

```

### 16.2 数据健康度

建议采用规则通过率，不使用人工主观打分：

```text
数据健康分
= 100 × SUM(规则权重 × 规则通过率) ÷ SUM(规则权重)
```

规则通过率：

```text
规则通过率 = 1 - 异常记录数 ÷ 应检查记录数
```

当应检查记录数为 0，该规则不进入分母。重大规则可设置更高权重，但权重需在规则中心可查。

## 22. 导出要求

- 支持当前筛选结果导出；
- 导出采用异步任务；
- 文件包含报表名称、统计期间、场景、数据截止时间、参数版本、筛选条件和导出人；
- 敏感字段按当前用户字段权限处理；
- Excel 核对值只能在差异中心导出，不能混入正式经营报表；
- 建议文件水印：`金融助手数据｜导出人｜导出时间`。

## 24. 非功能需求

### 24.1 性能

- 驾驶舱 P95 ≤ 3 秒；
- 10 万行内明细分页 P95 ≤ 5 秒；
- 超过 5,000 行导出走异步任务；
- 前端不一次性加载全量明细。

### 24.2 安全

- 全链路 HTTPS；
- 敏感字段加密存储或脱敏；
- 权限服务端校验，不能只在前端隐藏；
- 导出权限和查看权限分离；
- 已锁定期间修改需二次审批。

### 24.3 可用性

- 所有金额显示单位；
- 负数使用负号及风险颜色，但颜色不能成为唯一信息；
- 空值显示“—”，零显示“0”；
- 图表提供可访问的表格或文本摘要；
- 页面保留筛选条件和分页状态。

## 25. 验收标准

### 25.1 数据源验收

1. 驾驶舱和五类报表均只读取金融助手正式数据；
2. Excel 数据仅出现在差异中心，并有明确“核对来源”标签；
3. 删除 Excel 核对文件不影响正式报表计算；
4. Excel 值不得通过普通导入覆盖已确认系统记录。

### 25.2 公式验收

至少覆盖：

- 同日多笔采购付款和销售回款；
- 部分采购退款、部分销售退款；
- 保证金收付和释放；
- 部分入库、部分出库、采购退货、销售退货、报损；
- 负资金占用；
- 销售金额为 0；
- 负毛利；
- 费率跨版本生效；
- 期初余额缺失；
- 未来日期实际数据；
- 已确认记录冲销；
- 已锁定期间调整；
- 相同来源单据重复接入。

### 25.3 报表勾稽验收

```text
采购库存出库数量 = 出货销售数量 ± 已解释差异
项目销售金额 = 出货销售金额 ± 已解释差异
项目销售成本 = 出货成本金额 ± 已审批调整
商品毛利 = 销售金额 - 销售成本
库存数量 = 入库 + 销退 - 出库 - 采退 - 报损 ± 调整
本日期初资金占用 = 前一日期末资金占用
项目净利润 = 利润构成项合计
```

金额容差默认 0.01 元，数量容差根据计量单位配置。所有超容差结果必须生成校验失败或差异记录。
