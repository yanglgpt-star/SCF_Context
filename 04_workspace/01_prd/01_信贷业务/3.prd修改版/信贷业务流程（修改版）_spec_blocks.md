## SB-01 客户管理列表

### 基础信息
- **页面名称**：客户管理列表
- **页面路径**：信贷业务 → 客户管理
- **角色权限**：平台运营

### Goal
平台运营人员能够通过搜索、筛选、分页查看企业客户信息，并执行新增、编辑、详情、启用/禁用、删除等操作。

### Scope
- 包含：客户列表展示、搜索筛选、分页、操作入口
- 不包含：客户财务信息的编辑（在详情页中管理）

### 搜索/筛选条件

| 字段名称 | 类型 | 占位文案 | 交互规则 |
|----------|------|----------|----------|
| 企业主体名称 | 文本输入 | 请输入 | 支持模糊搜索 |
| 统一社会信用代码 | 文本输入 | 请输入 | 支持模糊搜索 |
| 企业状态 | 下拉选择 | 请选择 | 枚举：启用、禁用 |
| 企业类型 | 下拉选择 | 请选择 | 枚举：资金方、核心企业、融资企业、监管企业、仓储企业、平台方 |

**按钮**：重置（次要）、搜索（主要）、新增（主要）

### 表格字段

| 字段名称 | 示例数据 | 对齐方式 | 说明 |
|----------|----------|----------|------|
| 企业主体名称 | 醒市技术 | 左对齐 | 企业全称 |
| 统一社会信用代码 | 134532 | 左对齐 | 企业唯一标识 |
| 企业简称 | 醒市 | 左对齐 | 简称展示 |
| 企业状态 | 启用 | 居中 | 状态标签：启用（绿色）、禁用（灰色） |
| 企业类型 | 资金方、核心企业 | 左对齐 | 多选用逗号分隔 |
| 创建时间 | 2026-03-15 | 居中 | `YYYY-MM-DD` |
| 操作 | - | 居中 | 详情、编辑、删除、启用/禁用 |

### 操作按钮规则

| 按钮 | 展示条件 | 交互说明 |
|------|----------|----------|
| 详情 | 所有状态 | 点击进入客户详情页 |
| 编辑 | 所有状态 | 点击进入编辑弹窗 |
| 删除 | **仅禁用状态** | 二次确认弹窗："是否删除客户信息"，确认后删除 |
| 启用 | 禁用时显示 | 点击切换为启用状态 |
| 禁用 | 启用时显示 | 点击切换为禁用状态 |

### 交互规则
- 删除仅对禁用状态客户可用
- 切换启用/禁用状态无需二次确认（若需确认，待补充）
- 客户编码规则：`KHGL` + 年月日 + 8位随机码（26字母+0~9）

### 验收标准
- ✅ 打开页面默认展示全部客户，按创建时间倒序排列
- ✅ 输入"醒市"点击搜索，列表仅显示企业主体名称包含"醒市"的数据
- ✅ 企业状态为"启用"时，操作列显示"禁用"按钮；为"禁用"时显示"启用"+"删除"按钮
- ✅ 点击"删除"弹出确认框，点击确认后该条数据从列表移除，刷新列表
- ✅ 分页默认10条，可切换为20条、50条

### Non-Goals
- 本次不包含批量导入/导出客户功能
- 不包含客户财务信息在列表中的展示与编辑

## SB-02 新增/编辑客户

### 基础信息
- **页面名称**：新增/编辑客户
- **页面路径**：客户管理列表 → 新增/编辑
- **交互形式**：弹窗/抽屉（推荐弹窗）

### Goal
平台运营人员能够录入或修改客户的基础信息、营业执照、法人信息、联系人信息。

### Scope
- 包含：基础信息、营业执照上传、法人信息、联系人信息
- 不包含：银行信息、开票信息（在客户详情页中管理）

### 表单字段

#### 基础信息

|----------|------|------|--------|----------|------|
| 企业名称 | 下拉选择 | 是 | - | - | 支持模糊搜索，选择后自动带出相关信息 |
| 客户编码 | 文本显示 | - | 自动生成 | 不可编辑 | `KHGL`+年月日+8位随机码 |
| 统一社会信用代码 | 文本输入 | 是 | 自动带出 | - | 选择企业后自动带出，可修改 |
| 企业简称 | 文本输入 | 是 | 自动带出 | - | 选择企业后自动带出，可修改 |
| 注册资本 | 文本输入 | 否 | 自动带出 | - | 选择企业后自动带出，可修改 |
| 企业类型 | 下拉多选 | 是 | - | 枚举值 | 资金方、核心企业、融资企业、监管企业、仓储企业、平台方 |
| 办公地址 | 文本输入 | 否 | - | - | 手动填写 |
| 注册地址 | 文本输入 | 否 | 自动带出 | - | 选择企业后自动带出，可修改 |
| 联系电话 | 文本输入 | 否 | - | 手机号格式 | 手动输入 |
| 成立日期 | 日期选择 | 否 | 自动带出 | - | 选择企业后自动带出，可修改 |
| 创建人 | 文本显示 | - | 当前登录人 | 不可编辑 | 默认当前登录用户 |
| 企业状态 | 单选 | 是 | 启用 | - | 启用/禁用，默认启用 |
| 创建日期 | 日期显示 | - | 当前日期 | 不可编辑 | `YYYY-MM-DD` |
| 主营信息 | 文本输入 | 否 | - | - | 手动填写 |

#### 营业执照

| 字段名称 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| 营业执照 | 文件上传 | 否 | 上传图片，支持jpg、png格式 |

#### 法人信息

| 字段名称 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|----------|------|------|--------|----------|------|
| 法人姓名 | 文本输入 | 是 | 自动带出 | - | 选择企业后自动带出，可修改 |
| 证件类型 | 下拉选择 | 是 | 身份证 | 枚举：身份证、其他 | - |
| 证件号码 | 文本输入 | 是 | - | 身份证格式校验 | 证件类型为身份证时校验格式 |
| 联系电话 | 文本输入 | 是 | - | 手机号格式校验 | 手动输入 |
| 法人证件正反面 | 文件上传 | 否 | - | - | 上传图片，支持jpg、png格式 |

| 字段名称 | 类型 | 必填 | 校验规则 | 说明 |
|----------|------|------|----------|------|
| 联系人姓名 | 文本输入 | 否 | - | 手动输入 |
| 联系人电话 | 文本输入 | 否 | 手机号格式校验 | 手动输入 |
| 证件类型 | 下拉选择 | 否 | 枚举：身份证、其他 | - |
| 证件号码 | 文本输入 | 否 | 身份证格式校验 | 手动输入 |
| 联系人证件正反面 | 文件上传 | 否 | - | 选择图片上传 |

### 操作按钮
- **保存**（主要按钮）：校验必填项，通过后保存数据，关闭弹窗，刷新列表
- **取消**（次要按钮）：关闭弹窗，不保存数据

### 验收标准
- ✅ 选择企业名称后，统一社会信用代码、企业简称、注册资本、注册地址、成立日期、法人姓名自动填充
- ✅ 未填必填项点击保存，对应字段下方显示红色提示"请输入/选择{字段名}"
- ✅ 输入错误手机号格式，提示"请输入正确的手机号"
- ✅ 保存成功后关闭弹窗，列表自动刷新并显示新数据
- ✅ 编辑时客户编码不可修改，其他可编辑字段可正常修改

### Non-Goals
- 不包含企业名称的实时工商校验接口
- 不包含营业执照OCR识别自动填充

## SB-03 客户详情

### 基础信息
- **页面名称**：客户详情
- **页面路径**：客户管理列表 → 详情
- **页面形式**：独立详情页

### Goal
平台运营人员能够查看客户的完整信息，包含主体信息和财务信息，并支持编辑主体信息和管理银行/开票信息。

### Scope
- 包含：主体信息展示、银行信息管理、开票信息管理
- 不包含：删除客户（在列表页操作）

### 页面结构
- **标签页**：主体信息 | 财务信息

### 主体信息
展示字段同【SB-02 新增/编辑客户】，只读展示，支持点击编辑进入编辑状态。

### 财务信息 — 银行信息

| 字段名称 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| 账户名称 | 文本输入 | 是 | 企业名称，不能修改 |
| 开户行 | 文本输入 | 是 | 手动填写 |
| 银行账号 | 文本输入 | 是 | 手动填写 |
| 开户行号 | 文本输入 | 否 | 手动填写 |
| 是否默认 | 单选 | 是 | 默认否 |
| 状态 | 单选 | 是 | 默认启用 |
| 备注 | 文本输入 | 否 | 手动填写 |

**操作规则**：
- 新增：弹框显示填写内容
- 编辑：禁用状态下显示按钮，点击后进入编辑
- 删除：禁用状态下显示按钮，提示"是否删除银行账号"
- 启用/禁用：状态切换

### 财务信息 — 开票信息

| 字段名称 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| 开票类型 | 下拉选择 | 是 | 下拉选择枚举值 |
| 抬头名称 | 文本输入 | 是 | 企业名称，不能修改 |
| 纳税人识别号 | 文本输入 | 是 | 手动填写 |
| 开户银行 | 文本输入 | 是 | 手动填写 |
| 开户银行账号 | 文本输入 | 是 | 手动填写 |
| 电话 | 文本输入 | 是 | 手动输入 |
| 地址 | 文本输入 | 是 | 手动输入 |
| 是否默认 | 单选 | 是 | 单选，默认否 |
| 状态 | 单选 | 是 | 单选，默认启用 |

### 验收标准
- ✅ 点击"详情"进入详情页，默认显示"主体信息"标签
- ✅ 主体信息页展示客户所有基础、法人、联系人信息，与新增时字段一致
- ✅ 切换到"财务信息"标签，展示银行信息列表和开票信息列表
- ✅ 银行信息/开票信息的操作按钮（编辑、删除、启用/禁用）按状态正确显示
- ✅ 银行信息列表中"是否默认"为"是"的条目有标识或置顶

### Non-Goals
- 不包含银行账号的联行号实时查询接口
- 不包含开票信息的税务校验接口

## SB-04 准入管理列表

### 基础信息
- **页面名称**：准入管理列表
- **页面路径**：信贷业务 → 准入管理
- **角色权限**：平台运营

### Goal
平台运营人员能够管理客户准入申请，查看准入状态，执行新增、编辑、删除、审核操作。

### 搜索/筛选条件

| 字段名称 | 类型 | 占位文案 | 交互规则 |
|----------|------|----------|----------|
| 客户准入编码 | 文本输入 | 请输入 | 模糊搜索 |
| 企业名称 | 文本输入 | 请输入 | 模糊搜索 |
| 统一社会信用代码 | 文本输入 | 请输入 | 模糊搜索 |
| 准入状态 | 下拉选择 | 请选择 | 枚举：未提交、审核中、已拒绝、已通过、已退回 |

**按钮**：重置（次要）、搜索（主要）、新增（主要）

### 表格字段

| 字段名称 | 示例数据 | 对齐方式 | 说明 |
|----------|----------|----------|------|
| 客户准入编码 | KHZR234567654 | 左对齐 | 准入唯一标识 |
| 企业名称 | 能良技术 | 左对齐 | - |
| 统一社会信用代码 | 1345342 | 左对齐 | - |
| 法人姓名 | 张三 | 左对齐 | - |
| 准入状态 | 已拒绝 | 居中 | 状态标签 |
| 平台审核状态 | 已通过 | 居中 | 审核状态标签 |
| 提交时间 | 2025-01-12 16:58 | 居中 | 日期时间格式 |
| 操作 | - | 居中 | 详情、审核、编辑、删除 |

### 准入状态定义

| 状态值 | 说明 | 流转条件 |
|--------|------|----------|
| 未提交 | 申请已创建但未提交 | 创建后默认状态 |
| 审核中 | 已提交，正在审核 | 提交后进入 |
| 已拒绝 | 申请被拒绝 | 审核不通过 |
| 已通过 | 申请已通过 | 审核通过 |
| 已退回 | 申请被退回修改 | 审核退回 |

### 平台审核状态定义

| 状态值 | 说明 |
|--------|------|
| 待审核 | 等待平台审核 |
| 审核中 | 正在审核中 |
| 已退回 | 审核退回修改 |
| 已通过 | 审核通过 |
| 已拒绝 | 审核拒绝 |

### 操作按钮规则

| 按钮 | 展示条件 | 交互说明 |
|------|----------|----------|
| 审核 | 准入状态为"审核中" | 点击进入审核页面 |
| 编辑 | 未提交、已退回 | 点击进入编辑弹窗 |
| 删除 | 未提交、已退回 | 二次确认后删除 |

### 准入与客户管理关系
1. 准入审批通过后，信息自动同步到客户管理，客户类型为"融资方"
2. 客户管理新增客户后，准入管理不能再新增同一客户（统一社会信用代码唯一）
3. 准入审核拒绝后，客户管理可以新增同一客户；审核通过和驳回都不能新增

### 验收标准
- ✅ 列表按提交时间倒序排列
- ✅ 准入状态为"审核中"时，操作列显示"审核"按钮
- ✅ 准入状态为"未提交"或"已退回"时，显示"编辑"和"删除"按钮
- ✅ 删除准入申请后，列表刷新，该条数据消失
- ✅ 准入审批通过后，客户管理列表自动增加对应企业

### Non-Goals
- 不包含风控自动审核（预留接口）
- 不包含多级审核流程的灵活配置

## SB-05 新增/编辑准入申请

### 基础信息
- **页面名称**：新增/编辑准入申请
- **页面路径**：准入管理列表 → 新增/编辑
- **交互形式**：弹窗/抽屉

### Goal
平台运营人员能够录入或修改客户准入申请信息，保存草稿或提交审核。

### 表单字段

#### 基础信息

| 字段名称 | 类型 | 必填 | 默认值 | 说明 |
|----------|------|------|--------|------|
| 企业名称 | 下拉选择 | 是 | - | 支持模糊搜索，选择后自动带出相关信息 |
| 准入编码 | 文本显示 | - | 自动生成 | 规则：`ZRGL`+年月日+8位随机码 |
| 统一社会信用代码 | 文本输入 | 是 | 自动带出 | 可修改 |
| 企业简称 | 文本输入 | 是 | 自动带出 | 可修改 |

## SB-15 还款审核

### 基础信息
- **页面名称**：还款审核
- **页面路径**：还款管理列表 → 审核
- **页面形式**：审批页面（左右分栏布局）

### Goal
平台运营人员能够查看还款申请详情并执行审核操作，确认还款完成后恢复额度。

### 页面布局
- **左侧**：还款申请详情（只读展示）
  - 还款基础信息（还款申请编号、融资申请编号、企业名称、融资金额、已还金额、剩余应还金额）
  - 还款明细信息（本次还款金额、还款日期、还款方式、还款账户、还款凭证预览）
  - 附件信息（预览、下载）
- **右侧**：审批操作区域

### 审批意见

| 字段名称 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| 审批意见 | 文本输入 | 是 | 必填 |

### 审批记录
显示历史审批记录列表，字段：审批时间、审批人、审批状态、审批意见。

### 审核规则

**审核通过**：
1. 还款状态更新为"已通过"
2. 平台审核状态更新为"已通过"
3. 循环额度情况下恢复授信额度
4. 更新融资申请的已还金额和剩余应还金额
5. 如全部还清，更新融资状态为"已结清"

**审核拒绝**：
1. 还款状态更新为"已拒绝"
2. 平台审核状态更新为"已拒绝"
3. 额度不恢复
4. 可重新发起还款申请

### 操作按钮
- **返回并打回**（次要）：退回申请，状态变为"已退回"
- **拒绝**（次要）：拒绝申请，状态变为"已拒绝"
- **通过**（主要）：通过申请，还款成功，额度恢复

### 操作按钮
- **保存**（次要）：保存草稿
- **提交**（主要）：提交解押申请
- **取消**（次要）：关闭弹窗，不保存

### 解押申请规则
1. 还款审批通过后，生成解押明细，数据同步到解押数据
2. 解押申请提交后，库存监管中的解质押数量相应增加
3. 当质押数量 - 解质押数量 = 0 时，货物状态变为"已解锁"
4. 已解锁货物可在出库管理中进行出库操作

### 验收标准
- ✅ 选择关联融资申请编号后，关联订单编号、出质人、融资模式、质权人、融资比例、融资申请日期自动填充
- ✅ 质押货物信息表格中仅展示该融资申请关联的入库货物
- ✅ 本次申请解押数量 ≤ 可解押数量，超出时提示"本次申请解押数量不能超过可解押数量"
- ✅ 解押金额根据"本次申请解押数量 × 采购单价"实时计算
- ✅ 解押汇总信息中，各汇总字段根据表格数据实时计算
- ✅ 点击"提交"后，解押数据同步到库存监管，解质押数量相应增加

### Non-Goals
- 不包含解押申请的独立审核流程（默认已通过）
- 不包含解押费用的自动扣款结算

## 附录 B：计算规则

| 计算项 | 公式 | 说明 |
|--------|------|------|
| 货值总价 | 单价 × 数量 | 货物总价值 |
| 最大申请金额 | 货值总价 × 融资比例 | 基于货值可融资的最大金额 |
| 还款本金 | 提货数量 × 单价 × 融资比例 | 提取货物对应的应还本金 |
| 剩余额度 | 总额度 - 额度占用 + 还款恢复额度 | 循环额度下还款后恢复 |
| 期限（月） | (截止年 - 生效年) × 12 + (截止月 - 生效月) | 根据生效日期和截止日期计算 |
| 剩余应还金额 | 融资金额 - 已还金额 | 还需还款的金额 |
| 逾期利息 | 逾期本金 × 逾期利率 × 逾期天数 / 360 | 逾期后产生的利息 |
