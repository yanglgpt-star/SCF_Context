## 一、一句话总纲

**日结只校验，月结锁账。** 锁账后该期间**禁止任何重算、改单、作废**——只剩两条出口，**语义不同、不能互相代替**。

> 指针：原文 `§一.3`（`:70`）；`§一.5.7`（`:316`）。

## 二、期间闸门（FL-04）：**只读不修改**

引擎在过账前读 `t_document_line.period`（记账期间）+ `t_period.is_closed`（会计期间表·是否已锁账）。

⚠️ **结账锁账是运维动作，引擎只读这个标志并拒绝越界过账——引擎自己不结账。**

撞上已锁账期间的单据**不是静默丢弃**，而是按两条不能互相代替的出口分流：

| 情形 | 走哪条 |
|---|---|
| 单据本就属于该期间、当时**漏了** | **当期补录单** `PERIOD_ADJUST`（必审，按当期口径量价，原业务日期仅供追溯） |
| 上次**结账本身结错了** | **反结账**（须审批留痕，记录谁 / 何时 / 因何 / 重开哪个月，`reopen_count + 1`） |
| 两者都不是 | **拒收**，退回业务方 |

> 指针：原文 `§四.1`（`:499`–`:506`）；`§四.2`（`:1967`）。

## 三、三条路不可互换（**最常被混**）

| 路 | 什么时候用 | 语义 |
|---|---|---|
| **改单** | **未锁账** | 这笔账写错了，直接改 |
| **反结账** | 已锁账、**结错了** | 「上次那个月结错了」——须**独立权限 + 二次确认 + 填写原因 + 审计日志** |
| **当期补录单** | 已锁账、**漏了一笔** | 「这笔在原期间**从未存在**」，必审 |

⚠️ **补录是「这笔在原期间从未存在」的语义，不能用反结账代替**——混用会让**审计无法区分「错误」与「遗漏」**。

> 指针：原文 `§一.5.7`（`:319`）；`§一.5.11` 危险动作（`:348`，审计日志 `:357`）；详细设计 `3.4.3` 反结账流程 PF8（`:514`）、`5.6.8`（`:2026`）。

## 四、月结做什么

```
月结对账（数量 + 金额双维度，金额分法人层 / 合并层两段）
  → 任一段不一致 → 补单 / 调账后重新对账
  → 一致 → 月结报表定稿 + 归档 + 期间快照（余额表/收发存/跌价表/对账报告）
  → 期间锁账 is_closed = 1
```

**关账时的恒等式检验**（差额不为 0 则**阻断月结**）：

```
F12  数量守恒：期末数量 = 期初数量 + 入库合计 − 出库合计
F13  金额守恒：期末金额 = 期初金额 + 入库金额 − 出库金额 + 成本调整额
```

> 指针：原文 `§二` 流程图（`:414`–`:420`）；`§三.13` 进销存周期表（`:1299`、`:1301`）；详细设计 `3.5.6` 月末结账流程 PF14（`:680`）、`9.1` 数量对账日清（`:2759`）、`9.2` 金额对账月结（`:2774`）。

## 五、跨期补录单怎么记账

- **一律按当期口径量价**——补录出库按**当期均价**结转、建**当期成本层**；单据上保留原业务日期，但**仅用于追溯，不用于取价、不参与排序**。
- **不新增凭证模板**——套用它所补的那笔业务对应的模板（补采购入库用 `8.1.1`、补销售出库用 `8.1.2`……），**科目与方向完全一致**；区别只在**凭证来源标记** `voucher_source = PERIOD_ADJUST`。
- **必审**。

> **为什么必须按当期口径**：排序键含 `seq_in_day`（当日序号），那个序号是当天按顺序分配的，**事后无法复原**。按历史原值算——报得出来，但报的是**假数**。

> 指针：原文 `§一.4`（`:108`）；详细设计 `5.6.8`（`:2026`）、`8.1.7` 舍入差异月末结转（`:2598`）。

## 六、编号别认错（**`E-` 前缀是重载的**）

| 形态 | 是什么 | 例 |
|---|---|---|
| `E-` + **数字** | **引擎决策项 / 日结硬校验编号** | `E-02` 批次行均价一致性 · `E-07` 月结即锁账 · `E-09` 反结账须审批·留痕 · `E-10` 补录按当期口径 |
| `E-` + **单词** | **报文错误码**（14 个，过账前产生） | `E-PERIOD-CLOSED` 期间已锁账 · `E-NEGATIVE-QTY` · `E-PRICE-MISSING` |

⚠️ **两者不是一套**，别把决策编号当错误码用，也别反过来。

> 指针：原文 `§四.2`（`:1989` 错误码表）；详细设计文档头部（`:15`）、`4.3.6`（`:1672`）。

| 对象 | 说明 |
|---|---|
| `t_period`（会计期间表） | `is_closed`（是否已锁账）· `reopen_count`（反结账次数，> 0 的期间报表上要标记） |

## 八、易错点

| 易错 | 正确 |
|---|---|
| 说「引擎会结账 / 会锁账」 | **引擎只读标志、拒绝越界过账，自己不结账** |
| 说「日结就锁账」 | **日结只校验，月结才锁账** |
| 用反结账处理「漏了一笔」 | 漏了 → **当期补录单**；错误 vs 遗漏，**语义不同、不可互换** |
| 补录单按原业务日期取价 | **一律按当期口径量价**，原业务日期仅供追溯 |
| 给补录单独设一套凭证科目 | **套用对应业务模板**，科目与方向一致，只改 `voucher_source` |
| 说「一期有反结账按钮」 | **一期不设页面按钮**（原文 `:369`），但规则完整定义 |
| 把 `E-07` 当报文错误码 | `E-` + 数字 = **决策编号**；`E-` + 单词 = 报文错误码 |
| 以为「已启用期初行」也能复检 | **跳过**——期间已锁定 |
