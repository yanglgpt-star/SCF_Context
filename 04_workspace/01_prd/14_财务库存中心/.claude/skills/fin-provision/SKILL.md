## 一、两条最反直觉的硬规则（先记住）

1. **计提范围仅 `is_internal = 1`** ——外部货主（代销寄售、借入他方货物）**不提**；二级产权人**也不提**（不是会计主体）。
2. **双轨取孰高** ——同一物料同时挂库龄法（`AGE`）与 3C 上市周期法（`LAUNCH`）时，取**两套结果的最大值**入账。

> 指针：原文 `§一.3`（`:69`）；`§二` 流程图（`:406`）；详细设计 `§6.5`（`:2217`）。

---

## 二、计提维度

按 **(物料, 仓库, 批次, 一级货主)** 逐笔计算后汇总——**批次与一级货主都要下钻**。

⚠️ **为什么必须下钻到一级货主**：同一批货挂在不同法人下，跌价是**各法人自己的账**。若按 (物料, 仓库, 批次) 算完再按法人分摊，**分摊基准是拍出来的**，每个法人的跌价准备都无法独立验证。

> 指针：详细设计 `§6.1`（`:2156`）。

**库龄跟随该批次剩余数量**——某批次数量减为 0，**库龄归零**（不再参与跌价）。

## 三、库龄怎么推（**这里有个大坑**）（原文 `§三.12` `:1244`）

| 品类 | 推导口径 |
|---|---|
| 序列号管理商品（个别计价单元） | 按**单台序列号绝对天数**：`AgeDay = DATEDIFF(Now(), InTime)` |
| 标品（移动加权平均单元） | **入库批次逆向倒扣法**——从统计日倒序遍历历史采购批次、从未售结存量中依次扣减，把结存量还原到各历史入库日 |

> ⚠️ **「倒扣」是库龄推导手法，与先入先出法（成本结转方法）完全无关**——原文专门写了这句澄清（`:1244`）。别把两者说成一回事。

**库龄 = 计算日 − 物料在该仓库的最早入库日期**（详细设计 `§6.1`）。

## 四、两套档位——**别混**

### 4.1 展示用：库龄区间六桶（原文 `§三.12` `:1244`，`§三.16` `:1419`）

| 桶 |
|---|
| 0-30 天 · 31-60 天 · 61-90 天 · 91-180 天 · 181-360 天 · **360 天以上**（标红加粗） |

**仅「批次余额」页签生效**——库龄以**批次入库日**起算，另外三个页签没有批次维度。

### 4.2 计提用：比例档（详细设计 `§6.2` `:2167`，标注为**建议默认**，可在 `t_depreciation_rule` 按物料类别覆盖）

| 库龄档（`AGE`，通用品类） | 计提比例 |
|---|---|
| 0 - 180 | 0% |
| 181 - 360 | 5% |
| 361 - 720 | 30% |
| 720 以上 | 50% |

| 上市天数档（`LAUNCH`，3C 专用） | 计提比例 |
|---|---|
| 0 - 90 | 0% |
| 91 - 180 | 10% |
| 181 - 365 | 25% |
| 365 以上 | 40% |

> ⚠️ **展示六桶 ≠ 计提四档**，边界与数量都不同。**两者不是同一套划分，不要互相套用**。

## 五、公式

```
跌价金额 = Σ (库龄区间内物料金额 × 该区间计提比例)
双轨：  provision = max(provision_by_age, provision_by_launch)
本期计提 = 本期应有准备 − 上期已计提
```

⚠️ **本期计提额是「变动额」不是「应有额」**——跌价准备是**余额科目**，凭证只能记变动额；上期已计提取 `t_depreciation_result.prev_provision_amount`。**没有这一列就算不出本期该提多少。**

**上市周期只对「当期在库」数量计提，不追溯历史。**

> 指针：详细设计 `§6.3`（`:2190`）；`4.6.1` 跌价计提结果表（`:1801`，两列 `provision_by_age` / `provision_by_launch` **不合并**，报表须同时披露两套明细供审计复核）。

## 六、凭证

每月末一张，**按法人分别出**（不做集团合并出账；合并层在集团报表里另行汇总）：

```
借：资产减值损失 - 存货跌价准备
    贷：存货跌价准备
```

> 指针：详细设计 `§6.4`（`:2206`）、`8.1.6` 凭证模板（`:2589`）。

## 七、页面（原文 `§三.12 库存表` `:1208`）

- 基准：`快照基准日期`（必填，库龄推演的统计基准日）；
- 两个动作：`[重新执行库龄推导 (异步任务)]`（按基准日重跑库龄推导）、`[生成跌价计提凭证建议]`（依据测算结果生成计提凭证建议）；
- 关键列：六个库龄桶的量与额 + `provision_amount`（建议跌价准备额，橙色，= Σ(在库金额 × 跌价比例)）。

## 八、易错点

| 易错 | 正确 |
|---|---|
| 说「外部货主也要计提」 | **仅 `is_internal = 1`** |
| 说「二级产权人也计提」 | **不提**——不是会计主体，不进存货总额自然不进跌价基数 |
| 双轨**相加** | **取孰高**（`max`） |
| 拿展示六桶去套计提比例 | 六桶是**展示**，四档是**计提**，两套 |
| 直接拿「应有准备」做本期凭证 | 记**变动额** = 本期应有 − 上期已计提 |
| 把库龄的「逆向倒扣」说成先入先出法 | **无关**——一个是库龄推导手法，一个是成本结转方法 |
| 忘了按 (物料, 仓库, 批次, 一级货主) 下钻 | 不下钻到一级货主，分摊基准就是拍出来的 |
| 把 `provision_by_age` / `provision_by_launch` 合并成一列 | **两列都留**，报表须同时披露 |
