财务库存中心（一期）· 原型页面 · 界面风格

界面风格方案对比 v1.0

按附件（仓配助手列表页）的风格，给原型试了四套。四套共用同一份模拟 DOM——同一张「结存流水数据（P05）」列表页，只换令牌与布局层，所以差别是真实的风格差别，不是内容差别。

只读本文件不改原型、不碰 PC端界面.html。挑定后才落到正式文件。
同 DOM四套共用一份模板，靠 data-skin / data-layout 切换。
单态沿用现有约束：不做系统主题跟随、不做深浅切换。
数据自洽模拟表逐行相加等于合计行；口径按「物理口径·仓库」标注。

先说一件必须由你拍板的事

现版的配色不是随手定的，是 A 方案「账簿绿格」，写在两处约束里：CLAUDE.md §四「配色以本目录既有的『账簿绿格』令牌为准」，以及 fin-prototype-edit skill 的「令牌源只认 PC端界面.html」。

附件那套是另一套语言——冷灰平底 + 白色侧栏 + 无衬线标题 + 蓝色链接。选 B / D 就等于换掉设计系统，那两处约束要一起改，令牌源 PC端界面.html 也要跟着重做，否则原型与令牌源会立刻不一致。

C 是折中：拿附件的骨架（白色侧栏 / 标签在上 / 居中分页 / 页签条），保留账簿的底与色——你上次说过「平灰底不好看、账簿格线更能接受」，C 就是照着这句话做的。

A

账簿绿格 现版 · 基准

照 632 KB 原型现状复刻：暖纸底 + 账簿横格线、深绿侧栏、衬线标题、标签在左的输入组、绿下划线链接、右对齐分页。

为什么留着它

全项目唯一有业务语义的界面：横格线来自账页、印色来自凭证、衬线标题来自账本。它不像任何一套通用后台，看一眼就知道是「存货核算」。

也是 16 页原型 + 规格抽屉 + 四层浮层已经落定的那套，零改动成本。

代价与注意

与附件差距最大：侧栏是深色、筛选项标签在左、没有页签条、分页靠右。

如果目标是「让业务方觉得这就是我们线上那套」，A 达不到。

B

仓配助手 附件原样

照附件直搬：白色侧栏 + 绿色实心胶囊选中、冷灰平底、纯白卡片、全无衬线、蓝色链接、页签条、居中分页（共 N 条 / 每页 / 前往）。

为什么选它

与附件逐项对齐：侧栏、筛选、按钮、表格、分页、页签条全部是同一种做法。业务方一眼认得出是自家系统。

交互惯性也一致——筛选标签在上、分页居中带总数，是他们的日常肌肉记忆。

代价与注意

平灰底正是你上次评价「不好看」的那一种；绿格线、印色、衬线标题三项账簿语义全部丢失。

要动 CLAUDE.md §四 与 PC端界面.html；16 页原型的 .filt / .bar / .tbl / .pg 都要重写。

绿色取自截图目测，落地前需与真实令牌核对。

C

附件骨架 + 账簿底 折中

拿附件的骨架——白色侧栏、绿色胶囊、标签在上、页签条、居中分页、无蓝链接；保留账簿的底与色——暖纸底 + 淡格线 + 账簿绿 + 衬线页面标题。

推荐有格线白侧栏保留账簿语义
页面底#F3F3E9
卡片面#FFFEF9
分隔线#DAD8C5
主色#1F5C46
侧栏底#FFFEF9
印色#B2422A

为什么推荐

骨架照抄附件，业务方认得出；底色留账簿，不丢身份。你上次对「账簿格线」的接受度明显高于平灰底，这一套就是那个判断的延续。

改动量比 B 小：只动布局层与令牌，账簿的 6 个 .tag--*、印色、.mnote 警示条这些语义件全部原样保留。

格线只有 .055 不透明度，在列表页这种密集版面上不抢行、不干扰读数，只是让底不空。

代价与注意

仍是混合体——严格说「和附件不完全一样」，如果甲方要求 1:1 复刻附件，C 不合格。

白色侧栏 + 暖底并置，需要把侧栏右边界线加重一点（已用 #E4E2D3），否则两者会糊成一片。

同样要动 §四 与令牌源——只是幅度比 B 小。

D

附件骨架 + 深色侧栏 折中

附件的骨架，但把侧栏换回深绿。冷灰底 + 深色侧栏 + 账簿绿主色——列表区和附件一模一样，全靠侧栏压住身份。

为什么可选

三套折中里对比最强：深色侧栏天然把导航区与工作区分开，长表格页面上尤其好用。

主色仍是账簿绿，所以「财务」的身份还在；只是从底色换成了侧栏来承担。

代价与注意

深色侧栏（#14231C）配冷灰底（#F5F6F7）色温打架——侧栏偏暖绿、主区偏冷，同一屏里看久了会觉得脏。

若选 D，建议把侧栏改成更中性的深青 #0F2B26 再评估。

同样要动 §四 与令牌源。

我的判断与顾虑

推荐 C。附件里真正有价值的不是那抹绿或那片灰，是它把列表页的动线理顺了：页签条在上、筛选标签在上、按钮分左右、分页居中带总数——这些是效率，不是配色。C 把这套骨架整套拿过来，同时留住你已经认可过的账簿底。

如果你要的是「和线上那套看起来是同一个产品」，那就是 B，别犹豫——但那要接受平灰底，并且把 CLAUDE.md §四 与 PC端界面.html 一起改掉。

我的顾虑有两个：

  • 绿色取值是目测的。附件截图里的绿我没法取到准确色值（#1FA84A 是估的）。定方案后请给我一份真实令牌或设计稿，我再锁死。
  • 规格抽屉与四层浮层没进这一轮。本页只做了列表页。原型里还有 .drawer 规格抽屉、.form 新建表单、.modal、四层浮层 dw/pw/mw/fw——那部分要不要跟、跟到哪一层，取决于你选哪套，我按你定的那套统一推。
