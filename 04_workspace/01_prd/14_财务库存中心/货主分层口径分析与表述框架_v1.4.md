## 0. 为什么这件事必须先谈"表述"

现有三份文档里，"库存"的维度是 `(物料, 仓库, 批次)`。加入货主分层后，这个维度会变成四轴，而四轴会同时击穿**余额表主键、对账维度、跌价计提范围、凭证辅助核算、单据类型**五个地方——也就是《差距清单》里的 F05、F14、F18 三条。

比"改哪里"更前置的问题是：**同一件事，两个团队叫法不同，就永远对不上。** 例如"一级货主"到底是法人主体还是货权主体、"批次价格"是批次的价格还是"批次 × 货主"的价格、"库存金额"要不要两级相加。这些问题如果不在表述层统一，后面写的每一行设计都要重新解释一遍。

## 1. 术语与语义

### 1.1 定义（已按 O-01 锁定）

| 术语 | 表述 | 关键含义 |
|---|---|---|
| **一级货主** | **法人主体（公司主体）** —— 对货物享有法律与经济所有权的法人 | **与 `legal_entity`（法人/账套）是同一个概念**，一个字段、两个叫法 |
| **二级货主** | **内部持有主体** —— 法人内部对该批货承担经营责任的主体（部门 / 项目 / 客户归属 / 代采项目） | 纯管理维度，**不进入存货核算与存货总额**；但**内部交易按内部结算价作价**（见 4.5） |
| **货主层级** | 一级为主、二级为从的树状归属：一级 1 : N 二级 | 建议实现为自关联树，不硬编码两级 |

> **统一用词**：文档中一律写「一级货主（法人主体）」，不再单说"货主"或"法人"。这样 F18（`legal_entity` 字段）不再需要单独讨论——**它就是一级货主**。

### 1.2 一级货主的"内部 / 外部"二分（这是全部差异的根源）

一级货主是法人主体，所以它天然分两类：

| 一级货主 | 典型场景 | `is_internal` | 是否计入我方存货 |
|---|---|---|---|
| **我方法人**（本法人 / 集团内其他法人） | 自营采购、代采垫资（垫资方持货权阶段）、集团内跨法人调拨 | 1 | **计入** |
| **外部法人** | 受托代销、寄售、监管货、代管货、已转货权未提货 | 0 | **不计入** |

> 这一条把《待决策清单 D-06 存货权属边界》从"逐类勾选的会计政策"变成了**一个可计算的规则**：看一级货主是不是我方。`D-06` 表里的"受托代销 / 寄售 = 不计入"与"在途 / 平台仓 / 海外仓 / 委托代销 = 计入"，本质都在问同一件事——**这批货的一级货主是谁**。
>
> **连带结论（修正原 O-08）**：既然一级货主是法人，外部法人的货**不需要另建台账表**，直接进同一张余额表、以 `is_internal = 0` 标记，存货汇总时按 `is_internal = 1` 过滤即可。这样物理数量与权属数量留在同一处，对账更简单。

### 1.3 表述规范：不要写"货主"

| 不推荐 | 推荐 | 原因 |
|---|---|---|
| 货主 | 一级货主（法人主体）/ 二级货主 | 层级不明 |
| 货主的库存 | 该货主名下的库存 | 归属关系不明 |
| 货主价格 | 该货主层的存货成本单价 | 价别不明 |
| 货主转移 | **货权转移** / **货主重分配** | 两件事：一件动法人（有损益），一件只动内部归属（无损益） |

### 1.4 与既有术语的对齐

| 本文用词 | 既有文档用词 | 说明 |
|---|---|---|
| 滑动平均 | 移动平均 `MA`（"移动加权平均"） | **同一件事**。统一为「移动加权平均（滑动平均）」，字段沿用 `MA` |
| 一品一价 | 个别计价 `SI` | **同一件事**。统一为「个别计价（按件核算，SN/序列号承接）」，`SI`。"一品一价"字面易被读成"一个物料一个价"（那是移动平均），建议不用 |
| 先入先出法 | `FIFO` | 一致 |

## 2. 货主的变化：四类事件

### 2.1 先分清两类变化

「采购和销售时处理方式不同」这句话，落到设计上其实是**四种事件**，被分成了两组：

| 组 | 事件 | 物理数量 | 法人（一级）是否变 | 特征 |
|---|---|---|---|---|
| **A 组：伴随物理移动** | 采购入库、销售出库、退货 | 变 | 变 | 货真的进出仓库 |
| **B 组：不伴随物理移动** | **货权转移**、**货主重分配** | **不变** | 货权转移变 / 重分配不变 | 货没动，只是归属变了 |

B 组是这套模型存在的理由，也是最容易被漏掉的一组。**如果只把货主当成采购/销售单据上的两个字段，B 组就无处表达**——而代采、仓储监管这类业务，B 组才是主线。

### 2.2 四类事件对照表（已按 O-03 锁定）

| 事件 | 物理数量 | 一级货主 | 二级货主 | 成本 | 凭证 | 单据 |
|---|---|---|---|---|---|---|
| 采购入库 | **+** | 供应商 → 某法人 | 确立 | **建立成本层**（计价方法的起点） | 是 | `PO_IN` |
| 销售出库 | **−** | 我方 → 客户 | 清零 | **结转成本**（计价方法的终点） | 是 | `SO_OUT` |
| **货权转移** | 0 | **变更** | 可不变 | **作价**：转出方按本层成本结转、确认损益；转入方按作价建层 | **是** | 一期新增**货权变更单** `OWNER_TRANSFER`（4.7） |
| **货主重分配** | 0 | **不变** | **变更** | **作价**（内部结算价）：一级层成本不变，差额进**二级内部损益** | **否**（会计凭证） | 一期新增**货权变更单** `OWNER_REASSIGN`（4.7） |
| 退货 | ± | 反向 | 反向 | 反向 | 是 | `PO_RET` / `SO_RET` |

### 2.3 派生规则（R1–R5）

O-01（一级货主 = 法人主体）+ O-02（二级不进存货总额）+ O-03（作价），三者合起来自动得出五条规则，**不需要再单独决策**：

| # | 派生规则 | 推导 |
|---|---|---|
| **R1** | **一级货权转移必作价、必出凭证、必产生损益** | 一级是法人 → 跨法人转移即真实交易 |
| **R2** | **二级货主重分配必作价（内部结算价）**：差额进**二级内部损益（管理口径）**，但**不确认会计损益、不出会计凭证** | 二级非会计主体 → 内部结算不动法人会计；但公司内部按内部转移定价考核（**公司特性**） |
| **R3** | **存货**均价池只在一级货主层建立；二级层另维护**内部结算价**（管理口径） | O-02 二级不进存货总额 → 二级不能有自己的**存货**成本；内部结算价是管理价格，不并入存货 |
| **R4** | **存货总额 = Σ 一级货主层中 `is_internal = 1` 的金额** | O-01 + O-02 的直接推论 |
| **R5** | **二级内部结算价不影响会计**：一级层成本、存货总额、会计凭证、跌价计提均与内部结算价无关 | R2 + R3 的合并表述 |

> R2 与 R3 要一起读：二级层同时持有**两个金额**——按一级均价算的**会计分摊额**（能与一级层加总）与按内部结算价算的**内部结算额**（用于二级内部损益）。两者不混用：前者必须能加总回一级层（硬校验），后者必然加不回去（差额就是尚未对外实现的内部毛利，见案例 7.2）。
>
> R5 是给实现团队的一句话提醒：**内部结算价是一条只走管理口径的旁路，不能让它渗进存货科目、存货总额或凭证**。一个数量、两个金额，是唯一的表达方式。

### 2.4 采购与销售的差异，应该这样表述

不要把差异写成"采购怎么处理、销售怎么处理"，而要写成**货主在成本链上的两个端点**：

- **采购入库 = 货主的诞生点。** 法人承接（供应商 → 我方），二级货主确立。这是**唯一会向成本池注入金额**的地方，所有计价方法的第一个层/均价池在这里建立。
- **销售出库 = 货主的消亡点。** 法人释放给客户，二级货主清零。这是**唯一会从成本池抽出金额**的地方，按计价方法结转。
- **货权转移 = 货主的换手点。** 既不是诞生也不是消亡：货没动、**集团内总量不变**、只是换了法人；**对外则总量减少**（变成应收账款）。

由此得出一条设计表述上的硬规则：

> **货主的变化不应写进采购/销售的单据逻辑里，应抽成独立的「货权事件」。**
> 否则「先采购入库（货权在垫资方）→ 再货权转移给客户 → 最后物理发货」这条代采链路无法表达——因为它会出现"货权已经不在我方、但货还物理在库里"的状态（见 7.4 案例）。

### 2.5 一个容易被忽略的状态：物理与权属分叉

B 组事件会造出平时想不到的库存状态：

| 状态 | 物理在库 | 权属（一级货主） | 典型场景 |
|---|---|---|---|
| **货在我方库、权属已不属我方** | 在库 | 外部法人 | 代采已转货权、客户未提货；受托代销 |
| **权属属我方、货不在我方库** | 在途 | 我方法人 | 已确认采购、货在途 |

这两种状态会让**物理数量**与**权属数量**分叉。表述上必须把两者分开命名：

- **在库数量**：物理在库的实物数量（仓库口径）
- **权属数量**：归属于某法人货主的数量（货主口径）

**一期建议**：允许分叉（因为代采转出未提货是真实业务），但**对账时明确用哪个口径**——数量对账用「在库数量」（业务系统也按物理管），存货金额用「权属数量」（见 7.4、7.7 案例）。若一期不承接该场景，需在文档中明确写"一期两者恒等"。

## 3. 库存的变化：数量守恒、价值分层

### 3.1 一句话表述

> **数量守恒，价值分层。**

- **数量（物理事实）**：在 `(物料, 仓库, 批次, 一级货主)` 维度唯一，且满足**层间汇总关系**——同一 `(物料, 仓库, 批次)` 下，**一级货主的数量 = 其名下二级货主数量之和**。**该等式因「每行 `owner_l2` 必填」而恒成立**（行级必填，缺失即 `E-OWNER-L2-MISSING`：二级货主缺失）；若允许二级为空，空值行即成为「有一级、无二级」的**无主数量**，汇总必然对不上。
- **价值（财务解释）**：每层有自己的金额与单价。**层级之间是汇总关系，不是相加关系**（R4）。

### 3.2 最容易致命的一条表述

> **公司存货总额 = Σ 一级货主层中 `is_internal = 1` 的金额。二级货主层是管理视角，不得与一级层相加。**

因为二级货主是**同一批货法人内部的拆分**，两级相加等于把同一批货算了两遍。这条必须写进文档、写进对账规则、写进报表口径，一处都不能松。

若涉及**多法人**（集团），每个法人各自是一级货主，彼此之间的转移是真实的内部交易——那时"相加"的对象是**各个法人的一级层**（合并报表口径），仍然不是"一级 + 二级"，且**内部未实现损益需抵消**（见 7.3 案例）。

### 3.3 库存维度与核算单元的表述

```
库存四轴维度   = (物料, 仓库, 批次, 一级货主)
存货核算单元   = (物料, 仓库, 一级货主)      ← 存货均价池 / 成本层在此建立（R3）
二级货主        = 分摊视图：会计分摊额按一级均价；内部结算额按内部结算价
```

| 轴 | 性质 | 是否分层 | 是否进均价池 |
|---|---|---|---|
| 物料 | 物理 | 否 | 是 |
| 仓库 | 物理 | 否 | 是 |
| 批次 / SN | 物理 | **否**（见第 5 章） | **MA：否**（批次不进均价池）；**SI / FIFO：是**（批次即成本单元，见 §6.2） |
| **一级货主（法人）** | **权属** | **是** | **是** |
| **二级货主** | **管理** | **是** | **否**（另维护内部结算价） |

> **批次与均价池的关系按计价方法分**：**`MA` 单元批次不进均价池**（均价池的最小单位是核算单元 `(物料, 仓库, 一级货主)`）；**`SI` / `FIFO` 单元批次即成本单元**（见 §6.2）。

### 3.4 库存"变化"的三种形态

| 形态 | 数量 | 金额 | 触发 |
|---|---|---|---|
| **增减** | 变 | 变 | 采购、销售、退货、盘点 |
| **换手** | 不变 | **集团内总额不变**、归属变；对外则减少 | 货权转移、货主重分配 |
| **重估** | 不变 | **变** | 暂估冲回、跌价计提、舍入结转 |

三类变化分开表述，才不会在流程图上混成一团。

## 4. 价格的变化

### 4.1 先把"价"拆成五种

| 价别 | 建议字段 | 含义 | 谁定义 | 是否进存货成本 |
|---|---|---|---|---|
| ① 业务价 | `biz_price` | 对外的采购价 / 销售价，外部给的输入 | 业务 / 采购 | 采购价进（不含税部分） |
| ② **存货成本价** | `cost_price` | 该 **一级货主层** 的存货成本单价，按计价方法算出 | 财务 | **是**（唯一真层，R3） |
| ③ **一级转移作价** | `transfer_price` | **一级货主之间**货权转移的结算价（O-03 已定为作价） | 双方 / 财务 | 转出方按本层成本结转；转入方按作价建层 |
| ④ **二级内部结算价** | `internal_price` | **二级货主之间**内部交易（重分配）的作价——**公司特性** | 财务 / 内部定价 | **否**，只进二级内部损益（R5，见 4.5） |
| ⑤ 资金占用/服务费 | `financing_fee` | 垫资、代采、监管产生的费用加成；**一期未落地**（二期考虑） | 财务 | **否** |

### 4.2 关键表述：存货成本价只有一个"真"层

> **存货成本价的真层是一级货主层。二级货主层的价若含费用加成，属管理口径，不得进入存货科目、不得作为跌价基数。**

理由：垫资、代采的资金占用费是**融资成本 / 服务收入**，不是存货成本。计入存货会虚增资产，是会计上的实质性错误。

| 层 | 成本的构成 | 用途 |
|---|---|---|
| 一级货主层 | 不含税采购价 + 可计入存货的附加费用分摊 | **存货科目、跌价基数、对外报表** |
| 二级货主层 | 会计分摊额（按**一级均价**）+ 内部结算额（按**内部结算价**），差额为内部未实现毛利 | 内部管理报表、部门考核、资金占用分析 |

### 4.3 货权转移的作价口径（O-03 已锁定）

**一级货权转移一律作价**（R1），转出方按本层成本结转并确认损益：

```
转出方：
  转出成本 = 转移数量 × 转出方本层成本单价（按计价方法确定，见第 6 章）
  转移收入 = 转移数量 × transfer_price
  转移损益 = 转移收入 − 转出成本

转入方：
  按 transfer_price 建立新的成本层（并入其均价池或新增 FIFO 层）
```

作价差额的会计去处**不是"存货"**，必须按交易性质指定科目：

| 场景 | 差额性质 | 科目方向 |
|---|---|---|
| 对外部法人（真实销售） | 销售毛利 | 主营业务收入 / 主营业务成本 |
| 集团内跨法人 | 内部交易损益 | 照常确认，**合并报表时抵消** |
| 垫资 / 代采加价部分 | 融资服务费 | 其他业务收入 / 利息收入（**不进存货**） |

### 4.4 价格变化对三种计价方法的影响（表述模板）

货权转移**在任何一种计价方法下都不能改变"物理层"**，只能改变层的归属标签。差别在于转出成本怎么算、转入方怎么建层：

| 计价方法 | 二级重分配（作价，管理口径） | 一级货权转移（作价，会计口径） |
|---|---|---|
| 移动加权平均 | 一级层均价**不变**；会计分摊额按一级均价平移；内部结算额按 `internal_price` 计，差额进二级内部损益 | 转出方按本层均价结转（**均价不变**）；转入方按作价并入自己的池并重算均价（同 F1 逻辑） |
| 个别计价 | 改单件的归属标签；会计成本不变，内部结算价差逐件进二级内部损益 | 逐件重估，按指定件的实际成本结转，逐件确认损益 |
| 先入先出法 | 层不变、层序不变，只改标签；同上，只是个内部结算价差 | 取最早物理层结转；转入方按作价建层，**层序仍按物理入库日** |

### 4.5 二级内部结算价的作价口径（公司特性，R2 / R5）

一级作价与二级作价的**共同点**是"都按某个价作价"；**根本区别**是去向不同——一级进会计，二级只进管理。

| 对比项 | 一级转移作价 `transfer_price` | 二级内部结算价 `internal_price` |
|---|---|---|
| 谁与谁之间 | 一级货主（法人）之间 | 二级货主（部门 / 项目）之间，同一法人内 |
| 触发事件 | 货权转移（`OWNER_TRANSFER`） | 货主重分配（`OWNER_REASSIGN`） |
| 是否出会计凭证 | **是** | **否**（二级非会计主体） |
| 是否确认会计损益 | **是** | **否**；差额进**二级内部损益（管理口径）** |
| 是否改变一级层成本 | 转出方均价不变、转入方均价重算 | **完全不变** |
| 是否改变存货总额 | 集团内不变（合并抵消），跨集团改变 | **完全不变**（R4 / R5） |
| 是否影响跌价基数 | 是（转入方成本变了） | **否** |
| 主要用途 | 会计确认 + 法人间结算 | 部门/项目考核、内部毛利分析 |

**核心实现约束：二级层同时挂两个金额。**

| 字段 | 计算 | 能否加总回一级层 |
|---|---|---|
| `alloc_amount` **会计分摊额** | 二级数量 × **一级层均价** | **能**——`Σ 二级 alloc_amount = 一级层金额`，这是硬校验 |
| `internal_amount` **内部结算额** | 按 `internal_price` 累计（含历次内部结算价差） | **不能**——差额 = **内部未实现毛利**，是正常现象 |

**内部结算损益公式（管理口径）**

```
转出方二级：
  内部收入 = 重分配数量 × internal_price
  内部成本 = 重分配数量 × 一级层均价
  内部损益 = 内部收入 − 内部成本        ← 正数是内部毛利，负数是内部亏损

转入方二级：
  内部结算成本基础 = 重分配数量 × internal_price
```

> 内部损益的**可加性**：只要货最终离开公司（对外销售 / 对外转移），各级内部毛利会逐段累加，最终合计**等于**对外的总毛利，不会重复也不会遗漏。所以在合并口径下，内部结算价只是"把总毛利切给各段"的工具——它**不创造也不消灭利润**。
>
> **两条必须写进校验清单的规则：**
>
> 1. `Σ 二级 alloc_amount = 一级层金额` —— **硬校验**，日结必须过。
> 2. `Σ 二级 internal_amount ≠ 一级层金额` —— **正常**，差额即内部未实现毛利。**不要对它做等式校验**，否则会天天报错。

### 4.6 作价来源与权威源（一期决策）

**结论：财务库存中心一期不配置"一级作价"，只配置"二级考核价"；两者的权威源不同，不能混为一谈。**

| 价别 | 一期来源 | 权威源 | 二期去向 |
|---|---|---|---|
| ① 业务价 `biz_price` | 采购单 / 销售单 | 业务系统 | 不变 |
| ③ **一级转移作价** `transfer_price` | **(a) 对外**：销售单 / 合同带入<br>**(b) 集团内**：货权变更单录入（4.7） | (a) 业务系统<br>(b) 库存中心（临时） | **产权交易中心** |
| ④ **二级内部结算价** `internal_price` | **带生效期的价目表**，财务维护、系统取价 | 财务（一期配置在库存中心） | **产权交易中心**（价目表随之迁移） |
| ⑤ 资金占用费 `financing_fee` | **一期未落地**（原设想：费率配置 × 占用天数） | 财务 | 不变 |

**为什么一级不配置**：对外的作价就是**销售价**，来自谈判与合同——财务中心再定一次是越权，而且配置一改，历史单据"记了多少收入"就失去依据。集团内的是**关联交易价**，逐笔谈定。财务中心的职责是**取价 + 校验**（与订单/合同不符时报警），**不是定价**。

**为什么二级必须配置**：它是**政策价**——财务统一制定、部门之间不逐笔谈，正是价目表的典型场景。

#### 价目表（`t_internal_price`）设计要点

| # | 要点 | 说明 |
|---|---|---|
| 1 | **带生效期**，不是"当前值" | 价格是**版本化**的，主键含 `effective_from` / `effective_to` |
| 2 | **按业务日期取价** | 重分配日落在哪段生效区间就取哪版——**绝不能用"当前配置"** |
| 3 | **取到即快照** | 取到的价写进单据行，重算**不回查配置**。否则调一次价，历史内部损益全变 |
| 4 | **优先级：更具体的赢** | (物料 + 转入方) > (物料) > (物料组) > (全局默认)；同优先级**不允许重叠**（唯一约束） |
| 5 | **两种定价方式都支持**（逐行选） | ①固定价 `FIXED`　②**成本加成率** `MARKUP` = 一级均价 × (1 + r)。**两者并存，不是二选一**（O-18）：财务可以 A 物料用固定价、B 物料用加成率，甚至可以同一物料对不同转入方用不同方式。`price_type` 是**行的属性**，不进主键 |
| 6 | **审批与状态** | 草稿 / 待审 / 生效 / 失效；只有**生效**的可被取价引用（审批归属见 O-19） |
| 7 | **兜底不静默** | 取不到价时要么**阻断**要求补配置，要么用显式默认率并写 `price_source = DEFAULT_RATE` |
| 8 | **单据行必带 `price_source`** | 合同 / 订单 / 手工录入 / 价目表 / 默认率——否则事后没人能解释这个数怎么来的 |

**第 5 点的两个坑（只在"两种方式混用"时才暴露）**

1. **唯一约束要落在"具体度键 + 生效区间"上，不能带上 `price_type`。** 若把 `price_type` 放进主键，同一个 (物料, 转入方) 在同一期间就能同时存在一条固定价和一条加成率——取价时谁赢没有依据。正确做法：**一个 (具体度, 生效区间) 只有一行**，这一行自己声明用哪种方式。这样"混用"是**跨物料/跨转入方的混用**，同一格子里永远不冲突。
2. **加成率的基数必须写明是"该一级货主层的均价"**，不是全公司均价、也不是上期均价。重分配不动一级货主，所以基数唯一、没有歧义；但实现时取错层级（比如取了 `(物料, 仓库)` 而不带 `一级货主`）不会报错，只会悄悄算错。

**成本加成行要存"一个价、三个数"**：`price_base`（加成基数 = 当时该一级货主层均价）、`markup_rate`（用的率）、`price_value`（算出的价）。只存结果，事后无法解释"这个价怎么来的"；只存率，重算时基数已经变了。三个都存，才能在不动配置的前提下复现这一笔。与 O-15 对齐：**加成是"在重分配时点按当时一级均价算一次并固化"，不是持续跟随**——措辞含糊会让实现做成动态跟随。

| `t_internal_price` 字段 | 说明 |
|---|---|
| `price_id` / `version` | 主键与版本 |
| `material_code` / `material_group` | 两者可空；都为空表示全局默认 |
| `from_owner_code` / `to_owner_code` | 二级货主范围，可空；`to` 比 `from` 优先。**这里的「可空」指本条配置的适用区间可省略（= 不限范围），不等于单据行上的 `owner_l2` 可空**——行级 `owner_l2` 恒为必填 |
| `price_type` | `FIXED` 固定价 / `MARKUP` 成本加成。**行的属性，不进主键**——两种方式靠"不同格子用不同方式"共存，不靠同一格子二选一 |
| `price_value` / `markup_rate` | 按 `price_type` 二选一：`FIXED` 填 `price_value`，`MARKUP` 填 `markup_rate` |
| `currency` | 币种；口径与一级均价一致（不含税） |
| `effective_from` / `effective_to` | 生效区间 |
| `status` | `DRAFT` / `PENDING` / `ACTIVE` / `INACTIVE` |
| `created_by` / `approved_by` / `approved_at` | 审批留痕 |

**取价规则（伪码）**

```
取价(物料 m, 转入方二级 o2, 业务日期 d):
  候选 = t_internal_price 中满足
          (material_code = m  或  material_group = m.组  或  两者皆空)
      且 (to_owner_code = o2 或 为空)
      且 effective_from <= d <= effective_to
      且 status = 'ACTIVE'
  按「具体度」降序，再按 effective_from 降序，取第一条   # 一个格子只有一行，不会同时命中两种方式
  若无候选 → 按兜底策略：阻断 或 用显式默认率并标记 price_source = DEFAULT_RATE
  按该行的 price_type 算价：
     FIXED  → price_value
     MARKUP → price_base = 该一级货主层均价(物料 m, 仓库 w, 一级货主 o1, 业务日期 d)
              price_value = round(price_base × (1 + markup_rate), 6)
  把 price_value 与 price_source、以及（MARKUP 时）price_base / markup_rate 一并快照进单据行
```

#### 权威源划分（一期先冻结，二期直接复用）

| 数据 | 权威源 | 另一方 |
|---|---|---|
| **货主档案** `t_cargo_owner` | **库存中心** | 交易中心只引用 `owner_code`，**不建第二份档案** |
| **一级成交价** | (对外) 业务系统　/　(集团内) 库存中心（临时） | 二期 → 产权交易中心 |
| **二级考核价目表** | **财务**（一期配置在库存中心） | 二期 → 产权交易中心 |
| **数量 / 物理在库** | **库存中心** | 交易中心**不得自行判断有没有货**——转移单须向库存中心校验物理在库 |
| **会计确认** | **库存中心 / 会计** | 交易中心只推送事件 + 接收「已核算」回执 |

#### 一条必须写进规划的边界纠正

产权交易中心"**不参与对外审计与开票**"，但**必须参与内部会计确认**——集团内跨法人转移是**关联交易**，按 R1 它必须**出凭证、确认损益、合并时抵消**（O-04）。所以它的准确定位是：

| 它不参与 | 它**必须**参与 |
|---|---|
| 外部开票 · 外部结算 · 外部审计 · 外部对手方 | **内部会计确认**：一级转移出凭证、确认损益、合并抵消 |

> 一句话分工：**交易中心决定"交易是否成立"，库存中心决定"会计怎么记"。** 这句话不写下来，二期两边会互相等对方。若交易中心被当成"纯管理台账"来建，一期"做集团内转移"这件事就断在它这一环——交易中心以为不用管会计，会计那边永远收不到事件。

### 4.7 货权变更单（一期临时载体，二期迁产权交易中心）

**背景**：产权交易中心**一期不落地、先规划**（2026-09-15 决定）。一期由财务库存中心提供一张**临时货权变更单**承载"货不动、权属动"的业务；单据**按"可剥离"形态设计**，二期整体搬迁，库存中心退回"只接收事件"的角色。

**单据要素**（关键：**自带价格与对手方，不依赖库存中心的业务逻辑**）

| 字段 | 说明 |
|---|---|
| `doc_no` / `doc_type` | `OWNER_TRANSFER` 一级产权转移 / `OWNER_REASSIGN` 二级重分配 |
| `biz_date` / `posting_date` | 成交业务日 / 记账日（取价按 `biz_date`） |
| `from_owner_code` / `to_owner_code` | 转出 / 转入一级货主；`OWNER_REASSIGN` 时两者相同 |
| `from_owner_l2` / `to_owner_l2` | 二级转出 / 转入（仅 `OWNER_REASSIGN`） |
| `material_code` / `warehouse_code` / `batch_no` / `qty` | 按 `(物料, 仓库, 批次)` 逐行 |
| `transfer_price` / `internal_price` | 作价，**按行**（一级 / 二级各一列） |
| `amount` | 作价金额 = `qty` × 价 |
| `price_source` | 合同 / 订单 / 手工录入 / 价目表 / 默认率 |
| `price_base` / `markup_rate` | **仅成本加成时填**：加成基数（当时该一级货主层均价）与用的率——与 `internal_price` 一起构成"一个价、三个数"，保证事后可复现（4.6） |
| `counterparty_contract_no` | 关联合同或协议号（`OWNER_TRANSFER` 填，便于关联交易披露） |
| `status` | 草稿 / 已提交 / 已审核 / **已核算** / 已冲销 |
| `reversal_of` | 反向单指向原单 |
| `is_accounting_event` | **一级 = 是，二级 = 否** —— 决定是否出凭证、是否确认损益（R1 / R2） |

**可剥离原则：决定二期不返工的 5 条**

1. 单据**自带价格与价格来源**，取价逻辑**不写在核算引擎里**；
2. **状态机自洽**（草稿 → 已提交 → 已审核 → 已核算 → 已冲销），不靠其他单据驱动；
3. 对手方是**货主编码**而非"客户/供应商"档案——二期交易中心复用同一 `owner_code`；
4. `is_accounting_event` **显式分列**，一级/二级不靠散落的 `if 单据类型` 判断；
5. 单据**不直接改余额**，只产生事件，余额改动仍归核算引擎——二期只需换事件的生产者。

**状态机与冲销规则**

| 阶段 | 库存中心 | 可否撤 | 处理 |
|---|---|---|---|
| 草稿 / 已提交 | 未见 | 可撤 | 作废 |
| 已审核 · 未核算 | 已接收待核算 | 可撤 | 作废；已下发则出反向单 |
| **已核算** | **已出凭证、已改余额** | **不可撤** | **反向货权变更单 + 红字凭证** |
| 已冲销 | 余额已回滚 | — | 终态 |

> **已核算的一律不可删，只能反向。** 一级的反向会产生红字凭证与一笔反向的关联交易——这是合规要求，不是实现选择。这条要写进操作规范，否则业务会以为撤单"点一下就没了"。

**一期 / 二期对照**

| | 一期（交易中心不落地） | 二期（交易中心落地后） |
|---|---|---|
| 谁产单 | **库存中心** | 产权交易中心 |
| 库存中心的角色 | **产单 + 核算** | **只收事件 + 核算** |
| 一级价来源 | 货权变更单录入 | 交易中心成交价 |
| 二级价来源 | 库存中心价目表 | 交易中心价目表 |
| 迁移方式 | — | **搬迁**（单据形态与字段不变，见"可剥离原则"） |

**算例**：案例 7.3（集团内跨法人转移）即本单的标准算例，二期迁移只换生产方、**不改数值**。

## 5. 批次的变化

### 5.1 一句话表述

> **批次是物理的，批次价格是价值的。**

| 概念 | 维度 | 是否分层 |
|---|---|---|
| 批次档案（生产日期、效期、来源） | 物料 + 批次号 | **否**——批次号是对"一堆实物"的命名 |
| 批次数量 | 物料 + 仓库 + 批次 + 一级货主 | 是 |
| **批次价格** | 物料 + 仓库 + 批次 + **一级货主** | **是** |
| 批次库龄（跌价用） | 物料 + 仓库 + 批次 | **否**——跟实物走 |

**同一个物理批次，可以被多个法人货主持有，因此同一个批次号在不同一级货主下可以有不同的价格。**

### 5.2 货权转移不改变批次的物理属性

| 指标 | 是否因货权转移而重置 | 理由 |
|---|---|---|
| 物理库龄（跌价用） | **否**，仍按最早入库日 | 跌价反映**实物的贬值**（3C 尤其明显），与谁持有无关 |
| 库龄分布（滞销识别） | 否 | 同上 |
| **持有库龄 / 持有天数** | 是，从该货主获得权属之日起算 | 服务"该货主压了多久货"的资金占用分析，是**另一个指标** |

表述上要把两个库龄分开命名：`aging_days`（物理库龄，对外与跌价用）/ `holding_days`（持有天数，管理口径）。

### 5.3 整体批次 vs 分层批次

| 表述 | 含义 | 用途 |
|---|---|---|
| 整体批次（物理批次） | 一个批次号 = 一堆实物，不分货主 | 追溯、效期、质量、盘点 |
| 分层批次（货主批次） | 批次 × 一级货主 = 一个"价值单元"，有独立数量/金额/单价 | 成本核算、跌价计提、凭证辅助核算 |

两者是**同一实物的两个视角**，不是两份数据。**分层批次的数量之和 = 整体批次的数量**——这是第 3 章"层间汇总关系"在批次上的具体化，也是盘点与对账能做的前提。

## 6. 三种计价方法 × 货主分层

### 6.1 总原则

> **加进货主维度，只换维度、不换公式。**

现有文档 `3.6.2` 的 F1–F4、`6.3` 的 F6–F11 全部沿用，只需把公式里的 `(物料, 仓库)` 替换为 `(物料, 仓库, 一级货主)`。**这是货主分层最省实现的路径**——公式、算例、伪代码的结构都不用动。

### 6.2 对照矩阵

| 维度 | 移动加权平均 | 个别计价（按件） | 先入先出法（FIFO） |
|---|---|---|---|
| 核算维度 | `(物料, 仓库, 一级货主)`，**不含批次** | `(物料, 仓库, 一级货主, 单品/SN)` | `(物料, 仓库, 一级货主)` + 物理入库层 |
| 成本单元 | 一个均价池 | 一件一个成本 | 一个入库层 |
| 批次角色 | 仅供库龄/跌价，不参与计价 | SN 即单品标识，批次=单品 | **入库层就是批次** |
| 一级货权转移（作价） | 转出按均价结转，**均价不变**；转入按作价并池重算 | 逐件按实际成本结转，逐件确认损益 | 取最早物理层结转；转入方按作价建层 |
| **二级重分配（内部作价）** | 一级均价与均价池**不变**；会计分摊额按一级均价，内部结算额按 `internal_price`，差额进二级内部损益 | 改归属标签；内部结算价差逐件进二级内部损益 | 层序不变、均价不变；内部结算价差进二级内部损益 |
| 舍入差异 | **有**（金额 2 位 vs 单价 6 位） | **无**（逐件实额） | 有（层结转时） |
| 与货主分层的契合度 | 中（多一层均价池） | **最高**（自带归属标签） | 中高（层与货主正交） |
| 一期是否启用 | **是** | **是** | **是** |

> **本矩阵的列口径**：**移动加权平均（`MA`）、个别计价（`SI`）与先入先出法（`FIFO`）三列均为一期口径**，三种方法一期同时支持。`SI` / `FIFO` 下**批次（SN / 物理入库层）本身即成本单元**，"批次不进均价池"的限定**仅适用于 `MA`**（见 §3.3）。

### 6.3 各自需要特别说明的表述

**移动加权平均**

- 同一物料在同一**一级货主**下合并为**一个均价池**，不按批次分池、不按二级货主分池（R3）。
- 货权转移时，转出方按**本层均价**转出（转出成本 = 数量 × 均价），因此**转出后均价不变**；转入方按作价金额并入自己的池并重算均价——**与采购入库的 F1 是同一个公式**，表述上直接写"换手按 F1 处理"即可。
- 风险提示：作价转移会改变**转入方**的均价，进而影响其后续所有出库成本。这一点必须在文档里显式写出，否则会被当成"转移不影响成本"而漏测。

**个别计价（按件核算）**

- 天然契合：**每件货自带成本，货主只是这件货的归属标签**，货权转移不需要任何分摊，因此**没有舍入差异**——这是它相对移动平均的最大精度优势，值得在选型对比里补一句。
- 一期启用（三种计价方法之一）。`launch_date`、SN、批次、一级货主四个字段是**一期硬要求**——必须出现在单据行上，SN 管理品类（如 3C 整机）的出库行尤其如此。
- 术语统一为「个别计价（按件核算）」，不用"一品一价"。

**先入先出法（FIFO）**

- 最需要注意的一条：**FIFO 的"层"是物理入库层，不分货主。货权转移不产生新层、不改变层序。**
- 但队列要**按货主分别排队**：不同货主的层不能混用。即：**FIFO 队列 = 该货主名下的层，按物理入库日排序。**
- 由 O-03 作价产生的一个必须拍板的口径：货权转移进来的层，其"排序日期"取**物理入库日**还是**转移日**？建议取**物理入库日**，与 `aging_days` 口径一致，全文表述为「实物先入先出」。此时转移进来的老货会排在前面并可能立即被出库——这符合"实物先到先出"。

### 6.4 三方法共同的表述约束

1. **货主维度替换后公式不变**（6.1）。
2. **存货总额只按一级货主层合计**（3.2 / R4）。
3. **二级货主不建存货均价池**：会计分摊额按一级均价，内部结算额另按 `internal_price` 计（R3 / 4.5）。
4. **货权转移不改变物理层与物理库龄**（5.2）。
5. **二级内部结算价不出凭证、不进存货、不影响跌价基数**（R5）。

## 7. 案例（Worked Examples）

> 以下算例均可直接转成 UAT 用例。口径约定：单价保留 6 位、金额保留 2 位、数量保留 4 位；采购金额默认不含税；一级货主即法人主体。

### 7.1 案例 1：基准场景 —— 采购入库（货主诞生）与销售出库（货主消亡）

**设定**：甲公司（法人主体，`is_internal = 1`），二级货主为"采购事业部"。物料 `M0001` @ `WH01`，移动加权平均，期初 0。

| 日期 | 单据 | 事件 | 一级货主 | 二级货主 | 数量 | 单价 | 金额 |
|---|---|---|---|---|---|---|---|
| 期初 | — | — | — | — | 0 | — | 0.00 |
| 3/01 | PO-0001 | 采购入库 | 甲公司 | 采购事业部 | +100 | 10.00 | 1,000.00 |
| 3/10 | SO-0001 | 销售出库 | 甲公司 | 采购事业部 | −40 | 10.00 | 400.00 |

**计算过程**

```
3/01 入库（F1）：new_qty = 0 + 100 = 100
                  new_amount = 0 + 1,000.00 = 1,000.00
                  new_price  = round(1,000.00 / 100, 6) = 10.000000
3/10 出库（F2）：out_amount = round(40 × 10.000000, 2) = 400.00
                  new_qty    = 100 − 40 = 60
                  new_amount = 1,000.00 − 400.00 = 600.00
                  new_price  = 10.000000（出库不改变单价）
```

**结存**

| 口径 | 数量 | 金额 | 单价 |
|---|---|---|---|
| 一级货主（甲公司）层 | 60 | 600.00 | 10.000000 |
| 二级货主（采购事业部）层 | 60 | 600.00 | （引用一级均价） |
| **存货总额** | — | **600.00** | — |

**要点**

1. 采购入库是**唯一往成本池注钱**的动作，均价池在此建立；销售出库按出库时点均价结转，**不改变均价**。
2. 二级货主随一级货主一同记录，但**不参与均价计算**（R3）；案例 1 中两者恰好相等，因为只有一条二级归属。
3. 期末存货总额 = **600.00**，不是 600.00 + 600.00。

---

### 7.2 案例 2：货主重分配（二级变更，**按内部结算价作价**，不出凭证）

**承接案例 1**。3/12 将 20 件从「采购事业部」划转给「电商事业部」（同一法人内部调整）。**公司特性：二级之间的内部交易也按内部结算价作价**，本例设 `internal_price = 11.00`。

| 项目 | 变化前 | 变化后 | 是否变化 |
|---|---|---|---|
| 一级货主（甲公司）层 | 60 / 600.00，均价 10.000000 | 60 / 600.00，均价 10.000000 | **三项全不变** |
| 二级：采购事业部 · 会计分摊额 | 60 / 600.00 | 40 / 400.00 | 变 |
| 二级：电商事业部 · 会计分摊额 | 0 / 0.00 | 20 / 200.00 | 变 |
| 二级：采购事业部 · 内部结算额 | 60 / 600.00 | 40 / 400.00 | 变 |
| 二级：电商事业部 · 内部结算额 | 0 / 0.00 | 20 / **220.00** | 变（按内部结算价） |
| 物理在库数量 | 60 | 60 | **不变** |
| 会计凭证 | — | **无** | — |
| 会计损益 | — | **无** | — |
| **二级内部损益** | — | **+20.00** | 变（**管理口径**） |

**计算：会计维度与管理维度分开走**

```
会计维度（不变）
  一级层：60 / 600.00，均价 10.000000                ← 数量、金额、均价三项全不变
  会计分摊额：采购部 40 × 10.000000 = 400.00
              电商部 20 × 10.000000 = 200.00
              Σ = 600.00  ✓ 能加总回一级层

管理维度（作价，公司特性）
  转出方 采购事业部：
    内部收入 = 20 × 11.00 = 220.00
    内部成本 = 20 × 10.00 = 200.00
    内部损益 = 220.00 − 200.00 = +20.00        ← 内部毛利（管理口径）
  转入方 电商事业部：
    内部结算成本基础 = 20 × 11.00 = 220.00
```

**校验：两条规则，一硬一软**

```
硬校验（日结必须过）
  层间数量：一级（甲）60 = 二级 40 ＋ 20                      ✓
  金额汇总：Σ 会计分摊额 400.00 ＋ 200.00 = 一级层 600.00      ✓

软校验（不等是正常的，不要做等式校验）
  Σ 内部结算额 = 400.00 ＋ 220.00 = 620.00 ≠ 一级层 600.00
  差额 20.00 = 内部未实现毛利
```

**要点**

1. 会计维度与管理维度**分开走**：会计分摊额按**一级均价**平移，内部结算额按**内部结算价**累计。这两个数字不同，且都不错（4.5）。
2. 一级层的**数量、金额、均价三项全部不变**；**会计凭证与会计损益均不产生**（R2）——因为二级不是法人、不是会计主体。
3. 作价的产物只有一样：**二级内部损益 +20.00**，进部门/项目考核，不进合并报表。
4. 这就是 O-02 与"公司特性"如何共存：**600.00 是存货**；40 + 20 是同一批货的管理拆分，**不得与存货相加**（若相加得 1,200.00 即为重复计价）。内部结算价是**旁路**，不改变这条结论（R5）。
5. 内部毛利**不创造利润**：这 20 件若最终由电商部按 15.00 对外卖出，采购部 20.00 + 电商部 20 × (15.00 − 11.00) = 80.00，合计 100.00 = 20 × (15.00 − 10.00)，与不分段时的总毛利完全一致。

### 7.3 案例 3：货权转移（一级变更，作价）—— 集团内跨法人

**设定**：甲、丙均为集团内法人（`is_internal = 1`），货权在集团内转移，**货物物理上不移动**（同仓）。物料 `M0002`，5 台。

| 步骤 | 日期 | 事件 | 一级货主 | 物理数量 | 甲层 | 丙层 |
|---|---|---|---|---|---|---|
| 1 | 4/01 | 采购入库 5 台 @1,000 | 甲公司 | +5 | 5 / 5,000.00 | — |
| 2 | 4/15 | **货权转移**，作价 5,200（含资金占用费 200） | 甲 → 丙 | **0** | 0 / 0.00（结清） | 5 / 5,200.00 |
| 3 | 4/20 | 丙对外出库 5 台 | 丙公司 | −5 | — | 0 / 0.00 |

**步骤 2 的计算与分录**

```
转出成本 = 5 × 1,000.000000 = 5,000.00          （甲按本层成本结转）
转移收入 = 5 × 1,040.000000 = 5,200.00          （作价）
转移损益 = 5,200.00 − 5,000.00 = 200.00

甲公司凭证：
  借：应收账款 - 丙公司                 5,200.00
      贷：主营业务收入                    5,000.00
      贷：其他业务收入 - 资金占用费           200.00
  借：主营业务成本                      5,000.00
      贷：库存商品 - M0002（WH01）        5,000.00
```

**步骤 3**：丙按自己的成本层（1,040.000000/台）对外结转，若对外售价 1,200/台则丙确认毛利 800.00。

**合并层面处理**

```
丙层 5,200.00 中含集团内部加价 200.00 → 内部未实现损益，合并报表抵消
抵消后集团口径：该 5 台的成本 = 5,000.00（还原为甲的原始成本）
```

**要点**

1. **物理数量为 0 的变化**——货没动，但权属与价值都换了人（R1）。
2. **作价转移不改变甲层均价**（甲按本层成本全额转出、层已清零）；若甲有剩余库存，其均价也不因转出而变。
3. **转移进来的丙层均价被作价拉高**（1,040 而非 1,000）——这正是 6.3 提示的"作价会改变转入方均价"，若丙后续继续采购或出库，成本基础已不同。
4. **200 元资金占用费不进存货成本**（4.2），单独走其他业务收入。

### 7.4 案例 4：对外货权转移 + 货留我方仓 —— 物理与权属分叉

**设定**：甲公司采购后，货权转移给外部客户丁公司（`is_internal = 0`），但**货物仍存放在甲公司仓库**（仓储监管场景）。物料 `M0003`，3 台。

| 步骤 | 日期 | 事件 | 一级货主 | 物理在库 | 权属数量 | 甲层 | 丁层 |
|---|---|---|---|---|---|---|---|
| 1 | 5/01 | 采购入库 3 台 @2,000 | 甲 | 3 | 3 | 3 / 6,000.00 | — |
| 2 | 5/05 | **货权转移**给丁，作价 6,300，货不提走 | 甲 → 丁 | **3（未动）** | **0** | 0 / 0.00（结清） | 3 / 6,300.00 |
| 3 | 5/20 | 丁提货 | 丁 | 0 | 0 | — | 0 / 0.00 |

**步骤 2 后的双口径状态**

| 口径 | 数量 | 说明 |
|---|---|---|
| **物理在库数量**（仓库口径） | **3** | 实物还在 `WH01`，业务系统也管着这 3 台 |
| **权属数量**（货主口径） | **0** | 已不属甲公司；丁层 3 台但 `is_internal = 0` |
| **甲公司存货总额** | **0.00** | 已按作价结转完毕 |

**步骤 2 的分录（甲公司）**

```
借：应收账款 - 丁公司                 6,300.00
    贷：主营业务收入                    6,000.00
    贷：其他业务收入 - 资金占用费           300.00
借：主营业务成本                      6,000.00
    贷：库存商品 - M0003（WH01）        6,000.00
```

**步骤 3**：丁提货触发**物理出库**，但甲公司**不再有任何成本结转**（成本已在 5/05 结转）。此时丁层清零，物理与权属重新一致。

**要点**

1. 这是**物理数量 ≠ 权属数量**的典型状态：5/05–5/20 之间，业务系统看是"有 3 台货"，财务看是"0 存货"。**两个数字都对，只是口径不同**——所以两个词必须分开命名（2.5）。
2. **数量对账用物理口径**（业务系统也按物理管），**存货金额用权属口径**。若混用，这 3 天必然爆出假差异。
3. 丁层虽在余额表中（`is_internal = 0`），但**不进入存货总额**（R4）——这也是为什么外部货主不需要另建台账表。
4. **一物两账**的边界在此明确：同一批货在物理台账与存货台账中各出现一次，但**只有存货台账进报表**。

### 7.5 案例 5：三种计价方法下的同一笔货权转移

**设定**：甲公司（一级货主）物料 `M0004` @ `WH01`，期初 0。

| 日期 | 事件 | 数量 | 单价 | 金额 |
|---|---|---|---|---|
| 4/01 | 采购入库 | +10 | 1,000.00 | 10,000.00 |
| 4/10 | 采购入库 | +10 | 1,200.00 | 12,000.00 |
| 4/20 | **货权转移给丙**（作价 1,300.00/台） | −5 | 1,300.00 | 6,500.00 |

**移动加权平均**

```
4/10 后：均价 = (10,000.00 + 12,000.00) / (10 + 10) = 22,000.00 / 20 = 1,100.000000
4/20 转出成本 = 5 × 1,100.000000 = 5,500.00
      甲层结存 = 15 台 / 16,500.00，均价仍为 1,100.000000（转出按均价，故不变）
      丙层      = 5 台 / 6,500.00（作价建层）
      甲转移损益 = 6,500.00 − 5,500.00 = 1,000.00
```

**个别计价（按件，设本次转移指定 4/01 入库的低成本件）**

```
4/20 转出成本 = 5 × 1,000.00 = 5,000.00
      甲层结存 = 5 台 @1,000（5,000.00）＋ 10 台 @1,200（12,000.00）= 15 台 / 17,000.00
      丙层      = 5 台 / 6,500.00
      甲转移损益 = 6,500.00 − 5,000.00 = 1,500.00
```

**先入先出法（层按物理入库日）**

```
队列：层1 = 4/01 入库 10 台 @1,000；层2 = 4/10 入库 10 台 @1,200
4/20 取最早层：转出成本 = 5 × 1,000.00 = 5,000.00
      甲层结存 = 层1 剩余 5 台 @1,000（5,000.00）＋ 层2 10 台 @1,200（12,000.00）= 15 台 / 17,000.00
      丙层      = 5 台 / 6,500.00
      甲转移损益 = 6,500.00 − 5,000.00 = 1,500.00
```

**三方法对照**

| 计价方法 | 转出成本 | 甲层结存 | 甲层均价 | 甲转移损益 | 舍入差异 |
|---|---|---|---|---|---|
| 移动加权平均 | 5,500.00 | 15 / 16,500.00 | 1,100.000000 | **1,000.00** | 无（本例整除） |
| 个别计价 | 5,000.00 | 15 / 17,000.00 | 逐件 | **1,500.00** | 无 |
| 先入先出法 | 5,000.00 | 15 / 17,000.00 | 分层 | **1,500.00** | 无 |

**要点**

1. **同一笔业务，三种方法损益差 500.00。** 本例处于价格上行期：FIFO 与个别计价结转低成本件 → 毛利高；移动平均把高价稀释进均价池 → 毛利居中。
2. **货权转移不改变物理层**：三种方法的层/件结构只受 4/01、4/10 的物理入库影响；4/20 的转移只改变层的**货主标签**。
3. **移动平均转出后均价不变**（按均价转出），**FIFO / 个别计价转出后剩余结构改变**（早层被消耗）。
4. **丙层的成本基础是作价 1,300.00，与甲按哪种方法结转无关**——作价与结转方法是两条独立的线。
5. 若丙是集团内法人，甲确认的 1,000.00（或 1,500.00）属**内部未实现损益**，合并时需抵消。

### 7.6 案例 6：跌价计提只按一级货主

**设定**：计算日 2026-03-31，物料 `M9001`（配件类，仅挂 `AGE` 规则）。甲公司名下 150 件 / 1,500.00；同仓另有丁公司（外部法人，受托代销）名下同类货 100 件 / 1,000.00。

| 一级货主 | `is_internal` | 在库数量 | 在库金额 | 是否计提 | 计提金额 |
|---|---|---|---|---|---|
| 甲公司 | 1 | 150 | 1,500.00 | **是** | **25.00** |
| 丁公司（受托代销） | 0 | 100 | 1,000.00 | **否** | 0.00 |
| **存货口径合计** | — | **150** | **1,500.00** | — | **25.00** |

**甲 layer 的库龄分层与计提**（沿用设计文档算例 3.7.4 的档位：181 天 5%）

| 入库日 | 库龄（天） | 结存数量 | 结存金额 | 计提比例 | 计提金额 |
|---|---|---|---|---|---|
| 2025-10-01 | 181 | 50 | 500.00 | 5% | 25.00 |
| 2025-11-15 | 136 | 40 | 400.00 | 0% | 0.00 |
| 2026-01-20 | 70 | 60 | 600.00 | 0% | 0.00 |
| 合计 | — | 150 | 1,500.00 | — | **25.00** |

**凭证**

```
借：资产减值损失 - 存货跌价准备     25.00
    贷：存货跌价准备               25.00
```

**若需按二级货主分摊到部门（管理口径，不产生凭证）**

```
采购事业部：25.00 × (40 / 150) = 6.67
电商事业部：25.00 × (110 / 150) = 18.33
```

**要点**

1. **跌价范围只含 `is_internal = 1` 的一级货主层**——丁公司的货不是我方资产，不计提、不进存货总额。
2. 若误把丁层计入：存货变成 2,500.00、多计提一笔，**虚增资产同时虚增减值损失**。
3. **二级货主不单独计提**（R3）；需要部门口径时，按一级计提额 × 二级数量占比**分摊**，属管理报表，不产生凭证。
4. 库龄按**物理入库日**算（5.2），不因货权转移重置。

### 7.7 案例 7：月末对账与勾稽

**设定**：甲公司（一级，`is_internal = 1`）名下 `M0001` @ `WH01`，二级分为采购事业部、电商事业部；另有丁公司（外部）代管货 `M0005` 3 台。

| # | 校验项 | 公式 / 口径 | 结果 |
|---|---|---|---|
| 1 | **数量守恒（物理）** | 期末 = 期初 + Σ入库 − Σ出库　（**货权转移不进入本式**，因数量不变） | ✓ |
| 2 | **价值守恒（一级层）** | 期末金额 = 期初 + Σ入 − Σ出 ± 舍入差异 | ✓ |
| 3 | **层间汇总** | 一级（甲）60 = 二级 采购事业部 40 ＋ 电商事业部 20 | ✓ |
| 4 | **存货总额** | Σ 一级层中 `is_internal = 1` 的金额 = 甲层 600.00（**不含**丁层） | ✓ |
| 5 | **与业务系统数量对账** | 按 `(物料, 仓库, 批次)` **物理口径**逐项比对 | 一致 |
| 6 | **与金蝶总账金额对账** | 本系统存货科目余额 vs 金蝶存货类科目余额（月结） | 一致 |
| 7 | Σ 二级 `alloc_amount` 汇总 | = 一级层金额　（**硬校验**，案例 7.2） | ✓ |
| — | Σ 二级 `internal_amount` 汇总 | ≠ 一级层金额是**正常**（差额 = 内部未实现毛利）——**不做等式校验** | — |

**与业务系统对账的两条口径约定**

```
数量对账基准：物理在库数量（业务系统按物理管理，不一定有货主维度）
              → 若业务侧也建货主维度，可对到 (物料, 仓库, 批次, 一级货主)
金额对账基准：金蝶总账（不比对业务系统，见《差距清单》F04）
```

**货权转移在守恒公式中的位置**

| 公式 | 货权转移的影响 |
|---|---|
| 数量守恒（校验 1） | **无影响**（数量不变） |
| 价值守恒（校验 2，单法人口径） | 转出方层减少、转入方层增加；**对外转移则总额减少**（转为应收），**集团内转移总额不变** |
| 层间汇总（校验 3） | 无影响 |
| 存货总额（校验 4） | 对外转移使存货总额下降；集团内转移不改变法人各自的一级层合计 |

**要点**

1. **货权转移不进数量守恒公式**——这是它与出入库的本质区别，必须在校验清单里写清，否则会被误加进"Σ出库"。
2. **物理口径与权属口径要在对账报告里分列**（7.4 的分叉场景下二者不等）。
3. 月度校验清单必须包含 **层间汇总（一级 = Σ二级）**，这是货主分层引入后新增的一条，漏掉就发现不了二级分摊错误。
4. 汇总二级金额时**只汇总会计分摊额**（`alloc_amount`）。若误用内部结算额（`internal_amount`）汇总，会得到"二级 > 一级"的假差异——那不是错误，是**内部未实现毛利**。这条要在校验清单里显式标注为"不做校验"，否则运维会天天来问（R5）。

## 8. 表述规范：维度与字段命名建议

### 8.1 货主档案：用树，不要硬编码两级

| 表 `t_cargo_owner` | 说明 |
|---|---|
| `owner_code` | 主键 |
| `owner_name` | 名称 |
| `owner_level` | 层级（1 / 2 / …）——一期用 1、2 |
| `parent_owner_code` | 上级货主，一级为空 |
| `is_internal` | 是否我方主体（**决定是否计入存货总额**，R4） |
| `legal_entity` | 对应法人/账套（**一级货主即此值**，O-01） |
| `is_active` / `effective_from` / `effective_to` | 启停与生效期 |

> **`is_inventory_accounted` 不属货主档案**：它挂在**仓库档案 `t_warehouse`**（"是否参与存货核算"是**仓库**的属性，不是货主的属性）；货主侧的权属判断用 `is_internal`。两字段语义不同，不可互相替代。

理由：两级是当前需求，三级是未来的可能性（集团 → 子公司 → 部门）。自关联树加 `owner_level` 即可兼容，硬编码两级字段将来要改主键。

### 8.2 与 `legal_entity` 的关系（O-01 已定：同一概念）

**决定**：一级货主 **就是** 法人主体，`legal_entity` 不再单独建字段，由货主档案承接。

| 影响 | 处理 |
|---|---|
| 《差距清单》F18 | **直接闭环**——货主表即为 `legal_entity` 的载体 |
| 设计文档 4.1 / 4.2 / 4.3 | 增加 `owner_code`（一级）即等于增加了法人维度 |
| 契约 2.1"仓库所属公司/组织" | 由货主档案 + 仓库的 `owner_code` 表达 |
| 契约 3"A 级：仓库归属（所属公司/组织）" | 与一级货主编码同源，一次对齐 |

### 8.3 库存与单据的字段建议

| 表 | 建议 | 说明 |
|---|---|---|
| `t_inventory_balance` | 主键 = `(物料, 仓库, 批次, **一级货主**)` | **存货账**。与《差距清单》F05 的粒度决策**必须同时定** |
| `t_owner_allocation`（建议新增） | `(物料, 仓库, 批次, 一级货主, **二级货主**)` + `qty` + `alloc_amount` + `internal_amount` + `internal_cost_price` | **管理拆分账**：`alloc_amount` 按**一级均价**分摊（可加总回一级层），`internal_amount` 按**内部结算价**累计（不可加总，差额 = 内部未实现毛利）；不建立存货均价池 |
| `t_internal_price`（建议新增） | `(物料 / 物料组) × (转入方二级) × 生效区间` + `price_type` + `price_value` / `markup_rate` + `status` | **二级考核价目表**（4.6）：带生效期、按业务日期取价、取到即快照；一期配在库存中心，二期随交易中心迁移 |

| `t_document_line` | `owner_l1`、`owner_l2` | 单据行上的货主归属 |
| `t_batch` | **不变** | 批次档案不加货主——物理属性，不因货主而变 |
| `t_voucher_line` | `owner_code`（一级） | 辅助核算维度；二级不体现（非会计主体） |
| `t_calc_log` | `owner_code` | 保持 before/after 快照在货主层可追溯 |

> 把二级货主放在独立的 `t_owner_allocation` 而不是塞进余额表主键，好处是：存货账的键只有四轴、口径干净；二级的调整（案例 2）变成一次分摊记录的改写，不会污染存货账，也不会误参与均价计算。若团队倾向单表，替代方案是在 `t_inventory_balance` 增加 `owner_l2` 列但**引擎只用一级聚合**——代价是每次聚合都要记得排除，容易出错，不推荐。

#### O-19 专述：一期"不做审批流"到底不做哪一半

这条容易在实现时被理解成"什么审批都不做"，所以要拆开说：

| 分一半看 | 一期 | 二期 |
|---|---|---|
| **单据状态机**里的「待审 / 已审核」状态位 | **保留** | 不变 |
| **审核动作**（一个人看一眼、点确认，`approved_by` / `approved_at` 留痕） | **做** | 不变 |
| **多级审批流引擎**（可配置节点、会签、条件分支、委托、超时升级） | **不做，只预留接口** | 接上 |

理由：状态位和审核动作是**会计留痕的组成部分**——没有 `approved_by`，事后无法回答"这笔补录谁批的"，审计过不去。而多级流程引擎是**组织流程的组成部分**，它会随组织架构变，一期硬做进去就会绑死在库存中心里。

**预留方式**：与设计文档 §7.6「数据接入适配层」同一套路——定义 `ApprovalGateway` 接口（`submit` / `approve` / `reject` / `query`），一期提供**单点直通实现**（提交即由当前有权限的人确认），二期换成真实流程引擎的实现，**单据侧代码不改**。这与 4.7 的"可剥离原则"是同一个设计意图：**边界先划在接口上，而不是划在功能上**。

> 这条同时解决《核算引擎设计要点》E-08 的落地问题：`PERIOD_ADJUST` **必审**在一期就是"必须过一次单点审核动作"，不是"必须走流程"。两处口径一致。

## 11. 一页速查

**表述七条**

1. **一级货主 = 法人主体（`legal_entity`）**；**二级货主 = 内部管理维度**。用 `t_cargo_owner` 自关联树 + 单列 `owner_code`，不硬编码两级。
2. **数量守恒，价值分层**：数量在 `(物料, 仓库, 批次, 一级货主)` 唯一，一级货主数量 = Σ 二级货主数量（**因每行 `owner_l2` 必填而恒成立**——行级必填属性，缺失即 `E-OWNER-L2-MISSING`：二级货主缺失；但它**只是行的必填属性，不是维度轴**，不进四轴、不进核算单元键、不进均价池）。
3. **存货总额 = Σ 一级货主层中 `is_internal = 1` 的金额**；二级层是管理视角，**绝不相加**。
4. **批次是物理的，批次价格是价值的**：同一批次号在不同一级货主下可以有不同的价格。
5. **货权转移不改变物理层、不改变物理库龄**；只有"持有天数"从转移日起算。
6. **货主变化分两组**：伴随物理移动（采购/销售/退货）与不伴随物理移动（货权转移/货主重分配）。**后者必须独立成单**。
7. **加进货主只换维度、不换公式**——F1–F4、F6–F11 全部沿用。

**派生五规则（由 O-01/O-02/O-03 + 内部作价特性得出）**

| # | 规则 |
|---|---|
| R1 | 一级货权转移**必作价、必出凭证、必产生会计损益** |
| R2 | 二级重分配**必按内部结算价作价**，差额进**二级内部损益（管理口径）**；**不出会计凭证、不确认会计损益** |
| R3 | **存货**均价池只在一级货主层建立；二级另维护**内部结算价**（管理口径） |
| R4 | **存货总额 = Σ 一级层 `is_internal = 1` 的金额** |
| R5 | **二级内部结算价不影响会计**：一级层成本、存货总额、凭证、跌价基数均与其无关 |

**二级层一个数量、两个金额**

| 金额 | 计算 | 能否加总回一级层 |
|---|---|---|
| `alloc_amount` 会计分摊额 | 数量 × **一级均价** | **能**——`Σ alloc_amount = 一级层金额`（**硬校验**） |
| `internal_amount` 内部结算额 | 按 **`internal_price`** 累计 | **不能**——差额 = 内部未实现毛利（**不做等式校验**） |

**作价来源与系统边界（v1.3）**

| 问题 | 结论 |
|---|---|
| 一级作价配不配置？ | **不配置**。它是交易数据；财务只**取价 + 校验**，不做定价（4.6） |
| 二级作价配不配置？ | **必须配置**。带生效期的价目表，按业务日期取价、取到即快照、调价不追溯（4.6） |
| 二级价用固定价还是加成率？ | **两种都要**，`price_type` 是**行属性**逐行选。唯一约束落在(具体度 + 生效区间)上、**不带上 `price_type`**，否则同一格子会出现两条互相竞争的行（4.6） |
| 加成率算完存什么？ | **一个价、三个数**：`price_base`（当时一级货主层均价）+ `markup_rate` + `price_value`。少存一个就没法复现（4.6） |
| 放在哪？ | 一期配在**库存中心**；二期随**产权交易中心**迁移——届时库存中心一个价格都不配 |
| 产权交易中心一期做吗？ | **不做，先规划**。一期由库存中心出**货权变更单**临时承载，按可剥离形态设计（4.7） |
| 「不参与审计开票」是什么意思？ | **≠ 不参与会计**。集团内跨法人转移仍**出凭证、确认损益、合并抵消**（4.6） |
| 一句话分工 | **交易中心决定"交易是否成立"，库存中心决定"会计怎么记"** |

**术语统一**

| 本文 | 统一后 |
|---|---|
| 滑动平均 | 移动加权平均（滑动平均）`MA` |
| 一品一价 | 个别计价（按件核算）`SI` |
