# PRD精简：通用方案——核销企业与银行管理

> **文档状态**：初稿（待业务确认）  
> **适用范围**：供应链金融平台——客户管理、贷后管理、结算管理模块

---

## 一、背景与目标

### 为什么做
原文档未覆盖核销企业管理和银行合作方退出管理，导致贷后资产处置和银行合作生命周期缺少统一规范，存在合规风险和操作盲区。

### 做什么
建立核销企业全生命周期管理规范（3类型5状态）和银行合作方准入/评级/退出/切换机制。

### 目标指标
- 核销企业状态同步延迟：≤1分钟（实时API）
- 银行评级报告生成频率：每季度自动
- 多银行切换业务中断时间：0（路由级自动切换）

---

## 二、范围决策

### 本次包含
1. **核销企业管理**：3种核销类型（主动注销/被动核销/强制清退）、5种企业状态（正常/预警/冻结/清算/已注销）、核销前状态管理、被动核销3级审批流程、强制清退流程、数据保留策略、重新合作机制
2. **银行合作方管理**：准入条件（5维度）+准入流程（8步）、5维度评级（A/B/C/D）、3种退出类型（主动/被动/强制）、多银行切换机制、对接技术规范
3. **系统集成要求**：核销状态同步（5个系统）、银行状态同步（3个系统）
4. **报表与审计**：核销企业报表（3张）、银行合作报表（3张）

### 本次不包含
- 核销后的具体账务会计分录规则（由财务系统PRD覆盖）
- 银行端内部核心系统改造
- 具体UI页面设计和交互流程
- 与法院/工商系统的直连接口（通过人工材料上传方式处理）

## 三、关键决策记录

| 决策项 | 决策结果 | 决策依据 |
|--------|----------|----------|
| 核销类型 | 主动注销/被动核销/强制清退 | 覆盖所有终止合作场景 |
| 企业状态 | 正常/预警/冻结/清算/已注销 | 清晰的状态机，权限逐层收紧 |
| 被动核销触发条件 | 破产/吊销满6个月/失联满1年/核销审批通过/ fraud立案 | 穷尽追索手段后的最终处置 |
| 核销审批层级 | 风控经理→财务总监→总经理(>50万) | 风险+财务+决策三层把关 |
| 强制清退触发 | 连续2季度C级且拒整改/不良率>10%/重大违约/刑事立案 | 核心企业专用红线 |
| 数据保留 | 基础档案/合同/审批/流水/催收永久；通信/日志10年；敏感证件5年删除 | 合规+隐私平衡 |
| 银行准入门槛 | 持牌机构+监管评级≥3级+初始授信≥5000万 | 风险可控+业务规模保障 |
| 银行评级维度 | 放款效率25%+资金稳定性25%+系统稳定性20%+配合度20%+风控10% | 量化合作质量 |
| 退出过渡期 | 主动90天/被动60天/强制立即 | 风险等级递进 |
| 多银行切换 | A级>B级>C级优先级自动路由 | 保障业务连续性 |
