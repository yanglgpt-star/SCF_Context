# PRD精简_货权管理

## 一、背景与目标

### 1.1 为什么做

- **决策层**：缺乏品类风险穿透分析能力——3C电子65%已接近红线而白酒65%仍在安全区间，但报表显示相同数字，导致3C不良率升至7.2%才发现。缺乏实时风控决策依据。
- **管理层**：
  - 质押率管理失控：质押率超标预警率仅70%，货权异常率5%
  - 出库审批效率低：审批时效从4小时延长至12小时，货物处置周期60天
  - 品类差异化监控缺失：25%品类风险未及时发现，预警及时率仅75%
- **执行层**：每日手工查询多系统判断放货条件，货值变化后逐笔核查质押率，容易遗漏关键风险点。

### 1.2 目标指标

| 目标指标 | 当前值 | 目标值 | 衡量方式 |
|---------|--------|--------|---------|
| 质押率超标预警率 | 70% | 100% | 系统预警覆盖的在库业务占比 |
| 货权异常率 | 5% | ≤2% | 月度异常业务数/总在库业务数 |
| 出库审批时效 | 12小时 | ≤2小时 | 从接收银行授权到下发WMS指令的平均时长 |
| 盘点差异率 | 3% | ≤2% | 盘点差异笔数/总盘点笔数 |
| 品类风险预警及时率 | 75% | ≥95% | 在时效要求内响应的预警占比 |
| 3C品类不良率 | 7.2% | ≤3% | 3C品类月度不良业务占比 |
| 货物处置周期 | 60天 | ≤45天 | 从启动到处置完成的平均天数 |
| 自动审批覆盖率 | — | 50% | 自动审批出库笔数/总出库笔数 |

## 二、范围决策

### 2.1 本期做（P0-P2）

| 优先级 | 模块 | 内容 |
|-------|------|------|
| P0 | 出库审批决策 | 银行授权接收、三重自动校验、智能审批策略（≤5万自动通过/>100%自动拒绝）、质押率分级标准 |
| P0 | 货值监控与预警 | 价格库管理、品类差异化监控、分级预警响应、相对质押率计算 |
| P0 | WMS实时对接 | 入库/出库/库存/盘点数据同步，出库指令下发 |
| P0 | 银行系统对接 | 出库授权接收、放款/还款数据同步 |
| P1 | 入库监控 | 入库预报、入库确认、自动比对、异常预警 |
| P1 | 库存总览 | 多维度统计（品类/仓库/客户/核心企业/风险）、货值分布、地图化展示 |
| P1 | 仓单管理 | 仓单开立、质押登记、变更、解押、区块链存证 |
| P1 | 盘点监控 | 盘点计划（按价值分层）、数据同步、差异识别与处理 |
| P1 | 价格数据源对接 | 中关村在线/1919/酒仙网等价格数据抓取/对接 |
| P2 | 品类差异化监控配置 | 3C新品发布/白酒串货/食品保质期等专项规则配置 |
| P2 | 异常出库监控 | 未经审批出库、数量不符、频繁出库、非营业时间出库等自动预警 |
| P2 | 报表与埋点 | 货权相关统计报表、核心操作行为埋点 |

### 2.2 本期不做（延后）

| 事项 | 原因 | 计划处理方式 |
|-----|------|------------|
| 与物流TMS/DMS系统的深度集成 | 原始文档定位为"非核心集成，可选"，本期聚焦WMS控货 | 延后至二期评估 |
| AI风险预测模型 | 需积累历史预警处置数据后方可训练 | 延后至数据积累充足后 |
| 全自动货物处置（无人审批） | 涉及资金安全和法律合规，需人工介入 | 保持人工审批环节 |
| 跨平台仓单互认 | 涉及行业标准统一，当前生态不成熟 | 待行业标准明确后评估 |
| 物联网传感器实时监控（温湿度等） | 原始文档仅提及食品存储条件监控，未明确传感器硬件方案 | 待仓储方硬件条件确认后评估 |

## 三、关键决策记录

| 决策 | 内容 | 原因 |
|-----|------|------|
| 【决策】5万元自动审批门槛 | 出库货值≤5万且出库后质押率≤80%自动通过 | 历史数据显示≤5万申请占总量65%但金额仅18%，风险敞口可控；约为单件3C产品2-3倍价值 |
| 【决策】80%质押率安全线 | 自动审批通过阈值设定为出库后质押率≤80% | 20%安全缓冲，可覆盖3C产品1.5个月极端下跌；行业对标京东75%/平安80% |
| 【决策】品类差异化质押率上限 | 3C电子70%、食品75%、白酒80%、家电80% | 基于各品类预期最大跌幅+安全边际计算，行业对标已确认 |
| 【决策】预警四级分层 | 正常(≤85%)、警戒(85-100%)、超标(100-115%)、紧急(>115%) | 基于相对质押率统一度量跨品类风险，已确认 |
| 【决策】WMS接口标准化 | 统一采用 `/api/wms/*` 路径（inbound/outbound/inventory/stocktaking/release） | 对接富勒FLUX/科箭Power WMS/巨沃WMS及自研WMS，Webhook+API模式 |
| 【决策】自动比对阈值 | 入库数量±5%、时间±3天，品类/品牌/型号必须一致 | 原始素材定义，覆盖合理误差 |
| 【决策】盘点差异处理 | ≤2%记录核查、2%-5%人工复盘、>5%冻结融资+实地核查 | 原始素材定义 |
| 【决策】3C动态阈值调整 | 新品发布期自动通过阈值下调10%（70%）、促销季下调5%（75%） | 3C产品新品发布后月跌幅10-15%，需动态应对 |
