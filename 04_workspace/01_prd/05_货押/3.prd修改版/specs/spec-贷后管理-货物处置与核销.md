# Spec：贷后管理——货物处置与核销

> **涉及端**：🔧 运营端、🏭 企业端-核心企业


> **对应PRD**：PRD_贷后管理.md — 5.2 货物处置 + 5.4 资产核销  
> **覆盖范围**：核心企业回购优先（未拆封90%/已拆封未使用85%/已使用80%）、平台渠道处置、市场拍卖、资产核销流程  
> **版本**：V1.0

---

## 1. Goal（目标）

**运营端风控/催收团队**通过多渠道货物处置（核心企业回购优先→平台渠道→市场拍卖）和规范化资产核销流程，实现：
- 货物处置周期≤45天（从启动处置到资金回收）
- 货物处置回收率≥85%（处置回收金额/逾期本金）
- 核销流程在线化，审批周期≤5个工作日

---

## 2. Scope（边界）

### 本次包含
- 处置方案智能推荐（优先核心企业回购，次选平台渠道/市场拍卖）
- 回购价格自动计算（市场价×折扣率，支持协商±10%）
- 回购流程在线化（邀请推送→评估→协商→签署协议→交接→付款→结案）
- 平台渠道处置管理（合作渠道商挂牌、报价收集）
- 市场拍卖流程管理（保留价设定、挂牌、最多3次拍卖）
- 资产核销在线申请（条件自动识别、证明材料上传）
- 核销多级审批流程（风控经理→财务总监→总经理>50万）

### 本次不包含
- 资产证券化管理（ABS，延后V3.0）
- 跨境法律诉讼支持（延后V3.0）
- 处置渠道智能竞价算法（自动比价）
- 自动对接外部拍卖平台API（仅支持线上记录和进度跟踪）
- 核销后的具体会计分录规则（由财务系统覆盖）
- 与法院/工商系统的直连接口（通过人工材料上传处理）

### 异常状态全覆盖

| 异常场景 | 系统行为 | 状态流转 |
|----------|----------|----------|
| 核心企业拒绝回购 | 自动转入次优处置渠道（平台渠道/市场拍卖），记录拒绝原因 | 回购→平台渠道/拍卖 |
| 回购价格协商不一致 | 平台风控经理介入协调；仍不一致则转入其他渠道 | 协商中→协调/转渠道 |
| 协商价格超出建议价±10% | 系统拦截，提示"需风控经理审批"，流转至风控经理待办 | 协商→审批 |
| 货物交接时发现损坏 | 拍照记录，按实际状况重新定价，差额由责任方承担 | 交接→重新定价 |
| 核心企业付款延迟超72小时 | 自动催办通知；超7天未付款启动法律程序 | 待付款→催办→法律 |
| 市场拍卖流拍 | 降低保留价再次拍卖，最多3次；仍流拍则协议转让 | 拍卖→降价再拍→协议转让 |
| 处置价格低于评估价70% | 系统拦截，提示"需额外审批"，流转至风控总监待办 | 定价→额外审批 |
| 核销申请被驳回 | 返回申请人，记录驳回原因，可补充材料后重新提交 | 审批中→已驳回→重新提交 |
| 核销执行后发现可执行财产 | 记录异常，触发专项审查流程（系统标记不可恢复） | 已核销→专项审查 |
| 同一客户多次申请核销 | 系统自动标记"高频核销客户"，触发专项审查 | 申请→专项审查 |

## 4. Constraints（约束）

### 技术约束
- 报表查询响应≤3秒
- 处置全流程记录留存不少于10年
- 核销记录永久留存，不可删除
- 支持移动端查看处置进度（弱网环境兼容）

### 安全约束
- 货物处置回收资金必须进入平台指定监管账户，禁止个人账户代收
- 核销申请一旦提交，审批完成前不可撤销
- 核销执行后不可恢复，系统需二次确认弹窗
- 诉讼文书等法律材料加密存储
- 处置过程中的货物照片、交接记录完整留存

### 业务约束
- 回购折扣率：未拆封90%、已拆封未使用85%、已使用80%（系统强制校验）
- 回购协商范围：建议价±10%，超出需风控经理审批
- 处置价格低于评估价70%时，需额外审批
- 核销条件：法律诉讼终结（终本裁定）+ 确无可执行财产 + 已穷尽追索手段
- 核销审批：金额>50万需总经理审批
- 自动识别建议核销：逾期>180天 AND 催收记录>10次 AND 诉讼状态="终本"
- 货物处置启动条件：逾期>30天且催收无效

### 跨模块约束
- **与WMS系统**：处置前查询在库货物实际状态，处置完成后确认货物出库
- **与核心企业ERP**：回购邀请推送、协同状态回传
- **与结算数据流**：回购完成金额、核销金额需在每月4日前同步至结算管理模块

## 5. Acceptance Criteria（验收标准）

| 编号 | 验收标准 | 验证方式 |
|------|----------|----------|
| AC-1 | 打开货物处置发起页，逾期>30天且催收无效的业务，系统智能推荐最优处置方案（优先显示"核心企业回购"及预计回收金额/周期） | 打开页面验证推荐逻辑和展示字段 |
| AC-2 | 调接口 `POST /api/disposal/repurchase/price`，输入货物状态"未拆封"和市场价100万，返回回购价90万（100万×90%）；输入"已拆封未使用"返回85万；输入"已使用"返回80万 | 调接口验证三种折扣率的计算准确性 |
| AC-3 | 打开回购流程跟踪页，可见7个节点（启动→推送→评估→协商→签署→交接→付款）的可视化进度条，当前节点高亮，超时节点显示红色提醒 | 打开页面验证进度条和时限提醒 |
| AC-4 | 核心企业拒绝回购后，系统自动将处置方案变更为"平台渠道处置"，原回购记录归档，新处置流程自动启动 | 模拟拒绝操作，验证状态自动流转 |
| AC-5 | 打开核销申请页，逾期>180天、催收记录>10次、诉讼状态="终本"的业务自动显示"建议核销"红色标签，业务信息自动带入 | 打开页面验证自动标记和字段带入 |
| AC-6 | 调接口 `POST /api/write-off/apply` 提交核销申请后，系统生成审批流程；金额≤50万的申请显示3级审批（风控经理→财务总监），金额>50万显示4级（+总经理） | 调接口验证审批层级动态变化 |
| AC-7 | 核销审批通过后，系统二次确认弹窗提示"核销执行后不可恢复"；确认后核销状态变为"已核销"，记录永久归档且不可修改 | 执行核销操作验证二次确认和最终状态 |

## 6. Non-Goals（非目标）

以下功能是AI/技术最容易顺手做的，但本期明确排除：

1. **基于AI的货物价值预测模型**：不使用机器学习预测货物未来市场价格
2. **自动对接外部拍卖平台API**：不直接对接阿里拍卖/京东拍卖等平台API，仅支持线上记录拍卖结果
3. **自动生成法院诉讼材料**：不提供起诉状、证据清单等法律文书的自动生成
4. **区块链存证（货物处置环节）**：不对处置过程做区块链存证
5. **资产证券化（ABS）管理**：不支持不良资产打包转让的系统化流程
6. **智能议价机器人**：不支持系统自动与核心企业进行回购价格的多轮自动谈判
7. **基于图像识别的货物自动状态判定**：不通过照片AI识别货物是"未拆封/已拆封/已使用"，由人工/WMS系统录入
