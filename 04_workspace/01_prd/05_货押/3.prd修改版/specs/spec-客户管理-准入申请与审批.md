# Spec：客户管理-准入申请与审批

> **涉及端**：🔧 运营端、🏭 企业端-核心企业、🏪 企业端-融资企业


## 1. Goal（目标）

**谁**：经销商（企业端）、平台运营人员（运营端）、核心企业（企业端）
**怎么做**：通过在线申请、推荐码验证、核心企业确认、系统自动校验、差异化准入矩阵匹配审批流程
**达成什么**：
- 准入审核时效从5天缩短至≤2天
- 资料一次性完整率从50%提升至≥90%
- 准入通过率稳定在60-70%
- 核心企业推荐响应率100%在线确认

---

## 2. Scope（边界）

### 本次包含
- 经销商在线准入申请提交（基本信息+推荐码+资料上传）
- 推荐码生成、验证与生命周期管理
- 核心企业在线推荐确认与数据提供
- 准入资料完整性自动校验（格式/大小/必填项/证照有效期）
- 差异化准入矩阵（核心企业S/A/B/C × 经销商A+/A/B/C）
- 审批流程模板配置（2级/3级/5级）
- 准入结果通知（经销商+核心企业）

### 本次不包含
- AI智能尽调（自动尽调报告生成）
- 区块链电子仓单存证
- 客户自助修改档案信息（档案变更需经平台审核）
- 移动端独立APP（通过H5/小程序覆盖）
- 第三方数据市场对接（除征信和核心企业ERP外）
- 【待确认】审批流程配置中并行审批和会签的具体业务场景

---

## 3. I/O（输入输出）

### 3.1 经销商准入申请提交（企业端→系统）

**输入字段**：

| 字段名 | 类型 | 必填 | 校验规则 | 所属端 |
|--------|------|------|----------||--------|------|------|----------|--------|
| 企业名称 | String(100) | 是 | 与营业执照一致 | | 🏪 企业端-融资企业 |
| 统一社会信用代码 | String(18) | 是 | 18位标准格式 | | 🏪 企业端-融资企业 |
| 法定代表人姓名 | String(50) | 是 | - | | 🏪 企业端-融资企业 |
| 法定代表人身份证号 | String(18) | 是 | 18位身份证校验 | | 🏪 企业端-融资企业 |
| 联系电话 | String(20) | 是 | 手机号格式 | | 🏪 企业端-融资企业 |
| 注册地址 | String(200) | 是 | - | | 🏪 企业端-融资企业 |
| 推荐码 | String(32) | 是 | 核心企业预生成 | | 🏭 企业端-核心企业 |
| 营业执照 | File | 是 | PDF/JPG/PNG，≤10MB | | 🔧 运营端 |
| 法人身份证正反面 | File | 是 | JPG/PNG，≤5MB，有效期≥6个月 | | 🔧 运营端 |
| 公司章程 | File | 是 | PDF，≤20MB | | 🔧 运营端 |
| 近一年度审计报告 | File | 是 | PDF，≤30MB | | 🔧 运营端 |
| 近6个月银行流水 | File | 是 | PDF/Excel，≤20MB | | 🏦 银行端 |
| 与核心企业合作协议 | File | 是 | PDF，≤20MB | | 🏭 企业端-核心企业 |
| 近一年向核心企业采购记录 | File | 是 | Excel/PDF，≤10MB | | 🏭 企业端-核心企业 |

**输出**：
- **成功**：申请提交成功，返回申请编号，状态="准入申请中"
- **失败（资料不完整）**：返回缺失清单，禁止提交
- **失败（格式不符）**：提示重新上传（如超出大小、格式错误）
- **失败（证照已过期）**：禁止提交，提示更新证照
- **异常（系统错误）**：返回"系统繁忙，请稍后重试"

### 3.2 推荐码验证（系统内部）

**输入**：推荐码 String(32)

**输出**：
- **有效**：返回核心企业信息、推荐码剩余可用次数、有效期
- **不存在**：返回"推荐码无效，请向核心企业重新获取"
- **已过期**：返回"推荐码已过期，请联系核心企业重新生成"
- **已达使用上限**：返回"推荐码已达使用上限，请联系核心企业"

### 3.3 核心企业推荐确认（系统→核心企业→系统）

**输入（系统向核心企业推送）**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 申请编号 | String(32) | 经销商准入申请编号 |
| 经销商名称 | String(100) | 提交申请的企业名称 |
| 统一社会信用代码 | String(18) | - |
| 推荐码 | String(32) | 使用的推荐码 |

**输出（核心企业返回）**：
- **确认推荐**：返回经销商信用评级（A+/A/B/C）、近期供货数据
- **拒绝推荐**：返回拒绝原因
- **超时未响应**：【待确认】超时时间（建议72小时），超时后系统自动驳回申请

### 3.4 系统自动校验（系统内部）

**输入**：经销商准入申请全量数据

**输出**：
- **全部通过**：状态流转至"资料审核中"
- **资料不完整**：列出缺失清单，状态="已驳回"，原因="资料不完整"
- **黑名单命中**：状态="已驳回"，原因="命中黑名单"
- **证照即将过期**：允许提交但标记"临期预警"，审批时重点提示
- **证照已过期**：禁止提交，提示更新证照
- **征信异常**：状态="已驳回"，原因="征信校验不通过"，附具体说明

### 3.5 差异化准入矩阵匹配（系统内部）

**输入**：核心企业等级（S/A/B/C）、经销商信用等级（A+/A/B/C，A+视为A级）

**输出**：

| 核心企业等级 / 经销商等级 | A+（视为A级） | A | B | C |
|--------------------------|---------------|-----|-----|-----|
| **S级** | 快速通道（2级审批） | 标准流程（3级审批） | 标准流程+尽调 | 加强流程（5级审批） |
| **A级** | 标准流程（3级审批） | 标准流程（3级审批） | 标准流程+尽调 | 加强流程（5级审批） |
| **B级** | 标准流程（3级审批） | 标准流程+尽调 | 加强流程（5级审批） | 加强流程（5级审批）+额度限制 |
| **C级** | 标准流程+尽调 | 加强流程（5级审批） | 加强流程+额度限制 | 暂停准入（待重新评估） |

**建议授信额度范围与质押率上限参考值**：

| 核心企业等级 / 经销商等级 | A+（视为A级） | A | B | C |
|--------------------------|---------------|-----|-----|-----|
| **S级** | 100-500万/品类上限+5% | 50-300万/品类上限 | 30-100万/品类上限-5% | 10-50万/品类上限-10% |
| **A级** | 50-300万/品类上限 | 30-200万/品类上限 | 20-80万/品类上限-5% | 10-50万/品类上限-10% |
| **B级** | 30-200万/品类上限 | 20-100万/品类上限-5% | 10-50万/品类上限-10% | 5-30万/品类上限-15% |
| **C级** | 20-100万/品类上限-5% | 10-50万/品类上限-10% | 5-30万/品类上限-15% | 暂停准入 |

> **注意**：上述授信额度范围和质押率上限为参考值，【待确认】待风控负责人最终确认。系统支持配置化调整。

### 3.6 审批结果通知（系统→经销商/核心企业）

**审批通过**：
- 经销商：开通平台账号，授予授信额度，通知准入成功
- 核心企业：通知推荐结果，纳入推荐质量评估统计

**审批驳回**：
- 经销商：说明驳回原因，允许补充资料重新提交
- 核心企业：通知推荐未通过

## 4. Constraints（约束）

### 4.1 技术约束
- 文件上传支持格式：PDF/JPG/PNG/Excel/DOC，单文件最大30MB
- 证照OCR识别准确率≥95%（用于有效期自动提取）
- 推荐码有效期可配置（S级默认60天）
- 核心企业ERP接口：HTTPS RESTful API，OAuth 2.0+JWT，8个标准接口
- 征信系统接口：企查查（主）+ 天眼查（备）双源策略

### 4.2 安全约束
- 客户征信数据、证照影像加密存储（AES-256）
- 敏感信息传输采用HTTPS/TLS
- 推荐码为一次性使用或限次使用，防止泄露滥用
- 黑名单数据每日同步更新

### 4.3 设计约束
- A+级经销商在平台侧**视为A级**，所有审批通道、授信额度、质押率上限均按A级处理
- 证照到期前默认30天预警（可配置，最小7天）
- 准入资料清单可配置化，不同客户类型（经销商/核心企业/银行/仓储方）相互独立
- 资料项停用后，新申请无需提交该资料，但历史已提交资料保留

## 5. Acceptance Criteria（验收标准）

### 5.1 经销商在线准入申请
1. **打开企业端准入申请页面**，经销商填写完整信息并上传所有必填资料后，点击"提交申请"，系统返回唯一申请编号，状态为"准入申请中"
2. **打开企业端准入申请页面**，经销商遗漏必填资料（如未上传营业执照），点击"提交申请"，系统列出缺失清单，提交按钮置灰不可点
3. **打开企业端准入申请页面**，经销商上传超过10MB的文件，系统实时提示"文件大小超出限制，请压缩后重新上传"
4. **打开企业端准入申请页面**，经销商上传格式为.txt的文件到营业执照栏，系统实时提示"仅支持PDF/JPG/PNG格式"
5. **打开企业端准入申请页面**，经销商填写已过期推荐码，系统提示"推荐码已过期，请联系核心企业重新生成"

### 5.2 推荐码验证与核心企业确认
6. **打开核心企业端推荐码管理页面**，核心企业点击"生成推荐码"，系统生成唯一推荐码，支持设置有效期和数量上限
7. **调接口** `/api/v1/referral-code/validate`，传入有效推荐码，返回核心企业信息、剩余可用次数、有效期
8. **调接口** `/api/v1/referral-code/validate`，传入不存在的推荐码，返回错误码"REFERRAL_CODE_INVALID"
9. **打开核心企业端推荐确认页面**，核心企业收到推荐确认通知后点击"确认推荐"，系统记录确认结果并获取经销商信用评级
10. **打开核心企业端推荐确认页面**，核心企业点击"拒绝推荐"，系统记录拒绝原因，经销商申请状态变更为"已驳回"

### 5.3 系统自动校验
11. **调接口** `/api/v1/admission/verify`，传入命中黑名单的企业名称，返回"命中黑名单，申请被驳回"并附命中原因
12. **打开企业端准入申请页面**，经销商上传距到期日20天的营业执照，系统允许提交但标记"临期预警"，审批端重点提示
13. **打开企业端准入申请页面**，经销商上传已过期营业执照，系统禁止提交并提示"证照已过期，请先更新"

### 5.4 差异化准入矩阵匹配
14. **调接口** `/api/v1/admission/match-flow`，输入核心企业等级=S、经销商等级=A+（视为A级），返回"快速通道（2级审批）"
15. **调接口** `/api/v1/admission/match-flow`，输入核心企业等级=C、经销商等级=C，返回"暂停准入（待重新评估）"
16. **打开运营端差异化准入矩阵配置页面**，运营人员修改某单元格的建议授信额度范围，保存后即时生效，新申请按新规则匹配

### 5.5 审批流程模板配置
17. **打开运营端审批流程模板配置页面**，运营人员创建"快速通道-2级审批"模板，配置初审→终审两个节点，保存后模板状态为"启用"
18. **打开运营端审批流程模板配置页面**，运营人员停用某审批流程模板，新申请不再匹配该模板，历史已匹配申请不受影响
19. **调接口** `/api/v1/admission/approval-flow`，查看已配置模板列表，返回模板ID、名称、级数、节点配置、启用状态

### 5.6 准入结果闭环
20. **打开经销商企业端消息中心**，准入审批通过后，经销商收到系统通知，内容包含"准入通过，授信额度XX万元"
21. **打开核心企业端消息中心**，推荐结果反馈后，核心企业收到通知，内容包含"您推荐的XX经销商已准入通过/驳回"
22. **打开运营端客户管理列表**，已准入客户显示状态="正常"，展示授信额度和客户等级标签

## 6. Non-Goals（非目标）

1. **AI智能尽调报告生成**：本期保留人工尽调环节，不接入AI自动生成尽调报告
2. **客户画像AI预测模型**：本期基于规则引擎评估客户资质，不构建AI预测模型
3. **区块链电子仓单存证**：归属货权管理模块，本期不涉及
4. **核心企业协同催收功能**：归属贷后管理模块，本期不涉及
5. **自动调整准入矩阵参数**：矩阵参数由运营人员配置调整，系统不自动根据数据动态调整
6. **实时视频面签**：本期不支持远程视频面签功能
7. **智能OCR自动填单**：仅做OCR信息提取辅助校验，不做自动填单
