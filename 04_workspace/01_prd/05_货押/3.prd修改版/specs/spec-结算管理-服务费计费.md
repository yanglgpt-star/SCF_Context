# Spec：结算管理——服务费计费

> **涉及端**：🔧 运营端


> **对应PRD**：PRD_结算管理.md — 5.2 服务费配置 + 5.3 账单管理  
> **覆盖范围**：服务费计算（A级3%/B级4%/C级5%）、分段计费（>100万降1%）、期限调整（≤30天+0.5%）、自动计税（6%增值税）  
> **版本**：V1.0

---

## 1. Goal（目标）

**财务/运营人员**通过配置化计费规则和自动化账单引擎，实现服务费精准计算和账单自动生成，达成：
- 账单准确率100%
- 服务费收缴率≥98%
- 单笔账单生成响应≤3秒
- 计费规则变更支持热更新，历史已确认账单不受影响

---

## 2. Scope（边界）

### 本次包含
- 4种计费模式配置（按融资金额比例/按天计息/固定费用/分段计费）
- 按客户等级差异化定价（A级3%/B级4%/C级5%）
- 分段计费（>100万降1%）
- 期限调整（≤30天+0.5%）
- 自动计税（6%增值税）
- 融资完成后自动账单生成（含唯一编号、PDF格式、计算过程明细）
- 计费规则版本管理（保存/查看历史/回滚/对比）
- 账单发送（一键发送邮件/短信）和催缴提醒

### 本次不包含
- 多币种结算（美元/港币等，延后V3.0）
- 电子发票集成（延后V2.0）
- 税务自动化申报（延后V2.0）
- 资金池统一调度和计息（延后V3.0）
- 客户信用评级动态调整费率（由客户管理模块负责）
- 银行流水对账（由分润对账模块负责）

| tax_amount | decimal(18,2) | 增值税额 = 服务费 × 6% |

### 异常状态全覆盖

| 异常场景 | 系统行为 | 处理方式 |
|----------|----------|----------|
| 规则配置冲突（同条件下多条规则） | 系统按优先级取第一条，记录冲突告警 | 人工核查后调整规则优先级 |
| 费率超出允许范围 | 系统拦截保存，提示"费率超出合规范围" | 调整至合规范围后重新保存 |
| 融资金额为0或负数 | 系统拦截计算，返回错误"融资金额非法" | 人工核查业务数据 |
| 账单金额与客户预期不符 | 支持差异查询，展示计算过程明细供核对 | 人工核查规则配置和业务数据 |
| 计算精度问题（小数位） | 系统统一保留2位小数，四舍五入 | 自动处理 |
| 规则版本变更时存在未结清账单 | 未结清账单按原版本计算，新账单按新版本 | 系统自动隔离 |
| 账单逾期（到期未付款） | 自动标记"逾期"，生成催缴任务，冻结客户新增融资 | 自动触发催缴流程 |
| 客户付款金额>账单金额 | 标记"多付款"，差额作为预付款可用于抵扣未来账单 | 自动挂账 |
| 客户付款金额<账单金额 | 标记"部分收款"，剩余金额继续催收 | 自动更新账单状态 |

## 4. Constraints（约束）

### 技术约束
- 单笔账单生成响应≤3秒
- 报表查询响应≤3秒
- 批量导出1000条数据≤10秒
- 计费规则配置变更支持热更新，无需重启服务
- 月末/季末结算高峰期支持弹性扩容
- 结算系统可用性≥99.9%

### 安全约束
- 资金相关操作需二次确认（弹窗+短信验证码）
- 支付接口调用需IP白名单+签名验证
- 敏感财务数据（银行账户、交易金额）传输加密
- 防重放攻击：所有支付请求需包含唯一请求ID
- 账单和分润明细保留不少于10年

### 业务约束
- 服务费费率：A级年化3%、B级4%、C级5%（系统强制校验）
- 分段计费：>100万部分降1%（如>100万段费率 = 原费率 - 1%）
- 期限调整：≤30天+0.5%，>90天-0.5%
- 增值税率：6%（系统自动计税，不可人工修改税率）
- 账单编号格式：BILL+年月日+6位流水号（如BILL20260426000001）
- 账单逾期标记：到期当天0点自动扫描，未付款标记"逾期"
- 历史版本隔离：规则版本变更后，已确认账单金额保持不变

### 跨模块约束
- **与客户管理**：客户等级变化时，新账单按新等级费率计算，已生成账单不受影响
- **与融资业务管理**：融资放款成功后触发账单生成
- **与贷后管理**：逾期账单状态同步至贷后模块，用于催收优先级判断

## 5. Acceptance Criteria（验收标准）

| 编号 | 验收标准 | 验证方式 |
|------|----------|----------|
| AC-1 | 打开服务费规则配置页，选择"按融资金额比例"模式，配置A级3%/B级4%/C级5%后保存，系统展示公式预览和示例计算结果 | 打开页面验证配置保存和公式预览 |
| AC-2 | 调接口 `POST /api/billing/calculate`，输入A级客户融资100万、期限60天、品类3C电子，返回服务费5000元（100万×3%×60/360），税额300元（5000×6%），合计5300元 | 调接口验证计算公式的准确性 |
| AC-3 | 融资业务放款成功后3秒内，系统自动生成待核对账单，账单编号符合BILL+年月日+6位流水号格式 | 模拟放款后验证账单生成时间和编号格式 |
| AC-4 | 调接口 `GET /api/bill/{bill_id}`，返回账单包含服务费金额、6%增值税额、合计金额、计算过程明细、应用规则版本号 | 调接口验证返回字段完整性 |
| AC-5 | 费率规则版本从V1.0变更为V2.0后，历史已确认账单金额保持不变，新放款业务按V2.0计算 | 变更规则后分别查询历史账单和新账单验证金额 |
| AC-6 | 分段计费场景：输入融资120万、费率规则（≤50万3.5%/50-100万3%/>100万2.5%），系统按50万×3.5% + 50万×3% + 20万×2.5% = 3.75万计算 | 调接口验证分段累加计算逻辑 |
| AC-7 | 打开账单详情页，可见标准PDF格式预览、付款信息、计算过程明细；点击"发送账单"后企业端收到邮件/短信通知 | 打开页面验证预览和发送功能 |

## 6. Non-Goals（非目标）

以下功能是AI/技术最容易顺手做的，但本期明确排除：

1. **AI智能定价推荐**：不基于历史数据和市场趋势自动推荐最优费率
2. **多币种（美元/港币）结算**：本期仅支持人民币计费
3. **自动对接税控系统开具电子发票**：不直接对接税务局电子发票系统
4. **客户信用评级动态调整费率**：客户等级变化触发费率调整由客户管理模块负责，结算仅读取结果
5. **资金池统一调度计息**：不涉及平台自有资金池的管理和计息
6. **实时费率A/B测试**：不支持同一时段对不同客户群体应用不同费率进行效果对比
7. **基于大数据的费率效果预测**：不预测不同费率对业务量的影响
