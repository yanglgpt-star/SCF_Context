# Spec：融资业务-审批流程引擎

> **涉及端**：🔧 运营端


## 1. Goal（目标）

**谁**：平台审批人员（运营端）、风控人员（运营端）、系统管理员（运营端）
**怎么做**：通过可配置的审批流程引擎，根据融资金额、客户等级、核心企业等级等条件智能匹配差异化审批流程（快速2级/标准3级/加强5级），结合5维度综合风险评分辅助审批决策，支持审批待办自动分配
**达成什么**：
- 审批时效从2.5天缩短至≤1天
- A级客户30万以下申请4小时内完成审批
- 审批通过后逾期率从3.2%降至≤1.5%
- 标准业务自动审批覆盖60%

---

## 2. Scope（边界）

### 本次包含
- 审批流程模板配置（快速2级/标准3级/加强5级）
- 智能流程匹配引擎（基于金额+客户等级+质押率+核心企业等级）
- 综合风险评分模型（5维度：客户资质20%/核心企业背书25%/历史表现25%/质押物评估20%/市场风险10%）
- 集成化审批页（一页集成所有决策信息）
- 审批待办列表与分配（按负载/专业领域/轮询）
- 审批状态流转与超时处理
- 审批质量考核（及时率/准确率/审批后逾期率）

### 本次不包含
- 移动端审批（审批操作仅在PC端支持）
- AI自动审批决策（系统仅提供建议，最终决策由人工做出）
- 审批案例库（P2，待运营确认是否本期上线）
- 智能外呼催收（归属贷后管理模块）
- 【待确认】审批人专业领域分配策略具体规则
- 【待确认】批量操作的具体范围
- 【待确认】新审批员"双人审核"机制的系统实现方式
- 【待确认】并行审批和会签的具体业务场景

## 3. I/O（输入输出）

### 3.1 审批流程模板配置

**输入（创建/更新模板）**：

| 字段名 | 类型 | 必填 | 说明 | 所属端 |
|--------|------|------|------||--------|------|------|------|--------|
| 模板ID | String(32) | 是 | 系统生成唯一标识 | | ⚙️ 系统 |
| 模板名称 | String(100) | 是 | 如"快速通道-2级审批" | | 🔧 运营端 |
| 审批级数 | Int | 是 | 2/3/5 | | 🔧 运营端 |
| 审批节点配置 | JSON | 是 | 各节点名称、审批角色、审批方式 | | 🔧 运营端 |
| 适用条件 | String(500) | 否 | 描述性文字 | | 🔧 运营端 |
| 超时提醒时间 | Int | 是 | 默认24小时（小时） | | 🔧 运营端 |
| 超时自动升级时间 | Int | 否 | 空=不自动升级（小时） | | 🔧 运营端 |
| 是否允许退回 | Boolean | 是 | true=允许退回上一节点或指定节点 | | 🔧 运营端 |
| 启用状态 | Enum | 是 | 启用/停用 | | ⚙️ 系统 |

**标准节点角色定义**：

| 节点 | 角色 | 说明 |
|------|------|------|
| 初审 | 初审员 | 资料完整性、基本信息核验 |
| 实地核查 | 风控专员 | 加强流程专属，实地/电话核查 |
| 风控审批 | 风控审批员 | 风险评估、评分复核 |
| 高管审批 | 高管审批员 | 加强流程专属，大额/高风险业务 |
| 终审 | 终审员 | 最终决策、额度确认 |

**输出（模板查询）**：
- **成功**：返回模板完整配置
- **不存在**：返回"模板不存在"
- **被引用**：删除时返回"该模板正被差异化准入矩阵引用，无法删除"

### 3.2 智能流程匹配

**输入（融资申请数据）**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 融资金额 | Decimal(18,2) | 单位：元 |
| 客户等级 | Enum | A/B/C（A+视为A级） |
| 核心企业等级 | Enum | S/A/B/C |
| 质押率 | Decimal(5,2) | 百分比 |
| 核心企业风险标注 | Boolean | 核心企业是否标注该经销商存在风险 |

**匹配规则**：

```
IF 融资金额 ≤ 30万 AND 客户等级 = A级 AND 质押率 ≤ 70% AND 核心企业等级 ≥ B级 THEN
  流程 = "快速通道"（2级：初审 → 终审）
ELSE IF 融资金额 ≤ 100万 THEN
  流程 = "标准流程"（3级：初审 → 风控审批 → 终审）
ELSE IF 融资金额 > 100万 OR 核心企业风险标注 = true OR 核心企业等级 = C级 THEN
  流程 = "加强流程"（5级：初审 → 实地核查 → 风控审批 → 高管审批 → 终审）
END IF
```

**输出（匹配结果）**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 匹配流程模板ID | String(32) | - |
| 流程名称 | String(100) | - |
| 审批级数 | Int | 2/3/5 |
| 节点列表 | Array[Object] | 节点名称、审批角色、超时时间 |
| 匹配原因 | String(200) | 说明匹配依据 |

**异常状态**：
- **无匹配模板**：返回"未找到匹配的审批流程模板，请联系系统管理员"
- **多个模板匹配**：按优先级排序，取第一个，记录日志告警

### 3.3 综合风险评分模型

**输入（5维度原始数据）**：

| 维度 | 权重 | 具体指标 | 数据来源 |
|------|------|----------|----------|
| 客户资质 | 20% | 征信评级、经营年限、注册资本 | 征信系统/客户档案 |
| 核心企业背书 | 25% | 推荐等级、推荐质量、经销商信用评级 | 核心企业接口/客户档案 |
| 历史表现 | 25% | 历史融资笔数、累计金额、逾期率 | 平台历史数据 |
| 质押物评估 | 20% | 品类风险、质押率、货值稳定性 | 货权管理模块 |
| 市场风险 | 10% | 品类价格波动率、新品发布周期 | 市场价格数据源 |

**计算公式**：

```
综合风险评分 = 
  客户资质得分 × 20% + 
  核心企业背书得分 × 25% + 
  历史表现得分 × 25% + 
  质押物评估得分 × 20% + 
  市场风险得分 × 10%
```

**输出（评分结果）**：

| 分数区间 | 风险等级 | 系统建议 | 审批通道 |
|----------|----------|----------|----------|
| 85-100分 | 低风险 | 建议通过，可适用快速审批通道 | 快速通道/标准流程 |
| 70-84分 | 中风险 | 建议通过，需审批人确认风险点 | 标准流程 |
| 60-69分 | 较高风险 | 建议谨慎，需上级复核 | 加强流程 |
| <60分 | 高风险 | 建议驳回，如需通过须风控总监审批 | 加强流程+特批 |

**各子维度得分计算**：【待确认】风控评分各子维度的具体评分细则（如征信评级如何映射到分数）待风控负责人确认

### 3.4 审批待办分配

**输入（待分配任务）**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 申请编号 | String(32) | - |
| 当前节点 | String(50) | 初审/风控审批/高管审批/终审 |
| 所需审批角色 | Enum | 初审员/风控审批员/高管审批员/终审员 |
| 品类 | String(50) | 质押物品类 |
| 核心企业ID | String(32) | - |

**分配策略**（按优先级）：

| 策略 | 说明 | 优先级 |
|------|------|--------|
| 按负载分配 | 选择当前待办数最少的审批人 | P1 |
| 按专业领域匹配 | 按品类归属/核心企业归属匹配 | P2【待确认】具体策略待运营确认 |
| 轮询分配 | 按顺序轮流分配 | P3 |
| 按客户归属 | 固定分配给客户所属客户经理关联的审批人 | P4 |

**输出（分配结果）**：
- **成功**：返回分配的审批人ID、姓名、预计处理时限
- **无可用审批人**：返回"当前无可用审批人，任务进入公共池等待认领"
- **审批人离职/请假**：系统自动转交同角色其他人员，待办任务不丢失

### 3.5 审批状态流转

**状态定义**：

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| 待初审 | 系统校验通过后进入初审队列 | 自动校验全部通过 |
| 初审中 | 初审员已认领/系统分配 | 自动分配或人工认领 |
| 初审通过 | 初审员审批通过 | 初审员点击"通过" |
| 初审驳回 | 初审员审批驳回 | 初审员点击"驳回" |
| 待实地核查 | 加强流程需实地核查 | 初审通过后触发 |
| 待风控审批 | 需风控专员复核 | 初审/实地核查通过后触发 |
| 待高管审批 | 加强流程需高管审批 | 风控审批通过后触发 |
| 待终审 | 进入终审节点 | 前置节点全部通过 |
| 终审通过 | 终审员审批通过 | 终审员点击"通过" |
| 终审驳回 | 终审员审批驳回 | 终审员点击"驳回" |
| 审批完成 | 放款申请已生成 | 终审通过后自动生成 |

**异常状态处理**：

| 异常场景 | 系统处理 |
|----------|----------|
| 超时未审批 | 自动升级给上级，同时通知原审批人和上级，记录超时情况纳入绩效考核 |
| 审批人离职/请假 | 系统自动转交同角色其他人员，待办任务不丢失 |
| 核心企业预警在审批过程中到达 | 实时推送，当前审批页面红色高亮提示；快速通道业务自动阻断转人工 |
| 审批退回 | 状态回退至指定节点，被退回节点需重新审批 |

### 3.6 审批操作

**输入（审批人操作）**：

| 字段名 | 类型 | 必填 | 说明 | 所属端 |
|--------|------|------|------||--------|------|------|------|--------|
| 申请编号 | String(32) | 是 | - | | ⚙️ 系统 |
| 操作类型 | Enum | 是 | 通过/驳回/退回 | | 🔧 运营端 |
| 审批意见 | String(500) | 是 | 必填，不少于10个字符 | | 🔧 运营端 |
| 退回节点 | String(50) | 条件必填 | 操作类型=退回时必填 | | 🔧 运营端 |
| 审批人ID | String(32) | 是 | - | | 🔧 运营端 |

**输出（操作结果）**：
- **通过**：状态流转至下一节点，通知下一节点审批人
- **驳回**：状态变更为"审批驳回"，通知企业端，说明驳回原因
- **退回**：状态回退至指定节点，通知该节点审批人
- **重复审批拦截**：同一节点同一审批人只能审批一次，审批后按钮置灰

## 4. Constraints（约束）

### 4.1 技术约束
- 集成化审批页完整加载时间≤3秒
- 待办列表查询响应时间≤2秒
- 综合风险评分计算时间≤1秒
- 审批超时提醒：默认24小时未处理推送提醒
- 审批超时自动升级：可配置，默认48小时
- 评分模型权重可配置调整（需管理员权限）

### 4.2 安全约束
- 审批操作需登录态验证+RBAC权限校验
- 审批页面敏感信息脱敏展示（银行账户中间位隐藏）
- 核心企业推送的经销商数据仅限审批相关角色查看
- 所有审批操作记录完整审计日志（操作人、时间、IP、内容、意见）
- 日志不可删除、不可修改，支持审计追溯

### 4.3 设计约束
- A+级经销商在平台侧**视为A级**，审批流程匹配时按A级处理
- 综合风险评分满分100分，系统仅提供建议，最终审批决策由人工做出
- 审批流程配置化：新增审批节点、调整流程分支无需改代码
- 同一笔业务终审通过后只能生成一笔放款申请
- 连续3笔审批通过后逾期的业务 → 触发审批权限复核

## 5. Acceptance Criteria（验收标准）

### 5.1 审批流程模板配置
1. **打开运营端审批流程配置页面**，运营人员创建"快速通道"模板，设置审批级数=2，节点配置为"初审→终审"，保存后模板状态为"启用"
2. **打开运营端审批流程配置页面**，运营人员修改某模板超时时间为12小时，保存后新进入该流程的申请按12小时计算超时
3. **打开运营端审批流程配置页面**，运营人员尝试删除正被差异化准入矩阵引用的模板，系统提示"该模板正被引用，无法删除"
4. **调接口** `/api/v1/approval-flow/template/list`，返回所有审批流程模板列表，包含模板ID、名称、级数、启用状态
5. **打开运营端审批流程配置页面**，运营人员停用某模板，新申请不再匹配该模板，历史已进入该模板的申请继续按原流程审批

### 5.2 智能流程匹配
6. **调接口** `/api/v1/approval-flow/match`，输入融资金额=25万、客户等级=A（含A+映射）、质押率=65%、核心企业等级=S，返回匹配流程="快速通道（2级）"
7. **调接口** `/api/v1/approval-flow/match`，输入融资金额=80万、客户等级=B、核心企业等级=A，返回匹配流程="标准流程（3级）"
8. **调接口** `/api/v1/approval-flow/match`，输入融资金额=150万、客户等级=A、核心企业等级=S，返回匹配流程="加强流程（5级）"
9. **调接口** `/api/v1/approval-flow/match`，输入融资金额=20万、客户等级=A、质押率=75%（>70%）、核心企业等级=B，返回匹配流程="标准流程（3级）"（因质押率不满足快速通道条件）
10. **调接口** `/api/v1/approval-flow/match`，输入核心企业风险标注=true，无论金额大小，返回匹配流程="加强流程（5级）"

### 5.3 综合风险评分
11. **打开运营端集成化审批页**，某申请综合风险评分=88分，页面展示五维雷达图，风险等级标签="低风险"，系统建议="建议通过，可适用快速审批通道"
12. **打开运营端集成化审批页**，某申请综合风险评分=55分，页面展示五维雷达图，风险等级标签="较高风险"，系统建议="建议谨慎，需上级复核"
13. **调接口** `/api/v1/risk-score/calculate`，传入客户资质、核心企业背书、历史表现、质押物评估、市场风险五个维度原始数据，返回综合评分及各维度得分
14. **打开运营端集成化审批页**，核心企业推荐等级=A+（视为A级），历史通过率=95%、逾期率=0.5%，核心企业背书维度得分高亮展示
15. **打开运营端评分模型配置页面**，管理员调整"客户资质"权重从20%调整为25%，保存后新申请按新权重计算评分

### 5.4 审批待办与分配
16. **打开运营端审批待办列表页**，列表展示申请编号、客户名称、融资金额、客户等级、核心企业、申请时间、当前节点、剩余审批时限，默认按紧急程度排序
17. **打开运营端审批待办列表页**，某任务剩余时限<4小时，该条记录黄色标记；已超时记录红色标记
18. **调接口** `/api/v1/approval/todo/assign`，系统自动将待初审任务分配给当前待办数最少的初审员，返回分配结果及审批人信息
19. **打开运营端审批待办列表页**，审批人A已离职，其名下待办任务自动转移至同角色审批人B，审批人B可在待办列表中查看并处理
20. **打开运营端审批待办列表页**，支持按优先级/客户等级/融资金额/申请时间/品类筛选，筛选后结果正确返回

### 5.5 审批操作与状态流转
21. **打开运营端集成化审批页**，审批人点击"通过"并填写审批意见"资料齐全，风险可控"，提交后状态变更为"初审通过"，下一节点审批人收到待办通知
22. **打开运营端集成化审批页**，审批人点击"驳回"并填写驳回原因，提交后企业端收到驳回通知，申请状态变更为"审批驳回"
23. **打开运营端集成化审批页**，审批人点击"退回"并选择退回至"初审"节点，状态回退，初审节点审批人收到重新审批通知
24. **打开运营端集成化审批页**，审批人已完成审批的节点，"通过"/"驳回"/"退回"按钮置灰不可再操作
25. **打开运营端审批详情页**，审批过程中核心企业推送风险预警，页面顶部红色横幅提示"核心企业风险预警：该经销商存在串货风险"，快速通道业务自动转人工审批

### 5.6 超时与异常处理
26. **调接口** `/api/v1/approval/timeout-check`，模拟某审批任务超过24小时未处理，系统向原审批人推送超时提醒通知
27. **调接口** `/api/v1/approval/timeout-check`，模拟某审批任务超过48小时未处理，系统自动升级至上级审批人，原审批人和上级均收到通知
28. **打开运营端审批质量报表**，页面展示各审批人审批及时率、准确率、审批后逾期率，连续3笔逾期的审批人记录标注"需权限复核"

## 6. Non-Goals（非目标）

1. **AI自动审批决策**：系统仅提供评分建议和风险提示，最终通过/驳回/退回决策必须由人工审批人做出
2. **审批案例库**：P2功能，待运营确认是否本期上线，本期不实现
3. **移动端审批**：审批操作仅在PC端运营端支持，本期不包含移动端审批APP或H5
4. **智能外呼催收**：M0阶段仅短信+IVR提醒，不含AI外呼，归属贷后管理模块
5. **跨品类组合融资审批**：一笔融资涉及多个品类质押物的复杂场景，本期不支持
6. **动态费率定价审批**：基于客户等级的差异化融资费率审批，待结算管理模块统一规划
7. **实时视频会议尽调**：加强流程中的实地核查支持线下或电话，本期不包含视频尽调
8. **审批人AI助手**：不提供AI生成审批意见或智能问答功能
