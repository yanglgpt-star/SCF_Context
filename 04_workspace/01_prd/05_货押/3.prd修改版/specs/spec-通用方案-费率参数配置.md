# Spec：通用方案——费率参数配置

> **涉及端**：🔧 运营端


> **对应PRD**：PRD_通用方案_待确认事项补充.md（章节三、六、七、八）  
> **适用范围**：供应链金融平台——融资、结算、风控、货权管理模块

---

## 1. Goal（目标）

平台运营人员通过配置中心统一管理服务费费率、逾期利率、分润规则、质押率及品类参数，使系统在融资计费、逾期计息、分润结算、货值监控等业务场景中自动读取最新参数，避免硬编码和模块间不一致。

---

## 2. Scope（边界）

### 本次包含
- 服务费费率配置（客户等级定价、分段计费、期限调整）
- 逾期利率配置（M0/M1/M2/M3+阶段及宽限期）
- 核心企业分润规则（4类分润+质量系数）
- 品类质押率上限及警戒/超标阈值
- 参数版本管理和生效机制

### 本次不包含
- 具体的计费引擎实现代码和SQL脚本
- 费率调整的历史对比分析页面
- 各模块计费结果的会计分录处理（由财务模块负责）
- 费率对平台收入影响的预测模型

---

## 3. I/O（输入输出）

### 3.1 服务费费率配置

#### 基础费率（按客户等级）

| 字段名 | 类型 | 长度/精度 | 必填 | 校验规则 | 所属端 |
|--------|------|----------|------|----------||--------|------|----------|------|----------|--------|
| customer_level | string | 2 | 是 | 枚举：A/B/C | | ⚙️ 系统 |
| annual_rate | decimal | (5,3) | 是 | A级=3.000%，B级=4.000%，C级=5.000% | | ⚙️ 系统 |
| effective_date | date | - | 是 | ≤当前日期时生效 | | ⚙️ 系统 |
| expire_date | date | - | 否 | 为空表示长期有效，必须>effective_date | | ⚙️ 系统 |

#### 分段计费调整

| 字段名 | 类型 | 长度/精度 | 必填 | 校验规则 | 所属端 |
|--------|------|----------|------|----------||--------|------|----------|------|----------|--------|
| amount_min | decimal | (18,2) | 是 | ≥0 | | ⚙️ 系统 |
| amount_max | decimal | (18,2) | 是 | >amount_min，amount_max=-1表示无上限 | | ⚙️ 系统 |
| rate_adjust | decimal | (5,3) | 是 | 单位%，可正可负，如-0.500% | | ⚙️ 系统 |

当前配置：
- ≤50万：+0%
- 50-100万：-0.5%
- >100万：-1.0%

#### 期限调整

| 字段名 | 类型 | 必填 | 校验规则 | 所属端 |
|--------|------|------|----------||--------|------|------|----------|--------|
| days_min | int | 是 | ≥1 | | ⚙️ 系统 |
| days_max | int | 是 | >days_min，days_max=-1表示无上限 | | ⚙️ 系统 |
| rate_adjust | decimal(5,3) | 是 | 单位% | | ⚙️ 系统 |

当前配置：
- ≤30天：+0.5%
- 31-90天：+0%
- >90天：-0.5%

| calc_base | string | ≤32 | 是 | M0/M1=逾期本金；M2/M3=逾期本金+已产生逾期利息 | | ⚙️ 系统 |

| grace_period_days | int | 是 | 当前=3，≥0 | | ⚙️ 系统 |
| grace_interest_flag | boolean | 是 | true=计正常利息，false=不计息；当前=true | | ⚙️ 系统 |

| rate | decimal | (6,4) | 是 | 首笔=0.1000%，后续=0.0500%，催收=0.2000%，回购=1.0000% | | 🏭 企业端-核心企业 |
| settlement_cycle | string | ≤16 | 是 | 枚举：MONTHLY/QUARTERLY | | ⚙️ 系统 |
| detail_gen_day | int | - | 是 | 月度=5，季度=10，范围1-28 | | ⚙️ 系统 |
| confirm_deadline_day | int | - | 是 | 月度=12，季度=20，范围1-28 | | ⚙️ 系统 |
| pay_day | int | - | 是 | 月度=15，季度=25，范围1-28 | | ⚙️ 系统 |

#### 质量系数

| 字段名 | 类型 | 长度/精度 | 必填 | 校验规则 | 所属端 |
|--------|------|----------|------|----------||--------|------|----------|------|----------|--------|
| core_enterprise_level | string | 2 | 是 | 枚举：S/A/B/C | | 🏭 企业端-核心企业 |
| quality_coefficient | decimal | (3,1) | 是 | S=1.5，A=1.2，B=1.0，C=0.8 | | ⚙️ 系统 |

### 3.4 品类质押率配置

| 字段名 | 类型 | 长度/精度 | 必填 | 校验规则 | 所属端 |
|--------|------|----------|------|----------||--------|------|----------|------|----------|--------|
| category_code | string | ≤16 | 是 | 枚举：3C/LIQUOR/FOOD/APPLIANCE | | ⚙️ 系统 |
| category_name | string | ≤64 | 是 | 3C电子/白酒/食品/家电 | | ⚙️ 系统 |
| pledge_ratio_max | decimal | (5,2) | 是 | 3C=70.00%，LIQUOR=80.00%，FOOD=75.00%，APPLIANCE=80.00% | | ⚙️ 系统 |
| alert_threshold | decimal | (5,2) | 是 | 相对质押率100%（即等于pledge_ratio_max时触发预警） | | ⚙️ 系统 |
| exceed_threshold | decimal | (5,2) | 是 | 相对质押率115% | | ⚙️ 系统 |
| new_product_discount | decimal | (5,2) | 否 | 新品发布期下调比例，3C=10%，其余空 | | ⚙️ 系统 |

### 3.5 参数读取接口输出

**成功**：
| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | int | 200 |
| data | object | 对应参数对象 |
| data.version | string | 参数版本号，如v20260426 |
| data.effective_time | datetime | 生效时间 |

**失败/网络异常**：
| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | int | 500/503 |
| message | string | "参数服务暂不可用" |

**降级**：参数服务不可用时，使用本地缓存（有效期24小时），超期后拒绝业务受理并提示"系统配置异常"。

## 4. Constraints（约束）

### 技术约束
- 所有费率/利率参数存储于配置中心，禁止业务代码硬编码
- 参数变更需记录版本号，旧版本参数在生效中的融资单上继续适用（不追溯）
- 逾期利率年化上限受系统硬约束：≤14.80%（当前LPR×4）
- 质押率上限不得>95%

### 安全约束
- 费率参数修改需"运营配置+财务复核"双岗操作
- 参数变更记录写入不可篡改审计日志
- 参数读取接口需鉴权，外部不可直接访问

### 设计约束
- 各模块通过统一配置中心接口读取参数，禁止直连数据库
- 参数生效时间可预设（如"下月1日生效"），避免中途变更导致计费争议

## 5. Acceptance Criteria（验收标准）

1. **打开运营端配置中心页面，查看服务费费率配置**：A级客户年化费率显示为3.000%，B级为4.000%，C级为5.000%；点击编辑将A级改为3.500%，提交后提示"需财务复核后方可生效"。
2. **打开配置中心逾期利率页面**：M1日利率显示0.0300%，M2显示0.0400%，M3+显示0.0400%；尝试将M1设为0.0500%，系统拦截提示"超过LPR×4上限，请修改"。
3. **打开配置中心品类质押率页面**：3C电子质押率上限显示70.00%，白酒80.00%，食品75.00%，家电80.00%；3C的相对质押率警戒阈值显示100%（即70%），超标阈值显示115%（即80.5%）。
4. **调用计费接口计算一笔C级客户、融资80万、期限60天的服务费**：返回结果中基础费率=5.000%，分段调整=-0.500%，期限调整=0%，最终年化费率=4.500%。
5. **模拟一笔100万融资逾期25天**：打开逾期明细，M0阶段（1-3天）逾期利息=0元，M1阶段（4-25天，22天）逾期利息=100万×0.03%×22=6,600元，计算结果与系统显示一致。
6. **将核心企业等级从B级调整为A级后生成分润明细**：合作质量奖金=基础分润×1.2（原B级为×1.0），分润金额在明细页中自动更新。

---

## 6. Non-Goals（非目标）

- ❌ 不实现费率A/B Test和多变量实验框架
- ❌ 不实现基于机器学习的动态费率定价模型
- ❌ 不实现费率调整的实时推送通知（仅记录审计日志）
- ❌ 不实现客户侧费率试算的前端H5页面（由融资模块负责）
- ❌ 不实现分润的自动税务代扣计算（由税务模块负责）
