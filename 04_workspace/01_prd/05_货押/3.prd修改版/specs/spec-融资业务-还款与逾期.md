# Spec：融资业务-还款与逾期

> **涉及端**：🔧 运营端、🏪 企业端-融资企业、🏦 银行端


## 1. Goal（目标）

**谁**：经销商（企业端）、平台运营人员（运营端）、财务人员（运营端）、催收人员（运营端）、银行系统（服务端）
**怎么做**：通过系统自动生成还款计划，到期前自动提醒，接收银行还款数据并自动对账，逾期后按M0-M4分级处理并触发贷后管理流程
**达成什么**：
- 到期前3天自动提醒覆盖率100%
- 逾期当天自动冻结客户新增融资
- 银行对账时效≤30分钟
- 还款数据自动接收与匹配成功率≥98%

---

## 2. Scope（边界）

### 本次包含
- 还款计划自动生成（基于融资本金、期限、利率、计息方式）
- 自动提醒机制（到期前3天/1天/当天/逾期后分级提醒）
- 还款数据接收（银行接口自动推送/企业端确认/财务手工录入）
- 还款自动对账（平台计划 vs 银行流水，±0.01元容差）
- 逾期分级处理（M0-M4，各等级对应不同催收策略和利率）
- 逾期利息自动计算（M1 0.03%/M2 0.04%/M3+ 0.04%，上限LPR 4倍）
- 核心企业协同催收触发与推送

### 本次不包含
- 智能外呼催收（M0阶段仅短信+IVR提醒，不含AI外呼）
- 线上直接还款（是否对接支付通道）【待确认】
- 资产核销与法务诉讼系统对接
- 货物处置评估流程（启动评估在M3阶段，具体处置流程归属货权管理模块）
- 动态费率定价（待结算管理模块统一规划）
- 【待确认】具体计息方式和还款计划计算公式
- 【待确认】宽限期天数（通用方案已确认3天，但还款计划模块需再次确认）

## 3. I/O（输入输出）

**输入**：

| 字段名 | 类型 | 必填 | 说明 | 所属端 |
|--------|------|------|------||--------|------|------|------|--------|

| 融资本金 | Decimal(18,2) | 是 | 单位：元 | | 🔧 运营端 |
| 融资期限 | Int | 是 | 单位：天 | | 🔧 运营端 |
| 利率 | Decimal(5,4) | 是 | 年化利率 | | 🔧 运营端 |
| 计息方式 | Enum | 是 | 【待确认】等额本息/先息后本/到期一次性还本付息 | | 🔧 运营端 |
| 放款日期 | Date | 是 | - | | 🏦 银行端 |
| 还款日规则 | Enum | 是 | 固定日/放款日对应日/月末 | | 🏦 银行端 |

**输出（还款计划表）**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 期数 | Int | 第几期 |
| 应还日期 | Date | - |
| 应还本金 | Decimal(18,2) | - |
| 应还利息 | Decimal(18,2) | - |
| 应还总额 | Decimal(18,2) | 本金+利息 |
| 还款状态 | Enum | 待还/已还/逾期 |
| 实际还款日期 | Date | 已还时填写 |

**计算公式**：【待确认】具体计息方式和还款计划计算公式待业务负责人/财务确认

**异常状态**：
- **计息方式未配置**：系统无法生成计划，推送待办给运营人员
- **利率超过上限**：系统校验不通过，提示"利率超过系统配置上限"

### 3.2 自动提醒机制

**输入（提醒触发条件）**：

| 提醒节点 | 触发条件 | 提醒方式 | 提醒对象 |
|----------|----------|----------|----------|
| 到期前3天 | 还款计划应还日期-3天 | 短信+系统消息 | 企业联系人 |
| 到期前1天 | 还款计划应还日期-1天 | 短信+系统消息 | 企业联系人+客户经理 |
| 到期当天（未还） | 应还日期当天00:00检查未还 | 短信+系统消息 | 企业联系人+客户经理+风控 |
| 逾期3天 | 逾期天数=3 | 短信+系统消息 | 企业联系人+客户经理+催收员 |
| 逾期7天 | 逾期天数=7 | 短信+系统消息 | 上述人员+风控主管 |

**输出（提醒发送）**：
- **发送成功**：记录发送日志（时间、方式、对象、内容）
- **发送失败**：进入重试队列，最多重试3次，仍失败则标记异常
- **退信/手机号无效**：标记客户联系信息异常，推送客户经理更新

**提醒内容模板**：【待确认】具体文案待运营和法务确认

**输入（数据来源2：企业端主动确认）**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 业务编号 | String(32) | - |
| 还款金额 | Decimal(18,2) | 企业自称还款金额 |

| 字段名 | 类型 | 说明 |
|--------|------|------|

**数据来源优先级**：银行接口自动推送 > 财务手工录入 > 企业端主动确认（企业端确认需财务复核）

### 3.4 还款自动对账

**输入**：
- 平台侧：还款计划（应还日期、应还金额、业务编号）
- 银行侧：银行流水（到账日期、到账金额、业务编号）

**匹配规则**：

```
1. 按业务编号精确匹配（银行备注中包含业务编号时优先）
2. 按金额匹配（允许±0.01元误差）
3. 按日期匹配（±1天内）
```

**输出**：

| 结果 | 系统处理 |
|------|----------|
| 匹配成功 | 更新还款计划状态="已还"；更新业务在途余额；如为最后一期，更新业务状态="已结清" |
| 匹配失败 | 标注异常，推送财务人员待办，需人工核查 |
| 部分还款 | 金额不足时，按"先利息后本金"原则冲抵，剩余本金继续计息 |
| 超额还款 | 超额部分退回或计入下期（【待确认】具体处理规则） |

### 3.5 逾期处理（M0-M4）

**输入（逾期判定）**：
- 应还日期 + 宽限期（已确认3天）后仍未收到足额还款

**逾期分级及处理**：

| 逾期天数 | 等级 | 逾期利率 | 系统动作 |
|----------|------|----------|----------|
| 1-3天 | M0（宽限期） | 0%（不计逾期利息） | 自动短信+IVR提醒；每日1次；冻结客户新增融资 |
| 4-15天 | M1 | 日利率0.03%（年化10.95%） | 自动生成催收任务，分配给初级催收员；每2天1次电话提醒；推送客户经理 |
| 16-30天 | M2 | 日利率0.04%（年化14.6%） | 升级高级催收员；自动推送核心企业协同催收；推送风控主管 |
| 31-90天 | M3 | 日利率0.04%（年化14.6%） | 催收经理介入；同步启动货物处置评估；法律诉讼准备 |
| >90天 | M4 | 日利率0.04%（年化14.6%） | 法务部接管；资产核销评估；推送高管层 |

**逾期利率上限约束**：系统校验配置逾期利率不得超过LPR 4倍，超出时系统拒绝配置并提示"逾期利率超过法定上限"

**逾期利息计算公式**：
```
逾期利息 = 逾期本金 × 逾期日利率 × 逾期天数
```

**核心企业协同催收触发条件**：

```
IF (逾期天数 ≥ 15天 OR 逾期金额 ≥ 30万) THEN
  自动推送核心企业协同催收
ELSE IF (客户等级 = A级 AND 逾期天数 ≥ 7天) THEN
  建议推送（需人工确认）
ELSE IF (核心企业推荐时承诺协同催收) THEN
  任何逾期立即推送
ELSE IF (核心企业标注为重点客户) THEN
  逾期3天推送
END IF
```

**输出（逾期处理结果）**：

| 动作 | 输出 |
|------|------|
| 标记逾期 | 业务状态变更为"逾期"，客户状态变更为"冻结" |
| 冻结新增融资 | 该客户不可提交新的融资申请 |
| 生成催收任务 | 催收任务进入催收人员待办列表 |
| 推送核心企业 | 核心企业端收到协同催收通知 |
| 通知风控 | 风控部门收到逾期预警通知 |
| 更新还款计划 | 该期还款计划状态变更为"逾期"，展示逾期天数和逾期利息 |

### 3.6 企业端还款中心

**输入（页面查询）**：客户ID

**输出**：

| 元素 | 说明 |
|------|------|
| 待还款列表 | 所有未结清业务，按到期日排序 |
| 还款计划表 | 每期应还金额、应还日期、实际还款日期、状态 |
| 立即还款按钮 | 跳转至还款操作页【待确认】线上还款方式 |
| 还款记录 | 历史还款记录查询 |
| 逾期提示 | 已逾期时红色展示逾期天数、逾期金额、逾期利息 |

## 4. Constraints（约束）

### 4.1 技术约束
- 还款计划生成响应时间≤1秒
- 自动提醒定时任务执行时间：每日凌晨1:00扫描当日应还和逾期数据
- 银行还款到账通知处理延迟≤5分钟
- 还款对账执行周期：每日自动执行
- 逾期利息计算精度：小数点后2位（分）
- 对账匹配容差：±0.01元

### 4.2 安全约束
- 还款到账核验优先以银行流水为准，企业端主动确认的还款需财务复核
- 还款金额与应还金额差异>0.01元时标记异常
- 所有还款记录永久留存，不可删除、不可修改
- 逾期处理操作记录完整审计日志

### 4.3 设计约束
- 宽限期3天（M0阶段）不计逾期利息，仅自动提醒，已确认
- 逾期利率：M1日利率0.03%，M2/M3+/M4日利率0.04%，上限LPR 4倍，已确认
- A+级经销商在平台侧**视为A级**，逾期协同催收触发条件按A级标准
- 到期当天00:00系统自动检查还款状态，未还款立即标记逾期并冻结新增融资
- 部分还款按"先利息后本金"原则冲抵
- 计息方式和还款日规则【待确认】

## 5. Acceptance Criteria（验收标准）

### 5.1 还款计划生成
1. **打开运营端还款计划详情页**，某笔融资业务放款成功后，系统自动生成还款计划表，展示期数、应还日期、应还本金、应还利息、应还总额
2. **调接口** `/api/v1/repayment-plan/generate`，传入融资本金=100万、期限=90天、利率=8%、放款日期=2026-04-01，返回还款计划表，最后一期应还总额=本金+总利息
3. **打开企业端还款中心**，经销商查看某笔在途业务，页面展示完整还款计划表，已还期数标记绿色，待还期数标记灰色，逾期期数标记红色
4. **打开运营端还款计划管理页**，运营人员修改某期应还日期（因节假日调整），保存后还款计划更新，企业端同步展示新日期
5. **调接口** `/api/v1/repayment-plan/{businessNo}`，传入业务编号，返回该业务完整还款计划，字段包含期数、应还日期、应还本金、应还利息、应还总额、还款状态

### 5.2 自动提醒
6. **调接口** `/api/v1/repayment/reminder/trigger`，模拟某笔业务应还日期为明天（T+1），系统触发"到期前1天"提醒，企业联系人和客户经理均收到短信+系统消息
7. **调接口** `/api/v1/repayment/reminder/trigger`，模拟某笔业务应还日期为3天后（T+3），系统触发"到期前3天"提醒，企业联系人收到短信+系统消息
8. **打开运营端消息记录页**，查看提醒发送日志，展示发送时间、接收人、发送方式（短信/系统消息）、发送状态（成功/失败）
9. **调接口** `/api/v1/repayment/reminder/trigger`，模拟手机号无效导致短信发送失败，系统标记联系信息异常，推送客户经理待办"请更新XX客户联系信息"
10. **打开企业端消息中心**，到期前3天提醒内容包含"您的融资业务（编号XX）将于3天后到期，应还金额XX元，请提前准备还款资金"

### 5.3 还款数据接收与对账
11. **调接口**（模拟银行回调）银行推送还款到账通知，金额=应还金额、日期=应还日期、业务编号匹配，系统更新还款计划状态="已还"，如为最后一期则更新业务状态="已结清"
12. **打开运营端还款对账页面**，系统每日自动对账，匹配成功的记录状态="已对账"，不匹配的记录状态="异常"并展示差异原因
13. **调接口** `/api/v1/repayment/reconcile`，平台应还金额=10000.00元，银行到账金额=10000.01元，系统按±0.01元容差判定匹配成功
14. **调接口** `/api/v1/repayment/reconcile`，平台应还金额=10000.00元，银行到账金额=9999.98元，系统判定匹配失败，推送财务人员待办
15. **打开运营端还款跟踪页**，企业端主动确认还款后，该笔还款记录状态="待复核"，财务人员复核通过后状态变更为"已确认"

### 5.4 逾期判定与处理
16. **调接口** `/api/v1/repayment/overdue/check`，模拟应还日期+3天宽限期后仍未还款，系统将该笔业务标记"逾期"，客户状态变更为"冻结"，企业端不可提交新融资申请
17. **打开运营端逾期跟踪列表**，逾期业务按逾期天数排序，展示业务编号、客户名称、逾期天数、逾期等级（M0/M1/M2/M3/M4）、逾期本金、逾期利息
18. **调接口** `/api/v1/repayment/overdue/check`，模拟逾期天数=5天（M1），系统自动生成催收任务并分配给初级催收员，催收员待办列表中新增该任务
19. **打开核心企业端消息中心**，逾期天数=16天（M2）且逾期金额≥30万，核心企业收到协同催收通知，内容包含"您推荐的XX经销商已逾期16天，逾期金额XX万，请协助催收"
20. **打开运营端逾期跟踪页**，逾期天数=31天（M3），该笔业务展示"货物处置评估已启动"标识，催收经理已介入

### 5.5 逾期利息计算
21. **调接口** `/api/v1/repayment/overdue/interest`，逾期本金=50万、逾期天数=10天（M1），返回逾期利息=500000×0.03%×10=1500元
22. **调接口** `/api/v1/repayment/overdue/interest`，逾期本金=50万、逾期天数=20天（M2），返回逾期利息=500000×0.04%×20=4000元
23. **打开运营端还款计划页**，某笔逾期业务展示逾期利息实时计算结果，公式透明展示"逾期利息=逾期本金×日利率×逾期天数"
24. **调接口** `/api/v1/repayment/overdue/interest`，系统配置逾期利率为0.1%（超过LPR 4倍），系统拒绝配置并提示"逾期利率超过法定上限"
25. **打开企业端还款中心**，已逾期业务红色展示"逾期XX天，逾期利息XX元（日利率0.03%/0.04%）"

### 5.6 结清与释放
26. **调接口** `/api/v1/repayment/confirm`，最后一期还款到账确认后，业务状态变更为"已结清"，客户授信额度中对应占用额度自动释放
27. **打开运营端业务列表页**，已结清业务展示状态="已结清"，支持筛选查看所有已结清业务
28. **打开企业端还款中心**，已结清业务移至"历史业务"列表，展示结清日期和总还款金额

## 6. Non-Goals（非目标）

1. **AI智能外呼催收**：M0-M4阶段仅短信+IVR提醒+人工电话，不含AI外呼机器人
2. **线上直接还款**：企业端是否支持对接支付通道直接还款【待确认】，本期至少支持银行转账后确认
3. **自动资产处置**：M3阶段启动货物处置评估，但具体处置流程和拍卖归属货权管理模块，本期不实现自动处置
4. **法务诉讼系统对接**：M4阶段法务部接管，但诉讼流程不接入系统，仅记录诉讼状态和结果
