# PRD精简：贷后管理

> **文档状态**：初稿（基于PRD_贷后管理.md V1.0精简）  
> **适用范围**：供应链金融平台——运营管理端（运营端）+ 企业端（核心企业/融资企业）+ 银行端  
> **业务领域**：控货质押模式下的逾期催收、货物处置与资产核销

---

## 一、背景与目标

### 为什么做
1. **逾期发现不及时**：还款到期日未还款但平台未及时发现，错失最佳催收窗口期。
2. **催收缺乏规范**：催收人员凭经验操作，措施和记录因人而异，效果难以评估。
3. **协同催收效率低**：约55%的协同请求未得到有效响应，协同催收成功率仅45%。
4. **货物处置低效**：处置周期平均60天，回收率仅75%，核心企业回购渠道未被充分利用。
5. **核销流程线下化**：核销申请和审批流程繁琐，证明材料管理不规范。

### 做什么
建立M0-M4分级催收体系、核心企业协同催收机制、多渠道货物处置（回购优先）、在线核销流程，覆盖逾期识别→催收执行→货物处置→资产核销全链路。

### 目标指标

| 目标项 | 现状 | 目标值 | 衡量方式 |
|--------|------|--------|----------|
| M1催收成功率 | 75% | ≥90% | M1阶段15天内回款或达成有效还款方案的比例 |
| 逾期回收率 | 82% | ≥90% | 逾期金额最终回收比例 |
| 协同催收成功率 | 45% | ≥65% | 核心企业协同后成功回款的案件比例 |
| 货物处置周期 | 60天 | ≤45天 | 从启动处置到资金回收的平均天数 |
| 货物处置回收率 | 75% | ≥85% | 处置回收金额/逾期本金 |
| 人均催收案件处理量 | 5笔/天 | 12笔/天 | 催收员日均处理案件数 |

## 二、范围决策

### 本次包含
1. **自动逾期识别**：每日0点扫描在途业务，自动标记逾期、计算逾期天数和利息、生成分级
2. **分级催收任务分配**：M0-M4五级催收策略匹配、任务自动分配责任人、催收记录在线化
3. **核心企业协同催收**：自动判断协同条件（逾期≥15天或≥30万）、推送协同请求、在线跟踪响应和结果
4. **处置方案智能推荐**：优先核心企业回购，次选平台渠道/市场拍卖，多渠道处置管理
5. **回购流程在线化**：自动计算回购价格、生成回购合同、在线确认、全流程进度跟踪
6. **逾期台账与统计**：逾期业务集中查询、风险总览、趋势分析、催收绩效报表
7. **资产核销在线申请与审批**：核销条件自动识别、在线提交证明材料、多级审批流程

### 本次不包含
- AI智能催收话术推荐（延后V2.0）
- 外部催收机构/律所自动委外对接（延后V2.0）
- 资产证券化管理（延后V3.0）
- 跨境法律诉讼支持（延后V3.0）
- 移动端催收APP完整功能（仅保留基础记录能力）
- 法律诉讼全流程管理（案件录入/进度跟踪/费用管理延后P2）

## 三、关键决策记录

| 决策项 | 决策结果 | 决策依据 |
|--------|----------|----------|
| 模块边界（贷后↔风险监控） | M0-M1早期提醒由风险监控负责；M2-M4催收执行由贷后负责 | 风险监控专注预警，贷后专注执行 |
| 逾期利率 | M1日利率0.03%（年化10.95%），M2/M3+日利率0.04%（年化14.6%），上限LPR 4倍 | 合规可控，配置中心可调 |
| M0宽限期 | 3天不计逾期利息 | 行业惯例，兼顾客户体验 |
| 协同催收触发条件 | 逾期≥15天或逾期金额≥30万自动推送；A级客户≥7天建议推送 | 兼顾效率与成本 |
| 回购折扣率 | 未拆封90%、已拆封未使用85%、已使用80% | 基于货物残值率推导 |
| 回购协商范围 | 建议价±10%，超出需风控经理审批 | 平衡效率与风控 |
| 处置价格底线 | 低于评估价70%需额外审批 | 防止资产贱卖 |
| 核销审批层级 | 催收主管→风控经理→财务总监→总经理(>50万) | 风险+财务+决策三层把关 |
| 贷后→结算数据同步 | 每月4日前同步催收回收金额、回购完成金额、核销金额 | 支撑月度分润结算 |
| 催收记录留存 | 操作日志≥5年，处置记录≥10年，核销记录永久 | 合规审计要求 |
| 协同催收SLA | 核心企业24小时内响应，每3天反馈进展，协同周期15天 | 保障协同效率 |
