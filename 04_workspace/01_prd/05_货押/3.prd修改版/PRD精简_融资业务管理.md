# PRD精简_融资业务管理

## 一、背景与目标

### 1.1 为什么做

**业务痛点**：
- 审批效率瓶颈：业务量从月均200笔增至500笔，审批时效从1天延长至2.5天，积压严重
- 申请一次通过率低：约40%申请因资料不完整需补充，平均沟通2-3轮，一次通过率仅60%
- 放款/还款数据协同差：银行出库授权通过邮件/传真，放款还款数据手工录入对账每日耗时2-4小时，放款成功率仅93%
- 缺乏全局业务视图：资产周转率从6.5次/年下降至5.2次/年，平均融资周期从50天延长至70天

**对标差距**：
| 维度 | 本平台现状 | 京东供应链金融 | 平安银行存货融资 |
|------|-----------|--------------|----------------|
| 小额快速审批 | 无，全部人工 | 有，≤30万快速通道 | 有，≤100万标准流程 |
| 审批时效 | 2.5天 | 约0.5天 | 约1天 |
| 银行对接 | 手工对账 | 系统直连 | 系统直连 |
| 一次通过率 | 60% | 约85% | 约80% |

### 1.2 做什么

构建可配置审批流程引擎、智能流程匹配、综合风险评分、在线融资申请与自动校验、银企直联放款管理、还款计划与逾期处理的全流程融资业务管理系统。

### 1.3 指标目标

| 指标 | 现状 | 目标值 | 优先级 |
|------|------|--------|--------|
| 审批时效 | 2.5天 | ≤1天 | P0 |
| A级客户30万以下审批时效 | - | ≤4小时 | P0 |
| 申请一次通过率 | 60% | ≥80% | P0 |
| 放款成功率 | 93% | ≥98% | P0 |
| 资产周转率 | 5.2次/年 | 6.5次/年 | P1 |
| 银行对账时效 | 2-4小时 | ≤30分钟 | P1 |
| 审批通过后逾期率 | 3.2% | ≤1.5% | P1 |

### 1.4 谁来决策

- **审批流程配置与规则**：运营负责人
- **综合风险评分模型权重**：风控负责人
- **放款金额修改权限**：待业务负责人/风控确认
- **逾期利率标准**：已确认（见下方关键决策）
- **银行接口规范**：已确认（见下方关键决策）

## 三、关键决策记录

### 3.1 等级映射规则（跨模块一致性）

- **经销商信用评级A+级**：在平台侧视为A级，享受A级对应的审批通道、费率政策和监控阈值。
- **快速通道条件**：金额≤30万 AND 客户等级=A级（含A+映射）AND 质押率≤70% AND 核心企业等级≥B级。

### 3.2 审批流程智能匹配规则

| 流程类型 | 级数 | 适用条件 |
|----------|------|----------|
| 快速通道 | 2级（初审→终审） | 金额≤30万 AND A级客户 AND 质押率≤70% AND 核心企业≥B级 |
| 标准流程 | 3级（初审→风控审批→终审） | 金额≤100万（不满足快速通道条件） |
| 加强流程 | 5级（初审→实地核查→风控审批→高管审批→终审） | 金额>100万 OR 核心企业标注风险 OR 核心企业等级=C级 |

### 3.3 综合风险评分模型（5维度）

| 维度 | 权重 | 数据来源 |
|------|------|----------|
| 客户资质 | 20% | 征信系统/客户档案 |
| 核心企业背书 | 25% | 核心企业接口/客户档案 |
| 历史表现 | 25% | 平台历史数据 |
| 质押物评估 | 20% | 货权管理模块 |
| 市场风险 | 10% | 市场价格数据源 |

**评分结果映射**：
- 85-100分：低风险，建议通过，可适用快速审批通道
- 70-84分：中风险，建议通过，需审批人确认风险点
- 60-69分：较高风险，建议谨慎，需上级复核
- <60分：高风险，建议驳回，如需通过须风控总监审批

### 3.4 逾期处理规则（已确认）

| 逾期天数 | 等级 | 系统动作 |
|----------|------|----------|
| 1-3天 | M0 | 自动短信+IVR提醒，每日1次，宽限期内不计逾期利息 |
| 4-15天 | M1 | 自动生成催收任务，日利率0.03%（年化10.95%） |
| 16-30天 | M2 | 升级高级催收员，日利率0.04%（年化14.6%） |
| 31-90天 | M3 | 催收经理介入，启动货物处置评估，日利率0.04% |
| >90天 | M4 | 法务部接管，资产核销评估 |

**逾期利率上限**：不得超过LPR 4倍（系统校验）。

### 3.5 银行接口规范（已确认）

- **接口协议**：银企直联API，HTTPS RESTful API
- **报文格式**：JSON
- **加密方式**：RSA非对称加密，RSA-SHA256签名
- **签名位置**：HTTP Header `X-Bank-Signature`
- **重试与幂等**：失败自动重试3次（间隔15分钟），每次请求携带唯一幂等键 `Idempotency-Key`
- **异常处理**：超过3次失败通知财务人员人工介入；本地记录待发送指令，网络恢复后批量补发

### 3.6 对账规则

- **放款对账**：每日，按金额匹配（±0.01元）、按时间匹配（±1天）、按账户匹配
- **还款对账**：按金额匹配（±0.01元）、按日期匹配（±1天）、按业务编号匹配

## 五、核心业务流程简述

### 5.1 融资业务全生命周期

企业端提交融资申请 → 系统自动校验（额度/货物/黑名单/证照）→ 获取核心企业最新数据 → 智能匹配审批流程（快速2级/标准3级/加强5级）→ 集成化审批页决策（参考综合风险评分/核心企业评价）→ 自动生成放款申请 → 财务确认 → 推送放款指令给银行 → 银行放款反馈 → 还款到期前3天自动提醒 → 到期当天检查还款状态 → 未还款则标记逾期并触发贷后管理流程。

### 5.2 审批状态流转

待初审 → 初审中 → 初审通过/驳回 → 待实地核查（加强流程）→ 待风控审批 → 待高管审批（加强流程）→ 待终审 → 终审通过/驳回 → 审批完成（放款申请已生成）。

### 5.3 放款状态流转

待生成 → 待财务确认 → 待发送指令 → 指令处理中 → 放款成功/放款失败 → 已撤销。

### 5.4 申请状态流转

草稿 → 待校验 → 校验中 → 校验通过/校验驳回 → 待审批 → 审批中 → 审批通过/审批驳回 → 放款中 → 放款成功/放款失败 → 还款中 → 已结清/逾期。
