# PRD_通用方案——核销企业与银行管理

> **文档状态**：初稿（待业务确认）  
> **适用范围**：供应链金融平台——客户管理、贷后管理、结算管理模块  
> **说明**：原文档未覆盖核销企业管理和银行合作方退出管理，本方案作为补充

---

## 一、核销企业管理方案

### 1.1 定义与范围

**核销企业**指因破产、注销、吊销营业执照、长期失联等原因，平台确认无法继续合作或无法追索债权的企业主体。

| 类型 | 适用对象 | 触发条件 |
|------|----------|----------|
| 主动注销 | 经销商/核心企业 | 企业主动申请注销合作，结清全部债务 |
| 被动核销 | 经销商/核心企业 | 破产、吊销、失联满1年、穷尽追索手段无效 |
| 强制清退 | 核心企业 | 连续2季度C级且拒绝整改、重大违约、欺诈行为 |

### 1.2 核销前状态管理

**企业状态流转**：

```
正常合作
    │
    ├── 经营异常 → 预警状态（黄色）→ 30天整改期
    │       │
    │       ├── 整改通过 → 恢复正常
    │       └── 整改未通过 → 冻结状态（橙色）
    │
    ├── 逾期严重 → 冻结状态（橙色）→ 催收/处置流程
    │       │
    │       ├── 回款/处置完成 → 恢复正常或终止合作
    │       └── 穷尽手段无效 → 核销评估（红色）
    │
    └── 主动申请注销 → 清算状态（蓝色）→ 结清债务 → 注销完成
```

**各状态权限限制**：

| 状态 | 新增融资 | 出库 | 额度调整 | 数据查看 |
|------|----------|------|----------|----------|
| 正常 | ✓ | ✓ | ✓ | ✓ |
| 预警 | ✓（降额） | ✓ | ✗ | ✓ |
| 冻结 | ✗ | ✗ | ✗ | ✓ |
| 清算 | ✗ | 仅还款相关 | ✗ | ✓ |
| 已注销 | ✗ | ✗ | ✗ | 仅历史查询 |

### 1.3 被动核销流程

```
触发条件确认（满足任一）
    │
    ├── 法院宣告破产
    ├── 营业执照被吊销满6个月
    ├── 失联满1年（无法联系+无经营痕迹）
    ├── 资产核销已审批通过（详见贷后管理PRD）
    └── 欺诈/重大违约被司法机关立案
    │
    ▼
发起核销申请
    │
    ├── 准备材料：
    │   · 破产裁定书/注销证明/吊销公告
    │   · 债务清偿情况说明
    │   · 追索记录（催收、诉讼、处置全过程）
    │   · 剩余债权金额计算表
    │
    ▼
核销审批（3级）
    │
    ├── 风控经理审核（3个工作日）
    │   · 核实债务是否穷尽追索手段
    │   · 确认剩余债权金额
    │
    ├── 财务总监审批
    │   · 确认账务处理方式
    │   · 确认坏账准备金冲抵
    │
    └── 总经理审批（>50万）
    │
    ▼
核销执行
    │
    ├── 更新企业状态为"已注销"
    ├── 冻结该企业所有账号
    ├── 剩余债权转入"已核销债权"科目
    ├── 用风险准备金冲抵损失（如有）
    ├── 保留追索权（如发现可执行财产可重新启动）
    └── 归档全部业务资料（永久保存）
```

### 1.4 强制清退（核心企业专用）

**触发条件**：
- 连续2季度评级为C级，且拒绝配合整改
- 推荐客户不良率>10%且拒不调整推荐策略
- 重大违约：恶意推送虚假数据、协助经销商欺诈
- 涉及刑事犯罪被司法机关立案

**清退流程**：
```
风控部门发起清退建议
    ↓
提交清退委员会审议（风控总监+业务总监+法务）
    ↓
总经理审批
    ↓
通知核心企业（提前30天书面通知）
    ↓
启动债务清算：
  · 停止新的推荐合作
  · 已推荐经销商存量业务正常管理至到期
  · 未结算分润按合同结清
  · 如有回购义务，已逾期业务优先启动回购
    ↓
清算完成 → 状态变更为"已清退"
```

### 1.5 数据保留策略

| 数据类型 | 已注销企业保留期 | 说明 |
|----------|-----------------|------|
| 基础档案 | 永久 | 企业名称、统一社会信用代码等 |
| 业务合同 | 永久 | 融资合同、质押合同等 |
| 审批记录 | 永久 | 全流程审批日志 |
| 交易流水 | 永久 | 放款、还款、服务费记录 |
| 催收记录 | 永久 | 全部催收过程记录 |
| 通信记录 | 10年 | 短信、邮件、站内信 |
| 操作日志 | 10年 | 系统操作审计日志 |
| 敏感证件 | 注销后5年删除 | 营业执照、身份证扫描件（脱敏后保留索引） |

### 1.6 重新合作机制

已注销/清退企业如满足以下条件，可申请重新合作：
- 已结清全部历史债务（含已核销后重新发现的债务）
- 注销原因已消除（如破产重组完成、新主体承接债务）
- 提供新的担保/保证金
- 重新走完整准入流程，按新企业对待

## 二、银行合作方管理方案

### 2.1 银行准入管理

**准入条件**：

| 维度 | 要求 | 说明 |
|------|------|------|
| 机构资质 | 持牌银行或持牌消费金融公司 | 不接受非持牌机构 |
| 监管评级 | 银保监会监管评级≥3级 | 确保银行稳健性 |
| 技术能力 | 支持银企直联或标准API对接 | 确保系统对接可行性 |
| 合作意愿 | 签署战略合作协议 | 明确双方权责 |
| 授信额度 | 初始合作授信≥5000万 | 确保业务规模 |

**准入流程**：
```
银行提交合作申请 → 平台业务部初审 → 风控部尽职调查
→ 技术部对接评估 → 法务部合同审核 → 总经理审批
→ 签署合作协议 → 系统对接测试 → 正式上线
```

**准入资料清单**：

| 序号 | 资料名称 | 是否必填 | 说明 |
|------|----------|----------|------|
| 1 | 金融许可证 | 是 | 银行经营许可证 |
| 2 | 营业执照 | 是 | 银行法人营业执照 |
| 3 | 近一年度年报/审计报告 | 是 | 验证财务稳健性 |
| 4 | 银保监监管评级证明 | 是 | 证明合规经营 |
| 5 | 技术对接能力说明 | 是 | API文档/对接方案 |
| 6 | 拟合作产品方案 | 是 | 利率范围、期限、额度 |
| 7 | 法律合规部门意见书 | 是 | 确认合作模式合规 |

### 2.2 银行评级与监控

**评级维度**：

| 维度 | 权重 | 指标 |
|------|------|------|
| 放款效率 | 25% | 平均放款时效、一次通过率 |
| 资金稳定性 | 25% | 授信额度使用率、临时调额响应速度 |
| 系统稳定性 | 20% | 接口可用率、故障恢复时间 |
| 合作配合度 | 20% | 问题响应时效、对账准确率 |
| 风险控制 | 10% | 不良率、逾期后协作处置积极性 |

**评级结果**：

| 等级 | 标准 | 差异化政策 |
|------|------|-----------|
| A级 | 综合评分≥90 | 优先推荐业务、更高额度占比、快速审批通道 |
| B级 | 综合评分75-89 | 正常合作 |
| C级 | 综合评分60-74 | 限制新业务推荐、加强监控 |
| D级 | 综合评分<60 | 暂停新增合作、启动退出评估 |

**监控频率**：每季度自动生成评级报告

### 2.3 银行退出管理

**退出类型**：

| 类型 | 触发条件 | 流程 |
|------|----------|------|
| 主动退出 | 银行单方面终止合作 | 提前90天书面通知，结清存量业务 |
| 被动退出 | 评级连续2季度D级/重大违约/监管处罚 | 平台发起，提前60天通知，存量业务转移或到期结清 |
| 强制退出 | 银行被吊销牌照/破产/涉及重大金融犯罪 | 立即暂停，启动应急预案 |

**退出清算流程**：
```
收到退出通知/触发退出条件
    ↓
冻结新增业务合作
    ↓
存量业务处理：
  · 未放款申请：终止，通知经销商更换银行
  · 在途融资：正常管理至到期，不再续贷
  · 逾期业务：加速催收/处置，银行配合回款
    ↓
资金清算：
  · 未结清服务费结算
  · 风险准备金清算（如有共管）
  · 账户余额划转
    ↓
系统下线：关闭API对接、清除敏感配置
    ↓
归档保存：合作记录永久保存
```

### 2.4 多银行切换机制

当某银行退出或临时额度不足时，平台需支持快速切换：

| 场景 | 切换策略 |
|------|----------|
| 单银行退出 | 自动将新申请路由至其他合作银行，按A级>B级>C级优先级分配 |
| 额度不足 | 触发"银行额度预警"，运营人员可手动调整各银行额度占比 |
| 银行系统故障 | 自动暂停向该银行推送新申请，已推送申请排队等待恢复 |
| 经销商指定银行 | 如经销商有合作偏好，优先满足；如指定银行不可用，推荐替代方案 |

**切换通知**：
- 银行变更时自动通知受影响经销商
- 通知内容：新合作银行、利率/期限变化（如有）、无需重新提交申请

### 2.5 银行对接技术规范（补充）

**对接方式优先级**：
1. **银企直联API**（首选）：实时、自动、效率高
2. **Open Banking API**（次选）：部分股份制银行/互联网银行支持
3. **网银文件交换**（备选）：城商行/农商行常见，日终批量

**测试环境要求**：
- 银行需提供测试环境（UAT/SIT）
- 测试通过标准：连续7天模拟交易100%成功
- 生产上线前需通过双方联合验收

## 三、系统集成要求

### 3.1 核销企业状态同步

核销企业状态变更需同步至以下系统：

| 同步目标 | 同步内容 | 同步方式 |
|----------|----------|----------|
| 融资业务系统 | 企业状态、融资权限 | 实时API |
| 货权管理系统 | 出库权限冻结 | 实时API |
| 风控监控系统 | 风险标签更新 | 实时API |
| 结算系统 | 账单暂停生成、分润结算 | 实时API |
| 电子签章系统 | 签署权限关闭 | 实时API |

### 3.2 银行状态同步

| 同步目标 | 同步内容 | 同步方式 |
|----------|----------|----------|
| 融资申请系统 | 可用银行列表、额度 | 实时API |
| 结算系统 | 银行账号、对账规则 | 配置同步 |
| 风控系统 | 银行评级、风险提示 | 每日批量 |

## 四、报表与审计

### 4.1 核销企业报表

| 报表名称 | 维度 | 用途 |
|----------|------|------|
| 企业注销统计表 | 时间、原因 | 管理层了解客户流失情况 |
| 核销债权回收跟踪表 | 企业、时间 | 追踪已核销债权的后续回收 |
| 强制清退企业清单 | 核心企业、原因 | 合规审计 |

### 4.2 银行合作报表

| 报表名称 | 维度 | 用途 |
|----------|------|------|
| 银行合作概览 | 银行、评级 | 管理层了解银行合作质量 |
| 银行额度使用分析 | 银行、时间 | 优化额度分配 |
| 银行退出影响评估 | 银行、存量业务 | 提前制定切换预案 |
