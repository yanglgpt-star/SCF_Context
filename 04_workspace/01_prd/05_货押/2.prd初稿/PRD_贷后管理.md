## 三、需求背景

### 3.1 问题现状

#### 用户/业务侧痛点
1. **逾期发现不及时**：还款到期日当天未还款但平台未及时发现，手工查询时已逾期2-3天，错失最佳催收窗口期。
2. **催收工作缺乏规范**：催收人员凭经验操作，措施和记录因人而异，催收效果难以评估和改进。
3. **核心企业协同不足**：缺乏协同催收的判断标准和流程，约55%的协同请求未得到有效响应，协同催收成功率仅45%。
4. **货物处置效率低**：处置周期平均60天，主要依赖市场拍卖渠道，回收率仅75%，核心企业回购渠道未被充分利用。
5. **回购流程不规范**：缺乏规范的回购流程和定价机制，需电话或邮件沟通回购条件和价格，谈判周期长。

#### 系统侧痛点
1. **无自动化逾期识别**：缺乏自动化的逾期识别和催收任务分配机制，依赖人工每日查询。
2. **催收记录分散**：催收记录手工记录在Excel或笔记本中，查找不便易丢失。
3. **缺乏在线跟踪**：缺乏核心企业催收动作和结果的在线跟踪机制，协同效率低。
4. **处置渠道单一**：货物处置主要依赖市场拍卖，缺乏多渠道处置方案的智能推荐。
5. **核销流程线下化**：核销申请和审批流程繁琐，证明材料管理不规范。

#### 行业对标

| 维度 | 本平台现状 | 平安银行存货融资 | 京东供应链金融 | 差距 |
|------|-----------|----------------|--------------|------|
| M1催收成功率 | 75% | 85% | 88% | 低10-13个百分点 |
| 协同催收成功率 | 45% | 60% | - | 低15个百分点 |
| 货物处置周期 | 60天 | 45天 | 30天 | 慢15-30天 |
| 回收率 | 75% | 82% | 85% | 低7-10个百分点 |

### 3.2 需求目标

| 目标项 | 现状 | 目标值 | 衡量方式 |
|--------|------|--------|----------|
| M1催收成功率 | 75% | ≥90% | M1阶段15天内回款或达成有效还款方案的比例 |
| 逾期回收率 | 82% | ≥90% | 逾期金额最终回收比例 |
| 协同催收成功率 | 45% | ≥65% | 核心企业协同后成功回款的案件比例 |
| 货物处置周期 | 60天 | ≤45天 | 从启动处置到资金回收的平均天数 |
| 货物处置回收率 | 75% | ≥85% | 处置回收金额/逾期本金 |
| 人均催收案件处理量 | 5笔/天 | 12笔/天 | 催收员日均处理案件数 |

## 五、需求详情

### 5.1 催收跟进（重点功能）

#### 5.1.1 解决的核⼼问题
1. 逾期发现不及时，错过最佳催收窗口期
2. 催收工作缺乏规范流程，效果因人而异
3. 核心企业协同催收效率低，约55%的协同请求未得到有效响应
4. 催收记录分散易丢失，经验无法沉淀

#### 5.1.2 自动逾期识别（服务端需求）

**执行时机**：每日0点自动执行

**识别逻辑**：
```
FOR EACH 在途业务 DO
  IF 还款到期日 ≤ 今天 AND 未结清 THEN
    标记为"逾期"
    计算逾期天数 = 今天 - 还款到期日
    计算逾期利息 = 逾期本金 × 逾期利率 × 逾期天数 / 360
    生成逾期记录
    自动分配催收任务
    冻结该客户新增融资
    发送逾期通知（客户+客户经理+风控）
  END IF
END FOR
```

**逾期分级规则**：

| 等级 | 逾期天数 | 催收方式 | 频率 | 责任人 | 是否协同 |
|------|----------|---------|------|--------|----------|
| M0 | 1-3天 | 自动短信+IVR电话 | 每日1次 | 系统自动 | 否 |
| M1 | 4-15天 | 催收员电话+上门 | 每2天1次 | 初级催收员 | 视情况 |
| M2 | 16-30天 | 高级催收员+法务函 | 每日1次 | 高级催收员 | 是（自动推送） |
| M3 | 31-90天 | 上门+法律诉讼准备 | 每日跟进 | 催收经理 | 是（强制推送） |
| M4 | >90天 | 法律诉讼+强制执行 | 持续跟进 | 法务部 | 是 |

**M3阶段并行策略**：
```
货物处置线（快）：
├─ 第31天：启动处置评估
├─ 第35天：确定处置方案（回购/拍卖）
├─ 第45天：完成处置，资金回收
└─ 优势：快速回收，减少损失

法律诉讼线（慢但彻底）：
├─ 第35天：提起诉讼
├─ 第60天：开庭审理
├─ 第90天：获得判决
└─ 优势：追索剩余欠款，形成法律约束

协同效果：处置回收不足部分，通过判决继续追索
```

#### 5.1.3 核心企业协同催收判断（服务端需求）

**自动判断逻辑**：
```
IF (逾期天数 ≥ 15天 OR 逾期金额 ≥ 30万) THEN
  自动推送核心企业协同催收

IF (客户等级 = A级 AND 逾期天数 ≥ 7天) THEN
  建议推送（需人工确认）

IF (核心企业推荐时承诺协同催收) THEN
  任何逾期立即推送

IF (核心企业标注为重点客户) THEN
  逾期3天推送（给核心企业留充足时间）
END IF
```

**协同SLA规范**：

| 环节 | 时效要求 | 责任方 |
|------|----------|--------|
| 协同请求推送 | 系统自动，即时 | 平台 |
| 核心企业响应 | 24小时内 | 核心企业 |
| 进展反馈 | 每3天反馈1次 | 核心企业 |
| 协同周期 | 15天 | 双方 |

**协同催收激励机制**：

| 激励项 | 规则 | 触发条件 |
|--------|------|----------|
| 积分奖励 | 成功协助催收奖励500积分 | 协同催收成功 |
| 现金奖励 | 催收成功金额的0.2% | 协同催收成功 |
| 等级提升 | 协助处置及时提高合作等级 | 协同响应及时且有效 |
| 负向约束 | 不配合扣减积分影响合作评级 | 拒绝协同或响应超时 |

#### 5.1.5 催收绩效管理（后台需求）

**催收员考核指标**：

| 指标 | 权重 | 目标值 | 计算方式 |
|------|------|--------|----------|
| 回款率 | 40% | ≥70% | 回收金额/分配逾期金额 |
| 案件处理量 | 25% | ≥12笔/天 | 日均处理案件数 |
| 客户满意度 | 15% | ≥4.0/5.0 | 催收后客户评价（如有） |
| 合规率 | 20% | 100% | 无投诉、无违规操作 |

**分级激励机制**：
```
月度催收成功率：
≥ 80%：优秀，奖金+30%
70-79%：良好，奖金+20%
60-69%：合格，正常奖金
< 60%：需改进，培训提升

特殊奖励：
- 成功协同催收大额案件（>50万）：额外奖励
- 创新催收方法被推广：奖励+晋升机会
```

### 5.2 货物处置（重点功能）

#### 5.2.1 解决的核⼼问题
1. 货物处置周期平均60天，效率低下
2. 处置渠道单一，主要依赖市场拍卖，回收率仅75%
3. 核心企业回购渠道未被充分利用
4. 回购价格谈判、合同签署、货物交接等环节缺乏规范流程

#### 5.2.2 处置方案智能推荐（服务端需求）

**核心企业回购条件判断**：
```
满足以下条件之一即推荐核心企业回购：
1. 核心企业在合作协议中承诺回购责任
2. 货物为核心企业品牌且未拆封
3. 货物价值 > 10万且市场价格稳定
4. 核心企业历史有回购记录

不满足条件 → 直接市场处置
满足条件 → 优先推送核心企业
```

**处置渠道优先级**：
1. **核心企业回购**（优先）：周期7天，回收率90-98%
2. **平台渠道变现**：利用平台合作渠道商处置，周期15-30天，回收率75-85%
3. **市场拍卖**：通过拍卖平台处置，周期30-45天，回收率70-80%
4. **法律诉讼后强制执行**：法院判决后强制执行，周期60-90天，回收率不确定

#### 5.2.3 智能定价（服务端需求）

**回购价格计算**：
```
回购价格 = 市场价格 × 回购折扣率

回购折扣率 = 基础折扣率 + 调整项

基础折扣率：
- 未拆封：90%
- 已拆封未使用：85%
- 已使用：80%

调整项：
+ 核心企业品牌：+5%
+ 货物完好无损：+3%
+ 包装齐全：+2%
- 逾期时间长（>60天）：-5%
- 过季商品：-10%
```

**示例**：
```
市场价100万，未拆封，核心品牌，完好
回购价 = 100万 × (90% + 5% + 3%) = 98万
```

**定价协商机制**：
1. 系统自动计算建议回购价（基于市场价和货物状态）
2. 推送给核心企业，核心企业可接受或提出协商
3. 协商范围：建议价的±10%
4. 超出范围：需平台风控经理审批
5. 达成一致：生成回购协议
6. 未达成一致：转入其他处置渠道

#### 5.2.4 回购流程在线化（前端需求）

**【货物处置发起页】**

页面元素：
1. **触发条件展示**：逾期天数、催收记录、处置原因
2. **质押物清单**：在库货物明细（品类、品牌、型号、数量、单价、货值）
3. **处置方案推荐**：

4. **操作按钮**：
   - 启动核心企业回购流程
   - 启动平台渠道处置

   - 人工指定其他方案

**【回购流程跟踪页】**

回购流程节点：
```
启动回购 → 推送回购邀请 → 核心企业评估 → 协商定价 → 签署回购协议 
→ 货物交接 → 付款 → 案件结清

页面元素：

   - 当前节点高亮显示

#### 5.2.6 异常处理

| 异常场景 | 处理方式 |

### 5.4 资产核销

#### 5.4.1 核销条件（服务端需求）

**核销条件**：
- 法律诉讼终结，法院出具"终本裁定"
- 客户确无可执行财产
- 已穷尽所有追索手段（催收、协同、处置、诉讼）
- 经风控总监、财务总监、总经理审批（金额>50万需总经理审批）

**自动识别**：
```
IF 逾期天数 > 180天 AND 催收记录 > 10次 AND 诉讼状态 = "终本" THEN
  系统标记"建议核销"
  推送核销申请提醒给催收主管
END IF
```

#### 5.4.2 核销在线申请（前端需求）

**【核销申请页】**

页面元素：
1. **业务信息自动带入**：客户名称、逾期本金、逾期利息、已回收金额、损失金额
2. **核销原因选择**：
   - 客户破产/注销
   - 无可执行财产
   - 诉讼终本
   - 其他（需填写说明）
3. **证明材料上传**：
   - 催收记录（系统自动关联）
   - 法律诉讼文书
   - 货物处置记录
   - 损失评估报告
   - 其他证明材料
4. **申请提交**：提交后进入审批流程

#### 5.4.3 核销审批流程（前端需求）

**审批流程**：
```
催收主管提交核销申请
    ↓

    ↓

    ↓
财务总监审批

3. **审批意见**：通过/驳回 + 意见说明
4. **历史审批记录**：各级审批人、时间、意见

## 九、风控

### 9.1 资金与权益安全
- 催收过程中禁止任何形式的暴力催收、骚扰催收
- 所有催收记录需完整留存，接受合规审计
- 货物处置回收资金必须进入平台指定监管账户，禁止个人账户代收
- 核销审批严格执行分级授权，大额核销（>50万）需总经理审批

### 9.2 操作防护
- 核销申请一旦提交，在审批完成前不可撤销
- 核销执行后不可恢复，系统需二次确认
- 货物处置价格低于评估价70%时，需额外审批
- 同一客户多次申请核销时，触发专项审查

### 9.3 数据安全
- 催收记录中的客户隐私信息脱敏展示
- 诉讼文书等法律材料加密存储
- 处置过程中的货物照片、交接记录完整留存

### 9.4 日志留存
- 催收操作日志留存不少于5年
- 货物处置全流程记录留存不少于10年
- 核销记录永久留存，不可删除
