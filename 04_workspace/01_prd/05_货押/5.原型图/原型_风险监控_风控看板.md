# 原型：风险监控 — 风控看板（运营端）

## 一、页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 风控看板 |
| **使用角色** | 决策层（总经理/风控总监）/ 管理层（部门经理）/ 执行层（风控专员/客户经理） |
| **页面目的** | 实时掌握全平台风险状况，提供统计卡片区/分布区/趋势区/TOP排行区/核心企业协同看板的多维度风险视图 |
| **入口路径** | 运营端 → 风险监控 → 风控看板 |
| **数据刷新** | 实时数据每5分钟自动刷新，趋势数据每小时刷新 |
| **数据权限** | 决策层可见全平台数据，管理层可见本部门数据，执行层可见本人负责客户数据 |

> **设计说明**：本页面为风险监控的核心决策看板，顶部6张统计卡片支持下钻，中部为风险分布和趋势分析，下部为核心企业协同看板和风险TOP排行。图表支持按时间范围（近7天/近30天/自定义）筛选。

### 4.8 数据权限控制

| 角色 | 可见范围 | 可操作范围 |
