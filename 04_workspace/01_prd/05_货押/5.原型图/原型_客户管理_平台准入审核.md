# 原型：客户管理 — 平台准入审核（运营端）

---

## 1. 页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 平台准入审核 |
| **使用角色** | 平台运营人员/审批人员（运营端） |
| **页面目的** | 运营人员查看经销商准入申请信息、核心企业推荐信息，结合系统智能建议进行审批决策 |
| **入口** | 运营端 → 客户管理 → 准入审核 → 待审核列表 → 点击"审核" |
| **关联Spec** | spec-客户管理-准入申请与审批.md + spec-客户管理-企业档案与推荐.md |

## 3. 元素说明表

### 3.1 页面标题栏

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|
| 申请编号 | 文本 | 唯一标识，如ADM-20260426-001 | | 🔧 运营端 |
| 快速通道标签 | 状态标签 | 紫色标签，匹配快速通道时展示 | | 🔧 运营端 |
| 标准流程标签 | 状态标签 | 蓝色标签，匹配标准流程时展示 | | 🔧 运营端 |
| 加强流程标签 | 状态标签 | 橙色标签，匹配加强流程时展示 | | 🔧 运营端 |
| 剩余时效 | 倒计时 | 距超时提醒的剩余时间，<4小时黄色高亮 | | 🔧 运营端 |

### 3.2 左侧：申请信息区

#### 基本信息卡片

| 字段 | 说明 |
|------|------|
| 企业名称 | 经销商填报的全称 |
| 统一社会信用代码 | 18位代码，中间位脱敏展示 |
| 法定代表人 | 姓名 |
| 联系电话 | 中间4位脱敏 |
| 注册地址 | 完整地址 |

#### 上传资料预览卡片

| 元素 | 说明 |
|------|------|
| 资料项列表 | 7项必传资料逐一展示 |
| 状态标记 | [✓]已上传格式正常 / [✗]格式异常 / [⚠]临期预警 |
| [预览]按钮 | 点击在新窗口预览文件内容 |
| [下载]按钮 | 点击下载原始文件 |

#### 资料完整性检查卡片

| 元素 | 说明 |
|------|------|
| 完整度统计 | 格式：已上传数/总数 |

| 缺失项 | 未上传项红色高亮，标注"缺失" |

### 3.3 右侧：审批决策区

#### 核心企业推荐信息（紫色高亮区块）

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|
| 核心企业名称 | 文本 | 推荐码对应的核心企业全称 | | 🔧 运营端 |

| 推荐质量等级 | 标签 | ≥90优秀 / 70-89良好 / 50-69一般 / <50较差 | | 🔧 运营端 |

| 近期供货数据 | 文本 | 核心企业ERP返回的近期供货概况 | | 🔧 运营端 |

|------|------|------|--------|

| 准入通道 | 文本 | 快速通道(2级) / 标准流程(3级) / 加强流程(5级) | | 🔧 运营端 |

#### 审批操作区

| 元素 | 类型 | 必填 | 说明 |
|------|------|------|------|

| [取消] | 按钮 | - | 返回待审核列表 |

## 4. 交互说明

### 4.1 页面加载交互

| 场景 | 系统行为 |
|------|----------|
| 进入审核详情页 | 左侧加载经销商申请信息，右侧并行加载核心企业推荐信息和系统智能建议 |
| 核心企业数据获取失败 | 紫色区块显示"核心企业数据获取失败，审批时请注意核验" |
| 加载超时 | 显示loading状态，超3秒提示"数据加载中，请稍候" |

### 4.2 差异化审批标签展示

| 匹配结果 | 标签展示 | 标签颜色 |
|----------|----------|----------|
| 快速通道（2级审批） | [🏷 快速通道] | 紫色 |
| 标准流程（3级审批） | [🏷 标准流程] | 蓝色 |
| 加强流程（5级审批） | [🏷 加强流程] | 橙色 |
| 标准流程+尽调 | [🏷 标准流程+尽调] | 黄色 |
| 加强流程+额度限制 | [🏷 加强流程·限额度] | 红色 |
| 暂停准入 | [🏷 暂停准入] | 灰色（禁用提交） |

### 4.3 资料完整性标记交互

| 状态 | 标记样式 | 交互 |
|------|----------|------|
| 已上传且正常 | 绿色[✓] | 悬停显示文件详情（文件名、大小、上传时间） |
| 已上传但临期 | 黄色[⚠] | 悬停显示临期详情，点击[预览]可查看证照有效期 |
| 已上传但格式异常 | 红色[✗] | 悬停显示异常原因 |
| 未上传（缺失） | 红色[缺失] | 点击可查看该资料的具体要求说明 |

### 4.4 审批操作交互

| 步骤 | 用户操作 | 系统行为 |
|------|----------|----------|
| 选择通过 | 点击"通过"单选 | 授信额度输入框激活，驳回原因下拉置灰 |
| 选择驳回 | 点击"驳回"单选 | 驳回原因下拉激活，授信额度输入框置灰 |
| 填写授信额度 | 输入金额 | 实时校验是否在建议范围内，超出范围黄色提示"超出建议范围，请确认" |
| 填写审批意见 | 输入文本 | 实时统计字符数，<10字符时红色提示"审批意见不少于10字符" |
| 提交审批 | 点击[提交审批] | 二次确认弹窗"确认提交审批结果？通过后不可撤销" → 确认后提交 |
| 取消 | 点击[取消] | 返回待审核列表，不保存当前操作 |

### 4.5 审批结果流转

| 审批操作 | 后续流转 |
|----------|----------|
| 通过（非终审节点） | 状态流转至下一节点，通知下一节点审批人 |
| 通过（终审节点） | 状态="审批完成"，自动生成立项，通知经销商准入成功，开通平台账号 |
| 驳回 | 状态="已驳回"，通知经销商驳回原因，允许补充资料重新提交 |
| 退回 | 状态回退至指定节点，通知该节点审批人重新审批 |

### 4.6 超时处理

| 场景 | 系统行为 |
|------|----------|
| 剩余时间<24h | 标题栏倒计时黄色高亮 |
| 剩余时间<4h | 标题栏倒计时红色高亮，推送催促通知给当前审批人 |
| 超时未审批 | 自动升级给上级审批人，原审批人和上级均收到通知，记录超时纳入绩效考核 |
