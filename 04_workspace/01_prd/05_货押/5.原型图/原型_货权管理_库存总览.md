# 原型：货权管理 — 库存总览（运营端）

## 一、页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 库存总览 |
| **使用角色** | 货权监控员 / 运营专员 / 风控专员 / 决策层 |
| **页面目的** | 提供全平台库存的5维度视图（品类/仓库/客户/核心企业/风险），支持实时监控、钻取分析和盘点管理 |
| **入口路径** | 运营端 → 货权管理 → 库存总览 |
| **数据刷新** | 每5分钟自动刷新 |

> **设计说明**：本页面为库存监控的核心看板，顶部展示关键KPI指标，中部为图表分析区，下部为库存明细表格。支持从汇总直接钻取到明细（品类→客户→单笔业务→货物明细）。

## 四、交互说明

### 4.1 页面加载交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 页面加载 | 加载KPI卡片、图表、表格数据 | 显示骨架屏 |
| 数据加载完成 | 渲染各区块，启动5分钟自动刷新定时器 | — |
| 5分钟定时器触发 | 自动刷新所有数据区块 | 刷新时显示loading小图标 |

### 4.2 KPI卡片交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 点击"总在库货值"卡片 | 下钻到库存明细列表 | 保持当前筛选条件 |
| 点击"质押率超标业务数"卡片 | 跳转风险监控-预警列表 | 自动筛选超标/紧急级别 |
| 点击"今日出入库笔数"卡片 | 下钻到出入库记录列表 | 默认筛选今日数据 |

### 4.3 筛选交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 选择品类 | 品牌下拉列表动态更新 | 仅显示该品类下的品牌 |
| 点击"搜索" | 应用所有筛选条件，刷新图表和表格 | 显示loading状态 |
| 点击"重置" | 清空所有筛选条件，恢复默认视图 | — |
| 输入客户名称 | 支持模糊搜索，回车触发搜索 | 最少输入2个字符 |

### 4.4 图表交互

| 触发条件 | 交互行为 | 说明 |

| 悬停柱状图 | 显示Tooltip：区间+业务数+占比 | 浮层跟随鼠标 |

| 悬停仓库标记 | 显示仓库名称 | 小浮层 |
| 点击仓库标记 | 弹出信息气泡 | 显示：仓库名称/在库货值/预警数量/负责人 |
| 点击"热力图"切换 | 地图切换为货值热力图模式 | 按区域展示货值分布密度 |

### 4.6 表格交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 点击客户名称 | 下钻到客户维度视图 | 展示该客户所有在途业务 |
| 点击业务编号 | 跳转业务详情页 | 展示单笔业务完整信息 |
| 勾选行复选框 | 选中该行，触发盘点按钮可用 | 支持多选 |
| 点击"导出报表" | 下载Excel/PDF文件 | 包含当前筛选条件下的全部字段 |
| 点击"触发盘点" | 弹出盘点任务创建对话框 | 对选中业务生成盘点计划 |
| 点击表头 | 按该列排序 | 支持升序/降序切换 |

### 4.7 钻取路径

```
库存总览（品类维度）
  → 点击品类 → 品类客户列表
    → 点击客户 → 客户业务列表
      → 点击业务 → 业务货物明细（SKU/数量/货值/质押率）
```

### 4.8 盘点任务交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 选中表格行后点击"触发盘点" | 弹出盘点任务创建对话框 | 预填选中业务信息 |
| 选择盘点类型 | 选项：常规盘点/加密盘点/紧急盘点 | 默认根据货物价值自动推荐 |
| 选择盘点时间 | 日期时间选择器 | 默认明日10:00 |
| 确认创建 | 生成盘点任务，推送WMS | 显示成功提示，刷新盘点计划列表 |
