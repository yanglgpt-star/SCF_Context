# 原型：融资业务 — 审批工作台（运营端）

---

## 1. 页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 审批工作台 |
| **使用角色** | 平台审批人员/风控人员（运营端） |
| **页面目的** | 提供审批人员一站式工作台，包含待办统计、审批列表筛选、审批详情查看与决策操作 |
| **入口** | 运营端 → 融资业务 → 审批工作台 |
| **关联Spec** | spec-融资业务-融资申请与放款.md + spec-融资业务-审批流程引擎.md |

## 3. 元素说明表

### 3.1 顶部统计卡片

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|
| 待审批 | 统计数字 | 当前审批人待处理的审批任务数量 | | 🔧 运营端 |
| 已审批 | 统计数字 | 本月已完成的审批数量 | | 🔧 运营端 |
| 平均时效 | 统计数字 | 本月审批平均耗时，与目标对比 | | 🔧 运营端 |

### 3.2 筛选面板

| 筛选条件 | 类型 | 选项/范围 | 所属端 |
|----------|------|-----------|--------|
| 客户等级 | 单选 | 全部/A级/B级/C级 | | 🔧 运营端 |
| 融资金额区间 | 滑块/数字输入 | 最小-最大（万元） | | 🔧 运营端 |
| 审批节点 | 多选 | 初审/实地核查/风控审批/高管审批/终审 | | 🔧 运营端 |
| 申请时间范围 | 日期选择 | 开始日期-结束日期 | | 🔧 运营端 |
| [重置筛选] | 按钮 | 清空所有筛选条件 | | 🔧 运营端 |
| [应用筛选] | 按钮 | 执行筛选，刷新列表 | | 🔧 运营端 |

### 3.3 审批列表

| 列名 | 说明 | 特殊样式 |
|------|------|----------|
| 编号 | 业务编号，如FIN-20260426-001 | - |
| 客户名称 | 经销商企业名称 | - |
| 申请金额 | 单位：万元 | - |
| 客户等级 | A/B/C标签 | 颜色区分 |
| 核心企业等级 | S/A/B/C标签 | 颜色区分 |
| 风险评分 | 综合风险评分（0-100） | ≥85绿色/70-84蓝色/60-69黄色/<60红色 |
| 当前节点/倒计时 | 当前审批节点+剩余时效 | <4h黄色⚠/<0h红色🔴 |

### 3.4 审批详情页 — 核心企业信息（紫色高亮区块）

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|
| 核心企业名称 | 文本 | 推荐码对应的核心企业全称 | | 🔧 运营端 |
| 核心企业等级 | 标签 | S/A/B/C，S级金色五星展示 | | 🔧 运营端 |
| 推荐质量得分 | 评分 | 0-100分，≥90优秀/70-89良好/50-69一般/<50较差 | | 🔧 运营端 |
| 推荐质量等级 | 标签 | 与得分区间对应 | | 🔧 运营端 |
| 经销商信用评级 | 文本 | A+/A/B/C，A+视为A级 | | 🔧 运营端 |
| 风险预警状态 | 状态标签 | [✓]正常 / [✗]风险标注（如有则红色高亮） | | 🔧 运营端 |

### 3.5 审批详情页 — 三卡片区

| 卡片 | 字段 | 数据来源 |
|------|------|----------|
| 客户资质 | 征信评级、经营年限、注册资本 | 征信系统/客户档案 |
| 历史表现 | 融资笔数、累计金额、逾期率、M3+逾期 | 平台历史数据 |
| 质押物评估 | 品类、品类风险、质押率、货值稳定性 | 货权管理模块 |

### 3.6 综合风险评分

| 维度 | 权重 | 数据来源 |
|------|------|----------|
| 客户资质 | 20% | 征信系统/客户档案 |
| 核心企业背书 | 25% | 核心企业接口/客户档案 |
| 历史表现 | 25% | 平台历史数据 |
| 质押物评估 | 20% | 货权管理模块 |
| 市场风险 | 10% | 市场价格数据源 |

| 分数区间 | 风险等级 | 系统建议 |
|----------|----------|----------|
| 85-100 | 低风险 🟢 | 建议通过，可适用快速审批通道 |
| 70-84 | 中风险 🔵 | 建议通过，需审批人确认风险点 |
| 60-69 | 较高风险 🟡 | 建议谨慎，需上级复核 |
| <60 | 高风险 🔴 | 建议驳回，如需通过须风控总监审批 |

### 3.7 审批操作区

| 操作类型 | 必填项 | 说明 |
|----------|--------|------|
| 通过 | 审批意见 | 流转至下一节点，终审通过后状态="审批完成" |
| 驳回 | 驳回原因 | 状态="审批驳回"，通知企业端 |
| 退回 | 退回节点+意见 | 回退至指定节点，通知该节点审批人 |
| 转上级 | 转交原因 | 当前任务转交上级审批人处理 |

## 4. 交互说明

### 4.1 审批列表交互

| 操作 | 系统行为 |
|------|----------|
| 点击列表行 | 进入该业务的审批详情页 |
| 排序切换 | 点击排序选项，列表按选中维度重新排序 |
| 筛选应用 | 点击[应用筛选]，列表按条件刷新，显示匹配结果数 |
| 分页切换 | 点击页码，加载对应页数据 |
| 倒计时<4h | 该行黄色高亮，提示紧急 |
| 倒计时<0h（已超时） | 该行红色高亮，提示已超时 |

### 4.2 核心企业风险预警交互

| 场景 | 系统行为 |
|------|----------|
| 核心企业标注风险 | 紫色区块中风险预警状态变为红色[✗]，显示具体风险标注内容（如"串货风险"） |
| 审批过程中预警到达 | 页面顶部红色横幅提示"核心企业风险预警：该经销商存在XX风险" |
| 快速通道遇风险 | 自动阻断转人工审批，通道标签变更为"加强流程" |

### 4.3 综合风险评分交互

| 交互 | 行为 |
|------|------|
| 悬停各维度进度条 | 显示该维度得分的详细计算依据 |
| 点击[查看征信报告] | 新窗口打开征信报告详情（敏感信息脱敏） |
| 点击[查看历史明细] | 新窗口打开该客户历史融资记录 |
| 点击[查看估值详情] | 新窗口打开质押物估值报告 |

### 4.4 审批操作交互

| 步骤 | 用户操作 | 系统行为 |
|------|----------|----------|
| 选择通过 | 点击"通过"单选 | 显示审批意见输入框，隐藏驳回/退回/转上级专属字段 |
| 选择驳回 | 点击"驳回"单选 | 显示驳回原因下拉，隐藏其他专属字段 |
| 选择退回 | 点击"退回"单选 | 显示退回节点下拉，隐藏其他专属字段 |
| 选择转上级 | 点击"转上级"单选 | 显示转交原因输入框，隐藏其他专属字段 |
| 提交审批 | 点击[提交审批] | 校验必填项→二次确认弹窗→提交→状态流转→通知相关方 |
| 重复审批拦截 | 已审批节点 | 该审批人对应的操作按钮置灰不可再操作 |

### 4.5 审批历史记录交互

| 交互 | 行为 |
|------|------|
| 展开/收起 | 点击标题可展开收起历史记录列表 |
| 查看详情 | 点击单条记录可查看完整审批意见和操作时间/IP等审计信息 |
| 流程图展示 | 可切换为流程图视图，直观展示当前节点和已完成节点 |

### 4.6 超时处理交互

| 场景 | 系统行为 |
|------|----------|
| 剩余<24h未处理 | 向审批人推送超时提醒通知 |
| 超时未处理 | 自动升级给上级审批人，原审批人和上级均收到通知 |
| 超时记录 | 纳入审批人绩效考核，在审批质量报表中展示 |

### 4.7 审批质量考核

| 指标 | 说明 |
|------|------|
| 及时率 | 规定时间内完成审批的比例 |
| 准确率 | 审批决策与最终业务结果的一致性 |
| 审批后逾期率 | 审批通过的业务中发生逾期的比例 |
| 权限复核标记 | 连续3笔审批通过后逾期的审批人，标注"需权限复核" |
