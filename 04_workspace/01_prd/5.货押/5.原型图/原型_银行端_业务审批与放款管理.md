# 原型：银行端 — 业务审批与放款管理

---

## 1. 页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 业务审批与放款管理 |
| **使用角色** | 银行客户经理 / 银行审批人员 / 银行放款专员（🏦 银行端） |
| **页面目的** | 银行端接收平台推送的融资申请，进行业务审批、放款指令确认、出库授权管理 |
| **入口** | 银行端登录 → 工作台 → 业务审批 / 放款管理 |
| **关联Spec** | spec-融资业务-融资申请与放款.md + spec-融资业务-审批流程引擎.md |

## 3. 元素说明表

### 3.1 工作台统计卡片

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|
| 待审批业务 | 统计数字 | 银行端待处理的审批任务数量 | 🏦 银行端 |
| 本月放款金额 | 统计数字 | 本月累计放款金额，含环比变化 | 🏦 银行端 |
| 在途业务数 | 统计数字 | 当前处于"在库监管"状态的业务数量 | 🏦 银行端 |
| 待授权出库 | 统计数字 | 经销商已申请还款但银行尚未发送出库授权的数量 | 🏦 银行端 |
| 快捷入口 | 按钮组 | 快速跳转到业务审批/放款管理/出库授权/业务监控 | 🏦 银行端 |

### 3.2 业务审批列表

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|
| 审批状态筛选 | 下拉选择 | 全部/待审批/已通过/已驳回 | 🏦 银行端 |
| 申请金额区间 | 数字输入 | 最低-最高金额筛选 | 🏦 银行端 |
| 质押品类筛选 | 下拉选择 | 全部/3C电子/白酒/食品/家电 | 🏦 银行端 |
| 申请时间范围 | 日期选择 | 开始日期-结束日期 | 🏦 银行端 |
| 业务编号 | 文本 | 平台融资业务唯一编号 | 🔄 跨端（平台生成，银行查看） |
| 经销商名称 | 文本 | 融资企业名称 | 🏪 企业端-融资企业 |
| 申请金额 | 金额 | 经销商申请的融资金额 | 🏪 企业端-融资企业 |
| 平台初审结果 | 标签 | 平台审批节点的结果状态 | 🔧 运营端 |
| 综合风险评分 | 数字 | 平台计算的综合风险评分（5维度） | 🔧 运营端 |
| 审批状态 | 标签 | 🟡待审批/🟢已通过/🔴已驳回 | 🏦 银行端 |

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|

| 放款结果反馈 | 系统自动 | 银行执行放款后，结果自动回传平台 | 🔄 跨端（银行→平台） |

## 4. 交互说明

### 4.1 审批流程

| 步骤 | 触发条件 | 交互行为 | 系统响应 |
|------|----------|----------|----------|
| 1 | 平台终审通过 | 平台自动推送审批请求到银行端 | 银行端待审批数量+1，发送系统通知+短信 |
| 2 | 银行审批人员点击"去审批" | 打开审批详情页 | 加载融资申请信息、平台审批记录、风险评分 |
| 3 | 审批人员选择结论并填写意见 | 点击"确认审批" | 校验必填项→保存审批结果→通知平台→更新业务状态 |
| 4 | 审批结论为"同意放款" | 系统自动生成放款指令 | 推送放款指令到银行端放款管理模块 |
| 5 | 审批结论为"拒绝" | 系统记录拒绝原因 | 通知平台→平台通知经销商→业务状态变为"银行拒绝" |

### 4.2 放款流程

| 步骤 | 触发条件 | 交互行为 | 系统响应 |
|------|----------|----------|----------|
| 1 | 银行审批通过 | 系统生成放款指令 | 放款指令状态="待确认"，推送银行端 |
| 2 | 银行放款专员点击"确认放款" | 弹出确认弹窗 | 展示放款详情，要求二次确认 |
| 3 | 点击"确认并执行放款" | 银行核心系统执行放款 | 记录放款结果→API回调平台→平台更新状态→通知经销商 |
| 4 | 放款成功 | 系统自动对账 | 银行流水与平台记录匹配，差异±0.01元内通过 |
| 5 | 放款失败 | 系统记录失败原因 | 通知平台和经销商，进入失败处理流程 |

### 4.3 出库授权流程

| 步骤 | 触发条件 | 交互行为 | 系统响应 |
|------|----------|----------|----------|
| 1 | 经销商还款到账 | 银行确认还款 | 银行端显示待授权出库提醒 |
| 2 | 银行人员填写授权信息 | 点击"发送授权" | 校验金额→生成授权编号→推送平台→平台接收校验 |
| 3 | 平台接收授权 | 三重校验引擎执行 | 校验通过→进入出库审批流程 |
| 4 | 授权过期 | 倒计时归零 | 授权状态自动变为"已过期"，需重新发送 |
| 5 | 授权被使用 | 出库审批通过并执行 | 授权状态变为"已使用"，记录使用金额 |
