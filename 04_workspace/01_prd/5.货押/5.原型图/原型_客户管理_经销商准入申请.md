# 原型：客户管理 — 经销商准入申请（企业端）

---

## 1. 页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 经销商准入申请 |
| **使用角色** | 经销商（企业端） |
| **页面目的** | 经销商在线提交准入申请，完成基本信息填报、推荐码验证、资质资料上传，经系统自动校验后提交至平台审核 |
| **入口** | 企业端首页 → 客户中心 → 准入申请 |
| **关联Spec** | spec-客户管理-准入申请与审批.md |

## 4. 交互说明

### 4.1 步骤流转交互

| 步骤 | 触发条件 | 系统行为 |
|------|----------|----------|
| ①→② | 基本信息全部填写且格式正确 | 步骤②自动激活，步骤①标记完成 |
| ②→③ | 推荐码验证通过 | 步骤③激活，展示核心企业信息卡片 |
| ③→④ | 全部必填资料上传完成 | 步骤④激活，自动汇总所有信息 |
| 任意步骤→保存草稿 | 点击[保存草稿] | 保存当前已填写内容，返回草稿编号 |

### 4.2 推荐码验证交互

| 场景 | 用户操作 | 系统反馈 |
|------|----------|----------|
| 推荐码有效 | 输入有效推荐码 → 点击[验证] | 展开验证结果卡片，显示核心企业信息、有效期、剩余次数 |
| 推荐码不存在 | 输入无效推荐码 → 点击[验证] | 输入框红框提示"推荐码无效，请向核心企业重新获取" |
| 推荐码已过期 | 输入过期推荐码 → 点击[验证] | 输入框红框提示"推荐码已过期，请联系核心企业重新生成" |
| 推荐码已达上限 | 输入已达上限推荐码 → 点击[验证] | 输入框红框提示"推荐码已达使用上限，请联系核心企业" |

### 4.3 文件上传交互

| 场景 | 系统行为 |
|------|----------|
| 拖拽/点击上传 | 弹出文件选择框，支持多文件选择 |
| 上传中 | 显示进度条，百分比实时更新 |
| 上传完成 | 显示文件名、大小，绿色[✓]标记 |
| 文件超出大小限制 | 实时提示"文件大小超出限制，请压缩后重新上传"，文件不保存 |
| 文件格式不符 | 实时提示"仅支持XX格式"，文件不保存 |
| 法人身份证有效期<6个月 | 上传完成后黄色[⚠]标记"临期预警"，允许提交但审批端重点提示 |
| 法人身份证已过期 | 上传完成后红色[✗]标记"证照已过期"，禁止提交 |

### 4.4 自动校验交互

| 校验项 | 触发时机 | 校验结果展示 |
|--------|----------|--------------|
| 完整性校验 | 每完成一个上传/输入 | 校验提示区实时更新，缺失项红色标注 |
| 格式校验 | 文件上传完成时 | 文件卡片旁实时显示校验结果 |
| 证照有效期校验 | 文件上传完成时 | 临期黄色预警，过期红色禁止 |
| 黑名单校验 | 提交时 | 命中则提交失败，返回具体命中原因 |
| 征信校验 | 提交时 | 异常则提交失败，返回具体异常说明 |

### 4.5 提交按钮状态控制

| 状态 | 按钮表现 | 触发条件 |
|------|----------|----------|
| 可用 | 蓝色可点击 | 全部必填项已填写、全部必填资料已上传、推荐码验证通过、无过期证照 |
| 置灰 | 灰色不可点击 | 任一必填项缺失/格式错误/文件未上传/推荐码未验证/证照已过期 |
| 加载中 | 按钮显示loading | 提交请求处理中 |

### 4.6 提交后交互

| 结果 | 系统行为 |
|------|----------|
| 提交成功 | 弹出成功弹窗，展示申请编号（如ADM-20260426-001）和当前状态"准入申请中" |
| 提交失败（资料不完整） | 弹出失败提示，列出缺失清单，定位到对应步骤 |
| 提交失败（黑名单命中） | 弹出失败提示"命中黑名单，申请被驳回"，附命中原因 |
| 提交失败（征信异常） | 弹出失败提示"征信校验不通过"，附具体说明 |
| 系统异常 | 提示"系统繁忙，请稍后重试" |
