# 原型：融资业务 — 融资申请（企业端）

---

## 1. 页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 融资申请 |
| **使用角色** | 经销商（企业端） |
| **页面目的** | 经销商在线提交融资申请，填写基本信息、质押物信息，系统自动校验后提交审批 |
| **入口** | 企业端首页 → 融资中心 → 申请融资 |
| **关联Spec** | spec-融资业务-融资申请与放款.md |

## 3. 元素说明表

### 3.1 顶部额度提示条

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|
| 可用授信额度 | 金额展示 | 总额度 - 已占用额度，实时计算 | | 🏪 企业端-融资企业 |
| 已占用额度 | 金额展示 | 所有在途业务占用额度之和 | | 🏪 企业端-融资企业 |
| 总额度 | 金额展示 | 当前授信总额度 | | 🏪 企业端-融资企业 |

### 3.2 步骤条

| 元素 | 类型 | 说明 | 所属端 |
|------|------|------|--------|
| 步骤①-基本信息 | 步骤节点 | 默认激活 | | 🏪 企业端-融资企业 |
| 步骤②-质押物信息 | 步骤节点 | 基本信息校验通过后激活 | | 🏪 企业端-融资企业 |
| 步骤③-资料上传 | 步骤节点 | 质押物信息填写完成后激活 | | 🏪 企业端-融资企业 |
| 步骤④-确认提交 | 步骤节点 | 资料上传完成后激活，展示汇总 | | 🏪 企业端-融资企业 |

### 3.3 基本信息表单字段

| 字段名 | 类型 | 必填 | 校验规则 | 交互说明 | 所属端 |
|--------|------|------|----------|----------|--------|
| 申请金额 | 数字输入 | 是 | ≤可用额度；≤质押物货值×质押率上限；≤单笔融资上限 | 输入时实时显示可用额度提示，超出时红框+红色提示 | | 🏪 企业端-融资企业 |
| 融资期限 | 下拉选择 | 是 | 在允许范围内（如7-180天） | 下拉选项：7/30/60/90/180天 | | 🏪 企业端-融资企业 |
| 资金用途 | 文本输入 | 是 | ≤500字符 | 实时非空校验 | | 🏪 企业端-融资企业 |
| 还款来源 | 文本输入 | 是 | ≤500字符 | 实时非空校验 | | 🏪 企业端-融资企业 |

### 3.4 关联已有仓单/质押物

| 选项 | 说明 |
|------|------|
| 不关联，新建质押物 | 默认选项，填写全新质押物信息 |
| 关联已有仓单 | 下拉选择已入库仓单，自动带入品类/货值等信息 |
| 关联已预报质押物 | 下拉选择已预报但未入库的质押物 |

### 3.5 质押物信息表单字段

| 字段名 | 类型 | 必填 | 校验规则 | 交互说明 | 所属端 |
|--------|------|------|----------|----------|--------|
| 质押物品类 | 下拉选择 | 是 | 必须与主营品类一致 | 下拉展示系统已配置品类 | | 🏪 企业端-融资企业 |
| 质押物品牌 | 文本输入 | 是 | ≤100字符 | - | | 🏪 企业端-融资企业 |
| 质押物型号 | 文本输入 | 是 | ≤100字符 | - | | 🏪 企业端-融资企业 |
| 质押物数量 | 数字输入 | 是 | >0 | 单位根据品类自动匹配 | | 🏪 企业端-融资企业 |
| 质押物货值 | 数字输入 | 是 | >0 | 显示系统估值参考价 | | 🏪 企业端-融资企业 |
| 预计入库日期 | 日期选择 | 是 | 申请日期+7天内 | 日期选择器限制可选范围 | | 🏪 企业端-融资企业 |

### 3.6 自动校验提示区

| 校验项 | 触发时机 | 提示样式 |
|--------|----------|----------|
| 可用额度校验 | 申请金额输入时 | [✓]绿色通过 / [✗]红色"超出可用额度" |
| 质押率校验 | 申请金额/货值变化时 | [✓]绿色通过 / [✗]红色"质押物可融资金额上限为XX万" |
| 品类一致性校验 | 品类选择时 | [✓]绿色通过 / [✗]红色"品类与主营不一致" |
| 客户状态校验 | 页面加载时 | [✓]正常 / [✗]红色"客户状态冻结，不可申请" |
| 证照有效期校验 | 页面加载时 | [✓]正常 / [✗]红色"XX证照已过期" |
| 逾期业务校验 | 页面加载时 | [✓]正常 / [✗]红色"有未结清逾期业务" |
| 单笔限额校验 | 申请金额输入时 | [✓]绿色通过 / [✗]红色"超出单笔限额" |
| 重复提交校验 | 提交时 | [✓]正常 / [✗]红色"请勿重复提交" |

### 3.7 资料上传区域

| 资料项 | 必填 | 支持格式 | 大小限制 |
|--------|------|----------|----------|
| 融资申请表 | 是（系统自动生成） | PDF | 自动生成 |
| 质押物清单及权属证明 | 是 | PDF/JPG/PNG | ≤20MB |
| 购销合同/订单 | 是 | PDF | ≤20MB |
| 其他补充资料 | 否 | PDF/JPG/PNG/Excel | ≤30MB |

### 3.8 操作按钮

| [下一步] | 当前步骤校验通过可用 | 进入下一步 |

## 4. 交互说明

### 4.1 步骤流转交互

| 步骤 | 触发条件 | 系统行为 |
|------|----------|----------|
| ①→② | 基本信息全部填写且格式正确 | 步骤②激活，自动校验客户基础状态 |
| ②→③ | 质押物信息填写完成且校验通过 | 步骤③激活 |
| ③→④ | 必传资料全部上传完成 | 步骤④激活，自动汇总所有信息并执行全量校验 |
| 任意步骤→保存草稿 | 点击[保存草稿] | 保存当前已填写内容，返回草稿编号 |

### 4.2 申请金额实时校验交互

| 场景 | 用户操作 | 系统反馈 |
|------|----------|----------|
| 金额在可用额度内 | 输入40万（可用50万） | 输入框旁绿色提示"申请金额合规" |
| 金额超出可用额度 | 输入60万（可用50万） | 输入框红框，实时提示"申请金额超过可用授信额度，当前可用50万元" |
| 金额超出质押率上限 | 输入50万（货值60万×70%=42万） | 输入框红框，提示"质押物可融资金额上限为42万" |
| 金额超出单笔限额 | 输入120万（A级限额100万） | 输入框红框，提示"超出A级客户单笔融资上限100万" |

### 4.3 质押物信息联动交互

| 场景 | 系统行为 |
|------|----------|
| 选择品类 | 自动匹配数量单位（如3C电子→"台"、建材→"吨"） |
| 关联已有仓单 | 自动带入品类、品牌、货值等信息，部分字段不可编辑 |
| 输入货值 | 显示系统估值参考价（来自货权管理模块） |
| 申请金额+货值均填写 | 实时计算并显示质押率：申请金额÷货值×100% |

### 4.4 自动校验实时展示交互

| 校验项 | 校验时机 | 通过样式 | 未通过样式 |
|--------|----------|----------|------------|
| 可用额度 | 申请金额输入/变化 | 绿色[✓] | 红色[✗]+文字提示 |
| 质押率 | 申请金额或货值变化 | 绿色[✓]+计算过程 | 红色[✗]+可融上限 |
| 品类一致性 | 品类选择时 | 绿色[✓] | 红色[✗] |
| 客户状态 | 页面加载 | 绿色[✓] | 红色[✗]，禁止继续 |
| 证照有效期 | 页面加载 | 绿色[✓] | 红色[✗]，禁止继续 |
| 逾期业务 | 页面加载 | 绿色[✓] | 红色[✗]，禁止继续 |
| 重复提交 | 提交时 | 绿色[✓] | 红色[✗]"请勿重复提交" |

### 4.5 提交前确认页交互

| 元素 | 交互 |
|------|------|
| 信息汇总区 | 按分类展示所有已填写信息，不可编辑 |
| 校验结果区 | 逐条展示8项自动校验结果，全部[✓]时显示"全部校验通过" |
| 提交按钮 | 全部校验通过时蓝色可用，任一未通过时灰色置灰 |

### 4.6 提交后交互

| 结果 | 系统行为 |
|------|----------|
| 提交成功 | 弹出成功弹窗，展示业务编号（如FIN-20260426-001），状态"待校验"，进入自动校验引擎 |
| 提交失败（必填项缺失） | 提示"请完善必填项：XX"，定位到对应步骤 |
| 提交失败（重复提交） | 提示"您已提交相似申请，请勿重复提交" |
| 校验驳回 | 状态="校验驳回"，返回具体不通过原因，通知客户经理 |
| 系统异常 | 提示"系统繁忙，请稍后重试" |
