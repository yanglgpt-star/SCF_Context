# 原型：风险监控 — 实时预警处置（运营端）

## 一、页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 实时预警处置 |
| **使用角色** | 风控专员 / 风控主管 / 部门经理 |
| **页面目的** | 接收并处置7×24小时自动生成的分层预警，按标准化7状态流转进行处置，支持跨模块联动操作 |
| **入口路径** | 运营端 → 风险监控 → 实时预警处置 |
| **页面组成** | 左侧筛选面板 + 中部预警列表 + 右侧预警详情页（点击后展开） |
| **数据刷新** | 预警列表每30秒自动刷新，详情页实时刷新 |

> **设计说明**：本页面为风控专员日常工作的核心操作界面，左侧为筛选面板，中部为按优先级排序的预警列表，右侧为点击预警后展开的详情页。预警按"级别降序+触发时间升序"排列，支持同客户多预警合并展示。

| 点击"重置筛选" | 清空所有条件，恢复默认视图 | 默认选中紧急+超标+警戒 |

### 4.3 预警列表交互

| 触发条件 | 交互行为 | 说明 |

### 4.4 预警详情页交互

### 4.5 快捷操作交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 点击"冻结融资" | 弹出二次确认对话框 | "确认冻结该客户新增融资权限？" |

### 4.6 处置措施交互

| 触发条件 | 交互行为 | 说明 |

### 4.7 状态流转交互

| 当前状态 | 可操作动作 | 下一状态 |
|---------|-----------|---------|
| 待处理 | 确认接收 / 转派 / 忽略（需审批） | 处理中 / 待处理（转派后） |
| 处理中 | 提交调查结果 / 申请协同 / 升级 | 待协同 / 处置中 / 已升级 |
| 待协同 | 跟进协同进度 / 取消协同 | 处置中（协同响应后） |
| 处置中 | 更新进度 / 调整方案 / 处置完成 | 待复核 |
| 待复核 | 通过 / 退回补充 | 已关闭 / 处置中 |
| 已关闭 | 查看详情 / 重新打开 | 处理中（重新打开后） |
| 已升级 | 上级接管 / 原责任人协助 | 处理中 |

### 4.8 时间轴交互

| 触发条件 | 交互行为 | 说明 |

### 4.9 升级机制交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 紧急预警2小时未响应 | 自动升级给风控主管 | 状态变更为"已升级"，通知原责任人+上级 |
| 超标预警4小时未响应 | 自动升级给风控主管 | 同上 |
| 警戒预警24小时未响应 | 自动升级给部门经理 | 同上 |

### 4.10 同客户多预警合并交互
