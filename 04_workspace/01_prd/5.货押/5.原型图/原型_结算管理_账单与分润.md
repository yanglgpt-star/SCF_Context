# 原型：结算管理 — 账单与分润（运营端）

> **对应Spec**：spec-结算管理-服务费计费.md + spec-结算管理-分润对账与资金.md  
> **页面角色**：运营端财务人员/财务主管  
> **版本**：V1.0

---

## 一、页面概述

结算管理页面是平台财务结算的核心操作界面，涵盖账单生成与管理、核心企业分润结算、以及银行收款对账三大功能模块。采用顶部Tab切换的组织方式，便于财务人员在不同结算场景间快速切换。

**核心功能**：
1. 账单管理：账单查询、核对、发送、催缴、标记付款
2. 分润结算：核心企业分润计算、确认/异议处理、支付指令生成
3. 收款对账：银行流水导入、自动匹配对账、异常处理

| 账单到期未付款 | 系统定时扫描（每日0点） | 自动标记"逾期"→生成催缴任务→冻结客户新增融资 |
| 点击"导出Excel" | 按钮点击 | 生成并下载当前筛选条件下的账单列表Excel |

### 4.3 分润结算交互

| 触发条件 | 交互行为 | 系统响应 |
|---------|---------|---------|
| 每月5日0点 | 系统自动触发 | 自动生成分润明细，状态"待确认"，推送核心企业端 |
| 季后首月10日0点 | 系统自动触发 | 自动生成季度质量奖金明细，状态"待确认" |
| 点击"计算分润" | 按钮点击 | 重新计算选中周期的分润数据，已确认周期不可重算 |
| 核心企业点击"确认无误" | 企业端操作回调 | 状态变为"已确认"，进入待支付队列 |
| 核心企业点击"提出异议" | 企业端操作回调 | 状态变为"有异议"，暂停支付，创建异议工单 |
| 财务核查后确认有误 | 运营端操作 | 调整金额，状态"已调整"，重新推送确认 |
| 财务核查后确认无误 | 运营端操作 | 记录说明，协商解决或强制确认 |
| 异议超期未处理（>5工作日） | 系统定时判断 | 自动视为"确认无误"，进入支付流程 |
| 点击"生成支付指令" | 按钮点击 | 生成支付指令编号，≤10万直接进入支付队列，>10万需总监审批 |
| 核心企业等级变更 | 系统自动识别 | 下季度分润自动按新系数计算，已结算不受影响 |

### 4.4 收款对账交互

| 触发条件 | 交互行为 | 系统响应 |
|---------|---------|---------|
| 点击"导入银行流水" | 按钮点击 | 打开文件选择器→上传Excel/CSV→解析并显示预览→确认导入 |
| 导入后系统自动匹配 | 系统后台处理 | 精确匹配（金额+付款方一致）→自动标记"已匹配"+更新账单状态"已付款" |
| 金额相近（±5%）+付款方一致 | 系统后台处理 | 标记"模糊匹配"，推荐关联，列表显示"待确认" |
| 付款方与账单企业不一致 | 系统后台处理 | 标记"付款方异常"，列表显示"异常" |
| 点击"确认"（模糊匹配） | 按钮点击 | 弹窗确认→标记"已匹配"→更新账单状态 |
| 点击"手动匹配" | 按钮点击 | 打开异常处理弹窗→选择匹配账单→确认 |
| 点击"标记差异" | 按钮点击 | 打开异常处理弹窗→选择差异类型→填写说明→确认 |
| 多付款确认 | 人工确认 | 标记"预付款"，差额挂账，可用于抵扣未来账单 |
| 少付款确认 | 系统自动处理 | 标记"部分收款"，剩余金额继续催收 |
| 重复付款 | 人工确认 | 标记"重复"，联系企业核实后退款或预存 |

### 4.5 分润明细页交互

| 触发条件 | 交互行为 | 系统响应 |
|---------|---------|---------|
| 点击"查看" | 按钮点击 | 打开分润明细弹窗，展示四类分润计算明细 |
| 点击"确认无误" | 按钮点击 | 二次确认弹窗→状态变为"已确认"→生成支付指令 |
| 点击"强制确认并进入支付" | 按钮点击 | 需财务主管权限→二次确认→状态变为"已确认"→生成支付指令 |
| 点击"生成支付指令" | 按钮点击 | 金额≤10万：直接进入支付队列；金额>10万：进入总监审批流程 |
