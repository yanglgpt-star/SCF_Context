# 原型：货权管理 — 出库审批（运营端）

## 一、页面概述

| 项目 | 说明 |
|------|------|
| **页面名称** | 出库审批 |
| **使用角色** | 货权监控员 / 风控专员 |
| **页面目的** | 接收银行出库授权后，通过三重自动校验和智能审批策略，完成出库审批决策 |
| **入口路径** | 运营端 → 货权管理 → 出库审批 |
| **页面状态** | 待人工审批 / 自动通过 / 自动拒绝 / 授权已过期 |

> **设计说明**：本页面为出库审批的核心操作页，顶部黑色区块为银行授权状态区，实时显示授权有效期倒计时。中部为质押率可视化对比和三重校验结果，底部为审批操作区。页面根据审批状态展示不同变体：自动通过/自动拒绝/待人工审批/授权已过期。

## 四、交互说明

### 4.1 页面加载交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 页面加载 | 自动请求银行授权状态、客户业务信息、三重校验结果 | 加载时显示骨架屏 |
| 数据加载完成 | 渲染页面各区块，倒计时开始实时递减 | — |

### 4.2 倒计时交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 倒计时 > 1小时 | 正常显示 HH:MM:SS | 黑色背景，白色文字 |
| 倒计时 ≤ 1小时 | 文字变橙色 | 提示即将过期 |
| 倒计时 ≤ 10分钟 | 文字变红色并闪烁 | 紧急提示 |
| 倒计时 = 0 | 显示"已过期"，审批按钮禁用 | 提示"授权已过期，请联系银行重新授权" |

### 4.3 审批通过交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 点击"审批通过" | 弹出二次确认对话框 | "确认通过该笔出库审批？" |
| 确认通过 | 调用 POST /api/wms/release 下发出库指令 | 按钮变为"处理中"状态 |
| 出库指令下发成功 | 页面刷新为"已通过"状态 | 显示"已通过"标签，按钮禁用 |
| 出库指令下发失败 | 显示错误提示，提供重试按钮 | 记录异常日志 |

### 4.4 审批驳回交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
| 点击"审批驳回" | 自动聚焦到驳回原因输入框 | 输入框边框高亮 |
| 输入驳回原因 < 10字 | 实时校验，显示红色提示 | "驳回原因最少10字" |
| 输入驳回原因 ≥ 10字 | 通过按钮（驳回按钮）变为可用 | — |
| 点击通过按钮（驳回） | 弹出二次确认对话框 | "确认驳回该笔出库审批？" |
| 确认驳回 | 记录驳回原因，通知企业端 | 页面刷新为"已驳回"状态 |

### 4.5 自动审批交互

| 触发条件 | 交互行为 | 说明 |
|---------|---------|------|
