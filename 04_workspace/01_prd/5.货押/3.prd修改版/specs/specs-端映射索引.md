# Specs 端映射索引

> **文档目的**：为所有 Spec 文件提供端归属的快速索引，便于技术评审和开发分工时快速定位各端的职责边界

---

## 端标记说明

| 标记 | 含义 | 说明 |
|------|------|------|
| 🔧 | **运营端** | 平台内部运营人员使用的后台管理功能 |
| 🏭 | **企业端-核心企业** | 链主企业使用的前台功能（推荐、协同、回购、分润） |
| 🏪 | **企业端-融资企业** | 经销商/资金需求方使用的前台功能（申请、查询、还款） |
| 🏦 | **银行端** | 合作银行使用的前台功能（审批、放款、授权、对账） |
| 📦 | **仓储方/WMS** | 仓储合作方系统使用的功能（入库、出库、库存、盘点、异常上报） |
| 🔄 | **跨端** | 涉及多个端的数据流、接口对接、通知联动 |
| ⚙️ | **系统** | 系统内部生成或自动处理，不特定属于某个端 |
