# Spec：贷后管理——分级催收

> **涉及端**：🔧 运营端、🏭 企业端-核心企业


> **对应PRD**：PRD_贷后管理.md — 5.1 催收跟进  
> **覆盖范围**：M0-M4五级催收策略、催收任务分配与跟踪、核心企业协同催收、催收记录与效果分析  
> **版本**：V1.0

---

## 1. Goal（目标）

**运营端催收团队**通过系统自动识别逾期、按M0-M4分级匹配催收策略、分配催收任务、协同核心企业催收、在线记录催收过程，达成：
- M1催收成功率≥90%（15天内回款或达成有效还款方案）
- 人均催收案件处理量≥12笔/天
- 协同催收成功率≥65%
- 逾期回收率≥90%

---

## 2. Scope（边界）

### 本次包含
- 每日0点自动逾期识别（扫描在途业务、标记逾期、计算逾期天数和利息、自动分级M0-M4）
- M0-M4分级催收任务自动分配（责任人匹配、任务推送、优先级排序）
- 催收记录在线工具（时间轴记录、快捷录入、移动端基础支持）
- 核心企业协同催收（自动判断条件、推送协同请求、在线跟踪响应和结果）
- 催收绩效统计（回款率、案件处理量、协同成功率）

### 本次不包含
- AI智能催收话术推荐（延后V2.0）
- 外部催收机构/律所自动委外对接（延后V2.0）
- 法律诉讼全流程管理（案件录入、进度跟踪、费用管理延后P2）
- 自动外呼/语音机器人（IVR仅支持系统触发，不包含智能对话）
- 客户情绪识别或AI辅助催收策略动态优化

### 异常状态全覆盖

| 异常场景 | 系统行为 | 状态流转 |
|----------|----------|----------|
| 还款到账 | 自动结清逾期，更新任务状态为"已结清"，释放融资额度 | 逾期→正常 |
| 客户失联（3次联系不上） | 标记"失联"，升级催收等级，触发核心企业协同 | M1→M2 |
| 承诺还款后再次违约 | 记录违约次数，升级催收等级，重新分配高级催收员 | 当前等级维持或升级 |
| 核心企业拒绝协同 | 记录原因，转入常规催收+处置评估 | 协同结束 |
| 任务超期未处理（>48小时） | 自动升级提醒给催收主管，重新分配或督办 | 待处理→督办 |
| M2逾期满30天未解决 | 自动触发货物处置评估流程 | 催收→处置 |
| M3逾期满90天未解决 | 自动标记"建议核销"，推送核销申请提醒 | 催收→核销评估 |
| 逾期利率超过LPR 4倍 | 系统拦截，按LPR 4倍封顶计算 | 计算异常→封顶 |

## 4. Constraints（约束）

### 技术约束
- 每日0点逾期识别全量扫描执行时间≤10分钟
- 催收任务推送延迟≤5分钟（逾期识别后至责任人收到待办）
- 催收记录保存响应≤1秒
- 并发催收员同时在线操作≥50人
- 催收系统可用性≥99.5%

### 安全约束
- 催收员只能查看分配给自己的催收任务（数据权限隔离）
- 客户联系方式等敏感信息脱敏展示（手机号中间4位隐藏）
- 催收操作日志留存不少于5年
- 禁止暴力催收、骚扰催收，所有催收记录完整留存接受合规审计

### 业务约束
- 逾期利率：M1日利率0.03%，M2/M3+日利率0.04%，系统强制校验上限不超过LPR 4倍
- M0（1-3天）宽限期不计逾期利息，由风险监控模块负责自动短信+IVR提醒
- M1（4-15天）由初级催收员负责，每2天1次
- M2（16-30天）由高级催收员负责，每日1次，自动推送核心企业协同
- M3（31-90天）由催收经理负责，每日跟进，并行启动货物处置
- M4（>90天）由法务部负责，持续跟进，启动诉讼+核销评估
- 协同催收触发条件：逾期≥15天 或 逾期金额≥30万（系统自动判断）

### 跨模块约束
- **与风险监控边界**：M0-M1早期提醒由风险监控负责，M2-M4催收执行由贷后负责；M1第7天仍未回款，风险监控自动升级预警并发送协同催收请求
- **与结算数据流**：催收回收金额需在每月4日前同步至结算管理模块

## 5. Acceptance Criteria（验收标准）

| 编号 | 验收标准 | 验证方式 |
|------|----------|----------|
| AC-1 | 每日0点系统自动扫描在途业务，还款到期日≤当天且未结清的业务被自动标记为"逾期"，并计算逾期天数和逾期利息 | 查看数据库/日志，验证逾期记录生成时间和字段准确性 |
| AC-2 | 打开催收任务列表页，可见统计卡片（待处理数、今日已催收、M1/M2/M3分别待处理数）和M0-M4颜色标识（绿/蓝/黄/红/紫） | 打开页面验证UI展示和颜色标识 |
| AC-3 | 调接口 `GET /api/collection/tasks?agent_id=xxx`，返回当前登录催收员的待处理任务列表，且不包含其他催收员任务 | 调接口验证数据权限隔离 |
| AC-4 | 满足协同条件（逾期≥15天或≥30万）的催收详情页显示"一键推送协同请求"按钮；点击后核心企业端收到协同通知 | 打开页面验证按钮显示逻辑；操作后验证企业端通知 |
| AC-5 | 核心企业响应协同请求后，运营端协同状态从"已推送"变为"已响应"，并显示响应内容和预计措施 | 打开页面验证状态流转和字段更新 |
| AC-6 | 调接口 `POST /api/collection/record` 录入催收记录后，催收详情页时间轴实时新增一条记录（含时间/方式/内容/反馈） | 调接口后打开页面验证时间轴更新 |
| AC-7 | 客户还款到账后，系统自动将该笔逾期标记为"已结清"，催收任务状态同步更新为"已结清"，客户新增融资额度自动释放 | 模拟还款到账，验证逾期状态和任务状态同步变更 |

## 6. Non-Goals（非目标）

以下功能是AI/技术最容易顺手做的，但本期明确排除：

1. **AI智能催收话术推荐**：不基于客户画像和历史数据自动生成最佳催收策略和话术
2. **自动外呼/语音机器人**：不开发AI语音对话能力，IVR仅播放预录通知
3. **客户情绪识别**：不通过语音/文本分析判断客户情绪状态
4. **基于机器学习的催收策略动态优化**：不根据历史催收数据自动调整分级策略和频率
5. **自动生成法律诉讼文书**：不提供起诉状、律师函等文书的自动生成能力
6. **智能预测逾期概率**：不基于大数据模型预测客户未来逾期风险（由风险监控模块负责）
7. **催收语音转文字的AI摘要生成**：移动端支持语音录入但仅做基础转文字，不做智能摘要
