# PRD精简_客户管理

## 一、背景与目标

### 1.1 为什么做

**业务痛点**：
- 缺乏核心企业推荐质量的量化评估，低质量客户占比过高（部分核心企业推荐客户不良率高达6.8%）
- 准入流程缺乏核心企业实时推荐确认，曾发生经销商伪造合作关系导致逾期损失80万元
- 客户信息分散在多个系统/Excel，准入审核平均5天
- 约50%申请因资料不完整需补充，平均沟通2-3轮

**对标差距**：
| 维度 | 本平台（现状） | 京东供应链金融 | 平安银行存货融资 |
|------|---------------|---------------|-----------------|
| 准入时效 | 平均5天 | 1-2天 | 2-3天 |
| 推荐机制 | 无系统化推荐确认 | 依托京东生态数据 | 依托银行自有征信 |
| 资料完整性校验 | 人工核对 | 系统前置校验 | 系统前置校验 |

### 1.2 做什么

建立标准化的客户准入和分层管理体系，覆盖经销商在线申请→推荐码验证→核心企业确认→资料校验→平台差异化审批→结果闭环的全流程，实现客户全生命周期管理。

### 1.3 指标目标

| 指标 | 现状 | 目标值 | 优先级 |
|------|------|--------|--------|
| 优质客户占比 | 未明确 | ≥60% | P0 |
| 客户不良率 | 未明确 | ≤2% | P0 |
| 准入时效 | 平均5天 | ≤2天 | P0 |
| 资料一次完整率 | 50% | ≥90% | P0 |
| 准入通过率 | 未明确 | 60-70% | P1 |
| 证照到期预警及时率 | 人工通知 | 100% | P1 |
| 核心企业推荐响应率 | 电话/邮件 | 100%在线确认 | P1 |
| 核心企业推荐质量评估覆盖率 | 无 | 100%每季度评估 | P2 |

### 1.4 谁来决策

- **准入标准与风控规则**：风控负责人最终确认
- **差异化准入矩阵参数（授信额度范围、质押率上限）**：待风控负责人最终确认
- **核心企业分级标准**：待运营部编制制度后确认
- **审批流程模板配置**：运营配置人员维护

## 三、关键决策记录

### 3.1 等级映射规则（跨模块一致性）

- **经销商信用评级A+级**：由核心企业评定，表示最优质经销商。在平台侧（融资、结算、风控模块）**A+级视为A级**，享受A级对应的审批通道、费率政策和监控阈值。
- **经销商信用评级A/B/C级**：与平台侧客户等级直接对应，无需映射。
- **核心企业等级S/A/B/C级**：在各模块中保持一致，影响推荐码有效期、授信额度上浮、分润质量系数等。

### 3.2 差异化准入矩阵（核心企业等级 × 经销商等级）

| 核心企业等级 / 经销商等级 | A+（视为A级） | A | B | C |
|--------------------------|---------------|-----|-----|-----|
| **S级** | 快速通道（2级审批） | 标准流程（3级审批） | 标准流程+尽调 | 加强流程（5级审批） |
| **A级** | 标准流程（3级审批） | 标准流程（3级审批） | 标准流程+尽调 | 加强流程（5级审批） |
| **B级** | 标准流程（3级审批） | 标准流程+尽调 | 加强流程（5级审批） | 加强流程（5级审批）+ 额度限制 |
| **C级** | 标准流程+尽调 | 加强流程（5级审批） | 加强流程+额度限制 | 暂停准入（待重新评估） |

### 3.3 快速通道触发条件

快速通道（2级审批）适用条件：
- 融资金额 ≤ 30万
- 客户等级为A级（含A+映射为A级）
- 质押率 ≤ 70%
- 核心企业等级 ≥ B级

### 3.4 接口规范（已确认）

- **核心企业ERP接口**：HTTPS RESTful API，OAuth 2.0+JWT，8个标准接口，风险预警实时推送，经销商数据每日同步。
- **征信系统接口**：企查查（主）+ 天眼查（备）双源策略。

## 五、业务流程简述

### 5.1 客户准入审核总流程

经销商在线提交准入申请（基本信息+推荐码+资料上传）→ 系统验证推荐码（有效性/有效期/额度）→ 向核心企业发起推荐确认 → 核心企业在线确认并提供经销商数据 → 系统自动校验（资料完整性/黑名单/证照有效期/征信）→ 匹配差异化审批流程 → 平台差异化审批 → 审批结果通知经销商并反馈核心企业纳入推荐质量评估。

### 5.2 推荐码生命周期

核心企业登录企业端 → 生成推荐码（设置有效期/数量上限）→ 经销商使用 → 系统发起推荐确认请求 → 核心企业确认/拒绝 → 推荐码状态流转（有效→已使用→已确认/已作废，或过期未使用→已过期）。

### 5.3 企业客户状态流转

准入申请中 → 资料审核中 → 尽调中/已驳回/待授信 → 正常 → 预警/冻结/已注销。
