# PRD精简：结算管理

> **文档状态**：初稿（基于PRD_结算管理.md V1.0精简）  
> **适用范围**：供应链金融平台——运营管理端（运营端）+ 企业端（核心企业/融资企业）+ 银行端  
> **业务领域**：控货质押模式下的服务费计算、账单管理、收款确认与分润结算

---

## 一、背景与目标

### 为什么做
1. **服务费计算复杂易出错**：按金额比例、按天计息、不同等级不同费率，约5%的账单存在计算错误需重新开具。
2. **账单生成效率低**：依赖手工制作Excel/Word，格式不统一，发送流程繁琐。
3. **分润计算争议多**：涉及推荐佣金、协同催收奖励、回购奖励、质量奖金多方计算，约10%的分润存在争议需重新核对。
4. **对账效率低**：收款后手工核对账单和银行流水，每日对账耗时2-4小时，易遗漏或重复。

### 做什么
建立配置化计费引擎实现服务费自动计算和账单生成，建立在线分润计算与确认机制，实现银行流水自动对账，搭建4账户资金管理体系。

### 目标指标

| 目标项 | 现状 | 目标值 | 衡量方式 |
|--------|------|--------|----------|
| 账单准确率 | 95% | 100% | 正确账单数/总账单数 |
| 服务费收缴率 | 92% | ≥98% | 实收服务费/应收服务费 |
| 分润准确率 | 90% | 100% | 正确分润笔数/总分润笔数 |
| 分润确认周期 | 7天 | ≤2天 | 从生成分润明细到双方确认的平均天数 |
| 对账时效 | 2-4小时 | ≤2小时 | 每日对账耗时 |
| 对账准确率 | 95% | 100% | 对账一致笔数/总对账笔数 |

---

## 二、范围决策

### 本次包含
1. **服务费计费规则配置**：4种计费模式（按金额比例/按天计息/固定费用/分段计费）、差异化定价（客户等级/品类/期限/金额）
2. **自动账单生成**：融资完成后自动计算服务费、生成标准PDF账单、推送财务核对
3. **分润自动计算**：推荐佣金（首笔0.1%/后续0.05%）、协同催收奖励（0.2%）、回购奖励（1.0%）、质量奖金（系数S1.5/A1.2/B1.0/C0.8）
4. **分润在线确认与争议处理**：核心企业在线查看明细、确认或提出异议、平台财务核查（3个工作日）
5. **银行流水导入与自动对账**：Excel/CSV/API导入、精确匹配+模糊匹配(±5%)、差异处理
6. **资金账户管理**：4个账户（融资监管户/运营收入户/分润支付户/风险准备金户）的余额管理与流水查询
7. **自动计税**：服务费按6%增值税自动计算

### 本次不包含
- 多币种结算（美元/港币等，延后V3.0）
- 税务自动化申报（延后V2.0）
- 电子发票集成（延后V2.0）
- 资金池统一调度和计息（延后V3.0）
- 第三方支付自动分润（本期仅生成支付指令）

## 三、关键决策记录

| 决策项 | 决策结果 | 决策依据 |
|--------|----------|----------|
| 服务费费率 | A级年化3%、B级4%、C级5% | 客户分层差异化定价 |
| 分段计费 | >100万降1%（如>100万段执行原费率-1%） | 鼓励大额融资 |
| 期限调整 | ≤30天+0.5%，>90天-0.5% | 短期风险补偿+长期优惠 |
| 推荐佣金率 | 首笔0.1%、后续0.05%、年度≥500万额外0.5% | 激励新客拓展+持续合作 |
| 协同催收奖励 | 协同催收成功金额×0.2% | 与贷后模块联动激励 |
| 回购合作奖励 | 回购货值×1.0% | 鼓励核心企业回购 |
| 质量系数 | S=1.5、A=1.2、B=1.0、C=0.8 | 核心企业分层激励 |
| 分润结算周期 | 月度（5日生成/12日截止/15日支付），季度质量奖金（10日/20日/25日） | 平衡效率与资金压力 |
| 税务处理 | 服务费按6%增值税，分润支出由核心企业开票 | 现行税法规定 |
| 资金账户体系 | 融资资金监管户+平台运营收入户+分润支付专用户+风险准备金户 | 资金隔离合规 |
| 风险准备金 | 服务费收入5%计提，最低余额为在途余额1% | 行业风控惯例 |
| 对账匹配规则 | 精确匹配（金额+付款方一致）+ 模糊匹配（±5%）+ 时间窗口≤30天 | 兼顾准确率与容错 |
| 贷后数据同步 | 每月4日前同步催收回收金额、回购完成金额、核销金额 | 支撑月度分润计算 |
| 分润支付安全 | 双人复核，大额(>10万)需财务总监审批 | 资金安全防控 |
