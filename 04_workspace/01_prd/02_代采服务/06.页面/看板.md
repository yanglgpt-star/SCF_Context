## 第三层：周期概览

### 时间维度切换 Tabs：日 / 周 / 月

| 维度 | 付款总额 (pay) | 还款总额 (repay) |
|------|---------------|-----------------|
| 日 | ¥32,800,000 | ¥21,500,000 |
| 周 | ¥198,000,000 | ¥145,000,000 |
| 月 | ¥856,000,000 | ¥623,000,000 |

**资占金额公式：**
```
资占金额 = 付款总额 - 还款总额
```
> 注：资占金额可为负数，负数时文字颜色切换为 `var(--red)`。

### 环比 & 目标值
```
环比：        静态模拟（日卡：▲8.2% / ▼2.1% / ▲12.4%）
目标值：      静态模拟（¥5,000万 / ¥3,800万 / ¥2,000万）
```

### 单位切换
```
fmt(v, unit):
  unit === 'yi'  → (v / 1e8).toFixed(2) + ' 亿'
  unit === 'wan' → (v / 1e4).toFixed(0) + ' 万'
  default        → v.toLocaleString() + ' 元'
```
默认单位：**万元（wan）**。

## 第四层：月度统计（分组柱状图）

### 全国月度数据生成

```js
// 当前实际月份（判断哪些已发生）
const currentRealMonth = new Date().getMonth() + 1  // 当前为 5

// 12 个月数据，未来月份 pay=0, repay=0
monthNum > currentRealMonth → { pay: 0, repay: 0 }

// 已发生月份公式（单位：万元）：
pay   = Math.round((600 + sin(i/12*PI*2)*200 + (i+1)*25 + random*80)) * 10000
repay = Math.round((400 + cos(i/12*PI*2)*150 + (i+1)*18 + random*60)) * 10000
```

**趋势图系列：**
| 系列 | 类型 | 颜色 | 数据源 |
|------|------|------|--------|
| 付款总额 | 柱形 | `#1890ff` | `payData = data.map(d => d.pay)` |
| 还款总额 | 柱形 | `#52c41a` | `repayData = data.map(d => d.repay)` |
| 资占金额 | 柱形 | `#00e5ff` | `netData = data.map(d => d.pay - d.repay)` |

**柱形参数：** `barWidth: '22%'`, `barGap: '10%'`, `borderRadius: [4,4,0,0]`。

### 省份月度数据（下钻）

```js
// 省份年度总额分摊到已发生的月份
monthlyBase = provinceData.basePay / 5  // 当前5月，所以除以5

// 已发生月份：
pay   = Math.round(monthlyBase * (0.7 + Math.random() * 0.6))
repay = Math.round(monthlyBase * 0.7 * (0.6 + Math.random() * 0.5))

// 未来月份：
pay = 0, repay = 0
```

## 全局功能

### 单位切换联动
```
点击单位 btn（元/万元/亿元）→ currentUnit = btn.dataset.unit
→ 重新渲染：renderTrend() + renderProvince() + renderAgents() + updatePeriodSummary()
```

### 刷新数据
```
点击刷新 → refreshAllData()
  1. provinceData = genProvinceData()        // 重新生成省份数据
  2. agentData = genAgentData()              // 重新生成经办人数据
  3. nationalMonthly = genNationalMonthly()  // 重新生成全国月度数据
  4. 重置下钻状态
  5. 重绘所有图表 + 更新时间戳
```

### 自适应 Resize
```
window.addEventListener('resize', () => {
  trendChart.resize()
  brandChart.resize()
  categoryChart.resize()
  agingChart.resize()
})
```

### 响应式断点
| 屏幕宽度 | KPI 布局 | 分布图布局 |
|----------|----------|-----------|
| >1200px | 4列 | 三列并排 |
| 768~1200px | 2列 | 三列并排 |
| <768px | 1列 | 单列堆叠 |

### ECharts 图表配置
```
theme: 暗色主题
  --bg-card: #111522
  --border: #1e2440
  tooltip: trigger:'axis' 或 'item'
  splitLine: { color: '#1e2440', type: 'dashed' }

```
