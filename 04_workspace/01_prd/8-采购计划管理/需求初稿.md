# 采购计划管理 - 需求初稿

## 1. 主要功能

1. **采购计划管理**：创建管理计划，填写计划相关信息
2. **采购计划对应的采购订单管理**：管理获取计划对应的采购订单数据
3. **订单判断日志**：管理订单判断日志

## 2. 采购计划管理详细功能

### 主要字段

| 类别 | 字段 |
| --- | --- |
| 基本信息 | 采购计划编码、品牌、品类 |
| 金额 | 采购总金额、已完成总金额、完成率 |
| 采购企业 | 采购企业 1、采购企业 2、采购企业 3 |
| 差价/账期 | 差价 1、差价 2、账期 1、账期 2 |
| 日期 | 预计开始日期、预计结束日期、实际执行日期、实际结束日期 |
| 状态 | 执行状态、计划状态 |
| 订单要求 | 单价、数量、总价等 |
| 供应商资质 | 合作期限、开票率、贸易金额等 |

### 主要操作

- 创建计划
- 删除计划
- 状态变更
- 执行计划
- 关闭计划

### 计划唯一性约束

**唯一键**：`品牌 + 品类 + 采购企业 1 + 采购企业 2 + 采购企业 3 + 预计开始日期 + 预计结束日期`

- 仅对 **计划状态 ≠ 关闭** 的有效计划进行校验（已关闭/已删除的计划不参与，允许重建）
- 采购总金额不参与唯一性校验（允许直接编辑调整金额）
- 差价、账期不参与唯一性校验（属于计划参数，非业务标识）

## 3. 采购订单判断

### 推送规则

- 将执行的采购计划推送给无仓，推送内容：**品牌、预计开始日期、预计结束日期**
- 定时任务推送给无仓；或者立即推送给无仓

### 订单判断规则

1. **判断供应商资质**：开票率、合作期限、贸易金额
2. **判断订单**：品牌、品类、单价、数量、总价
3. **已采购总价判断**：是否超过目标金额，超过目标金额则采购计划关闭

## 4. 订单管理（采购企业 1 的采购订单）（无仓推送）

### 订单管理字段

| 字段 |
| --- |
| 计划编码、品牌、品类、商品名称、商品 SKU、SKU 编码 |
| 订单号、订单单价、订单数量、供应商、采购商 |
| 下单时间、下单人、付款方式 |

### 查询条件

- 计划编码
- 品牌
- 品类
- SKU 编码
- 订单号
- 下单时间

## 5. 订单判断日志
