## 0. 评审速览（先读这一页）

### 0.1 一句话说清这个系统

> **业务库存中心管「实物」，财务库存中心管「价值」。** 两者通过《数据交接契约》衔接：业务侧推单据流水与主数据，财务侧算成本、出凭证、出报表，并把「库存价值月报」**反向回传**给业务侧。
> 本文回答**做什么、做到什么程度算合格**；「怎么做」在《详细设计文档》v0.4 里，每个需求都标了对应章节。

| 项 | 数量 |

| 货主层级 | **两级**（一级 = 法人 / 二级 = 内部管理维度） |
| 单据类型 | **11 类** |

### 0.3 评审要认的六条口径（每条都可当场验证）

| # | 口径 | 一句话验证方式 |
|---|---|---|
| 1 | **存货总额只累加一级层 `is_internal = 1`** | 报表上二级层的金额能不能加进总额？**不能** |
| 2 | **二级层「一个数量、两个金额」** | `alloc_amount`（× 一级均价）**能**加总回一级层，硬校验；`internal_amount`（× 内部结算价）**不能**加总，不做等式校验 |
| 3 | **一级作价是交易数据、二级作价是政策数据** | 系统里**配不到**一级价（只取价 + 校验），只配二级价目表 |
| 4 | **二级重分配不出凭证** | `t_voucher_header` 里查不到 `OWNER_REASSIGN` 来源的单据 |
| 5 | **月结即锁账，锁账后只有两条路** | 结错了 → 反结账（须审批留痕）；漏一笔 → 当期补录单（必审，按**当期**口径量价） |
| 6 | **对外数字必须带口径标注** | 任取一个数字，能不能回答「这是存货口径还是管理口径、哪个货主层」 |

## 1. 业务背景与目标

### 1.1 要解决的问题

| # | 问题 | 现状 |
|---|---|---|
| 1 | ERP（金蝶）现有存货核算无法满足精细化成本管理 | 成本口径粗、不可追溯、无法按法人/货主细算 |
| 2 | 业务管实物、财务管价值，二者职责未分离 | 两边各算一套成本，同一个「库存金额」两个数 |
| 3 | 缺少独立、灵活、可追溯的成本计算与凭证生成能力 | 依赖人工 Excel，月结靠人堆 |

### 1.2 目标与成功标准

| 目标 | 成功标准（可验收） |
|---|---|
| 成本算得准 | 98% 以上的余额可反推到原始单据与当时取价（`price_source` / `price_base` / `markup_rate` / `price_value`） |
| 账实对得上 | 数量对账**按日**通过；金额对账**按月**与金蝶总账一致（法人层 + 合并层两段） |
| 口径说得清 | 任一对外数字都带口径标注；两个金额口径**并列回传**，业务侧不会挑错 |
| 期间守得住 | 月结即锁账；锁账后改动**只有**反结账（须审批）与当期补录单（必审）两条路，且留痕 |
| 8 周能上线 | 11 类单据全覆盖的 UAT 通过；《库存价值月报》随月结分发 |

### 1.3 业务画像（决定计价与跌价方法）

| 维度 | 情况 | 对设计的影响 |
|---|---|---|
| 业务模式 | 纯贸易 / 零售 / 电商（**无自有生产环节**） | 不引入标准成本；仓库类型不设「原料库 / 在制品库」 |
| 主营品类 | 3C 数码（高值整机走 SN）、出行商品 | 高值整机**一期即可用个别计价**（按 SN 单台结转）；3C 跌价需叠加**上市周期**档 |
| 3C 贬值规律 | 由**新品发布**驱动，不由存放时长驱动 | 库龄法 + 上市周期法**双轨取孰高** |

## 2. 范围

### 2.1 一期做（In Scope）

| 维度 | 范围 |
|---|---|
| 库存维度 | **四轴** `(物料, 仓库, 批次, 一级货主)`；核算单元 `(物料, 仓库, 一级货主)`，批次**不进**均价池 |
| 货主分层 | 一级货主 = 法人主体；二级货主 = 内部管理维度，走独立分摊账，**不进余额表主键、不进存货总额** |
| 核算主体 | **多法人**（一期已确认存在集团内跨法人转移） |
| 计价方法 | 移动加权平均 `MA`（全局默认）/ 个别计价 `SI` / 先入先出法 `FIFO`，按**核算单元**粒度配置 |
| 作价来源 | 一级 `transfer_price`（交易数据，不配置）；二级 `internal_price`（政策数据，带生效期价目表） |
| 跌价准备 | 库龄法 + 3C 上市周期法双轨取孰高；**计提范围仅 `is_internal = 1`** |
| 会计期间 | 引入 `t_period` + `is_closed`；日结只校验、**月结即锁账**；反结账须审批留痕 |
| 凭证处理 | 生成凭证清单 + Excel 导出（**一期不直推金蝶**）；含货权转移与集团内抵消，**不含二级内部结算价差** |
| 数据接入 | **API 对接为主**（一期主通道，接口协议待定）；**Excel/CSV 导入入口保留**（过渡与手工补录）。两条通道走**同一套字段、校验、幂等、错误回执**，由**适配层** `InventoryDataAdapter` 隔离——字段定义见《通用数据接口字段定义》v1.0 |
| 审批流 | **不建审批流引擎**，保留「待审 / 已审核」状态位 + 单点审核动作 + 留痕；预留 `ApprovalGateway` |

### 2.2 一期明确不做（Out of Scope）

| 不做 | 理由 / 替代 |
|---|---|
| 产权交易中心落地 | 由本中心出**临时货权变更单**承载；二期**搬迁**（已按可剥离形态设计，不是重写） |
| 多层级货主（三级及以上） | 一期只做两级；表结构用自关联树表达，不写死两级 |
| 二级层的会计凭证 | 二级不是法人、不是会计主体（R2） |
| 标准成本 `STD` | 无生产环节，无料工费差异管理对象 |
| 直推金蝶总账 | 一期导出 Excel 由财务手工过账 |
| 货押融资相关库存状态 | 后续再议，不纳入一期 |
| 完整会计期间（含期间损益结转） | 二期 |
| **接口协议与鉴权的最终定型** | 一期**不等待**——字段层先冻结（《通用数据接口字段定义》`§9` 留映射位），协议定型后**只补映射、不改字段** |

### 2.3 二期规划（一期要为它留好口子）

- 产权交易中心落地，货权变更单与其价目表 `t_internal_price` **搬迁**过去
- 接入真实审批流引擎（**换 `ApprovalGateway` 实现，不动调用方**）
- 直推金蝶总账；移动加权平均按月结转版本

## 4. 核心业务规则（评审要认的口径）

> 本章是**口径的唯一权威表述**。设计与开发照此实现，报表与回传照此标注。

### 4.1 四轴与核算单元

| 概念 | 定义 | 关键约束 |
|---|---|---|
| **库存维度（四轴）** | `(物料, 仓库, 批次, 一级货主)` | 余额表主键 |
| **存货核算单元** | `(物料, 仓库, 一级货主)` | **均价池的所有者**——均价属于核算单元，不属于批次行 |
| **批次的位置** | 只做**拆分与库龄 / 跌价基数** | 批次行 `unit_price` **必须等于均价行（`batch_no IS NULL` 那一行）的 `unit_price`**；均价行才是均价的持有者 |

> **为什么批次不建均价池**：若按批次建池，同一核算单元内会有多个互相独立的均价，出库时取哪个池的价**不可判定**。

### 4.2 货主分层五条硬约束（R1–R5）

| # | 规则 |
|---|---|
| **R1** | 一级货权转移**必作价、必出凭证、必产生会计损益** |
| **R2** | 二级重分配**必按内部结算价作价**，差额进二级内部损益（**管理口径**）；**不出会计凭证、不确认会计损益** |
| **R3** | **存货**均价池**只在一级货主层**建立；二级另维护内部结算价 |
| **R4** | 存货总额 = Σ 一级层中 `is_internal = 1` 的金额（**二级层绝不相加**） |
| **R5** | **二级内部结算价不影响会计**——一级层成本、存货总额、凭证、跌价基数均与其无关 |

### 4.3 二级层「一个数量、两个金额」

| 字段 | 算法 | 能否加总 | 用途 |
|---|---|---|---|
| `alloc_amount` | 数量 × **一级均价** | **能** —— `Σ alloc_amount = 一级层金额`，**硬校验**，不平**整单回滚** | 二级数量与金额的成本还原 |
| `internal_amount` | 按 `internal_price` 逐笔累计 | **不能** —— 差额 = 内部未实现毛利，**不做等式校验** | 二级内部考核、内部结算损益 |

### 4.4 两级作价：两个来源，两条铁律

| | 一级 `OWNER_TRANSFER` | 二级 `OWNER_REASSIGN` |
|---|---|---|
| 作价来源 | `transfer_price` —— **交易数据** | `internal_price` —— **政策数据** |
| 谁来定 | 对外来自销售单 / 合同，集团内逐笔录入；**财务只取价 + 校验，不配置** | 系统内维护**带生效期的价目表** `t_internal_price` |
| 定价方式 | — | `FIXED` 固定价 / `MARKUP` 成本加成率（**逐行选**） |
| 是否改一级余额 | **是**（转出减、转入增） | **否**（只写分摊账） |
| 是否出凭证 | **是**（视同销售 + 成本结转 + 集团内抵消） | **否** |
| 是否影响存货总额 | 否（一减一增；集团内需抵消） | **否** |

**取价三条铁律（两级通用）**：**按业务日期取价** → **取到即快照** → **调价不追溯**。

**一个价、三个数**（`MARKUP` 时）：`price_base`（**当时该一级货主层均价**，注意层级别取错）+ `markup_rate` + `price_value`。三者都要落库——只存 `price_value` 日后无法回答「这个价怎么来的」。

> **一条容易踩的边界**：产权交易中心「**不参与对外审计、开票**」**≠「不参与会计」**。集团内跨法人转移是**关联交易**——不开票，但仍必须出凭证、确认损益、合并抵消。分工一句话：**交易中心决定「交易是否成立」，库存中心决定「会计怎么记」**。

### 4.5 口径标注原则

> **任何对外的数字都要能回答「这是存货口径还是管理口径、是哪个货主层」。**
> **若不区分口径，业务侧必然挑一个当「库存金额」——红线以新形式复发，而且这次是「契约里写了、实现里没区分」。**

| 口径 | 含义 | 使用限制 |
|---|---|---|
| **存货口径** | 一级货主层 · `is_internal = 1` | 对外唯一权威值 |
| **管理口径 · 非会计** | 二级内部结算价累计（`internal_amount` / `internal_pl`） | **必须与存货口径成对出现，禁止单独使用** |
| 物理口径 | 物理层（仓库, 批次） | 与数量对账基准一致 |
| 明细口径 | (物料, 仓库, 批次, 一级货主) | 库龄等 |

### 9.1 上线标准（Checklist）

- [ ] 内部 UAT 通过（覆盖 20+ 物料、**11 类单据全部覆盖**）
- [ ] 财务部确认抽样对账通过（**数量对账按日、金额对账按金蝶总账**）
- [ ] 凭证生成符合会计政策（**借贷平衡校验通过**、**按法人分账**）

- [ ] **期间锁账与反结账流程演练通过**（含审批留痕、`snapshot_version` 重出）
- [ ] 用户手册 + 运维手册完成
- [ ] 应急方案就绪（含接口延迟、数据缺失、回退方案）

### 9.2 UAT 用例蓝本（设计文档 §3.7 的 7 组算例）

> 这 7 组算例**可直接转成 UAT 用例**，口径约定：单价 6 位、金额 2 位、数量 4 位、采购金额默认不含税。

| 用例 | 覆盖 | 关键期望值 |
|---|---|---|
| **算例 1** 移动平均全链路 | FR-25 FR-26 FR-28 FR-42 | 期末 60 件 / 470.00 / 单价 7.833333；数量与金额守恒勾稽通过 |
| **算例 2** 舍入与尾差 | FR-28 FR-49 | 累计舍入差异 ≈ −0.01，月末结转后库存金额回到理论值，舍入账户清零 |
| **算例 3** 改单 + 作废红冲 | FR-21 FR-22 FR-45 | 最终 150 件 / 1,852.94；改单后 `version 1→2`；作废行 `red_flag = 1` |
| **算例 4** 库龄法跌价 | FR-46 FR-47 FR-49 | 应有 25.00 − 上期 10.00 = **本期补提 15.00** |
| **算例 5** 3C 双轨取孰高 | FR-48 | 场景 A：max(0, 20,000) = **20,000.00**；场景 B：max(6,000, 5,000) = **6,000.00** |
| **算例 6** 调拨跨仓 | FR-18 FR-19 FR-26 | 场景二：调入仓合并后 50 件 / 510.00 / 单价 **10.200000** |
| **算例 7** 一级转移 + 二级重分配 | FR-35 – FR-40 | A 转出后均价仍 **10.000000**；B 转入后 **12.000000**；`Σ alloc_amount = 480.00` 硬校验通过；抵消后合并存货 **400.00** |

### 9.3 算例 7 的 6 个校验点（货权变更单 UAT 基线）

| # | 校验 | 期望 |
|---|---|---|
| 1 | A 转出后均价 | 保持 `10.000000`（**出库不改单价**） |
| 2 | B 转入后均价 | `12.000000`（按 `transfer_price` 重建，**不是** A 的 10.00） |
| 3 | `Σ alloc_amount` vs 一级层金额 | **必须相等**（480.00），否则整单回滚 |
| 4 | `Σ internal_amount` | **允许不等**（520.00），差额 40.00 进二级内部损益 |
| 5 | 二级重分配是否生成凭证 | **不生成** |
| 6 | 一级转移是否影响存货总额 | 跨法人且集团内需**抵消 80.00** |
