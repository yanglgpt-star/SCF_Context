01

货主分层

两个层级 · 一套口径

两级货主：谁是法人，谁在内部

一级货主是法人主体，对货物享有法律与经济所有权，决定这批货是否计入我方存货； 二级货主是公司内部的持有主体——部门、事业部、代采项目、客户归属——纯管理维度。 一级 1 对 N 二级，用一张自关联树表达，不硬编码两级。

读法 一级货主是法人，所以它天然分「我方 / 集团内 / 外部」三类；is_internal 一个字段就能决定是否计入存货，不必逐类勾选会计政策。

外部货主不必另建台账

一级货主既然是法人，外部法人的货就直接进同一张余额表、以 is_internal = 0 标记， 存货汇总时过滤即可——物理数量与权属数量留在同一处，对账反而更简单。 《待决策清单 D-06 存货权属边界》里那些逐条勾选的场景，本质都在问同一件事：这批货的一级货主是谁。

库存的第四个维度轴

原来的库存维度是 (物料, 仓库, 批次) 三轴；加进货主后成为四轴。 但核算单元只到一级货主——因为二级不进存货总额，它不能有自己的均价池。

物料 物理
仓库 物理
批次 / SN 物理 · 不进均价池
一级货主 权属 · 法人主体
二级货主 · 管理维度
存货核算单元 = (物料, 仓库, 一级货主) — 均价池与成本层在这里建立。 批次只服务库龄与跌价，在移动加权平均下不参与计价。

最容易致命的一条：两级不能相加

二级货主是同一批货在法人内部的拆分，不是另一批货。 所以 存货总额 = Σ 一级货主层中 is_internal = 1 的金额，二级层只作管理视角。 两级相加等于把同一批货算两遍。

四类货主变化

用两个问题就能把所有库存事件定位：货有没有动、一级货权有没有变。 右下角那一格——货没动、权属变了——正是这套模型存在的理由。

由此得到一条设计上的硬规则：货主的变化不应写进采购／销售的单据逻辑，应抽成独立的「货权事件」。 否则「先采购入库（货权在垫资方）→ 再货权转移给客户 → 最后物理发货」这条链路无法表达—— 它会出现「货权已经不在我方、但货还物理在库里」的状态。

由三项决策自动推出的五条规则

一级是法人、二级是管理维度、转移是作价，再加上二级之间内部交易也作价这条公司特性—— 合起来决定了下面五条，不需要再单独拍板。

R1

一级货权转移必作价、必出凭证、必产生会计损益。一级是法人，跨法人转移即真实交易。

R2

二级重分配必按内部结算价作价，差额进二级内部损益（管理口径）；但不出会计凭证、不确认会计损益。二级非会计主体，内部作价动不了法人会计。

R3

存货均价池只在一级货主层建立。二级另维护内部结算价（管理口径），不并入存货成本。

R4

存货总额 = Σ 一级层中 is_internal = 1 的金额。两条已定决策的直接推论。

R5

二级内部结算价不影响会计。一级层成本、存货总额、凭证、跌价基数均与它无关——它是一条只走管理口径的旁路。

二级层：一个数量，两个金额

二级既然同时有"会计分摊"和"内部结算"两件事，就必须挂两个金额。混用这两个数，是对账错误的唯一来源。

金额计算能否加总回一级层
alloc_amount 会计分摊额 数量 × 一级均价 能　Σ alloc_amount = 一级层金额　硬校验
internal_amount 内部结算额 按 internal_price 累计 不能　差额 = 内部未实现毛利　不做等式校验

作价来源与系统边界

作价这张表要先问一句：这个价是"谈出来的"还是"定出来的"。 谈出来的是交易数据，存货系统不该配；定出来的是政策数据，必须配成带生效期的价目表。

价别性质一期来源权威源二期去向
biz_price 业务价 交易数据 采购单 / 销售单带入 业务系统 不变
transfer_price 一级转移作价 交易数据 对外：销售单 / 合同带入
集团内：货权变更单逐笔录入		 业务系统 / 库存中心（临时） 产权交易中心
internal_price 二级内部结算价 政策数据 带生效期的价目表，财务维护、系统取价；固定价与成本加成率两种方式并存（逐行选） 财务（一期配在库存中心） 产权交易中心
financing_fee 资金占用费 政策数据 费率配置 × 占用天数 财务 不变

为什么一级不配、二级必须配 对外的作价就是销售价，来自谈判与合同——财务再定一次是越权，而且配置一改，历史单据"记了多少收入"就失去依据； 集团内的是关联交易价，逐笔谈定。财务中心的职责是取价 + 校验，不是定价。 二级则相反：它是政策价，财务统一制定、部门之间不逐笔谈，正是价目表的典型场景。 取价三条铁律：按业务日期取（不是"当前配置"）、取到即快照进单据行（重算不回查）、调价不追溯。 两种定价方式（FIXED / MARKUP）以行的属性并存，唯一约束落在 (具体度 + 生效区间) 上、不带上定价方式； 加成率算完存一个价、三个数（基数 + 率 + 结果），只存结果事后没法复现。

数据权威源另一方怎么用

规划产权交易中心时最容易踩的一条：「不参与对外审计、开票」≠「不参与会计」。 集团内跨法人转移是关联交易——不开票，但按 R1 仍必须出凭证、确认损益、合并抵消。 所以分工要写死一句话：交易中心决定"交易是否成立"，库存中心决定"会计怎么记"。否则二期两边互相等对方。

一期临时载体 产权交易中心一期不落地、先规划，一期由财务库存中心出货权变更单承载（OWNER_TRANSFER 一级产权转移 / OWNER_REASSIGN 二级重分配）。 单据自带价格、对手方与价格来源，并用 is_accounting_event 显式分列一级（出凭证）与二级（不出凭证），不直接改余额、只产生事件—— 按"可剥离"形态设计，二期是搬迁而不是重写。 撤单同理：已核算的一律不可撤，只能反向单 + 红字凭证。

审批流的边界（O-19） 几处都写了"必审"——货权变更单要审、跨期补录单 PERIOD_ADJUST 必审、反结账须批。但一期不建审批流引擎， 只保留单据状态机里的「待审 / 已审核」状态位和一个审核动作（一个人看一眼、点确认，记 approved_by / approved_at）。 所谓"必审"= 这一步动作不能跳过，不是"必须跑一条可配置的审批流"。 预留方式与数据接入适配层同一套路：定义 ApprovalGateway（submit / approve / reject / query），一期给单点直通实现， 二期接上真审批流时换实现、不动调用方——闸先划在接口上，闸门二期再装。 同一条闸也用在反结账上，所以反结账与补录单是两个单据类型、两种留痕，不能互相代替：反结账是"上次结错了"，补录是"漏了一笔"。

唯一的对外依赖（O-07）：业务侧是否也建货主维度 一级货主是库存的第四根轴，财务侧已按此建表。但它能不能进数据交接契约的快照维度，取决于 业务库存中心是否也建货主维度——这是契约变更，不由我方单方决定（契约 v1.2 §10.1 已正式提出）。 若不建，双方一期按物理层 (物料, 仓库, 批次) 对账，货主层对账推二期补。 这是全部决策项里唯一一项我方给不出默认值的外部依赖，须与业务团队在 W1 接口评审会上确认。

三处口径分叉

引入货主后会出现平时想不到的分叉，对账报告必须把两个口径分列：

状态物理在库权属（一级货主）典型场景
货在我方库、权属已不属我方在库外部法人代采已转货权、客户未提货；受托代销
权属属我方、货不在我方库在途我方法人已确认采购、货在运输中
货主换了、仓库没换在库集团内另一法人集团内跨法人转移，同仓不变

因此术语必须分开命名：在库数量是物理在库的实物数量（仓库口径）， 权属数量是归属某法人的数量（货主口径）。 数量对账用前者，存货金额用后者。

采购入库与销售出库：货主的诞生与消亡

移动加权平均

设定　甲公司（法人主体，is_internal = 1），二级货主为「采购事业部」。 物料 M0001 @ WH01，移动加权平均，期初 0。

日期单据事件一级货主数量单价金额
3/01PO-0001采购入库甲公司+10010.001,000.00
3/10SO-0001销售出库甲公司 → 客户−4010.00400.00
结存——甲公司6010.000000600.00
计算过程
3/01 入库（F1）
  new_qty    = 0 + 100             = 100
  new_amount = 0 + 1,000.00        = 1,000.00
  new_price  = round(1,000.00/100, 6) = 10.000000

3/10 出库（F2）
  out_amount = round(40 × 10.000000, 2) = 400.00
  new_qty    = 100 − 40            = 60
  new_amount = 1,000.00 − 400.00   = 600.00
  new_price  = 10.000000  ← 出库不改变单价
货主的变化
采购入库：一级货主 供应商 → 甲公司；销售出库：甲公司 → 客户。二级始终为采购事业部。
库存的变化 · 数量
0 → 100 → 60
库存的变化 · 金额
0 → 1,000.00 → 600.00；存货总额取一级层，不是 1,200.00
价格的变化
均价 10.000000 在采购入库时建立；出库按均价结转、不改变均价
批次与批次价格
批次档案不变（物理属性）；批次价格 = 该批次 × 甲公司层均价
凭证与损益
采购入库建立成本层；销售出库结转成本 400.00

结论

  • 采购入库是唯一往成本池注钱的动作，销售出库是唯一往外抽钱的动作——所有计价方法的起点与终点都在这里。
  • 二级货主随一级货主一同记录，但不参与均价计算：均价池只有一级一层。

货主重分配：二级变更，按内部结算价作价

承案例 1 · 公司特性

设定　3/12 将 20 件从「采购事业部」划转给「电商事业部」——同一法人内部的调整。 公司特性：二级之间的内部交易也作价，本例内部结算价 internal_price = 11.00。

项目变化前变化后是否变化
一级货主（甲公司）层60 / 600.00 / 10.00000060 / 600.00 / 10.000000三项全不变
二级 · 采购事业部　会计分摊额60 / 600.0040 / 400.00变
二级 · 电商事业部　会计分摊额0 / 0.0020 / 200.00变
二级 · 电商事业部　内部结算额0 / 0.0020 / 220.00变（按内部结算价）
物理在库数量6060不变
会计凭证 / 会计损益——无 / 无
二级内部损益—+20.00管理口径
计算与校验
会计维度（不变）
  一级层 60 / 600.00，均价 10.000000          ← 三项全不变
  分摊额　采购部 40 × 10.000000 = 400.00
  　　　　电商部 20 × 10.000000 = 200.00
  　　　　Σ = 600.00                          ✓ 能加总回一级层

管理维度（作价，公司特性）
  转出方 采购事业部
    内部收入 = 20 × 11.00 = 220.00
    内部成本 = 20 × 10.00 = 200.00
    内部损益 = +20.00                     ← 内部毛利
  转入方 电商事业部
    内部结算成本基础 = 20 × 11.00 = 220.00

校验：一硬一软
  硬：Σ 分摊额 400.00 + 200.00 = 一级层 600.00        ✓
  软：Σ 结算额 400.00 + 220.00 = 620.00 ≠ 600.00
      差额 20.00 = 内部未实现毛利                    ← 正常，不校验
货主的变化
一级货主 不变（仍是甲公司）；二级货主 采购事业部 → 电商事业部 20 件
库存的变化 · 数量
60 → 60，物理未动
库存的变化 · 金额
一级层 600.00 不变
价格的变化
会计无变化（仍按一级均价 10.000000 分摊）；管理口径新增 内部结算价 11.00
批次与批次价格
不变
凭证与损益
会计无凭证、无损益；二级内部损益 +20.00（管理口径，R2）

结论

  • 会计维度与管理维度分开走：分摊额按一级均价，结算额按内部结算价。两个数字不同，且都不错（R3 · R5）。
  • 600.00 是存货；40 + 20 是同一批货的管理拆分，不得与存货相加。相加得 1,200.00 就是重复计价。
  • 内部毛利不创造利润：这 20 件若由电商部按 15.00 卖出，采购部 20.00 + 电商部 80.00 = 100.00，与不分段时的总毛利完全一致。

货权转移（作价）：集团内跨法人，货不移动

移动加权平均

设定　甲、丙均为集团内法人（is_internal = 1），货权在集团内转移， 货物物理上不移动（同仓）。物料 M0002，5 台，作价 5,200（含资金占用费 200）。

步骤日期事件一级货主物理数量甲层丙层
14/01采购入库 5 台 @1,000甲公司+55 / 5,000.00—
24/15货权转移，作价 5,200甲 → 丙00 / 0.005 / 5,200.00
34/20丙对外出库 5 台丙公司−5—0 / 0.00
甲公司凭证 · 步骤 2
转出成本 = 5 × 1,000.000000 = 5,000.00   （甲按本层成本结转）
转移收入 = 5 × 1,040.000000 = 5,200.00   （作价）
转移损益 = 5,200.00 − 5,000.00 = 200.00

借：应收账款 - 丙公司              5,200.00
    贷：主营业务收入                  5,000.00
    贷：其他业务收入 - 资金占用费       200.00
借：主营业务成本                   5,000.00
    贷：库存商品 - M0002（WH01）      5,000.00

合并层面：丙层 5,200.00 含集团内部加价 200.00 → 内部未实现损益，需抵消
货主的变化
一级货主 甲公司 → 丙公司；二级不变。物理数量变化为 0——货没动，权属与价值都换了人。
库存的变化 · 数量
物理 5 台未动；甲层结清 0，丙层建立 5
库存的变化 · 金额
甲层 5,000.00 → 0；丙层 0 → 5,200.00；集团内总额不变
价格的变化
甲按本层成本 1,000.000000 转出；丙层按作价建层 1,040.000000
批次与批次价格
批次档案不变；物理库龄不重置；只有「持有天数」从转移日起算
凭证与损益
转移损益 200.00；出凭证；200 元资金占用费走其他业务收入，不进存货成本

结论

  • 作价会拉高丙层的均价（1,040 而非 1,000）——若丙后续继续出库，成本基础已不同。这一点必须在文档里显式写出，否则会被当成「转移不影响成本」而漏测。
  • 资金占用费是融资服务收入，计入存货会虚增资产，是会计上的实质性错误。
  • 集团内转移照常确认损益，但合并报表时需抵消内部未实现损益。

对外货权转移，货留我方仓：物理与权属分叉

监管仓场景

设定　甲公司采购后，货权转移给外部客户丁公司（is_internal = 0）， 但货物仍存放在甲公司仓库。物料 M0003，3 台，作价 6,300。

步骤日期事件一级货主物理在库权属数量甲层丁层
15/01采购入库 3 台 @2,000甲公司333 / 6,000.00—
25/05货权转移给丁，货不提走甲 → 丁300 / 0.003 / 6,300.00
35/20丁提货丁公司00—0 / 0.00
甲公司凭证 · 步骤 2
借：应收账款 - 丁公司              6,300.00
    贷：主营业务收入                  6,000.00
    贷：其他业务收入 - 资金占用费       300.00
借：主营业务成本                   6,000.00
    贷：库存商品 - M0003（WH01）      6,000.00

步骤 3 丁提货触发物理出库，但甲公司不再有任何成本结转
—— 成本已在 5/05 结转完毕
货主的变化
一级货主 甲公司 → 丁公司（外部），is_internal = 0
库存的变化 · 数量
分叉：物理在库 3／权属数量 0
库存的变化 · 金额
甲公司存货 0.00（已按作价结转完毕）
价格的变化
作价 2,100.000000/台建丁层；甲按本层成本 2,000 结转
批次与批次价格
批次仍在甲公司库内，物理库龄继续走
凭证与损益
收入 6,300（其中资金占用费 300）；成本 6,000；服务收入 300.00

结论

  • 5/05–5/20 之间，业务系统看是「有 3 台货」，财务看是「0 存货」。两个数字都对，只是口径不同——所以两个词必须分开命名。
  • 数量对账用物理口径（业务系统也按物理管），存货金额用权属口径。若混用，这 3 天必然爆出假差异。
  • 丁层虽在余额表中，但以 is_internal = 0 标记、不进存货总额——这也是外部货主不必另建台账表的原因。

同一笔货权转移，三种计价方法的结果差异

MA / SI / FIFO

设定　甲公司物料 M0004 @ WH01，期初 0。 4/01 入库 10 台 @1,000；4/10 入库 10 台 @1,200；4/20 作价 1,300/台转移 5 台给丙。

价格为上行期，两种后进先出成本的结转方式（个别计价指定低价件、先进先出取最早层）结转到低成本的件， 毛利因而高于移动加权平均——同一笔业务，损益差 500.00。

货主的变化
同一笔转移，一级货主 甲 → 丙；三方法一致
库存的变化 · 数量
物理 不变（货权转移不改变物理层）

批次与批次价格

凭证与损益
转移损益 1,000 / 1,500 / 1,500

结论

  • 丙层的成本基础是作价 1,300，与甲按哪种方法结转无关——作价与结转方法是两条独立的线。
  • 若丙是集团内法人，甲确认的损益属内部未实现损益，合并时需抵消。
  • FIFO 下还需拍板一个口径：转移进来的层，排序日期取物理入库日还是转移日？建议取物理入库日，与库龄口径一致，表述为「实物先进先出」（O-11）。

设定　甲公司（一级，is_internal = 1）名下 M0001 @ WH01， 二级分为采购事业部、电商事业部；另有丁公司（外部）代管货 M0005 3 台。

结论

  • 货权转移不进数量守恒公式——必须在校验清单里写清，否则会被误加进「Σ出库」。
  • 物理口径与权属口径要在对账报告里分列（案例 4 的分叉场景下二者不等）。
  • 月度校验清单必须包含层间汇总（一级 = Σ二级）——这是货主分层引入后新增的一条，漏掉就发现不了二级分摊错误。
  • 汇总二级金额时只汇总会计分摊额。若误用内部结算额汇总，会得到「二级 > 一级」的假差异——那不是错误，是内部未实现毛利。这条要在校验清单里显式标注为「不做校验」。
