# 数据库索引创建指南

## 为什么需要索引？

微信云数据库的默认索引（仅 `_id`）不足以支持按类别、餐次等字段组合查询。缺少索引时，控制台会显示索引建议告警，查询性能也会受影响。

## 需要创建的索引

打开微信开发者工具 → 云开发 → 数据库 → `foods` 集合 → 索引管理 → 添加索引：

### foods 集合（3个复合索引）

| 索引字段 | 顺序 | 说明 |
| :--- | :--- | :--- |
| `isMeat` ↑ + `meal_type` ↑ | 升序+升序 | 随机点菜按荤素+餐次筛选 |
| `category` ↑ + `meal_type` ↑ | 升序+升序 | 菜谱库按分类+餐次筛选 |
| `isMeat` ↑ + `category` ↑ + `meal_type` ↑ | 升序+升序+升序 | 组合筛选 |

### meal_logs 集合（1个索引）

| 索引字段 | 顺序 | 说明 |
| :--- | :--- | :--- |
| `date` ↓ | 降序 | 按日期查询最近记录 |

## 创建步骤（图文说明）

1. 在微信开发者工具中，点击左上角"云开发"图标
2. 在弹出窗口选择"数据库" tab
3. 点击左侧集合列表中的 `foods`
4. 点击"索引管理" tab
5. 点击"添加索引"
6. 按上表填入字段名和排序方式
7. 点击"确定"创建

重复以上步骤创建所有索引。
