## 标注参考标准

| 字段 | 可选值 | 说明 |
| :--- | :--- | :--- |
| `meal_type` | 早餐, 午餐, 晚餐, 下午茶 | 可以多个，如 ["午餐","晚餐"] |
| `target` | 大人, 小孩, 全家 | 可以在 JSON 里限制字段 |
| `taste` | 清淡, 微辣, 重辣, 酸甜, 香辣, 酱香, 奶香, 蒜香, 咖喱, 葱香, 椒盐, 甜, 酸辣 | 可以多个 |
| `cook_time` | 数字（分钟） | 实际烹饪时长 |
| `tags` | 快手菜, 下饭菜, 减脂, 硬菜, 家常, 烤箱菜, 快手早餐, 汤羹, 主食, 甜品, 素菜, 荤菜 | 可以多个 |

## 核验要点

- **餐次**：啤酒鸭通常晚餐吃，不标早餐；蛋炒饭可以标早餐+午餐
- **受众**：辣菜只标大人；清淡的菜标全家；小孩也能吃的标 小孩+全家
- **口味**：按最突出的口味标，不要太多（1-2 个足够）
- **时长**：与实际经验接近，不要太理论
- **标签**：3-5 个最合适的，不要堆砌
