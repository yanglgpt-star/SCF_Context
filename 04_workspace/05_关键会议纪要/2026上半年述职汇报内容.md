## 一、半年度工作概述

### 1.1 核心职责

- CAD图纸智能识别算法研发：实现墙体、门窗、管道、线缆等构件的自动识别与提取
- 光伏/电气领域AI算法开发：屋顶识别、组件排布、桥架布线等智能算法
- 定制化项目交付：负责先导、728、常州光微网等多个重点项目的算法研发与交付
- 技术攻坚与缺陷修复：处理识图准确率、排布效率、系统稳定性等核心技术问题
- 新技术探索：AI+CAD方向调研、GNN论文研究、OCR准确率优化

## 四、问题与改进反思

### 问题 1：项目中后期需求变更频繁

| 维度 | 内容 |
|------|------|
| **问题描述** | 先导项目在算法开发过程中多次方案调整，导致部分代码重构 |
| **原因分析** | 前期需求边界不清晰，客户在开发过程中提出新的需求 |
| **改进措施** | 加强与客户前期沟通，明确需求边界；采用配置化框架降低变更成本 |
| **落地计划** | 推广配置化算法框架至更多项目，提升应对需求变更的灵活性 |

### 问题 2：多项目并行时专注度分散

| 维度 | 内容 |
|------|------|
| **问题描述** | 高峰期同时推进4-5个项目，上下文切换成本高 |
| **原因分析** | 项目排期集中，缺乏有效的时间管理策略 |
| **改进措施** | 合理规划时间块分配，重要项目安排整块时间集中攻坚 |
| **落地计划** | 采用番茄工作法 + 时间块管理，提升单任务专注度 |

### 问题 3：技术文档沉淀不足

| 维度 | 内容 |
|------|------|
| **问题描述** | 项目交付后未形成系统的技术文档，不利于知识传承 |
| **原因分析** | 交付时间紧，优先保障代码产出，文档编写被延后 |
| **改进措施** | 输出翻模手册等文档，初步建立文档习惯 |
| **落地计划** | 每个项目完成后同步输出技术文档，建立个人知识库 |

### 问题 4：部分缺陷复现定位周期长

| 维度 | 内容 |
|------|------|
| **问题描述** | 客户环境与开发环境差异，部分bug难以快速复现 |
| **原因分析** | 缺乏标准化的复现流程和环境信息采集 |
| **改进措施** | 加强与测试/客户的沟通，获取更详细的复现步骤和环境信息 |
| **落地计划** | 推动建立标准化问题复现流程，引入更完善的日志系统 |
