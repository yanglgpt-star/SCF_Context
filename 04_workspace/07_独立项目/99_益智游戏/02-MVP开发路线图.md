# MVP 开发路线图

## 核心理念：最小可行性产品，分四期迭代

不要一上来就做复杂识别和 NFC。**第一期只做最核心的任务闭环**，确保孩子能玩起来，再逐步丰富。

---

## 阶段一：基石版（MVP）— 预计 2-3 周

### 目标
跑通完整任务闭环：**接收任务 → 线下执行 → 家长确认 → 获得星星**

### 需要开发的页面
| 页面 | 优先级 | 说明 |
|------|--------|------|
| 安全宣誓页 | P0 | 首次启动展示，每周确认一次 |
| 首页（冒险入口） | P0 | 角色形象 + 开始冒险按钮 |
| 任务卡片页 | P0 | 展示任务内容 + 语音播放 |
| 家长审核页 | P0 | 待审核列表 + 通过/驳回 |
| 完成反馈页 | P0 | 庆祝动画 + 星星增加 |

### 需要开发的云函数
- `login` — 用户登录
- `getDailyTask` — 获取今日任务
- `submitTask` — 提交完成
- `reviewTask` — 审核通过/驳回

### 预置任务（写死在云数据库）
| 类型 | 任务示例 | 验证方式 |
|------|---------|----------|
| 颜色形状 | "找3个红色的圆形物品" | 家长确认 |
| 颜色形状 | "找1个黄色的三角形" | 家长确认 |
| 小搬运工 | "把5本书从大到小排列" | 家长确认 |
| 小搬运工 | "把积木按颜色分类" | 家长确认 |
| 声音采集 | "敲一下不锈钢碗" | 家长确认 |
| 寻宝 | "去冰箱找到小贴纸" | 家长确认 |

### 第一阶段不做的
- ❌ 拍照/录音上传验证
- ❌ NFC / 二维码
- ❌ 勋章系统
- ❌ 数据分析
- ❌ 愿望清单
- ❌ 虚拟树动画
- ❌ 家长任务编辑器（直接去云开发控制台加）

---

## 阶段二：反馈增强版 — 预计 1-2 周

### 新增功能
| 功能 | 说明 |
|------|------|
| **拍照上传** | 孩子完成任务后拍照提交，替代纯文字确认 |
| **录音上传** | 声音采集类任务录下声音提交 |
| **审核详情页** | 家长可在审核时查看照片/听录音 |
| **完成统计** | 简单的今日/累计完成数字统计 |

### 改动范围
- 任务卡片页增加"拍照"、"录音"按钮
- 云函数 `submitTask` 增加文件上传逻辑
- 新增云存储读写权限配置
- 家长审核页增加媒体预览

---

## 阶段三：激励系统版 — 预计 1-2 周

### 新增功能
| 功能 | 说明 |
|------|------|
| **勋章墙** | 完成特定条件解锁勋章，有专门页面展示 |
| **虚拟树** | 每完成一个任务树长大一点，动画展示 |
| **愿望清单** | 家长设定愿望和价格，孩子积累星星兑换 |
| **每日打卡** | 连续完成展示 streak 天数 |

### 改动范围
- 新增"我的成就"页面
- 新增"愿望清单"页面
- 首页增加虚拟树组件
- 云函数 `getStats` 提供统计数据
- 新增 `wishes` 表和相关接口

---

## 阶段四：家长工具 + 进阶玩法版 — 预计 2-3 周

### 新增功能
| 功能 | 说明 |
|------|------|
| **家长任务编辑器** | 小程序内直接创建/编辑任务（不再去控制台） |
| **任务模板库** | 系统预置 20+ 按年龄推荐的任务模板 |
| **成长报告** | 按日/周/月维度的完成趋势图表 |
| **NFC 验证** | 贴 NFC 贴纸，碰触自动完成任务 |
| **扫码解密** | 打印二维码，扫出来是下一关线索 |
| **多孩子支持** | 一个家庭可以添加多个孩子，切换角色 |

### 改动范围
- 家长端增加完整的 CRUD 任务管理界面
- 集成 wx.getNFCAdapter()
- 集成小程序码生成
- 新增家庭组概念，支持家长关联多个孩子

## 开发工具准备

### 1. 环境搭建
1. 注册微信小程序账号（个人主体即可）
2. 下载安装微信开发者工具
3. 创建小程序项目，开通云开发
4. 创建云开发环境（建议名为 `prod`）

### 2. 需要准备的素材
| 素材 | 说明 | 获取方式 |
|------|------|---------|
| 角色形象 | 1 个卡通角色（引导员） | 自己画 / AI 生成 |
| 任务图标 | 每个任务类型的图标 | 图标库（Iconfont） |
| 语音录音 | 家长自己录的任务指令 | 小程序录音功能 / 手机录音 |
| 勋章图标 | 8 个勋章图标 | AI 生成 / 设计工具 |
| 安全宣誓图 | 安全规则儿童插画 | AI 生成 |

### 3. 云开发资源配置
```
环境：prod（正式）/ dev（开发）
数据库：6 个集合 + 索引
云存储：语音文件 + 图片 + 勋章图标
云函数：6-8 个 Node.js 函数
```

## 关键技术决策

| 决策点 | 选择 | 原因 |
|--------|------|------|
| 前端框架 | 小程序原生 | 个人项目，简单轻量，云开发原生集成 |
| 状态管理 | 全局 app.js 变量 + 云数据库 | 无需引入第三方库 |
| 语音方案 | 微信录音 API + 云存储 | 原生支持，省去 TTS 费用 |
| 家长验证 | 简单密码 / 手势密码 | 无需短信验证码 |
| 动画方案 | CSS 动画 + lottie-mini | 轻量高效 |
