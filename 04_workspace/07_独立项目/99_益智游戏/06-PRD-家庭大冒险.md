## 1. 产品概述

### 1.1 产品定位

「家庭大冒险」是一款面向 3-8 岁儿童的 O2O（Online to Offline）任务驱动型益智游戏微信小程序。它将线下亲子互动任务与线上激励系统结合，让孩子在完成现实世界中的挑战（如整理玩具、认识颜色）的过程中获得成就感，同时为家长提供便捷的任务管理和成长追踪工具。

### 1.2 产品愿景

让不认字的小朋友也能独立使用，让亲子互动变得有趣可量化。

### 1.3 核心价值

| 角色 | 价值主张 |
|------|----------|
| 孩子（3-8岁） | 像玩游戏一样完成任务，获得星星和勋章，不认字也能用 |
| 家长 | 轻松管理任务、追踪成长、培养孩子好习惯 |
| 家庭 | 创造高质量的亲子互动时光 |

### 1.4 技术栈

| 层 | 技术 |
|---|------|
| 前端框架 | 微信小程序原生（WXML + WXSS + JS） |
| 后端 | 微信云开发（Cloud Functions + Cloud Database + Cloud Storage） |
| 云环境 | `cloud1-4gk9uga539a7186b` |
| AppID | `wxb00ae4eee515a779` |
| 基础库 | 3.7.0+ |
| 语音合成 | RealtimeTTS 插件（`wxe1b17419621fcc3e`）客户端流式合成，组件化播放 |

## 3. 用户故事与核心流程

### 3.1 核心故事

#### 孩子视角

```
1. 打开小程序 → 看到角色引导和今日任务预览
2. 点击「出发」 → 进入任务页，自动听到任务语音播报
3. 完成任务内容 → 点击「做完啦」
4. 拍照/录音/找家长确认提交
5. 家长审核通过 → 🎉 庆祝动画 + 星星增加
```

#### 家长视角

```
1. 打开小程序 → 安全宣誓（7天有效期）→ 进入管理页
2. 查看/编辑任务列表 → 可为任务录制语音
3. 审核孩子提交的任务 → 通过或驳回
4. 查看成长报告 → 了解孩子完成趋势
5. 在多孩子之间切换 → 查看各孩子独立进度
```

### 3.2 核心用户流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐

│ (首次)    │    │ 今日任务  │    │ 语音播报  │    │ 拍照/录音 │    │ 🎉庆祝    │

                                               └──────────┘
```

### 4.3 页面详细说明

#### 安全宣誓页（safety）

- **触发条件**：首次启动 / 安全确认过期（7天）
- **内容**：5 条安全规则（不碰电源、不爬高、不吃陌生人物品等）
- **交互**：每条规则前有 checkbox，全部勾选后「我承诺」按钮点亮
- **存储**：`wx.setStorageSync('safety_confirmed', true)` + 有效期

#### 首页（index）

- **角色引导区**：`<character>` 组件，6 种 emoji 状态（🦸 😄 🤔 🎉 😴 🏃）
- **问候语**：显示孩子昵称（如"小宝！"）
- **任务预览卡片**：类别 emoji + 任务标题 + 难度星星
- **开始按钮**：「🚀 出发！」按钮
- **底部导航**：纯图标（🏅 成就 / 🏠 首页 / 👤 管理）

#### 任务页（task）

- **类别徽章**：🎨 颜色形状 / 📦 分类 / 🎵 声音 / 🗺️ 寻宝
- **语音按钮**：280rpx 超大圆形，点击播放/停止
  - 状态：🔈 点我听 → ⏳ 生成中 → 🔊 播放中 → ✅ 再听一遍 → ❌ 点我重试
- **任务详情**：标题 + 描述 + 难度⭐⭐⭐
- **提示横幅**：💡 任务小提示
- **操作按钮**：「✅ 做完啦」→ 跳转提交 / 「🔄 换一个」→ 回到首页

#### 提交页（submit）

- **验证方式**（根据任务 verifyType）：
  - `photo`：📷 拍照 / 从相册选
  - `audio`：🎙️ 录音按钮，显示录音时长
  - `parent_confirm`：👨‍👩‍👦 找爸爸妈妈确认
- **提交按钮**：绿色渐变「✅ 提交」
- 提交后在 task_logs 中标记为 pending（家长审核模式）或 completed（直接确认模式）

#### 审核页（review）

- 任务提交列表，带验证材料预览（照片/录音）
- 通过 → 加星星（调用 reviewTask），驳回 → 可重新提交

#### 成功页（success）

- 🎉 庆祝动画 + 星星粒子特效
- 显示获得星星数、总星星数
- 虚拟树成长状态

#### 成就页（achievement）

- **勋章墙**：8 个勋章，未解锁为灰色
- **虚拟树**：种子→发芽→开花→结果四季动画
- **统计数据**：总完成次数、连续打卡天数、本周完成数

#### 愿望页（wishes）

- 愿望列表（家长预设）
- 星星余额显示
- 兑换按钮（消耗星星）

#### 管理页（admin）

- 密码验证（预设密码 `888888`）
- 孩子列表 + 切换选中孩子
- 添加孩子（设置昵称）
- 进入任务编辑 / 成长报告

#### 任务编辑页（admin-task）

- 任务列表（显示类别 emoji + 标题 + 语音状态）
- 录制语音按钮（🔇 语音 / 🔊 重录 / ⏺ 录音中...）
- 新增/编辑/停用任务

#### 成长报告页（report）

- 完成趋势图
- 分类统计
- 各孩子对比（多孩子模式下）

## 5. 功能详述

### 5.1 基石功能（MVP）

#### 5.1.1 安全宣誓

- 展示 5 条安全规则，使用儿童友好语言
- 全部勾选后方可进入
- 有效期 7 天，过期重新确认
- 本地存储校验，不依赖网络

#### 5.1.2 任务系统

- **任务池**：38 条预置任务，覆盖 4 个类别
- **每日任务**：每日随机分配，避免当日重复
- **难度分级**：1-5 星（⭐），匹配不同年龄段
- **任务状态**：待分配 → 已分配(pending) → 已完成(completed) → 已审核(reviewed)

#### 5.1.3 审核系统

- 家长审核任务完成情况
- 通过：增加星星，更新连续打卡
- 驳回：任务重置，可重新提交
- 审核材料预览（照片/录音）

#### 5.1.4 星星系统

- 完成任务获得星星（根据难度）
- 星星用于兑换愿望
- 连续打卡额外奖励

### 5.2 反馈增强功能

#### 5.2.1 拍照验证

- 使用微信相机 API 拍照
- 支持从相册选择
- 图片上传到云存储

#### 5.2.2 录音验证

- 使用微信录音 API
- 录音时长显示
- 音频上传到云存储

#### 5.2.3 语音系统（核心）

| 组件 | 说明 |
|------|------|
| 家长录制 | 在 admin-task 页录制，上传云存储，绑定任务 |
| TTS 自动合成 | RealtimeTTS 插件（`wxe1b17419621fcc3e`），客户端流式合成，组件化播放 |
| 自动播放 | 家长录制：页面加载后自动播放；TTS 插件：组件内嵌，点按即播 |
| 状态反馈 | 家长录制：自定义 loading/playing/done/error；TTS 插件：内置 default/playing 状态 |

**TTS 技术方案**：
- **主方案**：`text2audio` 插件，WXML 组件 `<text2audio>`，流式实时播放
- **插件配置**：需在 `app.json` 注册 + 创建导出文件 `index.js` + 页面 JSON 注册组件
- **免费额度**：未配置腾讯云账号时每天 5 次调用（开发测试足够）
- **生产环境**：需配置腾讯云语音合成 AppId/SecretId/SecretKey

### 5.3 儿童友好 UI

#### 5.3.1 全页面 Emoji 化

| 页面 | 关键设计 |
|------|----------|
| 首页 | 大角色引导 + emoji 类别预览 + 纯图标底部导航（🏅 🏠 👤） |
| 任务页 | 类别 emoji 徽章 + 超大语音按钮（280rpx）+ 纯图标操作按钮（✅ 🔄） |
| 提交页 | 大 icon 引导（📷 🎙️ 👨‍👩‍👦）+ 简化文字 |
| 角色组件 | 纯 emoji 实现（🦸 😄 🤔 🎉 😴 🏃），6 种 CSS 动画 |

#### 5.3.2 交互设计要点

- **大点击区域**：所有按钮 >= 100rpx
- **视觉反馈**：`:active` 缩放效果，渐变背景
- **无文字依赖**：核心操作通过 emoji + 图标完成
- **声音引导**：语音播报替代文字阅读
- **柔和色彩**：暖色调（橙色/红色渐变），不刺眼

### 5.4 激励系统

#### 5.4.1 勋章系统（8 枚）

| 勋章 | 解锁条件 |
|------|----------|
| 🌟 初次冒险 | 完成第 1 个任务 |
| 🔥 小火焰 | 连续完成 3 天 |
| 💪 小勇士 | 累计完成 10 个任务 |
| 🏆 常胜将军 | 累计完成 30 个任务 |
| 🎯 全能王 | 完成所有 4 个类别的任务 |
| 🌈 彩虹收集者 | 获得 50 颗星星 |
| ⚡ 闪电侠 | 连续完成 7 天 |
| 👑 大英雄 | 累计完成 50 个任务 + 获得全部勋章 |

#### 5.4.2 虚拟树

- 种子 → 发芽 → 小苗 → 开花 → 结果（5 阶段）
- 完成任务累积成长值
- 每个阶段切换动画

#### 5.4.3 愿望兑换

- 家长预设愿望（如"去游乐园"、"吃冰淇淋"）
- 每个愿望消耗一定星星数
- 兑换后状态变为 redeemed

### 5.5 家长工具

#### 5.5.1 多孩子支持

- 家长账号关联多个孩子
- 每个孩子独立进度、星星、勋章
- 管理页切换当前操作的孩子
- 云函数通过 `asUser` 参数指定操作目标

#### 5.5.2 任务管理

- 查看所有任务列表
- 新增/编辑/停用任务
- 为任务录制语音（覆盖 TTS 合成）
- 任务参数：标题、类别、难度、描述、提示、验证方式

#### 5.5.3 成长报告

- 任务完成趋势（按天/周/月）
- 类别分布统计
- 各孩子数据对比
- 连续打卡记录

### 6.2 关键设计决策

| 决策 | 方案 | 理由 |
|------|------|------|
| 语音方案 | RealtimeTTS 插件 `<text2audio>` 组件（流式合成） | WXML 组件化集成，客户端合成，流式实时播放，无需云函数 |
| 语音触发 | 页面加载自动触发 | 不认字儿童需要语音引导，无需手动操作 |
| 多孩子 | `asUser` 参数模式 | 所有云函数通过参数指定操作目标，后端统一处理 |
| 任务数据导入 | `seedData` 云函数 | JSON Lines 导入格式兼容性问题，改用程序化插入 |
| UI 方案 | Emoji + CSS | 无需图片资源，零加载延迟，适配所有设备 |
| 认证 | 微信 OPENID | 无需额外登录，云开发天然支持 |
| 家长密码 | 本地校验（`888888`）| MVP 简化方案，后续可改为云函数验证 |

### 6.3 数据流

#### 语音生成流程

```
任务页加载
    │
    ├── 有 voiceUrl（家长已录制）
    │     ├── 创建 InnerAudioContext
    │     ├── 自动播放
    │     └── 状态反馈: loading→playing→done→error
    │
    └── 无 voiceUrl
          ├── WXML 渲染 <text2audio> 组件
          ├── 组件内置默认 slot（🔈 听任务）
          ├── 用户点击 → 组件自动调用 TTS
          ├── 流式合成 + 实时播放
          └── 播放中切换至 playing slot（🔊 播放中...）
```

#### 多孩子操作流程

```
家长选择孩子
    │
    └── app.globalData.activeChild = child.openId
          │
          └── 所有云函数调用携带 asUser = activeChild
                │
                └── 云函数内部：userId = event.asUser || OPENID
```

## 7. UI/UX 设计原则

### 7.1 儿童友好设计准则

## 9. 云函数 API

### 9.1 login

```
输入: 无（自动获取 OPENID）
输出: { userInfo, role, children[], isNew }
逻辑: 自动注册/登录，家长账号返回孩子列表
```

### 9.2 getDailyTask

```
输入: { asUser?: string }
输出: { task, isRepeat }
逻辑: 随机抽取当日未完成任务，支持 asUser 多孩子
```

### 9.3 submitTask

```
输入: { taskId, status, photoUrl?, audioUrl?, asUser? }
输出: { success }
逻辑: 提交任务完成记录，更新 task_logs
```

### 9.4 reviewTask

```
输入: { logId, action: 'approve'|'reject', stars?, note?, asUser? }
输出: { success }
逻辑: 审核通过/驳回，通过时加星星并检测勋章解锁
```

### 9.5 addTask

```
输入: { action: 'add'|'update'|'delete'|'setVoice', taskData, taskId?, voiceUrl? }
输出: { success }
逻辑: CRUD 任务 + 设置语音
```

### 9.6 getStats

```
输入: { type: 'pending'|'achievement'|'wishes'|... , asUser? }
输出: 根据 type 返回统计数据
逻辑: 支持 asUser 多孩子，6 种统计模式
```

### 9.7 generateVoice

```
输入: { taskId, text } 或 { batch: true }
输出: { success, voiceUrl }
逻辑: Edge TTS 合成 → 云存储上传 → 更新任务 voiceUrl
注意: 云函数超时需设置为 30 秒
```

### 9.8 seedData

```
输入: { type: 'tasks' | 'wishes' }
输出: { success, total, created }
逻辑: 程序化导入 38 条任务 / 6 个愿望
```
