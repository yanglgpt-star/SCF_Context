# 开发前准备清单

> 以下清单建议按序号顺序逐项完成，打 ✓ 表示已完成，☐ 表示待办。

---

## 一、账号与环境准备

### 1.1 微信小程序账号
- [ ] 注册微信小程序账号（[mp.weixin.qq.com](https://mp.weixin.qq.com)）— 个人主体即可，无需营业执照
- [ ] 完成小程序基本信息填写（名称、头像、简介）
  - 建议名称示例：家庭大冒险 / 宝贝任务岛
  - 头像可先用 AI 生成占位
- [ ] 获取 AppID（小程序管理后台 → 开发 → 开发设置）
- [ ] 开通微信云开发（小程序管理后台 → 云开发 → 开通）
- [ ] 申请获取「开发版」和「体验版」二维码

### 1.2 开发工具
- [ ] 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（最新稳定版）
- [ ] 安装 Node.js（推荐 v18+，云函数 Node.js 环境）
- [ ] 安装 Git（版本管理）
- [ ] 建议创建 GitHub 私有仓库用于代码管理

### 1.3 云开发初始化
- [ ] 创建云开发环境（建议命名 `prod`，后续只在正式环境开发）
- [ ] 开通云数据库（6 个集合 + 索引）
- [ ] 开通云存储（用于存放语音、图片、图标）
- [ ] 开通云函数（Node.js 运行环境）
- [ ] 记录云开发环境 ID（后续在 `app.js` 中配置）

## 二、设计素材准备

### 2.1 角色与视觉
| 素材 | 数量 | 用途 | 来源建议 |
|------|------|------|---------|
| IP 角色形象 | 1 个 | 引导员（全程陪伴） | AI 生成（Midjourney / DALL·E） |
| 角色表情包 | 3-4 个 | 高兴、加油、思考、庆祝 | 基于主形象延展 |
| 任务卡片背景 | 4 张 | 4 类任务各自风格背景 | AI 生成 |
| 庆祝动画 | 1 个 | 任务完成弹窗 | Lottie 动画 / CSS 动画 |
| 虚拟树素材 | 5-6 张 | 种子→发芽→小苗→小树→开花→结果 | AI 生成 |
| 空白背景图 | 1 张 | 首页、成就页通用背景 | AI 生成 |

### 2.2 图标素材
| 素材 | 数量 | 用途 |
|------|------|------|
| 勋章图标 | 8 个 | 成就勋章墙 |
| 任务类型图标 | 4 个 | 颜色/整理/声音/寻宝 |
| 功能图标 | 10 个 | 导航、按钮、状态指示 |
| 星星图标 | 1 个 | 奖励通用图标 |

> 图标来源推荐：Iconfont 阿里巴巴矢量图标库（免费商用）、Flaticon、或 AI 生成后转 SVG。

### 2.3 音频素材
| 素材 | 数量 | 来源 |
|------|------|------|
| 背景音乐 | 1-2 首 | 免版权音乐库（建议轻快风格） |
| 按钮音效 | 3-5 个 | 点击、成功、失败、翻页 |
| 家长语音任务 | 待录 | MVP 阶段 6 条，后续逐步录制 |

> **关键提醒**：语音是灵魂！建议 MVP 阶段直接由家长用小程序内录音功能录制，后期再优化音质。孩子更喜欢家长真实的声音，比专业配音更有亲切感。

## 三、数据与内容准备

### 3.1 初始数据库数据

需要提前准备 JSON 文件/Markdown 表格，开发时导入云数据库。

#### 任务数据（tasks）
- [ ] 预先写好 MVP 阶段至少 **6 条** 任务数据（见 [03-任务类型与内容库.md](03-任务类型与内容库.md)）
- [ ] 每条任务准备好：标题、描述、提示语、难度、类别、验证方式
- [ ] 任务封面图标（可先用 emoji 占位）

#### 勋章定义（badges）
- [ ] 第一批 3-5 个勋章定义（初次冒险、小侦探、颜色大师等）

#### 安全宣誓内容（可写在代码中或数据库中）
- [ ] 准备好安全规则文本，适合儿童阅读

#### 初始愿望模板（可选阶段三再准备）
- [ ] 1-2 个愿望模板（去游乐场、吃冰淇淋）

### 3.2 语音录制脚本

| 场景 | 文案示例 | 状态 |
|------|---------|------|
| 欢迎语 | "小宝，准备好了吗？让我们一起开始今天的冒险吧！" | ☐ |
| 任务播报 | "你的任务是——在家里找到 3 个红色的圆形物品！" | ☐ |
| 完成鼓励 | "太棒了！你完成了今天的任务！奖励你一颗小星星！" | ☐ |
| 连续打卡 | "你已经连续完成 3 天了，真了不起！" | ☐ |
| 安全提醒 | "记住哦，不可以碰热水壶、插座和厨房的刀！" | ☐ |

## 四、代码架构准备

### 4.1 项目目录结构（建议）

```
family-adventure/
├── miniprogram/                # 小程序代码
│   ├── app.js                  # 全局入口，云开发初始化
│   ├── app.json                # 全局配置
│   ├── app.wxss                # 全局样式
│   ├── pages/
│   │   ├── index/              # 首页（冒险入口）
│   │   ├── task/               # 任务卡片页
│   │   ├── submit/             # 任务提交页
│   │   ├── review/             # 家长审核页
│   │   ├── success/            # 完成反馈页
│   │   ├── achievement/        # 成就勋章页
│   │   ├── wishes/             # 愿望清单页
│   │   ├── safety/             # 安全宣誓页
│   │   ├── admin/              # 家长管理首页
│   │   └── admin-task/         # 家长任务管理
│   ├── components/             # 复用组件
│   │   ├── star-effect/        # 星星动画
│   │   ├── character/          # 角色形象
│   │   └── progress-bar/       # 进度条
│   ├── utils/                  # 工具函数
│   │   ├── util.js             # 通用函数
│   │   ├── format.js           # 时间/数字格式化
│   │   └── constants.js        # 常量定义
│   └── images/                 # 图片资源
│       ├── character/          # 角色图片
│       ├── badges/             # 勋章图标
│       ├── icons/              # 功能图标
│       └── bg/                 # 背景图
├── cloudfunctions/             # 云函数
│   ├── login/
│   ├── getDailyTask/
│   ├── submitTask/
│   ├── reviewTask/
│   ├── getStats/
│   └── addTask/
├── project.config.json         # 项目配置
└── README.md                   # 项目说明
```

### 4.2 全局配置要点
- [ ] project.config.json 中配置 AppID、云函数根目录
- [ ] app.json 中配置页面路径、TabBar（如有）、窗口样式
- [ ] app.js 中初始化云开发环境：
  ```js
  wx.cloud.init({
    env: '你的云环境ID',
    traceUser: true
  })
  ```

## 五、技术预研清单

> 部分能力需要在开发前确认可用性，避免开发到一半发现不支持。

- [ ] 确认 `wx.createInnerAudioContext()` 可用（语音播放）
- [ ] 确认 `wx.getRecorderManager()` 可用（录音提交）
- [ ] 确认 `wx.chooseMedia()` 可用（拍照上传）
- [ ] 了解云函数定时触发器配置（未来每日任务刷新用）
- [ ] 了解微信服务号消息模板能力（可选，推送任务提醒）
- [ ] 了解 `wx.getNFCAdapter()` 兼容性（阶段四，部分机型不支持）

## 六、安全与合规自查

- [ ] 小程序服务类目选择：**教育 > 亲子互动** 或 **工具 > 家庭辅助**
- [ ] 用户隐私协议说明（注册时展示，说明收集 openId 用途）
- [ ] 儿童个人信息保护合规（参照《儿童个人信息网络保护规定》）
- [ ] 不涉及诱导分享、虚拟支付（个人小程序不能开通微信支付）
- [ ] 安全宣誓中明确告知孩子：不可以碰插座、热水、刀具、药物

---

## 七、汇总：需要整理的文件清单

> 以下是在开发前你应该逐一手头准备好的文件，一并整理到这个文件夹下。

| # | 文件名 | 用途 | 准备方式 | 优先级 |
|---|--------|------|---------|--------|
| 1 | `主题色与UI规范.xxx` | 定义主色、字体、圆角规范 | 自己定或参考设计系统 | P0 |
| 2 | `角色形象.png` | 引导员角色（全套表情） | AI 生成/设计 | P0 |
| 3 | `任务数据.json` | 预置任务，导入云数据库 | 手动编写 | P0 |
| 4 | `勋章数据.json` | 勋章定义，导入云数据库 | 手动编写 | P1 |
| 5 | `语音录制脚本.txt` | 各场景录音文案 | 手动编写 | P1 |
| 6 | `sql初始化.txt` | 云数据库集合索引配置 | 手动编写 | P1 |
| 7 | `隐私协议.txt` | 用户协议文本 | 参考模板修改 | P1 |
| 8 | `安全宣誓文案.txt` | 儿童版安全规则 | 手动编写 | P0 |
| 9 | `图标素材.zip` | 功能图标、勋章图标 | 图标库下载 | P2 |
| 10 | `测试用例.md` | 功能测试case列表 | 开发后补充 | P3 |

> **建议**：按照 P0 → P1 → P2 的顺序准备，P0 是开发前必备，P1 是 MVP 阶段需要，P2/P3 可以边开发边补。
