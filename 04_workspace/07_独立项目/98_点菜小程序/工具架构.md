# 🏠 家庭点菜小程序：项目设计文档

## 1. 项目定位
一个旨在解决“今天吃什么”家庭难题的小工具，兼顾大人与孩子的口味，记录家庭饮食历史。

---

## 2. 核心功能模块

### 2.1 菜谱管理（库）
*   **多维分类**：
    *   **餐次分类**：早餐、中餐、晚餐、下午茶/零食。
    *   **受众分类**：宝宝餐（低油盐/软烂）、大人餐（香辣/下饭）、全家共有。
*   **做法详情**：
    *   食材清单（主料、辅料）。
    *   步骤说明（文字 + 图片/视频）。
    *   烹饪贴士（例如：“小孩吃不加辣”、“排骨需多炖20分钟”）。

### 2.2 智能点菜（首页）
*   **手动点菜**：从菜谱库中勾选。
*   **随机点菜**：点击“随机一下”，系统根据餐次自动推荐一荤一素一汤。
*   **快捷组合**：支持保存“常用套餐”（如：周一常规早餐）。

### 2.3 饮食记录（历史）
*   **每周看板**：以日历或列表形式展示过去7天的食谱。
*   **频率提醒**：如果本周已经吃过3次土豆，系统在点菜时提示“本周土豆摄入较多”。
*   **最爱排行榜**：根据历史记录统计出全家人点票最高的菜品。

---

## 3. 数据库结构设计 (Cloud DB)

建议使用微信小程序云开发数据库，主要设计以下集合（表）：

### `foods` (菜品表)
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `_id` | String | 唯一标识 |
| `name` | String | 菜名 (如: 西红柿炒鸡蛋) |
| `meal_type` | Array | [早餐, 中餐, 晚餐] |
| `target` | Array | [小孩, 大人] |
| `ingredients` | Array | [西红柿, 鸡蛋, 葱花] |
| `steps` | String | 详细烹饪步骤 |
| `image` | String | 菜品图片路径 |

### `meal_logs` (记录表)
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `date` | Date | 日期 (YYYY-MM-DD) |
| `type` | String | 早餐/中餐/晚餐 |
| `food_ids` | Array | 关联的菜品 ID 列表 |

## 4. 适合家庭的分类示例

| 分类 | 适合小孩 (示例) | 适合大人 (示例) | 共同做法建议 |
| :--- | :--- | :--- | :--- |
| **早餐** | 虾仁蒸蛋、燕麦粥 | 葱油拌面、酸辣粉 | 蒸蛋大人版加辣油/生抽 |
| **中餐** | 番茄炖牛腩 (不辣) | 水煮肉片 (重辣) | 一锅两出：牛腩先炖好，分出一小锅加辣 |
| **晚餐** | 清蒸鲈鱼、时蔬泥 | 小炒肉、麻婆豆腐 | 鱼肉全家共享，蔬菜大人加蘸水 |

## 5. 技术实现建议

### 方案 A：微信小程序（推荐）
*   **优点**：无需下载，家人通过微信即可访问；云开发（WeChat Cloud）提供免费存储和数据库。
*   **核心组件**：
    *   `vant-weapp` (UI组件库)：快速搭建美观的表单和列表。
    *   `calendar` (日历组件)：用于展示每周记录。

### 方案 B：Notion / 飞书文档 (低代码方案)
*   **优点**：完全不需要写代码。
*   **实现**：
    1.  建立一个 **多维表格**。
    2.  设置分类标签（早/中/晚、大人/小孩）。
    3.  利用“看板视图”管理每周食谱。

## 6. 特色功能亮点 (Bonus)

1.  **食材清单导出**：选好下周菜后，一键生成“超市购物清单”。
2.  **口味投票**：家人可以在记录中点赞或踩，作为下次是否再做的参考。
3.  **换一换**：如果随机出的菜不想吃，支持单道菜“原地换一颗”。
