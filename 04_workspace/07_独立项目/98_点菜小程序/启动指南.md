# 点菜小程序 — 启动指南

按以下步骤操作，即可将项目跑起来。

---

## Step 1：注册小程序账号

1. 打开 https://mp.weixin.qq.com/ → 注册小程序账号（个人主体即可）
2. 登录后 → **开发管理** → **开发设置** → 复制 **AppID**

## Step 2：打开项目

1. 打开 **微信开发者工具**
2. 点击 **新建项目**
3. 项目目录选择：本文件夹下的 `miniapp/`
4. 填入 **AppID**（注册后获得）
5. 点击确定打开项目

## Step 3：开通云开发

1. 在开发者工具中，点击顶部工具栏的 **云开发** 图标
2. 开通云开发（首次免费）
3. 记录 **云环境 ID**（如 `order-dev-123abc`）
4. 创建以下数据库集合：

| 集合名 | 权限 |
| :--- | :--- |
| `foods` | 所有用户可读，仅创建者可写 |
| `meal_logs` | 仅创建者可读写 |
| `favorites` | 仅创建者可读写 |

## Step 4：导入菜品数据

### 方式 A：手动导入（推荐）

1. 在开发者工具中 → **云开发** → **数据库** → 选择 `foods` 集合
2. 点击 **导入** → 选择 `data/dishes_tagged.json`
3. 确认导入成功（应有 363 条记录）

### 方式 B：脚本导入（批量）

1. 右键 `cloudfunctions/` → 新建云函数 `batchImport`
2. 用以下代码：

```javascript
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database();

exports.main = async (event, context) => {
  const { data } = event;
  const batch = data.map(item => db.collection('foods').add({ data: item }));
  return Promise.all(batch);
};
```

## Step 5：配置项目

1. 打开 `miniprogram/app.js`
2. 将 `YOUR_CLOUD_ENV_ID` 替换为你的云环境 ID
3. 打开 `project.config.json`
4. 将 `YOUR_APPID_HERE` 替换为你的 AppID

## Step 6：安装依赖

在开发者工具中：
1. 菜单栏 → **工具** → **构建 npm**
2. 或者：在 `miniprogram/` 目录下右键 → **在内建终端中打开**
3. 执行 `npm install`

## Step 7：编译运行

1. 点击工具栏 **编译** 按钮
2. 模拟器中应出现小程序界面
3. Tab 栏：点菜 / 菜谱 / 记录 可切换

## 目录结构说明

```

├── project.config.json      ← 项目配置（需填 AppID）
├── miniprogram/
│   ├── app.json             ← 全局配置

│   ├── app.wxss             ← 全局样式

│   ├── utils/util.js        ← 工具函数

│   │   ├── recipes/         ← 菜谱库
│   │   ├── recipe-detail/   ← 菜谱详情
│   │   └── history/         ← 饮食记录
│   └── images/              ← Tab 图标
├── cloudfunctions/          ← 云函数
└── scripts/                 ← 工具脚本
```

## 常见问题

**Q：导入 JSON 时报错格式不对？**
A：确保 JSON 是数组格式，每个元素是一个菜品对象。`_id` 字段会自动生成，记得删除 JSON 中的 `_id` 字段。

**Q：Tab 图标显示空白？**
A：占位图标是简单圆点，不影响功能。可以替换为设计好的图标文件。

**Q：云函数部署失败？**
A：右键 cloudfunctions/ 下的函数目录 → 上传并部署。
