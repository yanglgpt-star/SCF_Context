## 一、作用粒度：核算单元，不是批次

| 概念 | 键 | 谁是所有者 |
|---|---|---|
| 库存维度（四轴） | `(商品, 仓库, 批次, 一级货主)` | 余额表主键 |
| **存货核算单元** | **`(商品, 仓库, 一级货主)`** | **均价池 / 成本层 / 凭证 / 跌价基数的所有者** |

**批次不进核算单元键**。加锁也按核算单元加——**批次不进锁 key**（原文 `:523`）。

> 指针：原文 `§一.5.2`（`:138`，核算单元表 `:143`，批次与均价池 `:145`）；`§一.4` 术语表（`:98`）；`§四.2`（`:2014`）。

## 二、三法速览

| 中文全称 | 一期状态 | 成本单元是什么 | 谁能改写均价 |
|---|---|---|---|
| 移动加权平均 | **全局默认** | 核算单元（一个均价池） | 只有**入库**能改；出库不动 |
| 个别计价 | 并发启用 | 批次 / 序列号（逐件） | 不建均价池，件与件互不拉平 |
| 先入先出法 | 并发启用 | **成本层**（每次入库成一层） | 逐层消耗，不重算 |

**配置粒度**：按核算单元在 `t_price_method_config`（计价方法配置表）配置；**缺失回落全局默认（移动加权平均）并告警**。

**两条腿可配不同方法**：调拨、一级货权转移同时动两个核算单元，**按腿解析**，不接受单一全局策略（原文 `§一.5.9` `:335`）。

> 指针：原文 `§一.3` 一期范围（`:64`、`:67`）；`§四.3 计价方式具体逻辑`（`:2042`）；详细设计 `4.1.6`（`:1156`）、`5.1`（`:1867`）、`§5.7 计算引擎伪代码`（`:2040`）。

## 三、规则摘要

### 3.1 移动加权平均（原文 `:2044`）

```
F1  入库：new_price = round((old_amount + 不含税金额 + 本行分摊费用) / (old_qty + base_qty), 6)
F2  出库：out_amount = round(out_qty × current_price, 2)；new_price = current_price   ← 出库不重算
F3  舍入差异 = out_amount − out_qty × current_price
F4  出清：出库后 qty = 0 且 amount ≠ 0 → 剩余金额全额结转、余额清零
```

- **入库只舍入单价、不回改金额**——入库金额是确定的入账数；回改它会破坏金额守恒（期初 + 入 − 出 = 期末）。
- **舍入差异只在出库产生**（入库金额确定、出库金额是算出来的）；累进 `rounding_diff_acc`，**月末一张独立凭证结转**（模板 `8.1.7`）。
- 边界：`old_qty = 0` → 单价 = 入库金额 ÷ 入库数量；**`new_qty = 0` 时禁止入库**。
- **税额绝不进成本**——入库金额是**不含税**口径，税额只进「应交税费 - 应交增值税（进项税额）」。

### 3.2 个别计价（原文 `:2090`）

- 按业务指定的**批次 / 序列号**逐件结转，成本跟着被指定的那一件走。
- 入库：**不并池**，按该件实际成本单独建成本层 / 资产档案（入库金额口径同 `F5a`）。
- 出库：**不取核算单元均价**，取拣货回传（或业务指定）的 SN / 批次对应成本求和。
- ⚠️ **一期硬要求：序列号必须出现在出库单据行上**——SN 管理品类缺 SN 即校验不通过。

### 3.3 先入先出法（原文 `:2106`）

- 每笔入库形成一个**新成本层**（层内数量 + 层单价）；出库从**最早**的层起逐层消耗。
- `出库成本 = Σ 各层被消耗数量 × 各层单价`；**核算单元均价不参与结转**。
- ⚠️ 该单元的商品一律按**批次 / 入库层**管理，否则成本层与批次余额表对不上。

### 3.4 三法对照（原文 `:2120`）

同一批单据、同样出 150 台：移动加权平均 → 出库成本 1,650.00 / 结存 11.000000；先入先出法 → 1,600.00 / 12.000000；个别计价 → 1,640.00 / 11.200000。

**结存单位成本是派生值**（结存金额 ÷ 结存数量）：移动加权平均下它就是计价输入；个别计价 / 先入先出法下**仅用于对账展示，不参与计价**——权威成本在成本层 `t_inventory_layer.layer_unit_cost`。

## 四、判据树：批次进不进均价池？

```
当前核算单元的计价方法是什么？
├─ 移动加权平均 → 批次【不进】均价池，只影响【库龄与跌价】
├─ 个别计价     → 批次 / SN 【就是】成本单元
└─ 先入先出法   → 批次【就是】成本层
```

**但无论哪种方法，核算单元仍是外层分组**（原文 `:2014`）——批次是核算单元**内部的成本明细**。

## 五、方法变更（反直觉，最常被漏）

**方法一经选定即锁定**：
- 同类存货方法须**一致**，变更须**披露**；
- 切换**只对新商品类别自开账日启用**；
- **不对存量品类中途切换**——换一次方法，历史**每一期**的成本、毛利、存货余额都会变。

> 指针：原文 `:2130`；选型依据见详细设计 `13.4`（`:3002`）。

## 六、两条全局铁律（跨方法生效）

1. **取价三条铁律**：按**业务日期**取价 → **取到即快照**（写进单据行与 `t_calc_log` 计算过程留痕表）→ **调价不追溯**。
2. **过账顺序**：排序键 = `(biz_date, seq_in_day)`，**全流程唯一决定"谁先谁后"的地方**，同日**入库优先**；**业务单号不可作排序键**。

> 指针：原文 `§一.5.4`（`:297`）、`§一.5.5`（`:301`）。

## 七、易错点

| 易错 | 正确 |
|---|---|
| 用「数量 × 派生均价」算**发生额** | 那个写法**只对结存一侧成立**；发生额必须取实际结转成本——个别计价 / 先入先出法下会算错、出口硬校验当场不平、**整单回滚**（原文 `:238`–`:241`） |
| 出库后重算均价 | **出库不重算单价**——这是移动加权平均与另两法在"谁能改均价"上的根本分界 |
| 把税额算进入库成本 | 入库金额是**不含税**口径 |
| 说「批次是核算轴」 | 批次**不是**核算轴、**不进**核算单元、**不进**会计均价池 |
| 中途给存量品类换方法 | **不行**——只对新商品类别自开账日启用 |
