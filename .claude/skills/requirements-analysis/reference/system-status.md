# 系统现状模板

## 概述

描述当前系统的整体情况，包括所有终端/后端服务、模块划分、功能页面以及现状。

---

## 一、终端/后端服务清单

| 序号 | 终端/服务 | 说明 | 所属域 |
|------|-----------|------|--------|
| 1 | 金融助手 | 供应链金融业务后台 | - |
| 2 | 运营助手 | 业务操作后台 | - |

---

## 二、系统现状详述

### 2.1 金融助手

**模块列表**：

| 模块名称 | 功能/页面 | 现状描述 |
|----------|-----------|----------|
| 融资需求收集 | 采购端融资需求收集 | 收集采购端的融资需求，为信贷业务提供数据基础（第一期不做，后期迁移） |
| 客户管理 | 企业客户全生命周期管理 | 维护企业客户信息，支持新增、编辑、详情、启用/禁用、删除，管理客户基础信息、法人信息、联系人信息、财务信息、开票信息 |
| 准入管理 | 客户准入申请与审核 | 客户进件准入申请（企业信息、主营业务、附件），平台审核（通过/拒绝/退回），准入通过后自动同步至客户管理 |
| 资产管理 | 代采业务资产管理 | 代采协议创建、保存/提交、合同上传、保证金缴纳、采购执行、创建分销、资产监控、协议全生命周期管理 |
| 代采中心 | 代采协议全生命周期管理 | 代采销售协议的创建、编辑、提交、撤销、删除，协议列表多维度搜索筛选，支持详情查看、合同上传、创建采购、创建分销等操作 |
| 保证金管理 | 保证金资金操作管理 | 保证金收取确认、原路退回、转货款抵扣，记录应收/实收金额、账单日期、处理日期、支付流水号、凭证附件 |
| 采购管理 | 采购订单管理与退款 | 采购订单列表展示、数据同步（自动+手动）、导出、单条/批量退款申请、串码信息查看 |
| 退款管理 | 退款申请处理与确认 | 退款申请记录管理、单条/批量确认收款、实收金额确认、附件上传、状态跟踪 |
| 销售管理 | 分销活动与销售订单 | 分销活动管理（发布/下架状态）、销售订单查看、数据同步（自动+手动）、导出 |
| 监管管理 | 出入库及库存数据监管 | 入库数据、出库数据、库存数据实时追踪，支持聚水潭数据同步（自动+手动）和导出，库存计算（累计入库-累计出库） |
| 先货后款 | 先货后款业务模式管理 | 采购订单确认（设置服务费率、账期）、确认列表管理（销售/冻结/剩余数量实时查询）、批量创建分销活动 |
| 额度管理 | 授信额度申请与管理 | 额度申请（客户信息、基础信息、额度信息、附件）、多级审核（初审/复审/终审/资方审核）、循环/非循环额度管理 |
| 融资管理 | 融资申请与审核放款 | 融资申请（基础信息、融资信息、货物信息、附件）、平台审核与资方审核、放款确认，支持赊销/预付款/货押三种融资模式 |
| 还款管理 | 还款申请与额度恢复 | 还款申请提交（还款金额、方式、凭证）、平台审核，审核通过后恢复循环额度，更新融资状态为已结清 |
| 仓储管理 | 质押物出入库与库存监管 | 入库管理（新增/编辑/入库操作）、出库管理（新增/编辑/出库操作）、库存监管（锁定/已解锁状态），监管方控制审核状态 |
| 解质押管理 | 解押申请与审核 | 解押申请新增（关联融资申请、质押货物信息、解押汇总）、平台审核，解押通过后库存监管状态更新为已解锁 |
